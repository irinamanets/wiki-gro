# Wiki Knowledge Base

Это read-only снапшот базы знаний `marketing-memory` — маркетинговая KB продукта ГРО: концепции, конкуренты, тренды, метрики, материалы, гайдлайны.

Репо обновляется автоматически после каждого ingest-батча в upstream. Чтобы получить свежие данные — `git pull`.

---

## Как работать с базой

### 1. Установи Claude Code

Следуй инструкции: https://docs.claude.com/en/docs/claude-code/overview

Коротко:
```bash
npm install -g @anthropic-ai/claude-code
```

### 2. Клонируй репозиторий

```bash
git clone git@gitlab.com:ilia34-group/<repo-name>.git wiki-kb
cd wiki-kb
```

### 3. Запусти Claude Code

```bash
claude
```

`CLAUDE.md` в корне активируется автоматически — Claude превратится в query-ассистента, который умеет искать и синтезировать ответы из `wiki/`.

### 4. Задавай вопросы

Примеры:
- «Какие конкуренты перечислены в базе?»
- «Что у нас есть про позиционирование?»
- «Покажи последние тренды по контент-форматам»
- «Какие отзывы пользователей про нашу ценовую модель?»
- «Что в базе написано про ICP (идеального клиента)?»

## Обновление

```bash
git pull
```

Upstream обновляется автоматически после каждого ingest-батча на сервере. Если ответ кажется устаревшим — сделай `git pull` и переспроси.

Твои собственные файлы в этой папке (заметки, локальные агенты, любые `.md` которых нет в апстриме) `git pull` **не трогает** — он применяет только то, что реально пришло из upstream.

### Если `git pull` ругается на "unrelated histories"

Это значит, что ты склонировал репозиторий до перехода на incremental-историю (раньше каждый snapshot был orphan force-push'ем). Выполни один раз:

```bash
git fetch origin
git reset --hard origin/main
```

После этого `git pull` будет работать как обычно.

## Что внутри

- `wiki/index.md` — каталог всех страниц
- `wiki/preset.yaml` — манифест пресета (темы, слои, теги)
- `wiki/rules.md` — доменные правила
- `wiki/overview.md` — синтез верхнего уровня
- `wiki/log.md` — журнал операций (последние обновления)
- `wiki/<layer>/<theme>/*.md` — сами страницы знаний, организованы по слоям (canon/evolving/volatile) и темам
- `wiki/sources/` — саммари исходных материалов (что откуда пришло)

## Ограничения

- **Read-only по сути** — основная папка `wiki/` поддерживается на upstream и переписывается на каждом обновлении. Твои локальные правки в этих файлах будут перетёрты при следующем `git pull`. Свои файлы рядом (новые `.md`, заметки, локальные агенты) сохраняются.
- **Snapshot'ы** — каждое обновление — incremental commit поверх предыдущего. История на GitLab растёт линейно, `git pull` работает как обычно.
- **Доверие к данным** — каждая страница имеет `confidence:` и `updated:` во front-matter. Поля `stale: true` и истёкший TTL — сигнал, что факт может быть устаревшим.
