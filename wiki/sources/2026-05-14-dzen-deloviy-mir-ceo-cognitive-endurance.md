## Релевантность

**Аудиторное совпадение:** статья из бизнес-издания для CEO (founder/директор/руководитель) — **прямой ICP-overlap** с GRO ([[canon/target-audience/ru-smb-founder-owner-seller]]). Релевантно.

**Нерелевантно для извлечения как фактов:**

- Конкретные нутрициологические утверждения («мозг забирает 20% энергии», «омега-3 помогают нейронам», «аспартам запускает инсулиновый отклик») — это медицинский контент, не маркетинговый. ГРО не рекомендует питание, не публикует health-advice. Не выносить в layer-страницы как факты.
- Конкретные рецепты перекусов («индейка + авокадо + хлеб») — то же.

**Релевантно для извлечения:**

1. **Content-pattern «Журнал Деловой Мир»** как business-publication exemplar (Дзен-канал «Деловой мир» — отдельная business-publication на Дзене с практическими guide-материалами для CEO; шаблон «эксперт + 5-шаговая программа + somatic hooks»).
2. **Hook-language register «somatic / телесная усталость»** — «туман в голове», «провал в 15:00», «батарейка села», «качели глюкозы», «топливо для CEO». Это **отдельный регистр** hook'ов для CEO-аудитории, дополняющий existing Bruch/Ghoshal-якорь в [[evolving/product-reception/gro-productivity-energy-angle]] (тот говорит про энергию/фокус **абстрактно**, эта статья — через **тело**).
3. **Format-template «5-шаговая программа на неделю»** — operational listicle с micro-commitments, узнаваемый advertorial-template для CEO-аудитории. Re-applicable для GRO content.
4. **Cross-link с productivity/energy angle** — статья косвенно валидирует распространённость problem-frame'а «усталость к 15:00 = норма» в среде ICP, что усиливает empathy-first hook'и GRO.

## Ключевые идеи (для content-mining, не для health-advice)

1. **Problem-frame статьи:** «вы устаёте не от работы, а от того, чем кормите мозг» — re-frame усталости как **management-вопроса**, а не «работайте меньше». Эта re-frame-механика повторяема: вместо «причина X, очевидная для всех», предложить альтернативное «настоящая причина — Y, которую вы не замечаете».
2. **Узнаваемое описание ICP-симптомов:** «не клевать носом после обеда, не терять фокус после каждой встречи и не ощущать туман в голове», «качели глюкозы», «батарейка села», «забитый календарь без результата». Это **CEO-specific somatic vocabulary** — словарь, на котором сегмент говорит про усталость, без motivational-clichés.
3. **Hook «топливо для CEO»** — metaphor-anchor: CEO = инструмент, требующий топлива (а не «надо быть сильнее»). Сходно с Krylov «эмоциональное состояние — рабочий инструмент» ([[evolving/product-reception/gro-productivity-energy-angle]] § «Эмоциональное состояние — рабочий инструмент»).
4. **5-шаговая operational программа на неделю** — формат микро-обязательств: «один новый шаг в неделю» (питьё воды утром / запас перекусов / triple-check белок-жир-клетчатка / убрать триггеры / распределённое питьё). Формат явно подражает «atomic habits»-механике, упакован под CEO-аудиторию.
5. **«Норма» оспорена как фрейм:** «"усталость после обеда — это норма" — старая картина». Re-framing-приём: то, что считается дефолтом, — на самом деле fixable. Это **общий content-pattern**, применимый к любому ICP-pain (а не только к питанию).

## Факты и цифры (audit-only, не переносить как факты)

Большинство утверждений статьи — медицинские/нутрициологические claims без proper citation:

- «Мозг забирает около 20% всей энергии тела» — общеизвестный fact в нейробиологии, ссылок нет.
- «500–700 мл воды натощак залпом разбавляет электролиты» — нутрициологическое утверждение.
- «По 150–200 мл за раз» — рекомендация.
- «Норма "2 литра в день" — усреднённая цифра, не учитывает вес/нагрузку».

В layer-страницы переносить **не нужно** — это вне маркетингового домена. Только audit-фиксация.

## Content-pattern: «Журнал Деловой Мир» как издание

Дзен-канал «Деловой мир» — отдельная business-publication, отличается от vc.ru / Inc. Russia / Forbes Russia форматом:

- **Practical-listicle для управленцев** (не news, не industry-analysis)
- **Гостевые эксперты** (нутрициолог, психолог, юрист — не сами журналисты пишут)
- **«Программа на неделю» / «5 шагов» / «6 ошибок»** — типовые format-templates
- **Тон**: дружелюбный, без академизма («без таблиц и запретов»), short-paragraph, второе лицо («вы»)
- **Visual:** обычно стоковые фото-иллюстрации продуктов/процессов
- **Disclaimer:** прямого native-ad disclaimer'а нет — материал presented как editorial guide, без видимого спонсора

**Дельта от vc.ru/Inc.** — vc.ru ориентирован на founder'ов/SaaS-аудиторию, «Деловой мир» — на **управленцев** (HR-директор, операционный, коммерческий, СEO средней корпорации), включая non-IT и не-founder сегмент.

**Дельта от Forbes Russia** — Forbes даёт native-ad pattern с явным `/spetsproekt/`-disclaimer'ом ([[evolving/content-trends/forbes-russia-native-ad-pattern-2026]]). «Деловой мир» — формат **editorial guide без visible sponsor**.
