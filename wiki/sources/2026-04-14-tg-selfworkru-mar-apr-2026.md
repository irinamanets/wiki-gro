## Ключевые идеи

### Визуальная идентичность (observable pattern)

- **Двухцветная синяя палитра**: насыщенно-синий (`#1B7CE8`-подобный) для «эмоциональных»/юмористических/праздничных карусельных обложек, светло-голубой (`#D8E6F5`-подобный) для новостных/explainer карточек. Чёткое функциональное разделение: холодный голубой = информация, насыщенный синий = эмоция/юмор.
- **Круглый «@»-логотип** в верхнем-левом углу каждой карточки — консистентный brand anchor.
- **Большой bold sans-serif заголовок**, left-aligned, без serif-сопровождения.
- **Анимационный коин-маскот** — антропоморфная монета (круглое тело с ножками/руками), которая меняет реквизит по теме поста (счёты для «налогов», военная пилотка для «СВО», грустное выражение для «без дохода»). Это **сквозной character** бренда, не разовая иллюстрация — маркер того, что канал инвестировал в персонажа.
- **Новостные карточки с зелёной плашкой «Новость»** — явный формат-сигнал читателю.
- **Шаблонные numbered cards**: «№1…№4» для серийных carousel-блоков (пост 3011–3019 о льготах — явно 4-numbered серия + обложка + «исключения»).
- **«Вы спрашиваете — мы отвечаем» rubric**: cover (заголовок + chat-bubble «Расскажите подробно о X») → chat-dialogue cards (вопрос чёрным, ответ в text-bubble) → иллюстрация предмета. Этот формат — экспликация Q&A как зрительной метафоры интерфейса мессенджера, что стилистически идеально ложится на Telegram-feed.
- **«Работать на дядю VS Быть дядей»** — before/after reflection-формат с **кот-мемами** в качестве визуального якоря (реальные фото котов в тематических позах). Юмор через anthropomorphism, не через «нарисованный мем».
- **Пасхальный seasonal branding** — тематический кролик + яйцо с «@» лого, карусель из стилизованных яиц-брендов («Kinder от Самозанятые.рф»). Пример того, как использовать **сезонный праздник как рекламный носитель**, не продавая ничего напрямую.
