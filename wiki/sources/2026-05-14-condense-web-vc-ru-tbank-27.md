4. **B2B2C партнёрская модель.** Tinkoff Выгода (кэшбэк + рассрочки + промокоды + диджитал-сэмплинг + клубы лояльности) = единая витрина для брендов с 40M аудиторией без построения собственного CRM. Это **референс для платформ-маркетплейсов** в любом сегменте.
