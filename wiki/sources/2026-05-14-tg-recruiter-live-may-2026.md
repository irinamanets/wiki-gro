## Ключевые факты и цифры (для strict-слоёв)

### Кейс мошенничества «Apple ID на собеседовании» (пост 4458, 2026-05-06)

Пост — LinkedIn-пересылка от Полины (Graphic Designer). Атрибуция: «По мнению Полины [conf:medium, src:2026-05-06]» — кейс описан первым лицом, верифицировать невозможно, но pattern совпадает с известными мошенническими схемами 2024-2026 (job-scam через Apple ID/iCloud lock из Find My).

**Tactic chain (как сработала схема):**
1. Полина откликается на вакансию (платформа не названа, вероятно LinkedIn).
2. Первый screening с «девушкой» (рекрутером) — без флагов.
3. Передача «HR'у» (мужчина) — адекватный screening-call без флагов.
4. После собеса HR просит «войти в его Apple ID на твоём айфоне для установки корпоративного приложения для задач».
5. Полина входит. Через секунду её выкидывает из звонка, телефон блокируется надписью «Пропавший iPhone» (Find My).

**Это уже второй раз для одной соискательницы в одном поиске.** Первый: «американская компания» через Behance, без собеса предложили оффер → потом просили документы / платный вход на сайт.

**Red flags по версии Полины (готовая чек-лист рамка):**
- Войти в чужой Apple ID / Google аккаунт.
- Установить приложение в обход стора.
- Прислать документы или оплатить что-либо до подписания договора.
- «Своё внутреннее приложение», которого нет нигде кроме их ссылки.

→ При появлении любого из этих — уходить «без объяснений».

`[conf:medium, src:2026-05-06]` — first-person кейс, но pattern признан, и автор канала ставит post-промо как материал для распространения.

## Ключевые идеи (качественная фактура)

- **Job-scam через Apple ID becomes recurring pattern (пост 4458)** — это уже **второй** мошеннический паттерн в опыте одной соискательницы за один цикл поиска (первый — Behance-«американский оффер»). Татьяна публикует пост 4458 как раннее предупреждение для аудитории канала. Combined signal: на фоне 36% соискателей `[conf:high, src:2026-04-06]`, боящихся мошеннических схем работодателей (из [[evolving-strict/market-data/ru-labor-market-hh-2026]]), реальные tactics эволюционируют — сейчас атакуют через iCloud-lock (использование Find My как ransomware), а не только через предоплату/документы. Это **расширение существующей категории «страхи соискателей»**, не отдельное явление.

- **HH product feature «история изменений резюме» (пост 4462)** — нетривиальная информация: либо это **новый user-facing feature**, который HH тихо запустил, либо **серверное логирование, которое стало видимым после сбоя**. Если первое — у HH появился новый репутационный сигнал для работодателя («не вертит ли кандидат резюме под каждую вакансию»), что меняет тактику соискателя (нужно держать одно мастер-резюме, а под разные роли использовать сопроводительное письмо). Если второе — это reliability-flag для HH (сбои на 2-3 дня в апреле-мае 2026, после которых данные «перемешиваются»). Оба сценария формируют hook для контента GRO про «как себя ведут платформы».

- **State-of-market май 2026 (пост 4468)** — наблюдение Татьяны на пятой неделе перерыва праздников: **растут продуктовый retail / аптечный retail / e-com / корма для животных (агро)**; **зарплаты под давлением, в реальном выражении возможно снижаются**; **единого места размещения вакансий нет** (LinkedIn → Telegram-каналы → hh = три параллельные сети). Это срез **май 2026**, дополняющий апрельские наблюдения и валидирующий тезис фрагментации каналов из поста 4438 предыдущего дампа. Маппинг на сегмент 1 «карьеристы»: важно показывать в контенте, в каких именно секторах сейчас рынок открыт, и где НЕ открыт.

- **Sosindex sharp anti-corporate narrative (пост 4459)** — sub-pattern «one-line виральный тезис о токсичности корпоративной культуры», работающий через шок-фрейминг (антидепрессанты как KPI вовлечённости). Метрики ~16K просмотров за 13 часов = высокий engagement-rate для текстового micro-формата. Это образец content-pattern для **карьерной аудитории через эмоциональный extreme-positioning** — то, что HR-каналы боятся произнести, авторские sosindex/anonymous-каналы артикулируют резко.
