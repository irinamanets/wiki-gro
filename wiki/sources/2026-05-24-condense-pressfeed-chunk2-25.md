## Ключевые идеи (по темам)

### marketing-frameworks
- **8 приёмов доверия через контент:** боль ЦА вместо «мы молодцы»; быть «рядом», не «над»; общий враг; язык ЦА; социальное доказательство; благотворительность; известные клиенты; экспертное мнение с атрибуцией. Нативная интеграция продукта «сквозь весь текст».
- **Оценка PR (Дарья Гусева, партнёр PR-агентства):** «лидогенерирующий PR — химера», связать PR с продажами можно только косвенно. 4 механизма влияния (прямая лидогенерация / PR-ловушки / PR-адвокат / почва для рекламы) + 3 KPI-стратегии (паритет / лидерство категории / нишевое присутствие). Каскад: бизнес-цели → коммуникационные цели → инструменты → KPI.
- **PR без политики (5 правил кризисной коммуникации):** нейтральный тон + предполётная проверка; внутренние брифинги; от политики к последствиям + переход в свою область; фокус на ценности клиента; стабильность через прозрачность. Анти-кейсы Monochrome (май 2026), Бойко-Полякевич (уголовное дело), Леруа Мерлен/Панина (2018).
- **Промышленный B2B-маркетинг (Анна Тарасова):** 4 мифа (маркетинг для розницы / всё решает цена / хороший продукт сам себя продаёт / сайты для ритейла) + роль промышленного маркетолога (длинный цикл, ИСО/ГОСТ/АСТМ, карты ЛПР, TCO/ROI, sales enablement).
- **Проверка качества текста (7-шаговый чек-лист):** смысл/ЦА → фактчек → структура → визуал → грамматика → ключи → антиплагиат (90-100%). Критерии качества + формулы заголовков.
- **Внутренние коммуникации / внутриком:** связующее звено руководство↔сотрудники, инструмент реализации HR-бренда. 2026-тренды (SPN Communications): отдельная команда Internal Communications, борьба с Great Detachment, CCO как бизнес-стратег.
- **Типология личного бренда (Том Питерс, 5 типов):** Эксперт / «Свой парень» / Провокатор / Смешанный / Хамелеон. 5 элементов + 3-шаговая стратегия. 10 правил личного бренда. Модель «видимый → заметный → узнаваемый».
- **Как стать экспертом 2026 («Сидорин Лаб»):** AI-видимость как новый критерий присутствия; экспертность ≠ стаж; навыки эксперта; этапы (ниша → углубление → soft skills → портфолио → контент).
