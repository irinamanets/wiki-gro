## Ключевые идеи

### 1. AI-замещение white-collar труда — лейтмотив канала

Горный последовательно возвращается к теме, что Claude Code (и аналогичные агенты) обнуляют целые классы задач. Три отдельных поста за 3 недели:

- **4961 (2026-03-23):** «Уволил фрилансера, потому что Claude Code делает его работу не хуже за один запрос. ЗА ОДИН, СУКА, ЗАПРОС. Я не знаю, как жить в 2026 году.» — это эмоциональный peak, не экспертная аналитика, но ценная как **фольклорный hook** от эксперта.
- **4969 (2026-03-27):** Death By Clawd — AI-оценщик жизнеспособности компаний. «Этот проект неуязвим, этот закроется через два года, а этот уже мертв — вместо его использования можно на простом русском языке написать файл для Claude Code и получить тот же результат.»
- **5005–5006 (2026-04-09/10):** RevenueCat отклонил оффер в $500M при 17× ARR. Горный: «Он работает с документированным API, обрабатывает весьма конечное количество сценариев, не защищён никакими сетевыми эффектами. Если "клиенты сами напишут себе CRM" воспринимается как угроза для Salesforce, то здесь ужас должен быть на много порядков сильнее.» Это **прямая атака на API-wrapper SaaS moat** — самый жёсткий публичный голос на русскоязычной сцене на эту тему.

Нарратив согласуется с [[evolving/industry-trends/software-moat-erosion-2026]] (Перегудов) и [[evolving/industry-trends/ai-solopreneurship-window-2026-2029]] (подкаст). Горный становится третьим независимым голосом в этом семействе hooks.

### 2. MVP vs прототип — канонический framework

Пост 4989 (2026-04-02): Горный последовательно различает «прототип» (который Claude Code делает за 5 минут) и «MVP» — положительный результат проверки **главной гипотезы**:

- Стандартный продукт → главная гипотеза «клиенту нужно» → MVP = полный процесс продажи с воспроизводимым поиском клиентов
- Deep-tech/невозможное → главная гипотеза «это физически работает» → MVP = рабочий образец
- Медиа/соцсеть → главная гипотеза «люди приходят и остаются» → MVP = виральный рост + retention

Это **стабильный фреймворк** с 15+-летней устойчивостью в VC-литературе (Eric Ries «Lean Startup» и вокруг), Горный артикулирует его в свежем AI-контексте. Уходит в [[canon/marketing-frameworks/mvp-definition-gorny]].

### 3. Российский AI-агент экосистема начинает формироваться сверху-вниз

Пост 4981 (2026-03-30): Yandex B2B Tech запускает грант до 1 млн ₽ через Yandex AI Studio. Упомянутые кейсы:

- **R77.ai** — проверка документов для банков/страховых за минуты вместо дней
- **Noumy.ai** — HR-оценка кандидатов на интервью
- **GO2AI** — ИИ-агенты для стратегии, сокращают цикл принятия решений с дней до часа

Плюс пост 5001: **NovaVoice** — российский distance speech-to-text с AI-фиксом оговорок, стартап запускается на Product Hunt, founder — член ShareAI клуба.

Плюс пост 5012: **AiAcademy.me** — подписка на доступ к нейросетям из России + SMM-кейс стартапа Чиббис (2,2M просмотров, 2k ₽/нед — ~0,001 ₽/view).

Это **4 разных вертикали** (fintech, HR, strategy, voice, infra) с государственно-корпоративной поддержкой (Яндекс как оркестратор + грант-программа). Картинка: российский AI-agent рынок формируется **не снизу через стартап-взрыв, а сверху через Big Tech инфраструктуру**. Значение для GRO: конкурентная среда на рынке «AI-инструменты для продуктивности/коучинга» насыщается быстрее, чем казалось ещё в январе 2026.

### 4. Маркетинг anti-patterns (Горный как cynic-commentator)

- **Product Hunt лончи** (пост 5009, в стиле Стругацких): «Взрослые солидные люди на Product Hunt не запускаются». Характеристика PH как канала для **доменного самосознания**: хорош только до тех пор, пока у тебя нет своего трафика и выручки. Ключевая метафора: «ментор спросит только: "Ты опять на Product Hunt?"».
- **April Fools корпоративные шутки** (пост 4985): «В декабре ставим ёлку, в апреле выдавливаем из себя юмор — традиция. Смешная шутка хороша в любой день, несмешная и сегодня плоха». Anti-pattern для brand-контента.
- **DOOH dashboard-vs-ROI** (пост 4995): эксперимент с электронными щитами в Москве — дашборды красивые, ROI не раскрыли. Горный: «целевая аудитория интеграции — маркетологи, а не владельцы бизнесов. Некоторым из них удобство и красота дашбордов важнее, чем отдача на вложенный рубль». Это hard-hit на маркетинговый **dashboard-fetishism** как объекционный нарратив.

Все три — короткие ремарки, но все три чистые anti-pattern hooks для контента GRO про «маркетинг, который работает vs маркетинг, который ощущается».

### 5. ShareAI ↔ GRO cross-link подтверждён

Пост 4979 (2026-03-30): Екатерина Лапшина (founder GRO) была гостем встречи ShareAI клуба Горного, прошла «в формате интервью, которое плавно переросло в открытый разговор с участниками клуба». Горный — основатель клуба, Лапшина — founder GRO (см. [[canon/product-knowledge/gro-team]]). Это **физическая верификация** того, что founder GRO находится в инсайдерском круге русскоязычной VC/AI сцены (клуб закрытый, вход через интервью). Фольклорный proof-point: GRO не случайный стартап, команда в нетворке.

Пост 4998 уточняет, что ShareAI — платный клуб с коротким интервью на входе, не всех берут. Аудитория: предприниматели и топы, не студенты.
