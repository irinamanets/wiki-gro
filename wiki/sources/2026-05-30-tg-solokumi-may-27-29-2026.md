## Ключевые идеи

### Пост 420 (2026-05-27) — Second Brain в Claude Code
- «Второй мозг» не только хранит данные (креативы, данные кампаний, исследования клиентов, инсайты по конкурентам, транскрипты глубинных интервью), но и **превращает их в систему принятия решений**: на входе данные → на выходе план действий (офферы для теста, отсортированные гипотезы, изменения в кабинетах).
- Кому Kumar & Solo собирают 2nd brain: **фаундеры** (трекинг бизнес-метрик — runrate по выручке/CPL, отвалы в продукте + сигналы по просроченным таскам); **маркетологи** (маркеры выгорания креативов/воронок + план исправления + трекинг runrate).
- **Ключевой принцип**: использовать не весь массив данных, а **только правильный кусок контекста** — если дать слишком много нецелевых данных, контекст заполнится, сессия деградирует, результат плохой.
- **Декомпозиция креатива конкурента**: скрин рекламы сам по себе бесполезен. Размечать по компонентам **Персона / Боль / Хук / Оффер / CTA / Результат**. Когда данные есть, Claude собирает новое крео из уже работавших компонентов. В базу класть и провалы (хуки, не удержавшие внимание; офферы без заявки; CTA, убившие конверсию).
- **Стек**: vault в Obsidian (бесплатные локальные markdown), Claude Code читает напрямую. Структура vault `second-brain/` с 6 подпапками: `00_raw/`, `01_components/`, `02_creatives/`, `03_performance/`, `04_competitors/`, `05_brand_context/`. `CLAUDE.md` — файл правил (где что лежит, аудитория, формат компонентов, что нельзя выдумывать).
- **Рабочий цикл**: всё сырьё в `00_raw/` → Claude раскладывает по папкам → подключаются трендвотчинг и скрейперы → базе можно задавать реальные вопросы («5 вариантов хука на эту персону на основе тех, у кого лучший CPL», «какие крео конкурентов крутятся дольше 2 месяцев», «какие CTA всегда сливают конверсию»).

### Пост 421 (2026-05-29) — 4 неочевидных тренда маркетинга 2027
- **I. Скорость петли обратной связи важнее качества конкретного крео.** Цикл «запустил → собрал данные → понял рост/падение метрики → итерация»: у большинства 1–2 недели и 5–6 итераций/квартал; у Kumar & Solo — **24 часа** (утром агент шлёт метрики за вчера с разбором причин, к вечеру новая пачка крео загружена в кабинет), **45+ итераций/квартал**. При равном бюджете «45 итераций статистически раздавит 5».
- **II. Отдел продаж — лучший источник данных для маркетинга.** AI разбирает 100% звонков, еженедельно выдаёт датасет: новые боли, триггеры, **фразы-виннеры**. Конкретный кейс: AI заметил повторяющуюся фразу страха клиента → добавили в хук (первые 3 секунды видео-крео) → крео-виннер с **CPL на 40% ниже среднего**.
- **III. Микс из 10 микро-блогеров > один крупный.** Крупные (500K+) — отрицательный ROI в большинстве ниш (завышенный ценник + размытая аудитория). Микро (5–50K) конвертят в **3–5 раз выше на единицу бюджета**. AI-агент тянет аналитику из Trendhero, считает прогнозный CPV/CPL, по бенчмарку ставит тег «брать/не брать», закрывает первые касания в переписке. Один менеджер ведёт **100+ блогеров** вместо 5.
- **IV. Конкуренты используют ваши крео как обучающие данные.** Стек: **Apify + Meta Ads Library + n8n + час настройки** — и все ваши крео/офферы/воронки разложены по полочкам. Любой крео/оффер/воронку можно скопировать за **48 часов** (тулы типа atria). Что скопировать **нельзя**: скорость петли (I), данные из звонков (II), глубину понимания клиента. Конкурентное преимущество — не крео, а **скорость генерации инсайтов и превращения их в действия**.
