## Ключевые идеи

### Кластер 1 — Новые AI-модели (image / video / 3D / world)

- **HiDream-O1-Image (8B)** (15651–15655) — раскрыт «загадочный Peanut» с арены: модель от vivago.ai. **Pixel-space, без VAE, без text-encoder**, рассуждающий prompt-агент внутри. Версии dev (28 шагов) / standard (50 шагов), разрешение до 2048, режим редактирования. Открыты дистиллированный и недистиллированный варианты + Reasoning-Driven Prompt Agent. Ostriss (AI Toolkit) восторженно: «самая крутая модель, которую я видел… изменит всю отрасль». Caveat автора: «мылит картинку, с кожей не очень» (15652) — дистиллят пока слабый.
- **Krea K-2** (15669–15670, 15698) — собственная модель Krea, тренирована с нуля, заточена на художественные стили (не фоторил). 19 мая раскатили **всем подписчикам + безлимит без кредитов на неделю** (Basic/Pro/Max/Business). Гайд Олега (тестил 2 недели до релиза): первое слово промпта = тег жанра/стиля, без него модель скатывается в дефолтный сглаженный реализм.
- **AsymFLUX.2 Klein** (15678–15680) — работает напрямую в пиксельном пространстве, No VAE, **на 40% быстрее**, меньше мыла. Понимание промпта — типичный Flux (чуда нет). Код + быстрое демо, поддержка ComfyUI на днях.
- **Pixal3D / Tencent** (15665) — новый 3D-генератор, под капотом Trellis.2, pixel back-projection в 3D-feature-volume. Веса + код + демо.
- **HY-World-2.0 / Tencent Hunyuan** (15688) — опенсорсный генератор миров (аналог Marble), код и веса выложены.
- **Starchild-1 / Odyssey** (15697) — multimodal world model, реалтайм (20FPS), редактирование и стриминг видео, упор на звук и управление генерацией в реальном времени (в т.ч. голосом). Демо пока нет, только техрепорт. Автор: «если размотать вперёд — это реально матрица».
- **Viggle.ai P.I.N.O.C** (15671) — pivot из мемных видосов в нейромокап: видео персонажа → скелет с анимацией в fbx/glb для Blender/Maya. Бесплатно, login as guest.
- **Video2Video / нейрорендер** (15690–15693) — обобщённый нейрорендер (снимаешь себя → нейрорендеришь), замена персонажа в Seedance мультиреференсом (`change the girl in the video to the man in the image`). Тезис автора: для каждой страны/стриминга можно подменять персонажей.
- **LTX Director** (15683) — All-in-One Timeline Editor в ComfyUI (I2V, T2V, FLFF, Prompt Relay, Custom Audio). «Никаких агентов и токенов».
- **Gemini Omni** (15656, 15661–15662) — cgevent-аттестация утечки: новая omni-модель Google, видео + улучшенный звук, контекст >12 млн токенов, может заменить Veo 3.1. В математике/тексте «явно получше» Seedance (наследие Flash + Nanobanana). Сильно цензурирована (Will Smith не пропускает).

### Кластер 2 — «Нейропрожарка» (7 разборов за неделю)

Рубрика #Нейропрожарка продолжается с устойчивой частотой. Новые разборы (детально — в [[evolving/content-trends/neuroprozharka-ai-indie-filmmaking-format]]):

- **«Мысли»** (15650, @aidirected) — конкурсное видео, «залетело» в соцсетях. Banana Pro/2 (стоп-кадры), Kling 3.0/Grok/Seedance 2.0 (видео), Suno (музыка).
- **«Приключения орчанки»** (15660, Герда-монтажёр) — первый опыт мультфильма по книгам Тармашева, ~14 рабочих дней. ChatGPT/Nano Banana Pro/Photoshop → Seedance 2.0/Kling 2.6/Grok → ElevenLabs/Suno → DaVinci/Topaz.
- **KGM Torres** (15668, ИИ-студия Ноль, aistudionull.ru) — **первый коммерческий рекламный ролик** в выборке: реальный бриф, 24 часа, статуэтка «ИИ энтузиасты». ~16 часов производства, бюджет 15–20 тыс ₽. Nano Banana Pro/Magnific/Photoshop → Kling 3.1/Seedance 2/Kling Omni → Suno/ElevenLabs → Premiere, сборка через Weavy. Лайфхак: генерация по среднему кадру; перевернули вертикальную сцену для физики колёс.
- **RED OR DEAD** (15672, Дмитрий + супруга) — конкурс Myfilm48, 96 часов, фантастика+«Город Грехов». NanoBanana Pro (персонажи-карточки) → Seedance 2.0 → DaVinci → Suno 5.5. Английский язык дал нормальный липсинк внутри генераций.
- **«Хватит меня бесить»** (15677, Алексей Николаев) — клип в hard style, Suno (бесплатные токены) + Seedance2 в 480p. ~1000 ₽.
- **«Lé Pôgnalî»** (15685, Александр Зуев) — фестиваль MyFilm48 сезон 7, 96 часов, тема Канны-2026. Seedance 2.0 720p + Kling 3.0/o3 + NBP + Suno 5.5. ~$100 спонсорских кредитов + ~2000 ₽ своих. (Медиа пропущено — 281 МБ > cap 200 МБ.)
- **ТВ-ролик «ультрареалистичная неидеальная жизнь»** (15695, Женя Пырьев / Щи Продакшен) — 1 месяц. Тезис: «как показать неидеальную жизнь, если ИИ всё идеализирует» → кастинг реальных актёров + выкуп прав на изображения, документальный формат, естественный свет, неидеальные лица/детали. Banano Pro/Kling/Seedance/Luma/DaVinci/Photoshop.

### Кластер 3 — Агентный контент-продакшн

- **Higgsfield Super Computer** (15674) — агент «сделай красиво»: сам выбирает модели (Seedance/Kling/Veo/Nano Banana/GPT-Image/Soul), анализирует автора и его соцсети (TikTok/IG/YT/Meta Ads Library), тренды, конкурентов; код+поиск; коннекты Notion/Gmail/Drive/Figma/Slack; работа в телеге; Soul ID обучение на лицах. Под капотом Claude Opus 4.7 (+ выбор Opus 4.6/Sonnet 4.6/GPT-5.5 Pro/Gemini 3.1 Pro). Вопрос автора: сколько это будет стоить — агент не заинтересован экономить токены.
- **Первый отзыв (Дима Киселёв, 15676)** — тизер несуществующего фильма (45 сек). Плюсы: экономит токены, спрашивает перед генерацией, принимает подсказки. Факт: подвис на референсах, упала песочница TTS, не подгрузился ffmpeg-монтаж, **новое правило Higgs «подтвердить авторство» сломало 3 ролика** (автор=агент, у которого нет полномочий подтверждать). Спалил >1500 кредитов. Вердикт: «продукт пока сырой. Игрушка для богатых».

### Кластер 4 — Thinking Machines / Claude Design

- **Interaction Models (Мира Мурати / Thinking Machines, 15664)** — новый подход к голосу/мультимодальности: реалтайм микрокусочками 200 мс, аудио+видео+текст параллельными потоками, асинхронное мышление. Умеет перебивать, говорить одновременно (синхронный перевод), реагировать на визуальные триггеры, держать чувство времени, вызывать инструменты параллельно с разговором. 276B MoE / 12B активных. FD-bench v1.5: **77.8 vs 46–54** у GPT-Realtime и Gemini-Live; turn-taking latency 400 мс. Research preview закрытый.
- **Claude Design + игровой прототип (15699, @VAI_ART)** — генерация UI в GPT Image 2 → Claude Design превращает скриншот в кликабельный HTML-прототип игрового UI за пару итераций (промпт писал тот же Claude). Тезис: «10 минут назад была идея — уже делаешь прототип»; «средний интерфейс раньше — ~месяц, теперь сильно короче двумя инструментами».

### Кластер 5 — RU enterprise-AI (рыночный контекст)

- **Норникель × ИОНХ РАН** (15666) — платформа генеративного дизайна неорганических материалов (металлы/сплавы/покрытия): 4-этапный конвейер (анализ научлитературы → генеративный + физико-химический дизайн структуры → LLM-планы синтеза → роботизированная лаборатория в цикле дообучения). Горизонт 2 года, отдельные контуры уже работают.
- **Норникель AI-архитектор** (15684) — первая отраслевая RU-система генеративного ИИ для проектирования заводов: цифровые агенты анализируют ТЗ, генерируют документацию, наполняют BIM-модель, сверяют с нормативами. Сроки документации −вдвое; эффект 10 млрд ₽/год, совокупно 50 млрд ₽.
- **Т-Банк Nulla** (15696) — группа ИИ-агентов для контролируемого пентеста: проверка серверов без разработчиков за **45 минут** (было 2–3 дня ручного аудита), адаптируется под защиту. Потестили на 1300 собственных сервисах.
