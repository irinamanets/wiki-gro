# Telegram @tinkoffbank #10574 — второй эпизод «Звёзды против мошенников» (Алексей Щербаков)

- **Экспертность автора:** verified — официальный корпоративный канал Т-Банка

Обе промо-плашки продвигают **разных celebrity-гостей** с одним и тем же форматом-механикой, тем же CTA-stack'ом, теми же TG/YT/VK-ссылками. Это **первое наблюдаемое подтверждение** серийности формата, а не единичной колаборации.

## Релевантность

Релевантно для marketing-memory по нескольким линиям:

1. **Серийность branded-show формата подтверждена.** Первый эпизод (#10546, Сатир) был первым проявлением, и в [[evolving/content-trends/branded-show-format-t-bank-stars-vs-fraudsters]] формат описан по одному кейсу. Теперь есть **вторая episode-instance** с другим celebrity — это сдвигает формат из «single-shot branded content» в **serialized branded-show** по-настоящему.
2. **Продолжение up-sell lattice в same campaign.** Промо-пост #10574 повторяет **точно** тот же CTA-stack, что и #10546: watch show → T-Refund → Защита близких → sweepstake 100 000 ₽ до 23 апреля. Это **campaign-level consistency**: серия эпизодов единым окном продвигает один converter-flow.
3. **Casting pattern — стендап-комики как operator'ы.** Сатир (пародист, имитация голосов) и Щербаков (стендап, импровизация, способность «поболтать и потянуть время») — это **не случайный celebrity-booking**, а **functional casting**: обоих выбрали за профессиональную способность удерживать мошенников в разговоре. Это подтверждает описание [[evolving/content-trends/branded-show-format-t-bank-stars-vs-fraudsters]] «celebrity как functional role, не face бренда».
4. **Рекламный Angle про узнаваемость комиков.** «Иногда они [мошенники] узнают его и даже извиняются» — это **extra-entertainment payoff**, которого не было в #10546 с Сатиром. Для user'а это **viral-moment hook**: интересно именно посмотреть, узнает ли мошенник Щербакова. Показывает, что casting разных celebrity'ев даёт **разные narrative-hooks** в пределах одного формата.
5. **Визуальное продолжение YT-конвенции.** Thumbnail следует той же YouTube-formula, что и #10546 — два крупных лица, центральный text-bubble, 3D-типография названия в правом нижнем углу, warm-tone фон с call-icons как bokeh. Это **template'д thumbnail-шаблон**, а не custom-дизайн на episode. Для GRO — референс: serialized-формат **требует template'а thumbnail'а** для узнаваемости серии.
6. **Cadence в TG-канале.** Между #10546 и #10574 — 28 постов (10546→10574). В TG feed это ~1–3 недели. Промо-эпизоды идут **не чаще раза в 2 недели**, что даёт аудитории успеть посмотреть первый. Разумная serialization cadence для 15-минутного длинного формата.

Не извлекаем:
- Биографические детали Щербакова (кто такой, стендап-карьера) — нерелевантно.
- Детали регулирования sweepstake'а — уже в #10546 source-странице.

## Ключевые идеи

1. **Branded show — не pilot, а serialized format.** Два observed episode с 2-недельным spacing'ом = serialization по-настоящему. Т-Банк не делал pilot-test-шоу, он производит **series**. Это поднимает планку marketing-ambition для крупных RU-брендов: не «запустили брендированный короткометражный контент», а «запустили branded series».
2. **Functional casting по professional-skill.** Сатир выбран за имитацию голосов, Щербаков — за импровизационную speech-способность. Оба — stand-up / пародический тип celebrity. Это **не случайность** — pattern намекает, что любой episode-гость шоу будет из этого skill-bucket'а. Для любого branded-show формата вывод: **kasting не по celebrity-recognition, а по functional-fit с механикой**.
3. **Narrative-hook на эпизод.** Первый эпизод продавался через emotional-hook «Начни плакать» (text-bubble в thumbnail). Второй — через **meta-хук**: «иногда мошенники узнают Щербакова и извиняются». Каждый эпизод имеет свой one-phrase hook, который дифференцирует один эпизод от другого даже при одинаковом format-framing. Это **episode-differentiation pattern**: при том же format-shell каждый episode продаётся своим headline-угол.
4. **Thumbnail-convention.** Оба thumbnail'а используют **identical** layout: два лица по краям, центральный text-bubble на beige-тоне, красный «отклонить вызов» icon, warm-yellow-orange-green bokeh как знак call-signal'ов, 3D-жёлтая 3-строчная типография названия в правом нижнем. Это **brand-template для YouTube thumbnails серии** — не ad-hoc дизайн на episode, а **branded series-template**. Recall: даже на YT Т-Банк не отказывается от template'ов, просто template **YouTube-specific**, а не TG-specific.
5. **Campaign-overlap с «Защитой близких» sweepstake до 23 апреля.** Оба эпизода ссылаются на **ту же sweepstake window** (100k ₽, до 23 апреля). Это **хитрый campaign-design**: серия эпизодов привязана к одной sweepstake-conversion-deadline. Viewer смотрит несколько эпизодов → each episode напоминает про deadline → aggregating FOMO. Это pattern **series-as-conversion-funnel**: entertainment-layer работает на same regulated-action.
6. **Consumer-yellow sub-brand включает even non-Yellow креативы.** Thumbnail #10574 **не yellow** доминантно — warm-orange-green BG, beige speech-bubble. НО 3D-типография «Звёзды против мошенников» — yellow. Yellow в этом креативе — **accent**, не dominant-palette. Это показывает, что внутри consumer-yellow sub-brand'а при переходе в платформу YouTube/VK **yellow становится secondary**, а platform-native convention — primary. Полная инверсия по сравнению с TG-креативами (где yellow dominant, product-object secondary).

## Распознанный текст

```
Давайте перелезать
через заборы
в костюмах?

ЗВЕЗДЫ ПРОТИВ МОШЕННИКОВ
```

**Визуал thumbnail:**
- Две крупных фигуры по краям кадра. Слева — мужчина с коротко стрижеными тёмными волосами, тёмный свитер с white-collar рубашкой, жесты рук в виде «когтей» перед лицом (expression-joke).
- Справа — мужчина (Алексей Щербаков) с короткими тёмными волосами, clip-on серёжка в ухе, рубашка в коричнево-красную клетку (plaid), поза «рука под подбородок, смотрит с лёгким weariness», **жёлтый смартфон у уха** (signals phone call).
- Центральный элемент: **бежевый speech-bubble** с текстом **«Давайте перелезать через заборы в костюмах?»** (абсурд-прикол, типичный content-frame мошеннической беседы).
- **Верхний-правый акцент:** зелёная round icon с белой phone-иконкой (accept-call indicator).
- **Центральный лево-низ акцент:** красная round icon с phone-иконкой «декline» (reject-call indicator).
- **Нижний-правый overlay:** **«ЗВЕЗДЫ ПРОТИВ МОШЕННИКОВ»** — жёлтая объёмная 3D-типография в 3 строках (identical к #10546).
- **Задний план:** warm-yellow-orange-green bokeh с круглыми фигурами (out-of-focus call-lights). Два размытых цветных круга зелёный+красный сверху — signaling incoming/outgoing call environment.
- **Палитра:** тёплый жёлто-оранжевый + чёрно-белая одежда + яркий красный и зелёный круглые accents + жёлтая типография.

**Стиль thumbnail — идентичная YouTube-formula с #10546:** крупные лица, центральный text-bubble, episode-specific text-hook, accents-icons, warm-bokeh, 3D-названиe серии. Это **template'd YouTube thumbnail для branded series**, не custom дизайн.
