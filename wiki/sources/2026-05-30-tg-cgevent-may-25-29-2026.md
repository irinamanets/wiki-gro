## Ключевые идеи (по сообщениям)

**AI-видео/image tooling:**
- **15757 Microsoft Lens** — опенсорсный image-генератор «с кодом»: Lens-800M base, 3.8B DiT с 48-block MMDiT, FLUX.2 VAE, TE ~GPT-OSS 20B, base resolution 1440×1440, Lens-Turbo (4 step) / Lens-Base (50 step CFG). Плюс: быстрая, опенсорс, почти без цензуры. Минус: «сыпется на людях», слабая анатомия. Демо/веса/код на HF + GitHub.
- **15765 Bonsai Image 4B** (PrismML, репост @ai_newz) — 1-битная квантизация FLUX.2 Klein 4B: DiT 930 МБ (1-бит) / 1.2 ГБ (тернар), весь комплект ~3.5 ГБ. Запуск в браузере и на телефонах с 2 ГБ RAM; 512×512 за 9.4 сек на iPhone 17 Pro Max (4 шага).
- **15768 ElevenLabs Music V2** — inpainting (перегенерить часть трека), быстрые смены стиля внутри трека, немузыкальные шумовые эффекты; обещан API (которого нет у SUNO).
- **15775 Stream Diffusion для музыки (DEMON)** — реалтаймовый генератор музыки с хардверными крутилками, под капотом опенсорс ACEStep1.5, локально на 30/40/5090.
- **15776/15780 нейрорендер** — Chaos (V-Ray) выпустил **Veras** (под капотом Nano Banana 2/Pro) для архвиза; энтузиаст **Матарави** развивает нейрорендер из Maya-previz (1 «настоящий» кадр как референс → нейрорендер с текстурами/светом).
- **15781 Higgsfield-плагины для Premiere/After Effects** — генерация внутри проф-софта, транзишены, рефрейм, удаление фона, апскейл до 4К.
- **15788 Nano Banana апгрейд** — GA по API (Gemini Enterprise Agent Platform); принимает видео на вход → понимает его → генерит картинки (video-2-image, аниме-комиксы из видео).
- **15791 FLUX Virtual Try-On** (Black Forest Lab) — виртуальная примерочная по API на Flux.2 Pro, $0.0375 за 1024×1024.
- **15752/15761/15769 Gemini Omni** — нейрорендер/нейрокомпоз, перевод+липсинк+дубляж с попаданием в губы (даже без указания исходного/целевого текста, сохраняет фоновую музыку, домонтирует длину); промпт-гайд от Google (4 правила: реальный мир, рендер текста, управление камерой, монтаж/композ).
- **15763 Seedance 2.0 — 16fps?** — статья TomLikesRobots: 24fps Seedance = 16fps, разогнанные дублированием каждого 2-го кадра (эффект stutter).
- **15785 CTO-ESTIMATE** — бесплатный агрегатор open-weight моделей (бенчмарки Artificial Analysis + конфиги HF), фильтры, сравнение, оценка GPU-требований.

**Институциональный сдвиг:**
- **15755 House of David** — два материала про постпродакшен сериала: Kling и Runway. Тезис автора: «видеогенерация вползает в постпродакшен прямо сейчас, не будет „лучшего" генератора, разные команды используют разные тулы».
- **15787 Netflix INKubator** — Netflix набирает персонал в AI-анимационную студию (короткий метр → полный метр); ранее купил InterPositive (стартап Бена Аффлека, ~$600M). Вакансии CG Experimental Artists требуют ComfyUI + fine-tune генеративных моделей.

**Frontier-модели:**
- **15771/15772 Mythos/Glasswing** — post-update Anthropic: партнёры нашли десятки тысяч уязвимостей; Cloudflare 2000 (400 high/critical); опенсорс-скан 1000+ репо → 6202 high/critical (из 23 тыс); 1752 проверено, 90% подтверждено; пример эксплойта wolfSSL (подделка сертификатов).
- **15784 Opus 4.8** — релиз: реже пропускает баги (×4), алайнмент, бенчмарки (84% Online-Mind2Web, Legal Agent Benchmark >10% all-pass); effort control (slider в claude.ai/Cowork, extra/xhigh/max); Dynamic workflows в Claude Code (сотни параллельных сабагентов); Fast mode 2.5× быстрее, 3× дешевле; Messages API принимает system-записи внутри messages.
- **15793 Epic UE6 teaser** — анонс на Rocket League Paris Major; цель — объединить traditional UE с UEFN-creator-tools; C++ → Verse; релиз 2028.

**Нейропрожарки (новые кейсы):**
- **15756 «Голубь 2»** (Анатолий Гейко) — игровой короткий метр, банана + сиденс 2.0 + клинг 3.0, голоса в ElevenLabs (русский), музыка Suno, апскейл Topaz, монтаж Premiere; ~2 недели; ~2-3 тыс токенов синткс.
- **15764 «Сицилимпилимбилия»** (Олег Усков) — AI-кинофестиваль MyFilm48 (96 ч, тема Канны), **1-е место Professional + спецприз AI Film Awards**. ChatGPT Image 2.0 + Nano Banana 2 + Photoshop → Kling 3 + Seedance 2.0 (TapNow 24k токенов ≈$240, weavy для доделок); озвучка частично сам/друг + звукреж $40; липсинк SyncPro 3 ~$5. **Итог ~$300, 96 часов.**
- **15774 «Переход»** (Руслан Аларханов) — личная реклама как ai-creator, банана 2 + Seedance 2.0, озвучка сам; 80-100k кредитов в Magnific (Freepik).
- **15783 «Shadow Race × Sevendust»** (Павел Жигарев / @noizlab) — racing concept music video, Nano Banana Pro + Seedance 2.0 + Topaz Starlight 2.5. Тезис: «достигли технического потолка в ИИ-генерациях, вопрос — в вере в силы и вкусе».
- **15795 «Погоня»** (Андрей + Екатерина Пинаевы) — конкурс «Ну, ИИ погоди!» Союзмультфильма, **шорт-лист**. Nano Banana Pro (раскадровка) + Kling 2.5 в Freepik (безлимит, €36) + Seedance 2.0 (один кадр, SJinn $50) + Suno (Syntx) + Topaz + CapCut; ~5 дней. Озвучка живая (имитация Папанова).
