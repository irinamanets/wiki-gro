## Релевантность

Источник продолжает прежнюю линию: **в основном нерелевантен прямому маркетинговому домену GRO**, но 5–7 сигналов из 50 постов имеют маркетинговую ценность как (a) обновление volatile-strict ландшафта AI-индустрии, (b) новые material для контент-плана GRO, (c) backup-source для уже зафиксированных нарративов.

**Релевантные извлечения** (в слои):

- **Anthropic compute crunch и pricing-revolt** (4532, 4543, 4550) — компания меняет прайсинг для энтерпрайза (отказ от тиров, всё сверх $20-подписки = API-цены, цены ×2–3), тестирует исключение Claude Code из Pro на 2% пользователей, выпустила постмортем о деградации Claude Code из-за смены reasoning effort high→medium и cost-optimisation промпта. Это **прямой материал** для обновления [[volatile-strict/competitor-news/openai-codex-vs-claude-code-2026-05]] и [[evolving/industry-trends/ai-corporate-race-mar-may-2026]] — операционный контекст за движением загрузок. Также сигнал, что сценарий «AI-инструмент дешевеет линейно» — миф; для GRO-нарратива это аргумент в пользу собственного vertical-продукта vs subscription stack hopping.
- **xAI сдаёт компьют в аренду + SpaceX-Cursor M&A опция $60B** (4536, 4542) — Маск как новый игрок neocloud-рынка; Cursor как первый клиент xAI Composer 2.5; опция выкупа Cursor SpaceXAI за $60B (или $10B компенсации). Сигнал консолидации coding-tools и параллельного capital-движения вокруг dev-tools. Backup-источник для [[evolving/industry-trends/ai-corporate-race-mar-may-2026]].
- **GPT-5.5 + Image 2.0 + ChatGPT Pro $100** (4524, 4541, 4545) — OpenAI feature-bundle Q2: цена API $5/$30 для базовой 5.5, $30/$180 Pro; Image Arena historical lead; «thinking capabilities» в image (gugling, до 8 консистентных картинок, 2K через API). Backup для ai-coding-tools-consolidation и ai-model-releases.
- **Yandex MiniLED TV Station + Alice Tool Calling** (4531) — Яндекс делает hardware+AI-платформа pivot: TV с YaOS X, Alice tool-calling (анализ экрана + автодёрг функций), Wi-Fi/Zigbee/Matter smart-home hub. Премиальный тир за 80–100к ₽. **Это уникальный сигнал**, не зафиксированный в других дампах — Яндекс расширяет нативно-AI-окружение в новые форматы (TV) с операторской рамкой «не голосовой помощник, а агент». Для GRO-marketing — пример того, как RU-вендор интегрирует AI в потребительский продукт.
- **LLM-on-LLM resume self-preference bias** (4558) — academic paper (arxiv.org/abs/2509.00462): когда кандидат пишет резюме через LLM и компания скринит через LLM, кандидаты с резюме на той же модели проходят отбор на **20–60% чаще** при идентичном содержании. Назван «self-preference bias» — модель узнаёт свой стиль и предпочитает «свой диалект». Это **высокорелевантно**: directly affects GRO-AI-pipeline messaging (если GRO когда-либо помогает с резюме / careers / outreach), плюс готовый hook для blog-контента про скрытые искажения AI-fit. Параллель с [[canon/marketing-frameworks/ai-text-markers-checklist]] и [[evolving/content-trends/ai-text-detection-landscape-2026]].
- **Anthropic Claude Code postmortem** (4550) — три проблемы за весну: (1) дефолтный reasoning effort незаметно сменили high→medium на месяц, (2) баг резал thinking из истории сессий >1ч, (3) системный промпт просил генерить меньше токенов. Сигнал о фрагильности AI-сервисов и правильности value-prop «свой vertical-продукт без middleware-зависимости». Полезно для backup [[evolving/industry-trends/ai-marketing-limits-2026]] и debate-content про reliability AI.
- **OpenAI Codex выручка ×2 за неделю + питомцы** (4557, 4559) — backup-источник для уже-зафиксированного [[volatile-strict/competitor-news/openai-codex-vs-claude-code-2026-05]]. Здесь: команда дурачится с тамагочи-питомцами (можно сделать гоблином); дайджест #116 явно фиксирует «выручка Codex выросла в два раза за неделю». Это согласуется с предыдущим signal'ом и дополнительный proof-point.
- **Talkie LLM 1930 эзотерика** (4555) — 13B модель натренирована на 260B токенов до 1930 года включительно. Для GRO нерелевантно прямо, но как content-hook про «AI как машина времени» / «AI и historical knowledge» — потенциальный creative spike для блога.

**Нерелевантно** (audit only, не в слои):

- Технические релизы моделей без прямого маркетингового сигнала: ERNIE Image 8B, Marble 1.1, Waypoint 1.5, Muse Spark, Qwen 3.6 35B-A3B и 27B, Kimi K2.6, DeepSeek V4 Pro/Flash, Xiaomi MiMo V2.5, Mistral Medium 3.5, Sber Kandinsky 6.0
- Инфраструктура: HF kernels репозиторий (Flash Attention готовый), eGPU на macOS, тренировка моделей на 60T токенов Claude в Meta
- Опенсорс-курьёзы: SynthID reverse engineering (взлом вотермарок Google)

- **Anthropic в патологии compute-shortage:** три параллельных сигнала за месяц — pricing revolt для enterprise (4532), тест исключения Claude Code из Pro (4543), Claude Code degradation postmortem с явным признанием cost-optimisation (4550). Все три указывают на структурную проблему ёмкости: модели Anthropic востребованы быстрее, чем компания может масштабировать compute.

- **Маск как neocloud-игрок:** xAI сдаёт компьют в аренду (Cursor — первый клиент, 4536), опция выкупа Cursor SpaceXAI за $60B (4542). Сигнал консолидации dev-tools и параллельного capital-движения через военно-космический хаб.
- **Image-генерация: новая волна:** GPT Image 2.0 (4541), Sber Kandinsky 6.0 Image Pro с editing-фокусом и Image RAG (4554), ERNIE Image 8B Apache 2.0 (4530). Сигнал, что image-сегмент входит в фазу commodity + thinking-режимы как differentiator.
- **Open-source модели Q2:** Qwen 3.6 (35B-A3B + 27B), Kimi K2.6, DeepSeek V4 Pro/Flash (1.6T-A49B + 284B-A13B), Xiaomi MiMo V2.5 Pro (1.02T-A42B), Mistral Medium 3.5 dense 128B. Темп = 1 крупный open release/неделю.
- **Yandex tool-calling в TV** — RU-vendor нативно строит AI-агента в premium-продукт (TV Station MiniLED). Это первый случай, когда зафиксирован в @ai_newz — ранее канал почти не писал про RU-вендоров.
- **LLM-on-LLM resume bias** (4558) — научный сигнал, что AI-fit content пишет «диалект модели-оценщика»; classic adverse-effect of AI rollout in HR.
