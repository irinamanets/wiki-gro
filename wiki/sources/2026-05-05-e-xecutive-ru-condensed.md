## Ключевые идеи

**Маркетинговые фреймворки (17 canon-страниц):**

- Бренд-менеджер: 4 компетенции (организация ЖЦ проекта, коммуникация, аналитика, креативность для нестандартных решений) — творческие разработки делегировать агентству
- Концепция «ценности для потребителя»: value = субъективно воспринимаемая совокупность качеств, готовность платить = только за нужные качества; B2C-формулировка через статус в референтной группе, B2B — через технологическое соответствие
- Антипаттерн «производственного ценообразования» vs правильный рыночный пайплайн (от ценности к мощностям, не наоборот)
- Defector + Loyalty Analysis CRM-фреймворк: «почему?» итеративно вместо немедленного снижения цены
- Microniche marketing: пакеты под микросегменты (Cellnet × BarclayCard, British Airways NY-London business class)
- Правило Парето 80/20 в маркетинге, рознице, sales focus + caveat правильной формулировки
- Конкурентный анализ через открытые сайты (без платного research) с 6-параметрической сеткой
- Consulting-brand-positioning: типы названий (legacy/описательные/инновационные/parent), кейс Accenture rebrand 2000 ($175M, 2677 предложений → 50 → проверка 49 стран), co-branding при equal merger vs полное поглощение
- BCG outsourcing matrix 3×3: качество компетенции × стратегическая важность → 6 решений (Покупай / Учись / Развивай / Защищай / Выделяй / Продавай)
- KPMG 5-stage restructuring: немедленные стабилизационные меры → 4-направленный анализ → план с KPIs/owners/сроками; «быстрые результаты» обязательны; anti-pattern «лоскутной» реструктуризации
- SCORE diagnostic: Symptom-Cause-Outcome-Resource-Effect — переход от проблемы к решению
- Bubble-chart prioritization (3 оси): рейтинг свойства × время × стоимость; «коэффициент проблемности» = важность / удовлетворённость; QFD-Hoshin шкала +9/+3/0/-3/-9
- «Завод → компания»: переход от производственно-центричной модели к предпринимательской (стратегия + продуктово-рыночный портфель + смена отрасли); приоритеты: финансовый/коммерческий директор > директор по производству; «информированный оппортунизм» Питерс-Уотермен
- M&A finance basics: synergy = сумма дисконтированных дополнительных потоков; goodwill = выплачено − справедливая стоимость активов (МСФО 22, 20 лет амортизации)
- 5 причин M&A: горизонтальная/вертикальная интеграция, эффект масштаба, налоги, синергия активов
- «Управленческая пирамида» Шиффмана: иерархическое руководство, запрет «через голову», нижний уровень не выносит проблемы наверх а решает
- Минимальный CRM для sales: 5 документов менеджера (профиль клиента / рабочий лист / отчёт за день / за месяц / клиентская БД) + 11 полей (статус / название / источник / ведущий / регион / контакт / категория / специализация / ценовая категория / особые условия / примечание)

**Positioning + target-audience (4 страницы):**

- «Война за внимание» (attention warfare) — глобальная высокоточная конкуренция за attention; anti-pattern одинаковых навязчивых мессаджей создаёт антипатию даже у непользователей
- Must-read 20 книг для менеджера/маркетолога (Якокка, Funky Business, Друкер, Кови, **Райс/Траут «Новое позиционирование»**, Котлер, Минцберг, Карнеги, Дойл) + COO IBS thesis: «если открываешь сверхважное в книге — у тебя нет основ или опыта»
- B2C vs B2B value сегментация: статус в группе vs технологическое соответствие; гендерная сегментация на одном продукте (мобильник: маленький полупрозрачный — для женщин ценность, для мужчин снижение)
- Internal change-resistance: страх потери и неизвестного → «снежный ком» интерпретаций → саботаж/уход; mitigation через максимально открытую коммуникацию + регулярные апдейты от непосредственных руководителей

**Industry trends (3 evolving-страницы):**

- Entertainment-трансформация бизнеса (2001 thesis, оказавшаяся прозорливой): продюсерский подход, проектный формат, мультиплатформенность одного бренда, сериализация, community building; «веб-год = 3 календарных месяца», скорость удваивается каждые 3 года
- HR как стратегический партнёр (CIPD/Ulrich): intangible активы 0-55% изменения рыночной стоимости; ключевая черта HR-партнёра по Ulrich = «персональное доверие»
- War for talents + corporate universities: 4-кратный рост КУ в США 1980-1997, McKinsey 75% инвесторов = governance ≈ финансовые показатели

**Content trends (2 evolving-страницы):**

- PR-менеджер интернет-проекта: принцип self-publishing (PR-менеджер обязательно сам публикуется → «оттачивает умение формировать новости»); ежедневный мониторинг СМИ; metric impression > click
- Контент важнее формата (pre-attention economy): «персональная страница может оказаться интереснее портала», корпоративный сайт нельзя поручать секретарше

**Competitor positioning (1 evolving-страница):**

- Open-source competitor analysis method: 6-параметрическая сетка анализа сайтов конкурентов (позиционирование / услуги / конкурентные преимущества / тон-стиль / отзывы-кейсы / акценты в новостях) + методическая ценность для GRO
