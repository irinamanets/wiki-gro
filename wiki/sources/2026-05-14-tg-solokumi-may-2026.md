# Telegram @solokumi — Кумар Виас + Соловьёв, 5–12 мая 2026

Дамп 12 постов (id 403–415) авторского Telegram-канала [@solokumi](https://t.me/solokumi) за период 5–12 мая 2026. Авторы — **Роман Кумар Виас** (серийный маркетинговый предприниматель, co-founder Refocus, EdTech-стартап с $2M ARR в Германии) и **Саша Соловьёв** (Kumar & Solo). Содержит два развёрнутых пост-гайда (FETE-фреймворк для AI-аутрича на Clay; GEO-плейбук с метриками и инструментами), два анонса конференций («Время сильных» от Бизнес-Клуба Атланты + VIBECON 13 мая), и карусель с продолжением банка скиллов для Claude Code (vol. 2 — ещё 7 скиллов).

## Релевантность

Сильно релевантно домену: 2 поста с детальным operational know-how (Clay-стек для outbound; GEO-плейбук с цифрами), 1 пост с продолжением каталога Claude Code скиллов (расширяет [[evolving/content-trends/claude-code-skills-bank-2026]]). 2 поста — анонсы конференций (фиксируется упоминание формата «Бизнес-Клуб Атланты — Время Сильных» и VIBECON как референсного формата ивента по вайбкодингу). Афферентные триггеры: маркетинговый AI-стек внутри Claude Code (пост 407) подсвечивает практику кастомных skills как замены SaaS-подписок — это важный нарратив для positioning продуктов вокруг агентов.

## Ключевые идеи

1. **FETE-фреймворк (Find → Enrich → Transform → Export)** для AI-персонализированного outbound через Clay/Claygent. Эффект — рост response rate с 1.1% до 4%+ против шаблонного outreach. Российский стек: Dadata + Контур.Фокус + СБИС + n8n + Unisender — 5–10x дешевле Clay, но требует интегратора.
2. **GEO (Generative Engine Optimization) — 6 практических механик** с метриками: правило первых 50 слов (44.2% AI-цитат — из первых 30% текста, +40% к цитируемости), FAQPage schema, llms.txt + robots.txt (GPTBot/ClaudeBot/PerplexityBot должны быть разрешены), 85% AI-цитат с чужих доменов (53% — отзовики/списки «Топ-10»), Reddit (46.7% источников Perplexity) и Wikipedia (47.9% источников ChatGPT), GEO Tracker AI для мониторинга.
3. **Метрики важности GEO**: позиция #1 в Google = CTR -38% за год; трафик из AI конвертится в 4+ раза лучше органики; регистрации из AI-источников в 10 раз чаще; Gartner прогнозирует -25% органического трафика к концу 2026.
4. **Claude Code Skills Bank — volume 2**: 7 новых скиллов (loki-mode рой 37 субагентов, Typefully cross-post, Remotion видео-из-текста, GStack от Garry Tan, ui-ux-pro-max, frontend-slides, nuwa-skill для виртуальных клонов экспертов). Расширяет существующий банк.
5. **Маркетинговый AI-стек внутри Claude Code (Refocus, German market)**: скилл генерации лендингов + скилл креативов + ассистент с фреймворками + базы знаний (replace SaaS-подписок). Пост 407 анонсирует это как кейс к VIBECON.
6. **Конференции как канал**: «Время Сильных» — практикум Бизнес-Клуба Атланты с топ-маркетологами (Воронин, Дашкиев, Спиридонов, Иванов, Амирханян, Бескромный, Носова) — формат «owners' billion-companies + practitioners». VIBECON — независимая конференция по вайбкодингу/агентам с 8 спикерами (Гершуни / cyber.fund, Ребрик / Fluently, Зуев / $1M ARR apps, Куклев / Agentcy).

Визуальная стилистика — современный SaaS / Web3 типа конференция, фиолетовая палитра — паттерн «vibecoding aesthetic».

### Посты 408–415 — карусель «Скиллы для Claude Code» (vol. 2)

Единый визуал: cyberpunk-городской фон в фиолетово-розовой палитре, белый Sans-serif заголовок, плотный текст-описание скилла, в подвале — URL GitHub-репо. 8 карточек:

**408 — обложка карусели.** «СКИЛЛЫ ДЛЯ CLAUDE CODE — ещё 7 топовых скиллов, которые превратят Клодика в универсального солдата под любую задачу: от постинга в соцсети до генерации видео».

**409 — Скилл I: LOKI-MODE — «свой рой из 37 агентов внутри Claude».** Запускает и оркеструет рой 37 субагентов в 6 свормах параллельно, каждый со своей ролью и контекстом. Работают автономно над разными кусками задачи (план → деплой → маркетинг), потом сводят результат. github.com/asklokesh/claudeskill-loki-mode

**410 — Скилл II: TYPEFULLY — «сразу постишь контент из Claude в свои соцсети».** Написал пост/тред в Claude → одной командой кидаешь в очередь на релиз в несколько соцсетей через Typefully (X, LinkedIn, Threads). Удобно для контент-завода. typefully.com/?settings=integrations-claude

**411 — Скилл III: REMOTION — «делай видео из текста одним кликом».** After Effects, где вместо мышки на таймлайне ты пишешь словами: «в первую секунду появись логотип слева, во вторую секунду — текст справа». Remotion читает и собирает готовый видеофайл. remotion.dev/docs/ai/skills

**412 — Скилл IV: GSTACK — «сборка Garry Tan, президента YCombinator».** Превращает Claude в инженерную команду из 23 инструментов под разные роли: CEO развивает продукт, Eng Manager выстраивает архитектуру, Designer ловит AI-слоп, Reviewer ищет баги, QA открывает реальный браузер для тестов, Release Engineer релизит готовый продукт. github.com/garrytan/gstack

**413 — Скилл V: UI-UX PRO MAX — «дизайн-интеллект под капотом Claude».** Внутри собрано 67 UI-стилей, 161 палитра, 57 пар шрифтов, 99 UX-правил, 25 типов графиков и поддержка 16 стеков. Подбирает дизайн под продукт и аудиторию вместо генерации шаблонов. Прокачанная версия скилла frontend-design. github.com/nextlevelbuilder/ui-ux-pro-max-skill

**414 — Скилл VI: FRONTEND SLIDES — «генеришь красивые презентации одним кликом».** Быстро генерирует презентацию из материалов в одном из 10 встроенных стилей; конвертирует PPT в нужный формат, сохраняя картинки и анимации. Для внутреннего шеринга — самое то. github.com/zarazhangrui/frontend-slides

**415 — Скилл VII: NUWA SKILL — «делай виртуальные копии экспертов».** Даёшь имя любого человека → Nuwa спавнит 6 research-агентов, которые роются в его книгах, подкастах и соцсетях. На выходе — готовый скилл «думать как X» с его ментальными моделями, методами принятия решений и паттернами речи. В репо готовые шаблоны: Джобс, Маск, Мангер, Фейнман, Навал, Талеб, Карпатый. github.com/alchaincyf/nuwa-skill
