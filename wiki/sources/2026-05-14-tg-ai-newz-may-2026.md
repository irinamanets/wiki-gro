## Релевантность

Источник продолжает прежнюю линию: **AI/ML индустриальный новостной канал**. 11 постов за 8 дней — это **узкий слой** (предыдущие дампы покрывали 50 постов за 4 недели), поэтому overlap с w15-w18 pool [[volatile/weekly-digest/ai-industry-news-w15-w18-2026]] минимальный, материал почти полностью новый.

**Релевантные извлечения** (в слои):

- **GPT-5.5 Instant новый default** (4560) — обновлённая default-модель ChatGPT, меньше галлюцинаций, короче ответы, новый memory-interface с указанием на каких воспоминаниях ответ построен. Это **второй источник** для уже зафиксированной (через @boris_again 2026-05-14) находки «GPT-5.5 Instant new default −52.5% галлюцинаций» в [[volatile-strict/industry-news/ai-model-releases-mar-apr-2026]]. Memory-interface визуализация — новая деталь, не зафиксированная ранее.
- **Anthropic арендует Colossus у SpaceX** (4561) — крупный compute-deal: 200+ тысяч GPU датацентра Маска. Контекст: датацентр был нужен для inference Grok, оказался избыточен → Anthropic снимает мощность, лимиты Pro ×2, лимиты API «в разы», параллельно интерес к программе орбитальных дата-центров SpaceX. **Это резолюция Anthropic compute crunch** из апреля 2026 (см. [[volatile/weekly-digest/ai-industry-news-w15-w18-2026|Tier A.1]] и [[volatile-strict/competitor-news/openai-codex-vs-claude-code-2026-05]]) — теперь у компании есть compute. Стратегический сигнал → новая страница `volatile-strict/competitor-news/anthropic-spacex-colossus-rental-2026-05`.
- **Claude Mythos нашёл 271 уязвимость в Firefox** (4562) — за месяц больше, чем разработчики за полтора года. Среди багов — sandbox-escape (заражение через простой клик). Все пофиксили в трёх последних релизах. Хорошие новости: «недавно переписанные с упором на безопасность» части браузера — чистые. Это **third-party operational attestation** для Mythos: модель не теоретически, а в production-сетинге Firefox реально нашла багов в 27× больше нормы. **Update** существующей страницы [[volatile-strict/industry-news/anthropic-claude-mythos-glasswing-2026]].
- **Google тестит Gemini Omni** (4564–4565) — в Gemini теперь видеогенерация, линейка Veo как самостоятельная заканчивается. Логика: Gemini уже выдаёт audio и images → добавление video — финальный шаг unified multimodal. Полный релиз ожидался на Google I/O. Сигнал для marketing-memory: **end of multi-product-line strategy у Google** — Gemini становится единым multi-modal-foundation. **Create new** `volatile-strict/competitor-news/google-gemini-omni-video-2026-05`.
- **Anthropic кредиты для third-party apps** (4571) — с 15 июня все Pro-подписчики получают кредитов на сумму подписки ($20/$100/$200) для использования сторонних приложений на Agent SDK (OpenClaw, кастомные тулы). Кредиты НЕ съедают основной лимит. **Это распределительный механизм для Agent SDK economy** — Anthropic превращает подписку в two-bucket-структуру (own product + third-party ecosystem credits). **Create new** `volatile-strict/competitor-news/anthropic-third-party-credits-2026-06`.
- **Claude Code multi-agent + /goal** (4569–4570) — Claude Code заводит multi-agent management (открытых терминалов меньше, оркестраторы поверх Claude Code напряглись) + клонирует /goal-режим из Codex (модель не останавливается до достижения цели). Это **second-source attestation для product parity** между Codex и Claude Code, **update** [[volatile-strict/competitor-news/openai-codex-vs-claude-code-2026-05]].
