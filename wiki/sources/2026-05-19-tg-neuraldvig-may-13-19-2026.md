## Ключевые идеи

1. **Промт-плотность скакнула до 18%** — 9/50 постов против стабильных 10–12% в предыдущих трёх срезах. Возможные объяснения: (а) канал увеличивает долю save-пригодного контента (промты — самый сохраняемый формат); (б) разовая флуктуация — нужен 5-й срез для подтверждения тренда. До подтверждения держим как `confidence: medium` единичный пик.
2. **Honesty-контракт расширяется от anti-flattery к anti-hallucination.** Если 3-й срез дал «brutal-honest mirror» (10639, против лести), то 4-й даёт промт против галлюцинаций (10710): «Никогда не представляй сгенерированную информацию как факт; помечай [Вывод]/[Предположение]/[Не проверено]». Это **второй вектор того же мета-запроса** — пользователи хотят, чтобы модель была честной по двум осям: не льстить и не выдумывать. Оба совпадают с позиционированием GRO («спорит, но не отказывает» + «структура, не одобрение»).
3. **RU-доступ к американским LLM API сужается через посредников.** После прямых блокировок Claude/OpenAI (май 2026) — теперь OpenRouter (агрегатор) запрещает россиянам использовать API американских компаний и режет пополнение аккаунтов. Это смещает сужение доступа с уровня вендора на уровень инфраструктурного посредника — новый вектор того же тренда.
4. **Образовательно-карьерная вертикаль доминирует в промтах** (4-й срез подряд): 10699 (поиск работы), 10716 (изучение языка), 10719 (Парето-обучение), 10726 (подготовка к собесу). Это именно сегменты ЦА GRO (карьеристы) — устойчивое подтверждение fit'а промт-формата для self-development бренд-канала.
5. **Бизнес/предпринимательские промты** (10691 «бизнес без капитала», 10721 LEGO для ГигаЧата как креативный) расширяют покрытие на сегмент 2 ЦА GRO.
6. **AI-инструментальный поток усиливается:** за неделю 4 анонса генеративных/продуктовых инструментов (Recraft, Krea 2, RevPDF, ppt-master) + 2 фичи Claude Code (agent-view, /goal). Канал работает как continuous AI-tools-radar — это контентная роль, которую GRO может частично перенять («AI-инструмент недели для самодисциплины»).
