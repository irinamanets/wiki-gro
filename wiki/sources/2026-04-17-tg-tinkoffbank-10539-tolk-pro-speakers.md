## Релевантность

Релевантно как **референс competitor event-promo механики** от крупного RU-игрока:

- Concrete механика **hybrid-event + promocode-скидка 30%** на тарифы (у Т-Инвестиций это премиальные тарифы брокера)
- Визуальный язык Т-Инвестиции для premium-сегмента (тёмно-фиолетовая палитра, групповой hero + индивидуальные портретные карточки по спикерам)
- Формат «1 hero-коллаж + 4 индивидуальные карточки-спикеры» — воспроизводимый шаблон для event-анонсов со множеством докладчиков
- Использование offline / online меток у каждого спикера — прозрачный сигнал hybrid-формата без отдельного объяснения
- Выбор spikers, сочетающий финансовую экспертизу с макро-рамкой (техно-феодализм, ИИ-трансформация капитала) — content-hook для investor-аудитории

Не извлекаем:
- Полный audit юр.дисклеймеров события (audit-only, специфика брокерского лицензирования)
- Оценка программы по существу (мы не в праве судить финансовые тезисы спикеров без дополнительных источников)

## Ключевые идеи

1. **Формат «hero-коллаж + индивидуальные speaker-карточки»** — 1 заглавный креатив собирает всех четырёх в одну композицию с общим названием события, затем следуют 4 отдельных карточки, одна на спикера. Hero выполняет attention-функцию в ленте (четыре лица + бренд + слоган), карточки-спикеры — credibility-функцию (каждая даёт одну строку регалий, одно фото, единый стиль). Переносимо на любой event с 3–6 докладчиками.

2. **Прозрачный offline/online-статус у каждого спикера в заголовке карточки** — «(онлайн)» vs «(офлайн)» сразу после имени. Это решает проблему hybrid-формата одним полем: аудитория понимает, кого можно встретить физически, а кого только по трансляции, без отдельной легенды.

3. **Stacking экспертных регалий в caption** — для каждого спикера даётся блок «что делал + что представит + где/как выступает». Формула: «автор/основатель [культовая вещь], [трек-рекорд в должности], [что конкретно разберёт на событии]». Это reusable biographical hook pattern: каждая строка даёт соискателю билета отдельный reason-to-attend.

4. **Промокод MART для -30% на тарифы** — привязка скидки не к билету на мероприятие, а к **брокерским тарифам**. То есть событие монетизируется не через ticket sales, а как lead-generation для upgrade на премиум-тариф. Ticket = call-to-action для upsell брокерского продукта.

5. **Выбор спикеров формирует позиционный нарратив** — все четверо сочетают «финансовую экспертизу» с «макро-нарративом будущего» (ИИ-трансформация капитала, технофеодализм, ИИ-visионерство, альтернативные активы). Т-Инвестиции таким образом позиционируются как площадка не для обычного retail-инвестора, а для premium-инвестора, интересующегося глобальными сдвигами — это отстройка от Сбер Инвестиций / ВТБ Инвестиций / БКС.
