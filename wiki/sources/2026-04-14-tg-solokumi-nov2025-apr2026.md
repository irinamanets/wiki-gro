## Ключевые идеи (верхнеуровневые)

- **Креатив = таргетинг.** Главная кристаллизация 2026 года. После Meta Andromeda (AI-таргетинг, запущен осенью 2025) «старая» стратегия «найди победителя и скейль» умерла; на её место встаёт «постоянно корми систему разнообразием из 15–20 креативов, обновляй цикл каждые 2 недели».
- **AI production cost для видео-креатива — $10–15 за ролик (~2 часа работы на полный цикл)** при достижимости 4 рилс в день, конверсии не хуже human-produced. Годом ранее (2024) тот же ролик стоил $200–250 и требовал недели работы продакшена.
- **Многоагентные маркетинговые системы требуют архитектуры в 3 слоя** (сенсоры/аналитики/исполнители), confidence scores на каждом выводе, triangulation-валидацию, фиксированный бюджет на токены и ROI-трекинг per-агент. Плоский подход «12 агентов общаются как попало» превращается в хаос (60+ потенциальных связей).
- **AI-native маркетолог 2026** умеет: строить креативный процесс на данных, системно анализировать крео конкурентов через ИИ-тулы, быстро тестировать сотни креативов, автоматизировать аналитику через n8n-агентов, промптить в Nano Banana/Midjourney/VEO3/Sora/Higgsfield, строить агентов на Cursor, вайбкодить лендинги через Base44/Lovable.
- **Vibecoding экосистема трёхуровневая**: L1 (prompt-to-site — Lovable, Base44, Vercel v0, Rork, Replit), L2 (IDE + агент — Cursor, Claude Code, Antigravity), L3 (ассистенты дополнения — Gemini CLI, Codex). Для маркетолога «связка Cursor + Claude Code закрывает огромный пласт задач».
- **CLAUDE.md** (5-block структура: кто/что не трогать/стиль/текущая задача/что сделано) — must-have для эффективного вайбкодинга. После 200 строк Claude начинает хуже соблюдать файл.
- **Telegram воронка не перформанс-канал.** Схема «клик → лид» почти не работает; человек должен прожить в контентном поле 2–4 недели и только потом покупать. Структура: привлечение (посевы/Telegram Ads/SMM) → контентная воронка (польза без продажи 1–2 недели) → прогрев → продажа. Бенчмарк ER по каналу: 15–20%.
- **Manychat welcome-цепочка** (запущена октябрь 2025) дала Refocus +50% к объёму лидов — простая автоматика, каждый новый подписчик получает welcome-сообщение с квалификационной логикой, вопросом номера телефона и падением сделки в CRM.
- **GEO/AEO оптимизация** (оптимизация под LLM): сайт — основной источник для ChatGPT/Perplexity/Gemini/Алисы; file LLM.txt — скам; работающий подход — страница `/for-llm` с важной инфой о бренде + публикации на площадках, которые нейросети считают авторитетными (проверить откуда они сейчас берут).
- **Claude Code /loop + Remote Tasks** (март 2026) — агент работает в фоне по расписанию, /loop крутит итерации локально, Remote Tasks выполняет на серверах Anthropic без включённого компа. Позволяет ночное расписание агентов (мониторинг кабинетов, ночной аудит, конкурентная разведка, утренний брифинг в Telegram).
- **Refocus Germany** (EdTech-проект автора) — публичная заявка о росте: $2M ARR за 10 месяцев со старта продаж, маржа в 2.5x выше чем в СНГ, цель $18M ARR к декабрю через запуск 5 новых курсов, в конце года — инвестраунд на ролл-апы локальных школ. Заявка в формате pitch-деки для инвестиционного мини-раунда.
