# МТС AdTech запустил Multi-Touch Attribution

В апреле 2026 МТС AdTech анонсировал новый инструмент сквозной атрибуции — **Multi-Touch Attribution (MTA)** `[conf:medium, src:2026-04-30]`. Цель — показать **реальный вклад каждого рекламного канала** в общий маркетинговый результат компании, приведённый к общему знаменателю. Источник анонса — пост @dnative ([[sources/2026-05-05-tg-dnative-7547-7596]] пост 7589) от **2026-04-30**.

## Методология

Инструмент использует **раздельную методологию измерения** для каждого типа канала:

| Канал | Метод сбора данных | Source |
|---|---|---|
| **Наружная реклама** | Триангуляция сигналов **базовых станций МТС** | `[conf:medium, src:2026-04-30]` |
| **Digital** | Классические **пиксели и счётчики** на сайте рекламодателя | `[conf:medium, src:2026-04-30]` |
| **Федеральное ТВ** | Через **KION** с **перевзвешиванием по Mediascope** | `[conf:medium, src:2026-04-30]` |
| **Блогеры** | Через **WhoIsBlogger** с **моделированием атрибуционного окна** | `[conf:medium, src:2026-04-30]` |

**Сверка результатов** с **Adriver, Weborama, Mediascope** для рыночной доверенности. После сверки отчёт уходит клиенту.

## Что это значит для рынка

### Уникальность подхода

Существующие attribution-инструменты в РФ (Adriver, AppMetrica, Weborama) фокусируются на **digital-only** или **отдельных каналах**. МТС AdTech первым публично заявляет о **сквозной кросс-канальной MTA**, **включая офлайн-каналы** (наружка через triangulation базовых станций — это уникальный технологический рычаг МТС, не воспроизводимый конкурентами без аналогичной телеком-инфраструктуры).

### Конкурентный контекст

- **Mediascope** держит классическое ТВ-измерение
- **Adriver / Weborama** — digital
- **WhoIsBlogger** — отдельная платформа для атрибуции блогер-кампаний
- **МТС AdTech MTA** — **агрегатор**, который собирает данные с этих 4 источников и приводит их к **единому отчёту** для маркетинг-команды клиента

### Pilot: MIUZ Diamonds × АДВ

Первый публичный pilot — **MIUZ Diamonds** (ювелирный ритейлер) с агентством **АДВ**: впервые измерили **вклад наружки в digital-конверсии** `[conf:medium, src:2026-04-30]`.

**Результаты pilot'а в посте dnative не указаны.** Наблюдаем для следующих кейсов.

## Применимость для GRO

- **GRO как продукт** — не задевается напрямую, но MTA-эпоха меняет ландшафт **measurement-ожиданий** клиентов GRO.
- **GRO как content-source для блога** — анонс **отлично подходит** как кейс для contentа про **сквозную аналитику маркетинга**. Hook: «Наружка через триангуляцию базовых станций — будущее или маркетинг-блефф?» — для предпринимательской/CMO-аудитории.
- **GRO как customer GRO в долгосрочной перспективе** — если у GRO есть multi-channel рекламные кампании, **MTA становится gold-standard измерения**, и не использовать его — значит делать решения «вслепую» по сравнению с конкурентами.
- **Hook: «Кто видит больше — тот и побеждает в маркетинге.** Если у вас нет sequel-attribution через 4 канала, ваш CMO принимает решения на половине данных.» `[conf:medium, src:2026-04-30]`

## Open questions

- **Цена/доступность МТС AdTech MTA** — в анонсе dnative не указана. Возможно, инструмент рассчитан на крупных клиентов с большими бюджетами на офлайн-наружку (что объясняет MIUZ-pilot).
- **Точность triangulation базовых станций** — не верифицирована. МТС располагает крупнейшей в РФ телеком-сетью, но triangulation в крупных городах с overlapping-радиусами может давать существенные ошибки.
- **Сроки расширения pilot'а** — следующие кейсы не названы.

## Что watch'им в ближайшие 30–90 дней

- **Следующие pilot-клиенты** (помимо MIUZ Diamonds) — будет ли запуск в FMCG, retail, beauty?
- **Цена для среднего бизнеса** — есть ли SMB-tier или это enterprise-only продукт?
- **Конкурентный ответ Adriver / Weborama / Mediascope** — выпустят ли свои MTA-предложения как агрегаторы?
- **Кейсы с ROI-цифрами** — публичные данные, насколько MTA меняет распределение бюджетов.
