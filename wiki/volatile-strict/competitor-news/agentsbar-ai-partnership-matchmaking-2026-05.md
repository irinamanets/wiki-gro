# Agentsbar — RU AI-агенты для бизнес-networking

Российский AI-стартап на ранней стадии: пользователь описывает сервису свои возможности/потребности, AI-агенты в назначенное время общаются между собой в поисках точек соприкосновения, пользователь получает отчёт + контакты. Освещён Александром Горным в посте 5057 (2026-05-08) — см. [[sources/2026-05-14-tg-startupoftheday-may-5-13-2026]].

## Базовые факты

- **Название:** Agentsbar (URL: https://agentsbar.com/) `[conf:high, src:2026-05-08]`
- **Сегмент:** AI-agent matchmaking для бизнес-партнёрств (vertical) `[conf:high, src:2026-05-08]`
- **Стадия:** очень ранняя — дизайн «программистский», монетизации нет `[conf:medium, src:2026-05-08]`
- **Активность:** 30 активных агентов на момент публикации `[conf:medium, src:2026-05-08]`
- **Основной use-case:** co-founder matching для стартаперов (по словам Горного) `[conf:medium, src:2026-05-08]`
- **Освещён в:** @startupoftheday (TG, Александр Горный), пост 5057, 2026-05-08 `[conf:high, src:2026-05-08]`

## Механика продукта

1. **Setup:** пользователь описывает в свободной форме свои возможности (что умеет делать, какие ресурсы есть) и потребности (что ищет — партнёр, ко-фаундер, supplier, customer)
2. **Agent dispatch:** в назначенное время AgentsBar запускает агентов, вооружённых описаниями участников
3. **Inter-agent communication:** агенты общаются между собой в поисках точек соприкосновения
4. **Output:** пользователь получает отчёт + контакты потенциальных партнёров

## Горный contextualization — Wise-аналогия

> «Шансы на успех призрачны, а ходить на мероприятия каждый день — довольно утомительно.»

**Counter-anchor к "AI agent matchmaking — слабая монетизация"**: Горный делает аналогию с Wise (валютообмен между путешественниками):

> «у Wise тоже 14 лет между знакомством на вечеринке и IPO прошло»

Wise origin: основатели познакомились на вечеринке, нашли точку соприкосновения, построили продукт. Сейчас Wise = ~$15B капитализация `[conf:medium, src:2026-05-08]`.

Это **double-message**:
1. **Bull case:** networking-продукты исторически выходят на $10B+ valuations
2. **Bear case temporal:** долгий горизонт (14 лет от 0 до IPO для Wise)

Поэтому 30 активных агентов / отсутствие монетизации на ранней стадии — **не bearish signal**, а early-state норма для category.

AI-agent matchmaking — **emerging category** в 2026. Существующие участники этой ниши (по данным wiki):

GRO — фитнес-приложение, **не B2B-networking**. Прямой product-relevance нет. Но **косвенный сигнал**:

### 1. Vertical AI-agent шаблоны в RU-рынке

Agentsbar — один из **первых RU AI-стартапов с peer-to-peer agent topology**. Если шаблон удержится — это означает, что **в RU быстро формируется agent-friendly консьюмерский слой**.
