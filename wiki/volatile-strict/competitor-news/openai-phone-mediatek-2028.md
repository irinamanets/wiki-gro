# OpenAI smartphone — план 2028

## Факт

По словам инсайдеров, OpenAI может выпустить **собственный smartphone**, где **все приложения будут заменены ИИ-агентами**. `[conf:low, src:2026-04-27]` Через @breakingtrends ([[sources/2026-05-05-tg-breakingtrends-apr21-may05]] пост 16696) от 27 апреля 2026.

**Партнёры по разработке (по словам инсайдеров):**
- MediaTek (chipset)
- Qualcomm (chipset / modem)
- Luxshare (manufacturing)

**Целевой год серийного производства:** 2028. `[conf:low, src:2026-04-27]`

**Мотивация (по словам инсайдеров):** OpenAI стремится **преодолеть ограничения**, которые Apple и Google накладывают на разработчиков (правила App Store, ограничения системных API, доли в платежах).

`[conf:low, src:2026-04-27]` — **низкий confidence потому что:** (1) только инсайдерские оценки, (2) запуск в 2028 = >2 года в будущем, (3) три партнёра одновременно — MediaTek + Qualcomm + Luxshare — необычная комбинация (обычно chipset один из двух), что может означать как complex-проект, так и слух с ошибочными деталями.

## Что это значит

**1. AI-нативный smartphone — потенциальный новый product-category.** До этого AI-функции встраивались в существующие смартфоны (Apple Intelligence, Galaxy AI, Pixel AI). OpenAI же предлагает **AI-first архитектуру**, где приложения = агенты, а не приложения с AI-функциями.

**2. Реакция против platform-tax.** OpenAI опирается на ChatGPT-мобильное приложение, которое подчиняется правилам Apple/Google. Собственный smartphone позволит OpenAI **обходить App Store** и иметь свои API доступа к камере, микрофону, контактам — без ограничений.

**3. Параллель с Humane AI Pin / Rabbit R1.** В 2024–2025 годах несколько стартапов пытались выпустить AI-нативные устройства (Humane AI Pin — провалился, Rabbit R1 — узкая аудитория, Friend — wearable). OpenAI как игрок с миллиардной выручкой имеет гораздо больше шансов вывести продукт на рынок, но **не гарантировано** — рынок hardware-AI устройств 2024–2025 показал, что узкий формат не работает, нужен полноценный smartphone.

## Импликации

**Для маркетинговой стратегии:**
- 2028 = **долгосрочный watch list**, не actionable now. Использовать только как **far-future inflection signal**, не как конкретный план.
- Если запуск состоится, AI-нативный смартфон может перевернуть mobile-маркетинг: **рекламодатели** работают не с Google/Apple Store, а с OpenAI Agent Marketplace. Это потенциально новый distribution-канал.

**Для GRO:**
- Не affect short-term. Watch только; до 2028 года GRO как product не должен закладывать AI-нативную мобильную платформу как условие распространения.
- При выходе продукта — пересмотр **mobile distribution strategy**: будет ли GRO как агент в OpenAI Agent Marketplace? Или просто mobile приложение через PWA / web?

## Caveats

- **Slух уровня инсайдеров.** До официального анонса OpenAI — не использовать в content. Use только в internal strategy notes.
- **2028 далеко.** За 2 года OpenAI может: запустить, отменить, запустить с задержкой, выкупить компанию (Humane?), пойти другим путём.
- **MediaTek + Qualcomm + Luxshare** — необычная комбинация. Если это правда, проект complex; если слух — детали могут быть неверны.
