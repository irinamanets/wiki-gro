# OpenAI ChatGPT Spreadsheets — расширения для Excel и Google Sheets всем (6 мая 2026)

6 мая 2026 OpenAI открыла расширения ChatGPT для **Microsoft Excel** и **Google Sheets** **всем пользователям, включая без подписки**. `[conf:high, src:2026-05-06]`

## Что выпустили

**ИИ-помощник в расширении** делает:

- **Создание файлов с нуля** — формулирует структуру по запросу
- **Форматирование** — стили, цвета, выравнивание
- **Визуализация данных** — графики, диаграммы
- **Помощь с формулами** — генерирует или объясняет

**Уровень модели и глубина рассуждений зависит от подписки** `[conf:high, src:2026-05-06]` — это **freemium dark pattern**: базовый функционал — всем, реальная мощность — только Plus/Pro.

## Маркетинговое значение

### 1. OpenAI идёт в B2B office-stack по бесплатной воронке

ChatGPT в Excel и Google Sheets для всех — это **freemium gateway в B2B-сегмент**. Корпоративный пользователь Microsoft 365 / Google Workspace получает доступ к ChatGPT-фичам, не платя OpenAI напрямую — но **глубокая часть рассуждений** требует Plus ($20/мес) или Pro ($100/мес).

**Гипотеза:** OpenAI **расширяет верхнюю воронку corporate-users** через бесплатный access. Чем больше людей в офисах попробуют ChatGPT в Excel/Sheets, тем больше конвертация в IT-департаментские закупки enterprise-лицензий.

### 2. Прямая угроза Microsoft Copilot

Microsoft Copilot для Excel позиционируется как **платная встроенная фича** Microsoft 365 — $30/мес/пользователь. **ChatGPT-расширение делает то же самое бесплатно** (с лимитированной моделью). Это создаёт когнитивную проблему для Microsoft: «зачем платить за Copilot, если в Excel уже работает ChatGPT?».

**Контекст:** Microsoft является крупнейшим инвестором OpenAI и одновременно конкурирует с ним через Copilot — это **co-opetition паттерн**. ChatGPT Spreadsheets — сигнал, что **OpenAI готова продавать в обход Microsoft sales channels** (см. [[evolving/industry-trends/ai-corporate-race-mar-may-2026]] update про OpenAI «The Development Company»).

### 3. Контекст для GRO как контент-сервиса

Excel / Google Sheets — **canonical-product у малого бизнеса и фрилансеров**. Многие SMB-клиенты GRO как пользователи приложения для тренировок — тренируются между задачами в Excel. **Контент-hook:**

- «AI вокруг вас уже в Excel — нужны не AI-курсы, а навык работать рядом с ним»
- «ChatGPT в табличке + GRO в перерыве — формат продуктивности 2026»

### 4. Часть мая 2026 release-wave

Часть hyperactive недели OpenAI 5-7 мая:
- 5 мая — GPT-5.5 Instant default ChatGPT
- 6 мая — Spreadsheets для всех
- 7 мая — 3 аудиомодели Realtime API (см. [[volatile-strict/competitor-news/openai-realtime-audio-models-2026-05]])

Темп: один большой релиз в день за три дня подряд. Это компетитивный ответ на anthropic-deepseek-moonshot-press release wave.
