# Клубы лояльности Тинькофф (пилот 2024)

В 2024 году Т-Банк запустил **«Клубы лояльности»** — внутреннюю витрину FMCG-брендов в банковском приложении с ступенчатым кэшбэком (5% → 20%) при масштабе аудитории 40M клиентов. Пилот с пятью брендами дал значимый uplift метрик, что сделало этот формат каноническим референсом B2B2C-партнёрств в российском retail-finance. `[conf:high, src:2024-01-01]`

## Метрики пилота (5 брендов)

| Метрика | Uplift | Источник |
|---|---|---|
| Средний чек | **+20%** | `[conf:high, src:2024-01-01]` |
| Оборот по товарам участников | **×2** | `[conf:high, src:2024-01-01]` |
| Уникальные позиции в чеке | **+40%** | `[conf:high, src:2024-01-01]` |

## Детализация по брендам

**Synergetic club:**
- Средний чек: **+20%** `[conf:high, src:2024-01-01]`
- Уникальные позиции в чеке: **+17.5%** `[conf:high, src:2024-01-01]`
- Количество купленных товаров: **+19.2%** `[conf:high, src:2024-01-01]`
- Частота покупок на клиента: **+8.4%** `[conf:high, src:2024-01-01]`

**«Добрый» club:**
- Средний чек: **×2** относительно контрольной группы за период действия программы `[conf:high, src:2024-01-01]`

## Структура программы

- **Витрина:** часть Tinkoff Выгода (унифицированная B2B2C-платформа: кэшбэк + рассрочки + промокоды + диджитал-сэмплинг + клубы лояльности).
- **Кэшбэк:** ступенчатый, от 5% до 20% в зависимости от уровня клуба. `[conf:high, src:2024-01-01]`
- **Targeting:** через transactional-историю Т-Банка → точный таргетинг по реальному покупательскому поведению (не только демография).
- **Surfaces:** push-уведомления, сторис в банковском приложении, fullscreen-баннеры, чековое распознавание для трекинга покупок вне партнёрских интеграций.

## Value proposition для брендов

1. **Готовая 40M аудитория без построения собственного CRM** `[conf:high, src:2024-01-01]`.
2. **Чековое распознавание** — бренд может реагировать на покупки даже без интеграции с retailer'ом.
3. **Quick launch** — старт акции без длительного технического онбординга.
4. **Closed-loop attribution** — Т-Банк видит и таргетинг, и фактическую покупку (банк = и channel, и attribution-инструмент).

## Почему эта программа — canon-strict

Программа — **исторический факт** с конкретными числовыми метриками пилота. Inline `[conf:high, src:2024-01-01]` маркеры обязательны на каждом числе. Methodology (B2B2C-партнёрство через единую банковскую витрину) — стабильная структура, переносимая на любой digital-банк с массовой аудиторией и transactional-data; конкретные числа +20% / ×2 / +40% — anchor-точки для бенчмаркинга.

## Связь с эволюцией T-Bank ecosystem-play

Клубы лояльности — **финальная нота 2024 года** в исторической цепочке T-Bank platform-expansion:
- 2019: Voice AI (Олег) → внутреннее обслуживание
- 2020: Вселенная Тинькофф ([[canon-strict/historical-campaigns/tbank-vselennaya-tinkoff-viral-2020]]) → viral marketing-актив
- 2021: VoiceKit → продажа voice-AI как B2B-инструмента
- 2023: Долями (BNPL) → расширение в pay-later сегмент
- **2024: Клубы лояльности → монетизация банковской аудитории через FMCG-партнёрства**
- 2026: Город / Топливо / Т-Образование / Сделка / Доли как 5+ sub-brand'ов ([[evolving/industry-trends/tbank-corporate-platform-stack-2026]])

## Применение для GRO

1. **Кэшбэк-партнёрства в фитнес-вертикали.** GRO может стать **витриной для FMCG/healthy-eating брендов** (как Т-Банк для Synergetic, «Добрый»): пользователь покупает протеин/спортпит/healthy-snacks через партнёрский слой GRO → бренд платит кэшбэк, GRO монетизирует аудиторию без увеличения подписочного чека.
2. **Ступенчатый кэшбэк (5–20%) работает.** Это не процент-приманка, а структура retention: чем выше уровень клуба, тем выше кэшбэк → инцентив для апгрейда подписки. `[conf:high, src:2024-01-01]`
3. **Чек-распознавание как infrastructural moat.** Если GRO добавит OCR чеков (или интеграции с продуктовыми ритейлерами), это даёт **closed-loop attribution** независимо от рекламной экосистемы партнёра.
4. **Quick launch как UVP для партнёров.** «Готовая аудитория без CRM-построения» — критически важная формулировка для B2B-pitch'а. GRO может использовать ту же риторику для брендов, рассматривающих fitness-вертикаль.
