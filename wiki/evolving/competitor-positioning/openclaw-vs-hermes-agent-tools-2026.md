# OpenClaw vs Hermes — два полюса open-source AI-агентов

Качественное сравнение двух open-source инструментов для запуска AI-агентов, разобранное founder-voice **Романа Кумара Виаса** ([[sources/2026-05-19-tg-solokumi-416-openclaw-vs-hermes|@solokumi пост 416, 2026-05-14]]). Релевантно как **adjacent-tool positioning**: ГРО — продукт в категории «AI для продуктивности», и понимание того, как позиционируются массовые DIY-агентные тулы, нужно для дифференциации и для контент-нарративов.

`evolving`, а не canon: конкретные тулы, их фичи и экономика быстро меняются; описания в источнике — single-source promo-grade. TTL soft 180 дней. Все числовые характеристики тулов идут с атрибуцией к автору и `confidence: low–medium` — это **не верифицированные benchmark'и**, а пересказ возможностей в промо-формате.

## Основная ось дифференциации

Автор раскладывает рынок DIY-агентов по двум полюсам:

| | **OpenClaw** | **Hermes** |
|---|---|---|
| Главная сила | Широта интеграций «из коробки» | Глубина + самообучение |
| Кто собрал | Инди-направление, массовый продукт | «Целая лаборатория», не один разработчик |
| Память | Сессионная (как обычный ассистент) | Трёхслойная (сессия + долгосрочные факты + Skill Memory) |
| Обучение на опыте | Нет (переспрашивает заново) | Да — пишет Skill Document после каждой задачи |
| Базовая модель | Раньше Claude → теперь GPT | Через OpenRouter, 200+ моделей `[conf:low, src:2026-05-14]` |
| Удешевление | ClawRouters (auto-routing на дешёвую модель) | Дешёвый хостинг (VPS $5/мес) `[conf:low, src:2026-05-14]` |
| Идеальный сценарий | Операционка в мессенджере | Контент / трендвотчинг / «второй мозг» |

## OpenClaw — широта и дистрибуция

- **Интеграции:** 50+ платформ из коробки `[conf:low, src:2026-05-14]` (Telegram, Discord, Slack, WhatsApp, Email, Binance, OKX), 13000+ скиллов в официальном реестре clawhub `[conf:low, src:2026-05-14]`.
- **Cost-routing:** тулза **ClawRouters** автоматически отправляет запрос самой дешёвой справляющейся модели → заявленная экономия 70–90% «без потери качества» `[conf:low, src:2026-05-14]`. Это операционализация того же тезиса, что лежит в [[evolving/industry-trends/ai-agent-economy-2026|экономике AI-агентов]] — стоимость inference как управляемая переменная, а не фиксированный налог.
- **Юзкейсы (по автору):** личный ассистент в мессенджере (напоминания → события календаря); мультиканальный агент (Telegram + email + мониторинг лидов в CRM + сбор метрик рекламных кабинетов из одного места); крон-автоматизации («каждый понедельник собирай метрики из Google Analytics и присылай саммари»).
- **Вывод автора:** «если нужен агент, который живёт в мессенджере и закрывает операционку — выбор OpenClaw».

Это согласуется с уже задокументированным **distribution-first** прочтением OpenClaw (Табунов в [[evolving/industry-trends/agent-first-world-openclaw-2026|agent-first мир]]): сила OpenClaw — встроенность в каналы, где пользователь уже сидит, а не превосходство capability.

## Hermes — самообучение как дифференциатор

- **Skill Document mechanic:** после каждой задачи агент пишет себе markdown-файл с тем, что сработало/не сработало и какой подход использован; в следующий раз похожую задачу делает лучше и быстрее. Заявление автора: «через 3 месяца знает ваш workflow лучше нового сотрудника» `[conf:low, src:2026-05-14]`.
- **Трёхслойная память:** (1) история сессии, (2) долгосрочные факты о пользователе между сессиями, (3) Skill Memory с накопленным опытом решения задач. Неиспользуемые навыки архивируются через 90 дней `[conf:low, src:2026-05-14]`, чтобы агент «не засорялся устаревшим опытом».
- **Модели и хостинг:** по подписке Claude уже не работает, но через OpenRouter — 200+ моделей `[conf:low, src:2026-05-14]`, переключение командой `hermes model`. Живёт на ноуте или на VPS за $5/мес `[conf:low, src:2026-05-14]`.
- **Юзкейсы (по автору):** контент и соцсети (через пару недель знает tone of voice / аудиторию / форматы — драфты без долгой допилки); трендвотчинг (мониторит конкурентов неделями, сам замечает важные изменения, не ждёт команды); «личный второй мозг» (помнит решения/предпочтения/контекст проектов между сессиями); подготовка к созвонам (помнит историю всех прошлых разговоров с клиентом).

Концепция **Skill Document / Skill Memory** прямо рифмуется с [[evolving/content-trends/claude-code-skills-bank-2026|банком скиллов Claude Code]], который тот же автор раскрывал ранее: skill как переносимая, накапливаемая единица знания агента — это сквозной нарратив @solokumi.

## Почему это важно для GRO-позиционирования

1. **«Самообучающийся агент» как product-narrative-маркер.** Hermes продаётся через идею «агент, который накапливает контекст про тебя и не переспрашивает». Это **тот же эмоциональный crux**, на котором держится позиционирование любого persistent-AI-продукта. Для ГРО это сигнал: «персонализация через память» — мейнстримящийся ожидаемый атрибут, не дифференциатор сам по себе; дифференцировать надо тем, что ГРО делает с этой памятью (дисциплина/привычка, а не «делает работу за тебя» — см. [[canon/marketing-frameworks/agent-vs-saas-pricing-arbitrage|agent vs SaaS arbitrage]] раздел «когда arbitrage не работает»).
2. **DIY-агент vs продукт.** OpenClaw/Hermes — это «собери агента сам». ГРО — готовый продукт. Контр-нарратив для ГРО: массовому пользователю не нужен агент-конструктор с VPS и `hermes model`, ему нужен результат «из коробки». Это смежно с [[evolving/competitor-positioning/onsa-robin-ai-chief-of-staff|team-resident AI]] (продукт > feature-конструктор) и с [[evolving/industry-trends/ai-solopreneurship-window-2026-2029|окном соло-фаундеров]] (DIY-агенты как инструмент именно для одиночек/технарей).
3. **Контент-сырьё.** Пара «OpenClaw для операционки vs Hermes для контента/трендвотчинга» — готовая рамка для объясняющего поста про «как выбрать AI-агента под задачу» (см. content-pattern: [[evolving/content-trends/ai-tool-comparison-reaction-gate-format]]).

## Caveat по достоверности

Все технические числа (13000+ скиллов, 70–90% экономии, 200+ моделей, 90-дневная архивация, VPS $5) — заявления автора в промо-формате, не верифицированы независимо. Часть номенклатуры пересекается с реальными продуктами, задокументированными в вики, но описания могут быть авторским упрощением. Цитировать в GRO-контенте только как «по словам Кумара Виаса» / «по описанию @solokumi». `confidence: medium` для самой рамки сравнения (она логична и от verified-эксперта), `low` для конкретных цифр.
