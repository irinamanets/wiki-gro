# Т-Банк «Топливо» как loyalty-card aggregator

Наблюдаемый стратегический сигнал: Т-Банк позиционирует сервис **«Топливо»** не как «оплата бензина через приложение», а как **aggregator партнёрских loyalty-программ**. Май 2026 — интеграция программы лояльности Газпромнефть «Нам по пути» прямо в Топливо. Pattern: банк → superapp → **aggregator-platform**.

Base-кейс: [[sources/2026-05-26-tg-tinkoffbank-may-19-26-2026]] — посты [@tinkoffbank/10742–10745](https://t.me/tinkoffbank/10742) (25 мая 2026).

## Стратегический сдвиг: от сервиса к aggregator'у

### До (Топливо как сервис)

| Параметр | Значение |
|---|---|
| **Что делает** | Pay-at-pump через приложение |
| **Value-prop** | Не выходить из машины, выбирать АЗС на карте, кэшбэк от Т-Банка |
| **Партнёры** | Сеть АЗС-партнёров |
| **Тип отношений** | Acquirer-Merchant (Т-Банк как payment processor) |
| **Brand-position** | Сервисное приложение Т-Банка |

### После (Топливо как aggregator)

| Параметр | Значение |
|---|---|
| **Что делает** | Pay-at-pump + хранит loyalty-карты партнёров |
| **Value-prop** | «Двойная выгода»: бонусы от партнёра + кэшбэк от Т-Банка |
| **Партнёры** | АЗС-сети как loyalty-program-issuers |
| **Тип отношений** | Platform-Participant (Т-Банк как ecosystem-orchestrator) |
| **Brand-position** | **Контейнер для loyalty-карт нескольких партнёров** |

**Conceptually:** Т-Банк превращается из «банка с приложением» в **«операционную систему для loyalty-программ»**. Партнёрские бонусы существуют **внутри Т-Банка**, не в отдельных приложениях АЗС.

## Aggregator-параллель с Доли (BNPL)

Этот ход — **повторение паттерна Доли** ([[evolving/competitor-positioning/tbank-doli-bnpl-sub-brand-palette-lavender]]):

| Pattern | Доли (BNPL) | Топливо (Loyalty) |
|---|---|---|
| **Initially** | T-Bank BNPL-сервис | T-Bank fuel-payment-сервис |
| **Then** | + ОТП-Банк "Давай делить" | + Газпромнефть "Нам по пути" |
| **Future** | + Other BNPL providers | + Other АЗС loyalty programs (Лукойл, Роснефть) |
| **Net effect** | Т-Банк = BNPL-aggregator (объединяет all BNPL для пользователя) | Т-Банк = fuel-loyalty-aggregator |

**Это явная strategy:** Т-Банк делает себя **single-pane-of-glass** для разных vertical-loyalty-программ. Пользователь больше не носит 10 loyalty-карт или приложений — они все в Т-Банке.

## Маркетинговая мессаджинг

Caption Газпромнефть-кампании (#10742): «Заправляетесь на Газпромнефти и до сих пор платите на кассе? Тогда у нас есть **две новости — хорошая и плохая**. Плохая — вы упускаете бонусы. Хорошая — можно добавить карту лояльности прямо в приложении Т-Банка. С картой лояльности можно не только копить и списывать бонусы, но еще и продолжать получать кэшбэк от сервиса «Топливо». **Получается двойная выгода**».

**Marketing-frame:** «двойная выгода» = ranned-and-stacked benefit:
- **Partner-bonuses** (Газпромнефть) — традиционная loyalty
- **+ Bank-cashback** (Т-Банк) — добавляется свыше

Frame подразумевает, что **обычно** один из этих benefits = lost. Т-Банк решает эту проблему. Это не зрительные сравнения с конкурентами (Сбер, ВТБ), а сравнение с «вы сейчас платите на кассе и теряете бонусы».

### Frictionless onboarding

Кампания включает **4-шаговый instructional carousel** (#10744):
1. Заходите в «Топливо»
2. Открываете меню → «Карты лояльности»
3. Выбираете «Газпромнефть»
4. Вводите номер телефона и код из СМС

**4 шага = sweet spot frictionless onboarding** (≤5 шагов для mobile-flow).

И отдельный карусель (#10745) с **UI demo** «Как использовать бонусы»: показывает приложение в moment-of-use → reduces fear of «как это работает в реальности».

## Visual-палитра — отход от T-Bank yellow

Все 4 креатива (#10742–10745) — в **light-blue palette** (Газпромнефть brand-color), не T-Bank yellow.

**Pattern:** Когда Т-Банк позиционирует партнёрский продукт в своём приложении, **уступает primary-color partner'у**. Это:
- **Partner-respect signal** (yellow-block override, как с Utair в апреле)
- **Co-brand visualcue** — пользователь сразу видит, что это **Газпромнефть-продукт inside Т-Банка**
- **Cognitive-anchor** — light-blue ассоциируется с Газпромнефтью

**Т-Банк yellow** появляется только как **«+» icon** (add-card affordance) и в bottom CTA-bar — accents, не dominant.

Это **6-я observable variation** consumer-yellow protocol (после Utair partner-color override): partner-product positioned inside Т-Банк = partner-color dominant.

## Стратегическое значение для Т-Банка

1. **Switching-cost для пользователя.** Когда пользователь добавил карту лояльности Газпромнефть в Т-Банк, у него **снижается готовность переключиться на другой банк** (потому что нужно ре-registering loyalty cards в новом приложении).
2. **Locking-out конкурентов.** Если другие банки **не имеют** инфраструктуры loyalty-aggregation, Т-Банк становится **default-выбор для multi-loyalty-users**.
3. **Data на partner-spending patterns.** Т-Банк теперь знает, сколько пользователи тратят у Газпромнефти, какой объём бонусов — это **data-моат**.
4. **Ecosystem-lock.** Когда добавятся 5+ АЗС-программ → Т-Банк становится **infrastructural standard** в fuel-loyalty domain.
5. **Cross-vertical playbook.** Этот pattern reусableusable: можно добавить **продуктовые сети** (Пятёрочка, Магнит) → grocery-loyalty-aggregator. **Аптеки** (36.6, Ригла) → pharma-loyalty-aggregator. **И т.д.**.

## Конкурентный landscape

| Игрок | Loyalty-aggregation strategy |
|---|---|
| **Т-Банк** | **Топливо + Доли** — два vertical-aggregator'а уже live; платформенная стратегия explicit |
| **Сбер** | СберПрайм + СберСпасибо — единая loyalty, не aggregator (закрытая система) |
| **ВТБ** | Multi-pay приложение, но без loyalty-aggregation |
| **Альфа** | Mobile-only, без agg-стратегии |
| **Газпромбанк** | Consumer-focused, no agg play |

Т-Банк — единственный из RU-банков, кто **explicitly строит aggregator-стратегию** на разных vertical'ах. См. также [[evolving/industry-trends/tbank-corporate-platform-stack-2026]].

## Для GRO — что унести

1. **Aggregator > pure-play** в smb или consumer-fitness. Если GRO — это **только subscription-тренировки**, есть risk одиночного продукта. Если GRO становится **aggregator'ом fitness-related services** (тренировки + nutrition + recovery + community), это **moat-усиление**.
2. **Partnership-led aggregator.** GRO может **ничего не строить сам**, а интегрировать существующие fitness/wellness-сервисы как «партнёры». Т-Банк не построил **Газпромнефть-loyalty-program** — он его **подключил**.
3. **Frictionless onboarding.** 4 шагового onboarding для добавления любого нового сервиса/партнёра.
4. **Partner-color respect.** Если интегрировать партнёрский сервис, его branding должен **dominate** в той зоне — не overwriting GRO-branding.
5. **Cross-vertical playbook.** Pattern reусable — сначала тренировки, потом nutrition, потом recovery, потом community-events.
