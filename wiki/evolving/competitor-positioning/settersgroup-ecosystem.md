# SETTERS Group — экосистема

Одна из ведущих креативных экосистем РФ, построенная вокруг агентства SETTERS. Не прямой конкурент GRO, но **значимый актор на рынке креативного маркетинга** — источник трендов, фреймворков, исследований и нарратива. Для GRO важен в двух ролях: (1) возможный партнёр/референс для креатива, (2) индикатор того, «что считается передовой практикой» в русском маркетинге 2026.

Источник — [[sources/2026-04-14-hutzp-telegram-20260402-0414|дамп канала @hutzp]]: посты 3427, 3428, 3438, 3441, 3450, 3455, 3463. `confidence: medium` — все данные из одного дампа, без перекрёстной проверки по другим источникам.

## Состав экосистемы

### SETTERS (материнское агентство)

- **Категория:** full-service creative agency.
- **Сооснователи:** Евгений Давыдов, Александра Жаркова (и другие). Из поста 3463 — сотрудница отмечает 2-летний юбилей работы с Жарковой и Давыдовым, что косвенно подтверждает действующий co-founding partnership.
- **Публичная позиция:** культовое креативное агентство «новой волны» русского маркетинга, известное брендингом, SMM-стратегией и продюсированием контента для крупных клиентов.
- **Неявный signals:** высокий уровень внутренней культуры («Делай как считаешь нужным», «Я тебе доверяю»), низкий микроменеджмент, «человеческий мэтч» как критерий найма (из поста 3463).

### SETTERS Media

- **Категория:** медиа-бренд + издательская студия в составе группы.
- **Продукт:** тренд-репорты, исследования, контент о маркетинге, культуре, работе. В дампе — тренд-репорт «Будущее работы» (апрель 2026), полная версия опубликована через канал [@huggabletalents/2631](https://t.me/huggabletalents/2631). См. [[evolving/industry-trends/future-of-work-trends-2026]] и [[canon/marketing-frameworks/organize-to-value-mckinsey]].
- **Визуальный код:** «SM»-ватермарк в правом верхнем углу всех карточек, минималистичный дизайн с градиентами неба и поля, Space-Mono для номеров слайдов, классическая grotesque для заголовков.
- **Контентная стратегия:** preview-карусели в Telegram (6 карточек) → CTA на полный PDF → дистрибуция через партнёрский канал @huggabletalents.

### REB8T (цифровая студия)

- **Категория:** digital / web-studio.
- **Входит в SETTERS Group** (из поста 3450: «наша цифровая студия REB8T»).
- **Юрлицо:** ИП Солдатов Александр Андреевич, ИНН 780443776385 (по erid-маркировке в посте 3450).
- **Managing director / контакт для заявок:** `@yarchi23` (Яр).
- **Канал студии:** [@webzdelnya](https://t.me/webzdelnya).
- **Кейсы (март–апрель 2026):**
  - **Мамисон** (mamison-resort.ru) — сайт горнолыжного курорта в Северной Осетии с интерактивной картой, статусами трасс/канаток, инфой по отелям/ресторанам/мастер-классам, **ИИ-помощником** для навигации.
  - **ВкусВилл Лидер** — промо-лендинг образовательного курса для руководителей/топ-менеджеров. Двустраничная структура: путь пользователя + треки повышения квалификации.
  - **Yardo** — корпоративный сайт девелопера жилой/коммерческой недвижимости в стиле швейцарской школы плакатного дизайна.
  - **Random Coffee** — редизайн после вступления в SCC, сокращение с 13 страниц до 4, 3 основных направления.
  - **REB8T STUDIO** (rebooot.me) — собственный сайт, «футуристичные UI + отсылки к старой компьютерной эстетике».
- **Стилистика:** типографика с акцентом на dense display-шрифты, тёмный бэкграунд, кейсы в формате «монохромная обложка + 2–3 скриншота + 1 tablet-mockup».

### Сообщество «Изионист»

- **Категория:** закрытое интеллектуальное комьюнити + журнал + ивенты.
- **Основатель:** Евгений Давыдов.
- **Домен:** `easyon.ist`.
- **Формат:** регулярные встречи-монологи экспертов с NPS-замером (из поста 3427: первая встреча с Сашей Пановым получила 10/10). Стратегический партнёр встреч — **Т-Бизнес**.
- **Продукт:** журнал «Изионист» — печатное издание, где выходят исследования и материалы. Номер весны 2026 посвящён «русскому культурному коду» и содержит результаты исследования **Synopsis Group** (1000+ респондентов), см. [[evolving/industry-trends/russian-cultural-code-branding-2026]] и [[canon/marketing-frameworks/narrative-as-brand-currency]]. Дистрибуция: Подписные издания (`podpisnie.ru`), Яндекс.Маркет.
- **Расширенный платный продукт (2026-05):** сборник «**Культурный код: инструкция к применению**» — 3-в-1 цифровой продукт по тому же исследованию Synopsis Group, продаваемый через Telegram-бот [@easylecturebot](https://t.me/easylecturebot?start=link_RqRfGK2FUz) (UTM-ссылка с affiliate-tracking конкретного канала-источника). Состав: ~100 слайдов детальной аналитики (расширение того, что в Telegram-карусели публикуется как 2-слайдовый превью) + диджитал-журнал «ИЗИОНИСТ» + тренд-репорт с примерами успешного применения «русского культурного кода» в проектах. Это **closed-loop monetization** thought-leadership-контента: исследование производится in-house → используется как магнит для Telegram-канала → tail-monetization через продажу сборника (см. [[sources/2026-05-14-tg-hutzp-may-2026-bundle]]). Паттерн **продуктизации thought-leadership** — ценный референс для GRO.
- **Регулярный event-продукт «интеллектуальный клуб» (детализация 2026-05):** offline-встречи с ротацией экспертных гостей, специально подбираемых **НЕ из креативной/маркетинговой индустрии** — «у нас в комьюнити состоят не только ребята из креатива, поэтому подсвечиваем мы не только темы креативной индустрии, чтобы смотреть на привычные вещи под новым углом». Наблюдаемые гости: **Денис Бобков** (ресторатор, основатель Masa Madre / Carniceria vino / Bambule / Tabi izakaya — встреча + экскурсия в соляные подвалы «Солянки», 2026-05-14) и **Айрат Багаутдинов** (основатель «Глазами инженера» — экосистема экскурсионных бюро; встреча «Как читать архитектуру», 2026-05-21 `[conf:high, src:2026-05-19]`). Отдельные встречи **co-sponsored Т-Бизнесом** (ad-marked). Двухконтурная воронка: free-trial event через [@easylecturebot](https://t.me/easylecturebot?start=link_mWvsneYyiJ) → платное членство через paywall. Полная анатомия формата — [[evolving/content-trends/founder-intellectual-club-event-format]].
- **Ценность для рынка:** Изионист действует как think-tank/nudge-tank для русского брендинга, задаёт рамку «новой идентичности» и «собственного языка» для российских компаний.

### SETTERS EDUCATION (образовательная единица)

Пятая единица экосистемы, ставшая видимой в дампе [[sources/2026-05-19-tg-hutzp-may-14-19-2026|@hutzp 3528–3543]] (раньше в вики фигурировали SETTERS-агентство, SETTERS Media, REB8T, Изионист, но не EDUCATION).

- **Категория:** EdTech — B2C онлайн-курсы + B2B corporate-learning.
- **B2C-флагман:** курс **«Креативное лидерство»** (5 лет на рынке), спикеры **Даша Золотухина** + **Саша Жаркова**, старт потока 25 мая 2026 `[conf:high, src:2026-05-18]`. Продуктовое позиционирование: alumni-community as moat (общий чат + оффлайн-встречи + совместные проекты выпускников), профессионально снятые лекции с cognitive-load-aware длиной, отдельная LMS-платформа с трекингом прогресса + конспектами лекций, peer-to-peer практика как заявленный главный USP. Контент платформы включает фреймворк «Creator: ты = создатель» (reactive→creative reframe) — см. [[canon/marketing-frameworks/creator-leadership-paradigm-shift]].
- **B2B-направление:** corporate-learning для клиентов («как мы выстраиваем корпоративное обучение для наших клиентов» — статья на secrets.tbank.ru). Активно нанимает: вакансия «Менеджер по развитию B2B-направления» (middle, опыт B2B-продаж полного цикла от 2 лет, гибрид/Москва) `[conf:high, src:2026-05-14]`.
- **Рекрутинговый суб-бренд:** **«A-Teams by SM»** (SETTERS Media) — найм оформляется как brand-content в фирменном тёмно-зелёном визуале и публикуется в author-канале (recruitment-as-content, см. [[evolving/content-trends/telegram-author-channel-patterns]]).
- **Значение для GRO:** прямой EdTech-референс для GRO Интенсива ([[canon/product-knowledge/gro-intensive]]) — структура позиционирования онлайн-курса (community moat + production + LMS + peer-to-peer) переносима практически 1-в-1.

## Характер деятельности (SWOT-профиль)

**Сильные стороны:**
- **Собственная медиа-платформа** (SETTERS Media + Изионист + блог Давыдова @hutzp) — экосистема производит и сама распространяет thought-leadership, не зависит от внешних медиа.
- **Репутационный капитал founders** — Давыдов и Жаркова позиционированы как «голоса индустрии».
- **Вертикальная интеграция:** агентство (SETTERS) + digital-студия (REB8T) + медиа (SETTERS Media) + комьюнити (Изионист) — закрывают весь пайплайн от стратегии до исполнения.
- **Tone of voice:** тёплый, humane, уважительный к людям и контексту. Противоположность «корпоративному» маркетингу.
- **Работа с важной клиентурой:** ВкусВилл, Мамисон, Random Coffee, Yardo, Т-Бизнес, HUGO — широкий диапазон B2C и B2B.

**Слабые стороны (в оптике рынка):**
- **Высокая зависимость от persona** Давыдова/Жарковой — риск ключевой фигуры.
- **Нет прозрачных метрик** — нельзя верифицировать масштабы (ни штат, ни ARR, ни клиентский портфель).
- **Креативное агентство в эпоху tiny teams и ИИ** — фундаментально уязвимый бизнес-модель, если клиенты научатся генерировать креатив через ИИ сами. Ironically, SETTERS Media **сами** пишут об этом тренде в «Будущее работы».

**Возможности:**
- Позиционирование как **поставщика фреймворков** (нарратив, «русский код», Organize to Value), а не исполнителя — смена модели от «делаем креатив» к «продаём рамки и исследования».
- Развитие Сообщества Изионист как платного премиум-мембер-клуба.

**Угрозы:**
- Конкуренция от более новых агентств, работающих «нативно с ИИ».
- Риск для экосистемы от регуляторики («иноагент», «запрещённая организация» — не применимо сейчас, но фундаментальный риск для любого visible-ru-бренда).

## Что это значит для GRO

1. **Потенциальный партнёр** для thought-leadership-коллабораций (Изионист как площадка, SETTERS Media как публикатор). Не прямая клиент-подрядчик-отношение, а со-авторство контента.
2. **Референс tone of voice** — GRO может ориентироваться на humane-воз SETTERS как на образец «не корпоративного» разговора с предпринимательской аудиторией.
3. **Источник фреймворков** — всё, что SETTERS Media публикует, стоит ingestить (via raw-drop URL'а).
4. **Anti-reference по бизнес-модели** — SETTERS-это услуговая компания с проектной загрузкой, GRO — это product-company. Не стоит копировать бизнес-модель.
5. **Visual direction:** типографический стек GRO ([[canon/brand-guidelines/gro-typography]]) уже близок к «глобальному стандарту». Можно сравнить визуальные паттерны SETTERS Media (grotesque + Space-Mono + градиенты) и позиционироваться **отдельно** — более тёплое/технологичное.

## Каналы дистрибуции (как SETTERS Group достигает аудитории)

- **Личный канал Давыдова** [@hutzp](https://t.me/hutzp) — самый личный, микс платных интеграций с органическим контентом. Примерно 50 сообщений за 12 дней = ~4 поста/день.
- **SETTERS Media-партнёры:** канал [@huggabletalents](https://t.me/huggabletalents/2631) — публикация полных тренд-репортов.
- **REB8T канал** [@webzdelnya](https://t.me/webzdelnya) — кейсы студии.
- **Сайт Сообщества** `easyon.ist` + UTM-трекинг (пример utm из поста 3427: `utm_source=tg&utm_medium=hutzp&utm_campaign=204_panov`).
- **Печатная дистрибуция:** Подписные издания (СПб + онлайн), Яндекс.Маркет для журнала Изионист.
