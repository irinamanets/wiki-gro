# Нейроцех (Молянов) -- indirect competitor / AI-community exemplar

Павел Молянов -- founder агентства «Сделаем» и подписочного сообщества Нейроцех. Проходит как indirect competitor для GRO в сегменте «предприниматели + ИИ», но работает через community-модель, а не через product-app.

## Продукт

- **Формат:** подписка-сообщество (вебинары + гайды + чат + курсы по вайбкодингу). Окна продаж ~1 раз в месяц
- **Агрегатор нейросетей:** Claude, ChatGPT, Grok, Gemini, Nano Banana, MidJourney, GPT Image -- оплата рублями, без VPN. 3000 кредитов на тесте, ежемесячная подписка или пакеты
- **Аудитория:** ~335 резидентов, ~50% предпринимателей/менеджеров, ~50% специалистов
- **Подписочная модель курса ИИ-копирайтинг:** входит в подписку 3 мес за 10 900 руб.; включает ChatGPT, Claude, Gemini, YandexGPT, GigaChat; блоки по фактчекингу, кастомизации под свой стиль, редактуре нейротекстов
- **Минимальный тариф доступа:** 999 руб./мес (подписка Нейроцех)
- **RAG-бот:** разрабатывается (векторная база данных + парсинг истории чата, гайдов, записей вебинаров) — отвечает только на основе внутренней базы, не выдумывает

## UX-проблема (выявлена через кастдевы)

Молянов публично описал ключевую проблему Нейроцеха: «в Нейроцехе так много всего, что хер разберешься» — information overload. Решают через переработку UX и AI-бота (RAG). Это классическая проблема масштабируемых обучающих продуктов — ценный ориентир для GRO: **простота точки входа важнее полноты контентной библиотеки**.

## Позиционирование

По мнению Молянова: «Мы не учим делегировать все задачи роботам, не учим профессиям будущего. Мы делаем обучение для специалистов, которые умеют делать свою работу». Это антитезис hype-community и ближе к positioning GRO как инструмента для профессионалов (см. [[canon/positioning/gro-value-proposition]]).

## Эволюция аудитории (1.5 года)

На старте: половина подписчиков -- копирайтеры и редакторы. Сейчас: менеджеры, предприниматели, инди-разработчики. Самые просматриваемые материалы -- про вайбкодинг в Claude Code и AI-assisted управление бизнесом через Cursor. Этот сдвиг подтверждает тренд из [[evolving/industry-trends/ai-solopreneurship-window-2026-2029]]: аудитория мигрирует от «попробовать AI» к «строить на AI».

## Competitive implications для GRO

- **Общий сегмент:** предприниматели и менеджеры, осваивающие ИИ для продуктивности
- **Различие:** Нейроцех = community + обучение + агрегатор; GRO = self-development app
- **Риск перехлёста:** если GRO выйдет в нарратив «вайбкодинг и агенты», аудитория Нейроцеха -- прямой конкурирующий канал
- **Возможность:** Нейроцех документирует кейсы (тендер через Claude Code, агент в продажах), которые GRO может использовать как сторонние proof-points для своего контента
