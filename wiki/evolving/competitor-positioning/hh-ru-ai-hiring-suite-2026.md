# ИИ-обвязка hh.ru — AI-помощник, Виртуальный рекрутер, AI-ранжирование

К 2026 году hh.ru полностью переходит от модели «job board + tools» к модели **AI-native HR-платформы**: каждый этап воронки (создание вакансии → сорсинг → коммуникация → скрининг → собеседование → офер → онбординг) имеет свой AI-инструмент. Этот системный сдвиг отличает 2026-срез от 2024-2025 (когда было разрозненные ИИ-фичи: NPS-генерация текста, чат-бот первичного контакта).

Источник — corporate blog hh.ru (срез 2026-05-05, [[sources/2026-05-05-hh-ru-condensed]]). Добавляет к [[evolving/competitor-positioning/hh-ru-hrtech-platform]] детализацию по новым AI-продуктам.

## ИИ-помощник для найма (AI hiring assistant)

**Запуск:** бета-режим — октябрь 2025; пилот до начала 2026; далее масштабирование на всех клиентов `[conf:high, src:2026-05-05]`.

**Что делает (полный цикл):**

- **Создание вакансии «своими словами»** — работодатель пишет описание свободно, ИИ конвертирует в структурированный draft. В 79% случаев работодатели вносят минимум изменений в черновик `[conf:high, src:2026-05-05]`
- **AI-сорсинг по базе резюме hh.ru** — модель ищет кандидатов с подходящими навыками, не только по точному matching должности
- **Диалог с кандидатами** — ИИ задаёт уточняющие вопросы, отвечает на типовые, работает с возражениями
- **Сортировка откликов** на 3 категории: «Подходит / Можно рассмотреть / Не сейчас»
- **Прозрачность** — ИИ показывает логику решений, чтобы рекрутер мог скорректировать

**Ограничения:** подключается максимум к 5 вакансиям одновременно `[conf:high, src:2026-05-05]`.

**Roadmap:** онбординг, назначение и анализ собеседования, подсказки по коммуникации `[conf:high, src:2026-05-05]`.

**Контекст-обоснование (статистика hh.ru, использованная в анонсе):**

- До 60% рабочего времени HR уходит на рутину `[conf:medium, src:2026-05-05]`
- На живое общение с кандидатами — лишь около 5% `[conf:medium, src:2026-05-05]`

## Виртуальный рекрутер (массовый найм)

**Запуск:** активно используется с начала 2025; за первые 8 месяцев 2025 пользуются крупные торговые сети, рестораны, федеральные банки, операторы связи `[conf:high, src:2026-05-05]`.

**Механика:**

- Привлечение кандидатов из базы hh.ru + внешних рекламных каналов
- Заполнение анкеты на лендинге (стандартный или брендированный)
- Автоматическая фильтрация по релевантности
- Оплата только за релевантные анкеты (не за просмотры)
- Интеграция с ATS/CRM, распределение откликов в целевые филиалы

**Позиционирование:** для **массового найма** (синие воротнички, линейный персонал, HoReCa). Это complement к ИИ-помощнику, а не замена: помощник — для штучных позиций (max 5 вакансий), Виртуальный рекрутер — для потоковых.

## AI-ранжирование поиска по резюме

**Запуск:** обновление поиска осенью 2025.

**Изменение:** при поиске по резюме hh.ru теперь приоритизирует **«более общительных» кандидатов** на основе анализа поведения (история ответов на звонки, скорость отклика на чат, отвечаемость на сообщения).

**Метрики после обновления:**

- Доля успешных контактов выросла на 10% `[conf:high, src:2026-05-05]`
- 38% кандидатов отвечают на первый звонок через hh.ru `[conf:high, src:2026-05-05]`
- 56% выходят на связь в течение суток (через чат или обратный звонок) `[conf:high, src:2026-05-05]`

## Новые алгоритмы поиска по резюме

Параллельно с ranking-обновлением hh.ru переработал сам поиск:

- **Поле «Общий опыт»** с группировкой должностей — алгоритм понимает, что Key Account Manager + Senior Sales Manager + B2B-менеджер по продажам = 6 лет в продажах `[conf:high, src:2026-05-05]`
- **Распознавание «спрятанного» опыта** — Software Engineer работал с Go, Kubernetes, Docker → система видит технологии в обязанностях и помечает как Go-разработчик, даже если в названии должности нет слова Go `[conf:high, src:2026-05-05]`
- **Фильтр «Опыт в профессии»** для уточнённого поиска

**Эффект на пул кандидатов:** показ кандидатов с подтверждёнными навыками, даже если в резюме указана не та должность, расширяет пул потенциальных кандидатов **до 1,7 раза** `[conf:high, src:2026-05-05]`.

## Тесты подтверждения навыков

Не AI per se, но тесно связано с навыкоцентричным поиском:

- Бейдж «Есть подтверждённые навыки» в резюме `[conf:high, src:2026-05-05]`
- Фильтр «Подтверждённые навыки» при просмотре откликов
- Отчёт с разбивкой по вопросам/ответам, антифрод-система
- Валидность 1 год, повторная попытка через месяц

**Roadmap (планы hh.ru):** добавление **практических заданий** в тесты (пока только теория) `[conf:medium, src:2026-05-05]`.

**Контекст-обоснование:** до трети соискателей получают отказ из-за несоответствия квалификации требованиям вакансии `[conf:medium, src:2026-05-05]`.

## Talantix (CRM) — обновления

Talantix — это **AI-обвязка для постингестового этапа** (после того, как кандидат уже в базе):

- **Раздел аналитики осенью 2025:**
  - «Общая воронка подбора» (источники, конверсии, причины отказов)
  - «Загрузка рекрутеров» (нагрузка по каждому, отклики vs активный поиск)
  - «Результаты работы» (план vs факт, среднее время закрытия, доля просроченных)

- **Talantix + Start Link integration:**
  - Автоперенос данных кандидата в кадровый сервис
  - Автораспознавание документов
  - Проверка кандидата по 20+ базам (банкротство, правонарушения, судебные дела, неоплаченные налоги)
  - Отчёт за 15 минут
  - Интеграция по API с 1С

- **Новые интеграции (осень 2025):** Яндекс Телемост, Zoom, Google Meet, календари Яндекс и Битрикс24 — создание встречи прямо из карточки кандидата

**Метрики связки (заявленные hh.ru):**

| Метрика | Значение | Source |
|---|---|---|
| Сокращение времени закрытия вакансии | до 30% | `[conf:medium, src:2026-05-05]` |
| Среднее время найма (Talantix + Start Link) | в 2 раза быстрее | `[conf:medium, src:2026-05-05]` |
| Экономия на подборе | до 38% (за счёт сокращения ручных операций) | `[conf:medium, src:2026-05-05]` |

`confidence: medium` — first-party вендор-метрики, без независимой верификации, с ожидаемым selection bias на лучших кейсах.

## Расшифровка звонков (AI-фича)

Запущена осенью 2025 в составе обновления звонков через hh.ru:

- **Расшифровка + краткие итоги разговора через AI** — саммари с оценкой соответствия кандидата критериям, готовится ~2 часа `[conf:high, src:2026-05-05]`
- QR-код на резюме для звонка с мобильного через браузер
- История «Исходящие звонки» с записями

См. полный профиль звонка как канала: [[evolving-strict/campaign-metrics/hh-ru-call-channel-effectiveness-2026]].

## Enterprise-валидация чат-бота подбора — кейс АШАН (добавлено 2026-05-14)

[[sources/2026-05-14-hh-ru-ashan-mass-hiring-case]] подтверждает реальное использование **чат-бота подбора** (Виртуальный рекрутер) крупным ритейлером — АШАН Ритейл Россия, команда 50+ рекрутеров, несколько направлений (ритейл, производство, ИТ, логистика, офис).

**Adoption-динамика:**

- Доля вакансий с подключённым чат-ботом: **9,7% (апрель) → 13,5% (июль)** — органический рост без форс-мажора `[conf:medium, src:2026-05-14]`
- До **20% откликов** по таким вакансиям поступают от кандидатов, найденных ботом в базе резюме `[conf:medium, src:2026-05-14]`

**Поведенческий паттерн АШАН:** рекрутеры первоначально боялись автоматизации («страх рекрутеров перед ботом»), но после наблюдения хорошей конверсии у bot-sourced кандидатов страх пропал — типичный S-curve adoption internal.

Смежные метрики по каналу звонков — в [[evolving-strict/campaign-metrics/hh-ru-call-channel-effectiveness-2026]].

## Что это значит для marketing-memory GRO

1. **Конкурентный сдвиг.** hh.ru — не просто HR-платформа с фичами; к 2026 году это **AI-обёртка над всей воронкой найма**. Для GRO это **context shift**: ЦА (карьеристы, рекрутеры, HRD) живёт в среде, где AI-инструменты автоматизируют большую часть рутины. Позиционирование GRO как «тренируй навыки человеком, не подменяй ИИ» становится более чётким контрастом.

2. **AI-driven навыкоцентричность.** Расширение пула кандидатов ×1,7 за счёт распознавания «спрятанных» навыков подтверждает [[evolving/industry-trends/skill-based-hiring-russia-2026|тренд навыкоцентричности]] на уровне инфраструктуры — не только в дискурсе, но и в alignment-механиках поисковых движков.

3. **Двойственность ИИ для соискателей.** 50% соискателей уже используют ИИ при поиске работы (резюме, тестовые) `[conf:medium, src:2026-05-05]` → работодатели усиливают AI-скрининг → это рынок «AI vs AI». GRO как тренажёр **навыков** (а не инструмент-генератор резюме) сидит **с правильной стороны** этого арбитража.

4. **Контент-хук:** «hh.ru теперь читает 6 лет опыта между строк — твоё резюме готово к этому?» — для сегмента «карьеристы».
