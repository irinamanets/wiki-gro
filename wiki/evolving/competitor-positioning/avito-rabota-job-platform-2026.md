# Avito Работа — RU job-platform 2026

Профиль конкурента в RU labor-marketplace категории. Anchor-точки взяты из advertorial поста 5041 (2026-04-29) в @startupoftheday Горного (см. [[sources/2026-05-05-tg-startupoftheday-apr-may-2026]]).

## Базовый профиль

- **Бренд:** Avito Работа
- **Юр. лицо:** ООО «КЕХ еКоммерц», ИНН 7710668349 (по advertorial-disclaimer)
- **Категория:** classifeds-style job-board как часть горизонтальной площадки Avito
- **Telegram-канал:** [Авито Работа](https://t.me/+ulNlcR6KQPY4Mjky)
- **Параллельные продукты:** часть екосистемы Avito (классифайд для частных продаж + спецсегмент Авто, недвижимость, услуги, работа)

## Anchor-метрики (Apr 2026)

### Аудитория соискателей

**20 миллионов соискателей в месяц** ищут вакансии на Авито Работе `[conf:medium, src:2026-04-29]`.

Это **anchor-точка для размера market**, преподнесённая в advertorial. Горный делает оценочную ремарку: «о смене работы примерно столько россиян и думает».

Калькуляция масштаба:
- Население РФ ≈ **144M** `[conf:high, src:2024]`
- Экономически активное население РФ ≈ **75M** `[conf:high, src:2024]`
- 20M / 75M ≈ **27% экономически активного** `[conf:medium, src:2026-04-29]`

То есть Avito Работа — **massive horizontal channel**, не niche. Сопоставимо или превосходит hh.ru по численности уникальных аудитории.

### Промо-оффер для работодателей

В promo (apr 29 2026) была акция: **+500 бонусов в Авито Кошелёк за каждую размещённую вакансию** `[conf:high, src:2026-04-29]`. Бонусы тратятся на дополнительные услуги (приоритетное размещение, premium etc).

## Сравнение с hh.ru

Avito Работа — **ближайший прямой конкурент** [[evolving/competitor-positioning/hh-ru-career-marketplace|hh.ru career marketplace]] в RU-сегменте. Оба — horizontal job-boards с self-service размещением вакансий и premium-tier'ом для работодателей.

| Параметр | Avito Работа | hh.ru |
|---|---|---|
| MAU соискателей | 20M `[conf:medium, src:2026-04-29]` | ~10-12M (older estimate) |
| Происхождение | Часть горизонтальной площадки Avito | Native job-platform с 2000 |
| Pricing model | Bonus-based ad-tech | Subscription tiers + per-vacancy |
| Адаптация AI | (нет публичных сигналов в этом source) | hh.ru AI-hiring suite (см. [[evolving/competitor-positioning/hh-ru-ai-hiring-suite-2026]]) |
| Target employer | SMB, гибрид (бренд "Avito" массовый, но Работа делает push в B2B) | Enterprise + SMB |

**Ключевая дифференциация:** hh.ru — **specialized HR-tech**, Avito Работа — **horizontal classifieds extension**. Это существенно разные positioning'и для **employer-side**: hh.ru продаёт expertise, Avito продаёт reach.

## Контекст RU labor-market

В Q1 2026 RU labor market развернулся в сторону работодателя (см. [[evolving/industry-trends/ru-labor-market-employer-turn-2026]]):

- HH-индекс удвоился до 9.6-11.4 (рынок работодателя при ≥8.0)
- Вакансии −27..30%, резюме +39..42%

В этом контексте **20M соискателей/месяц на Avito Работе** — это **прямое отражение employer-shift**: больше людей **активно ищут работу**, не ждут пассивно. Это **высокая ликвидность кандидатского рынка**, что объективно облегчает работу маркетплейсу как matching-агрегатору.

## Что это значит для GRO

### 1. Avito Работа как канал найма для GRO-команды

GRO как растущий стартап (см. [[canon/product-knowledge/gro-team]]) может рассматривать Avito Работу для найма **non-tech ролей** (operations, customer-success, sales, marketing-juniors). Tech-роли традиционно идут через hh.ru / специализированные. **20M MAU = большая воронка**, особенно для massive-pool позиций.

### 2. Avito Работа в content GRO

Если GRO когда-либо будет писать контент про **карьерный сегмент** (см. [[evolving/content-trends/career-audience-hooks-2026]]), Avito Работа — **ещё один platform-anchor** наряду с hh.ru:

> «20M россиян **прямо сейчас** ищут новую работу — это каждый третий экономически активный житель РФ `[conf:medium, src:2026-04-29]`. Если вы из их числа, ваша спина болит больше обычного — стресс выглядит как осанка.»

Это **direct content hook** связывающий labor-market anxiety с GRO product (стресс ↔ постура).

### 3. Avito Работа advertorial pattern

Advertorial в @startupoftheday — **standard pattern** для RU B2B-платформ. Avito Работа уже размещалась там, как ранее — Лавка, Сбер, Т-Банк (см. [[sources/2026-04-14-tg-startupoftheday-mar-apr-2026]]). Если GRO когда-либо рассматривает author-channel ad-buy, Горный представляет **proven channel** для broad-audience SaaS / B2B-платформ.
