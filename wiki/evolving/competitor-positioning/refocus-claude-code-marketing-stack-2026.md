# Refocus — маркетинговый AI-стек внутри Claude Code

Анонсированный Р. Кумар Виасом ([@solokumi пост 407, 2026-05-11](https://t.me/solokumi)) операционный кейс: **немецкий проект Refocus заменил несколько маркетинговых SaaS-подписок на кастомные скиллы внутри Claude Code**. На VIBECON 13 мая 2026 Виас презентовал этот стек как воспроизводимый паттерн.

Это **competitor-positioning кейс** — не потому, что Refocus конкурирует с ГРО (он EdTech, ГРО — другая вертикаль), а потому что Refocus демонстрирует **новый operating model для маркетингового отдела**, который ГРО может либо адаптировать, либо использовать как differentiator-нарратив против тех, кто всё ещё сидит на стеке из 10+ SaaS.

## Состав стека (по анонсу VIBECON)

Виас перечисляет четыре компонента:

1. **Скилл для генерации крутых нешаблонных лендингов** — заменяет full-stack landing tools (Webflow + Framer + дизайн-агентство для уникальной верстки).
2. **Скилл для создания креативов, которые пробивают баннерную слепоту** — заменяет связку Midjourney/DALL-E + Figma + дизайнер на ad creatives.
3. **Ассистент для маркетолога, который держит в голове все наши фреймворки** — заменяет «общую wiki + Notion-баки» через RAG-агента, который оперативно отвечает на вопрос «как мы делали такой кейс год назад».
4. **Базы знаний, которые заменили несколько SaaS-подписок** — RAG-индексы вместо отдельных SaaS-инструментов (предположительно: SimilarWeb для конкурентного анализа, Semrush/Ahrefs для контент-планирования, какие-то research-сервисы).

## Утверждаемый эффект

> «Всё это работает в нашем немецком проекте прямо сейчас.»
>
> — Р. Кумар Виас, @solokumi пост 407, 2026-05-11

Виас не приводит конкретных метрик («сэкономили X на подписках, ускорили Y на Z%»), но позиционирует как **production-ready** operating model на момент конца апреля — начала мая 2026.

## Почему это важно для нарратива

**Главный тезис** Виаса:

> Кастомные in-house скиллы под Claude Code = функциональная замена SaaS-стеку маркетингового отдела.

Это совпадает с метаустановкой из [[evolving/content-trends/claude-code-skills-bank-2026]] («не врубать сразу 50 скиллов, собирать маленький стек под повторяющиеся процессы») и из [[canon/marketing-frameworks/multi-agent-marketing-org-principles]] (рой агентов вместо армии SDR-ов и копирайтеров).

**Operational tradeoff vs SaaS-стек**:

| Параметр | SaaS-стек (старый mode) | In-house Claude Code скиллы |
|---|---|---|
| **Цена** | $5K–$50K/мес suite на 10–20 инструментов | $200–$2K/мес на Anthropic API + инфра |
| **Кастомизация** | Низкая (что есть в продукте — то и используешь) | Высокая (промпт под себя, фреймворки в RAG) |
| **Время до first value** | Часы (купил подписку — пользуешься) | Дни / недели (нужно собрать скилл) |
| **Lock-in** | Высокий (контракты, миграция данных) | Низкий (промпты — свои, RAG-индексы — свои) |
| **Поддержка / SLA** | SaaS-провайдер | Внутренняя команда |
| **Зависимость от model** | Слабая (продукт абстрагирует) | Сильная (зависишь от Claude/OpenAI uptime + pricing) |

## Контекст: Refocus как кейс

Refocus — немецкий EdTech-стартап (онлайн-обучение профессиям, аналог Skillbox / Geek Brains для DE-рынка). На начало 2026 — $2M ARR `[conf:medium, src:2026-04-14]` (из [[sources/2026-04-14-tg-solokumi-nov2025-apr2026]]). Виас co-founder; ранее Qmarketing Academy (куплен Skyeng в 2021).

То есть стек **работает на реальном продукте**, не в демо-проекте — это весомый сигнал для positioning'а.

## Что это значит для ГРО

Три прикладных вывода для маркетинга ГРО:

1. **Нарратив-хук**: «маркетинговый отдел из 1 человека + рой Claude-скиллов» — это пример demand-side narrative, который ГРО может использовать в контенте (например, на блоге как кейс-стади или в подкасте).
2. **Differentiator против медленных конкурентов**: SaaS-производители маркетинговых инструментов в 2026 году встанут перед выбором — пытаться продавать suite-of-SaaS или предлагать «one Claude skill вместо 10 SaaS». Тот, кто медленнее, проиграет нарратив.
3. **Внутренний use**: если ГРО ещё не собрал свой маркетинговый стек скиллов — кейс Refocus подсказывает MVP-набор (4 скилла: лендинги, креативы, фреймворк-ассистент, RAG-базы).
