# Курс «Claude Code для предпринимателя» — Горный × Шевченко

Новый продукт в RU AI-tutor сегменте, запускающийся 2026-05-16. Соавторы — **Александр Горный** (founder ShareAI клуба, ex-Mail.ru Group, ежедневный VC-обозреватель @startupoftheday) и **Григорий Шевченко** (CEO агентства ~30 человек, опыт массового внедрения Claude Code в бизнес-процессы).

Анонс через 3 поста в @startupoftheday: 5044 (запуск 2026-04-30), 5048 (objection-ответ 2026-05-02), 5051 (target-расширение 2026-05-04). Источник — [[sources/2026-05-05-tg-startupoftheday-apr-may-2026]].

**Update 2026-05-14** (по 2 постам 5058 + 5067 из [[sources/2026-05-14-tg-startupoftheday-may-5-13-2026]]): добавлены данные о **составе группы** на момент 2026-05-08 и **программе** на момент старта 2026-05-16.

## Состав группы (на 2026-05-08, пост 5058)

> «В группе курса сейчас под 100 человек. Смотрю, кто о себе пишет: основатель, основатель, директор по развитию, управляющий партнер, Head of Product. Вы будете в хорошей компании.»

**~100 человек** в группе, по самоописанию — **decision-makers уровня founder / C-level / Head**. Это подтверждает **founder/exec target** курса (а не student-developers, не junior-сотрудников).

Это **strong signal в подтверждение positioning-thesis #3** (см. ниже): курс реально привлекает entrepreneurs, не разработчиков.

## Программа (по посту 5067, 2026-05-13)

3 содержательных блока:

1. **Установка и первые шаги** — onboarding для не-программистов
2. **Продвинутые инструменты:** субагенты, MCP, n8n и подобное
3. **Применение в обычной жизни обычного менеджера** — не «единорог из одного человека», а упрощение жизни себе и **бизнес-процессов компании**

**Формат:** записанные видео лекций + вебинары для ответов на вопросы (asynchronous-first с live Q&A).

**Основа content:**
- Личный опыт Горного **«для себя»** (часы в неделю, одна подписка)
- Опыт Шевченко **«переналадить работу маркетингового агентства»** (десятки часов в неделю, все сотрудники)

**Позиционирование границ:**
> «НЕ занимаемся вайбкодингом и оптимизацией "промышленного программирования". Не потому, что это плохо и неинтересно, но где-то же надо проводить границу.»

Это **очень important threshold setting**: курс **specifically NOT** для vibe-coding или enterprise dev-tooling. **Это для operations и personal productivity**.

## Базовые факты

- **Платформа:** [claude.aiacademy.me](https://claude.aiacademy.me/) — отдельный subdomain главной AiAcademy.me (см. [[evolving/industry-trends/ru-vertical-ai-signals-2026]] для context AiAcademy как infrastructure-каналов доступа к моделям из РФ)
- **Старт:** **2026-05-16**
- **Скидка:** до **2026-05-03** включительно (узкое окно ранней покупки)
- **Целевая аудитория:** «владельцы бизнеса и руководители». Эксплицитно НЕ программисты — Горный неоднократно подчёркивает. Включает offline-businesses (например, владельцы ресторанов).
- **Соавторы:**
  - **Александр Горный** — VC-обозреватель, founder ShareAI закрытого клуба
  - **Григорий Шевченко** — CEO агентства ~30 человек, **internal Claude Code adoption proof-point**

## Positioning-thesis

Через 3 поста Горный артикулирует следующее positioning:

### 1. «Claude Code — must-have, как ChatGPT» (5044)

> «Claude Code, или Codex, или Cursor — штуки, без которых уже нельзя.»
> «Без ChatGPT, Excel, интернета, электричества — тоже можно. Но все-таки нельзя 😊»

Это **paradox of inevitability**: Горный позиционирует Claude Code как новый Excel — освоить **обязательно**, иначе отстанешь.

### 2. «Курс = фильтр, не секретные знания» (5048)

Ответ на распространённое возражение: «Я сам могу, всё бесплатно есть на YouTube или в самом Claude».

> «Безусловно, да. Всё и правда есть бесплатно в миллионе мест. Ценность любого курса не в "секретных знаниях", а в **отборе полезного**. В том, что автор выбрал важные темы и подтемы, а неважные выкинул. В том, что он взял один лучший из 1000 существующих и 100 правильных ответов. **В фильтре, а не в количестве материалов**.»

Это **фундаментальный thesis для всей edtech-отрасли** в эпоху бесконечной информации. Может быть переиспользован для GRO (см. ниже).

### 3. «Полезен для офлайн-бизнеса при минимальном threshold» (5051)

Ответ на вопрос «нужен ли курс владельцу ресторана?»:

> «Если в вашей жизни есть хотя бы пара часов работы за компьютером в день или расходы на "компьютерных" сотрудников для вас материальны, то курс будет полезен.»
> «Если ни вы, ни сотрудники за компьютерами не сидите реально — то, увы, нет.»

Это **honest threshold-criterion**, не over-reach к marketing «для всех». Сегментирует по реальному use-case, не по vanity demographics.

### 4. «Founder-CEO normalization сигнала» (cross-context)

Горный сам — founder ShareAI и автор @startupoftheday. Шевченко — CEO внедряющего агентства. То есть **course built by people who built businesses with Claude Code**, не академики. Это часть растущего паттерна **vibe-coding founder-CEO normalization** (см. [[evolving/competitor-positioning/vibecoding-stack-ecosystem-2026]] и [[canon/marketing-frameworks/peregudov-vibecoding-founder-playbook-2026]]).

## Категория RU AI-tutor — где этот продукт сидит

В RU AI-education сегменте уже несколько слоёв:

| Слой | Примеры | Дифференциатор |
|---|---|---|
| Doctrine API access | AiAcademy.me (подписка на доступ к моделям из РФ) | Infrastructure layer, proxy для санкционного блока (см. [[evolving/industry-trends/ru-vertical-ai-signals-2026]]) |
| No-code AI-agent platforms | Just AI Cloud, ru-nocode-ai-agent-platforms | Platform-as-a-service, build agents without code (см. [[evolving/competitor-positioning/ru-nocode-ai-agent-platforms-2026]]) |
| Academic/online schools | (Skillbox, Yandex Practicum, Karpov, etc) | Long-form structured curriculum для специалистов |
| Author-led founder courses | **claude.aiacademy.me (этот)** | **Practical entrepreneurship-focused, founder-led, agent-tool focus** |

**Дифференциация этого курса:**

1. **Founder-led, не academic.** Шевченко практик внедрения, Горный — VC-обозреватель с insider-доступом к founders.
2. **Не-разработческий target.** Маркетинг прицеливается на **бизнес-владельцев**, не на тех, кто пишет код. Это **massive market expansion** vs Cursor/Claude tutorials, которые предполагают coding background.
3. **Pre-existing distribution.** Горный имеет канал @startupoftheday (минимум десятки тысяч подписчиков), Шевченко — клиентскую базу агентства. Курс launches на **warm audience**, не cold ads.
4. **AiAcademy.me brand alignment.** Использует существующий бренд AiAcademy (RU AI-infrastructure), а не запускает новый. Это **brand-extension move**, не green-field.

## Что это значит для GRO

GRO — фитнес-приложение, **не AI-tutor**. Прямой конкурент-релевантности нет. Но **косвенно** этот сигнал важен:

### 1. Edtech curated-filter thesis применим к GRO

«Курс = фильтр, не секретные знания» — это **универсальный thesis** для любой edtech / structured-content offerings. GRO как product-which-curates-fitness-knowledge может позиционироваться по тому же принципу:

> «Все упражнения для спины известны, всё на YouTube бесплатно. Но никто не выбрал из 1000 правильную последовательность для вашей спины. GRO — это **отбор**, а не количество.»

Это **готовый positioning hook**. Подходит для лонгридов про GRO как «structured curation» vs «free-but-overwhelming YouTube».

### 2. Founder-led credibility pattern

Pattern «founder, который сам внедрил → теперь учит других» в 2026 становится default-trust-signal в RU edtech. Шевченко учит как внедрить, потому что внедрил у себя. Это **direct anti-pattern для academic / theory-only курсов**.

GRO trust-pattern: **Лапшина (founder) сама использует GRO** = direct credibility (см. [[canon/product-knowledge/gro-team]]). Этот паттерн нужно **публично эксплицировать в content** — больше историй про реальное использование GRO самой founder-командой.

### 3. Цена внимания в RU AI-content-канале

Горный регулярно интегрирует свой курс в @startupoftheday (3 поста за 5 дней — высокая частота для author-channel'а). Это сигнал **«AI-курс продавать на AI-content-канале — высокая конверсия в 2026»**. Если GRO в будущем будет рассматривать sponsorship/advertising на AI-content RU-каналах (например, @neuraldvig, @startupoftheday) — этот ingest даёт baseline conversion-feel для author-promo.

### 4. Threshold-criterion для marketing GRO

«Полезен если есть пара часов компьютерной работы или материальные расходы на сотрудников» — это **honest threshold formulation**. GRO может позаимствовать паттерн:

> «Полезен, если: (а) у вас есть боли в спине от сидячей работы, или (б) вы ищете системность в тренировках, или (в) вы хотите экспертный курс без подписки на дорогого тренера. Если ничего из этого — не для вас.»

Это **anti-marketing-for-all positioning**, которое работает.
