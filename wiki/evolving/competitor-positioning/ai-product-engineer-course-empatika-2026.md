# AI Product Engineer course (Empatika, Байрам Аннаков) — 4-й поток (май 2026)

**Источник:** Байрам Аннаков, пост 1741 ([[sources/2026-05-14-tg-products-and-startups-may-2026]]), youtube.com/watch?v=j4oZaFRrEYM — публичный отрывок 1-й встречи. Курс хостится на платформе **Empatika** (empatika.com/courses/ai-product-engineer).

## Позиционирование

**Курс — это не «промпт-инжиниринг для маркетологов».** Это инженерно-продуктовый курс, адресованный разработчикам, тех-руководителям и founder'ам, которые строят AI-продукты, а не пользуются ими.

**Тезис курса (вытащен из видеоотрывка 1-й встречи):**

> «Контекст стал главной поверхностью программирования.»

То есть курс продаёт **смену парадигмы**: с «писать код» на «управлять контекстом» (соответствует Software 3.0 / agentic engineering, см. [[canon/marketing-frameworks/karpathy-software-3-agentic-engineering]]).

## Программа 1-й встречи (раскрыто)

Из отрывка 1-й встречи 4-го потока:

1. **Что такое контекст** и почему он стал главной «поверхностью программирования»
2. **Работа с недетерминированностью LLM** — фундамент для всех остальных модулей
3. **Инструменты контроля:** Plan Mode, Constitution
4. **Сдвиг роли разработчика** — от оператора к **апруверу**
5. **Сборка V0 своего AI-коллеги** с помощью SDK: Claude Agents SDK / Codex SDK / Cursor SDK
6. **Сквозной демо-проект — TARS**, бот-ассистент в Telegram, который улучшается на каждой встрече

## Format

- **Поточный курс** (потоки нумеруются — 4-й поток = май 2026, значит запуск был летом-осенью 2025, ~3-4 потока в год)
- **Cohort-based** — встречи в режиме live
- **Демо-driven** — сквозной проект TARS на протяжении всего курса
- Хостинг: Empatika (платформа Бая для образовательного контента, [empatika.com](https://empatika.com))

## Канал коммуникации курса — @ProductsAndStartups

Telegram-канал [@ProductsAndStartups](https://t.me/ProductsAndStartups) (несколько тысяч инженерно-предпринимательской аудитории) — **главный inbound-канал** курса:

- Анонсы новых потоков
- Отрывки встреч (как 1741)
- Контент-маркетинг через пост-разборы (1740 Stanford, 1745 slot-machine, 1746 generative UI, 1748 CEO-CTO bridge — все они **дублируют темы курса**)

Это классический **content-first cohort funnel:** канал → ценный контент по теме → trust → конверсия в платный поток. Аналог Andrew Ng / DeepLearning.AI модели.

## Контент-стратегия и анонс-стиль

Анонсы потоков — **низкий шум**, **высокий signal**. Не «успей записаться!», а «вот ссылка на отрывок, посмотрите ценность сами». Это анти-инфоцыганский tone, который и есть конкурентное преимущество в сегменте B2B-tech-аудитории.

**Anti-pattern, который Бай намеренно избегает:**
- Контртаймеры со скидкой
- «Только 10 мест осталось!»
- Эмоциональные крючки про FOMO

**Pattern, который Бай использует:**
- Контент-предобучение через пост-разборы (Stanford, METR, slot-machine, generative UI) → когда юзер видит анонс курса, у него уже есть наработанный «язык» Бая
- Public artifacts (open-source skills, slide-inspector, ai-personal-os-skills repo) — каждый акт делится — это **proof of practitioner status**
- Без registration-pop-up'ов в самом посте

## Релевантность для GRO

**GRO не competitor этому курсу** напрямую (другая аудитория), но:

1. **Tone-of-voice референс:** как делать educational контент **без инфоцыганщины** в нише AI-инструментов
2. **Content-first funnel:** методология «канал-разборов → анонс продукта без давления»
3. **Practitioner credibility:** доказательство, что contrarian-позиции (Stanford → harness > prompt) формируют trust лучше «возьми наш курс и заработаешь миллион»

## Tracking signals (для следующих дампов)

При следующих апдейтах канала проверять:

- **Анонсы 5-го потока** — частота потоков отражает спрос
- **Цена** — если откроют публично, можно сравнить с другими русскоязычными AI-курсами
- **Партнёрства** — Бай ведёт курс на Empatika, возможны кросс-promos с другими educators
- **Список ключевых концептов** — каждый новый поток ввод новых тем (текущий: TARS, SDK, Plan Mode, Constitution); сдвиг = сдвиг рыночной потребности
