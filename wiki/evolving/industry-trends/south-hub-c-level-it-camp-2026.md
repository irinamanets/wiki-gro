# South HUB — закрытый кэмп для С-Level в IT

Observed event-формат, sibling к [[evolving/industry-trends/closed-vc-camp-format-spring-ai-weekend-2026|Spring AI Weekend]] (CATS.VC), но в другой вертикали: **закрытый кэмп для С-Level enterprise IT** (CIO, CDO, CISO, CEO), не VC-вертикаль и не founder-only audience. Зафиксирован на анонсе **5-го сезона South HUB** через pre-event онлайн-эфир 2026-05-26 19:00 в TG-канале @egoshin_kedprof (пост 575).

Первичный источник: [[sources/2026-05-26-tg-egoshin-kedprof-may-20-26-2026|TG @egoshin_kedprof 20–26 мая 2026]], пост 575.

## Параметры наблюдаемого формата

| Параметр | Значение в South HUB v5 | Generalization |
|---|---|---|
| Аудитория | С-Level в IT (CIO / CDO / CISO / CEO IT-департаментов) | C-suite mono-функция |
| Вертикаль | Enterprise IT (не VC, не founder, не product) | mono-vertical, top-down |
| Длительность основного event'а | (не озвучено в анонсе, по аналогии с Spring AI Weekend = 2–3 дня) | weekend / multi-day cohort |
| Количество участников | (не озвучено, по аналогии с премиум-кэмпами = 30–60) | tight cohort |
| Локация | (не озвучено в анонсе) | премиум-выездная |
| Формат | Воркшопы, **«Совет директоров на кэмпе»**, хакатон со Snow BASE, **Family-трек** | workshop + closed discussions + family |
| Pre-event teaser | Онлайн-эфир «South HUB всё, что вы хотели знать!» за неделю до основного event'а | live-broadcast как warm-up |
| Бренд-визуал | Логотип «SOUTHUUUB» (стилизованное растягивание), белый/кремовый фон + 3D-полупрозрачные призмы в персиково-оранжевых тонах | premium minimalist |
| Pre-event модератор | Константин Егошин (founder Кеды профессора / co-founder GRO) — как «привычный интервьюер сцены» | community-host pattern |

## Чем отличается от Spring AI Weekend

| Атрибут | Spring AI Weekend | South HUB |
|---|---|---|
| Вертикаль | AI investment + venture (founder × investor) | Enterprise IT (C-suite × C-suite peer-networking) |
| Аудитория | AI-founders / AI-investors / отраслевые экспертные C-level | CIO / CDO / CISO / CTO / CEO IT-департаментов |
| Спикеры | Юрий Максимов (Positive Technologies), Глеб Михеев (Сбер AI), Алексей Милевский, Дмитрий Бугайченко (Сбер b2c) и др. | Программный директор + крупные корпорации (AstraZeneca / НСПК / Т-Банк) |
| Анкор | CATS.VC × Forest Hills Golf Resort | South HUB как самостоятельный бренд-кэмп |
| Family-трек | Не озвучено | **Family-трек явно есть** (привозят семью, иногда «всю команду или бабушку») |
| Хакатон | Не озвучено | **Хакатон со Snow BASE** (cross-link на [[sources/2026-04-14-tg-egoshin-kedprof|апрельский дамп Егошина]] — SnowBase) |
| Pre-event teaser | TG-author teaser-постов (Фомичёв за 9 дней) | Live-broadcast с модератором-инфлюенсером |
| Длительность | 2–3 дня (weekend) | (не озвучено) |

**Ключевое отличие:** South HUB **более длинный и более «pure event»** (есть family-трек = люди привозят семьи на несколько дней), Spring AI Weekend **более короткий и более «founder-investor speed-networking»** (тигер-формат для high-density deal flow).

## Cross-link: Snow BASE как связующее звено

Из анонса 575: «как появился хакатон и при чём здесь Snow BASE». **Snow BASE** — формат, уже знакомый из [[sources/2026-04-14-tg-egoshin-kedprof|апрельского дампа Егошина]] (пост 542 — «ТОП мыслей с SnowBase»), это **закрытый AI-сеанс в виде ski-trip** для топ-management RU-AI компаний (Т-Банк, Яндекс, X5 Tech). South HUB → Snow BASE = «континиум» для одной и той же C-Level аудитории через год: South HUB (лето) → Snow BASE (зима). Это **community-loyalty через сезонную циклику** — приём, увеличивающий retention в premium-event-программе.

## Pre-event live-broadcast как PR-канал

Pre-event онлайн-эфир South HUB — это **content-format**, а не сам event. Параметры:

- **Время:** 60-минутный эфир за **1 неделю до основного event'а** (даты основного не озвучены)
- **Платформы:** YouTube live + VK live одновременно (multi-platform норма для RU-event-PR 2026)
- **Формат:** интервью с организаторами + контент-сообщества (типа «как формируется программа», «что такое Совет директоров на кэмпе», «зачем Family-трек»)
- **Модератор:** **Константин Егошин**, founder Кеды профессора и co-founder GRO — внешняя фигура, не сотрудник South HUB
- **Бенефит для event'а:** Егошин приводит свою TG-аудиторию (карьеристы + предприниматели) в funnel South HUB, расширяя reach beyond own audience
- **Бенефит для модератора:** Егошин получает access к C-Level speaker'ам (контент для своего канала + networking)
- **Бенефит для аудитории:** прозрачность event-формата за неделю до того, как зарегистрироваться

Это **reusable content-format для founder-events**: pre-event live-broadcast «вопросы организаторам» с внешним модератором-инфлюенсером + multi-platform дистрибуция.

## Применимость для маркетинга GRO

1. **Не аудитория-direct.** South HUB С-Level enterprise IT ≠ GRO ICP (карьеристы / предприниматели / lifestyle audience). Direct CTA на South HUB-аудиторию для GRO **не имеет смысла**.
2. **Pre-event live-broadcast как reusable формат.** Если GRO станет партнёром любого премиум-event'а (как [[evolving/industry-trends/closed-vc-camp-format-spring-ai-weekend-2026|Spring AI Weekend]] или подобного), можно делать **pre-event onlайн-эфир «вопросы организаторам»** с Лапшиной или Чевдарь в роли интервьюера. Бенефит — paid-traffic-free warm-up + retention бренда в exclusive-сообществе.
3. **Family-трек как content-hook.** Идея «привозят бабушку или всю команду на event» — **сильный contrast-hook** для founder-story-content. Если/когда GRO будет писать про «event-life balance», можно использовать South HUB как референс-кейс.
4. **South HUB → Snow BASE → community-continuum.** Pattern «сезонные events для одной аудитории» **переносим на GRO-community**: квартальные / полугодовые offline-events для core-юзеров, формирующие retention через предсказуемые встречи. Это canon-pattern для high-LTV products (см. также [[evolving/competitor-positioning/atlanty-business-club-positioning-2026|Атланты Бизнес Клуб]] как RU-precedent).
