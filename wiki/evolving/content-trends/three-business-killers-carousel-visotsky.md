# Carousel «3 убийцы бизнеса» — диагностический infographic-паттерн

Reusable content-формат, зафиксированный на [[sources/2026-05-19-tg-alexander-visotsky-may-14-19-2026|@alexander_visotsky, посты 3801/3802/3803]] (2026-05-18). Текстовый анонс (3801) с CTA на мастер-класс, затем **три карточки-инфографики** (одна тема на карточку), опубликованные одной серией в одну минуту. Это вариация [[evolving/content-trends/telegram-native-formats|нативного Telegram-формата]] и [[evolving/content-trends/expert-cobranded-tg-carousel-pattern|expert-карусели]], но заточенная под **диагностику боли** через named-anti-patterns.

## Зачем GRO

Для авторов GRO-контента: готовый шаблон «3 ошибки, которые ты делаешь прямо сейчас» под сегменты [[canon/target-audience/ru-smb-founder-owner-seller|предпринимателей]] и адаптируемый под solo-professionals. Формат saturation-resistant (короткие визуальные карточки), легко переносится в Instagram-карусель или reels-серию.

## Анатомия формата

| Элемент | Реализация у Высоцкого | Функция |
|---|---|---|
| Текстовый якорь-пост | 3801: «🟡 Три вещи, которые убивают бизнес. Предприниматели делают их прямо сейчас. Ни одна не решается усилием воли. Только системой.» + CTA на мастер-класс | Превью + CTA, ставит число «3» как обещание структуры |
| 3 визуальные карточки | По одной боли на карточку: жёлтый хайлайт-заголовок капсом + 2 абзаца тела + минималистичная диаграмма (бутылочное горлышко / падающий график / раздвоение) | Каждая карточка self-contained, шерится отдельно |
| Жирный «приговор» в конце карточки | «Делегировать — это разрешить людям ошибаться…», «он просто берёт у бизнеса в долг» | Memorable takeaway, цитатопригодная строка |
| Единый визуальный стиль | Светло-серый фон, жёлтый хайлайт заголовка, чёрный текст, тонкая line-art диаграмма с ⚠ | Узнаваемая серия, brand-consistency |

**Ключ механики:** каждый «убийца» = **named anti-pattern с механизмом**, а не общий совет. Не «делегируйте больше», а «"сам быстрее сделаю" → команда перестаёт стараться → платишь зарплату, чтобы работать самому». Боль названа фразой, которую читатель **узнаёт в своей голове**.

## Три хука (готовые формулировки)

### 1. «Сам быстрее сделаю» — самая дорогая фраза в бизнесе

**Оригинал (3801):** псевдо-делегирование. «Он экономит время сотрудника, но теряет время владельца. Команда привыкает, что финальный штрих всё равно за ним, и перестаёт стараться. Делегировать — это разрешить людям ошибаться, теряя деньги сегодня, чтобы они начали эти деньги приносить завтра.»

**Почему работает:** называет конкретную внутреннюю фразу-триггер. Reframe делегирования из «передать задачу» в «разрешить ошибаться = инвестиция». Диаграмма «много линий → одна точка» визуализирует владельца-бутылочное-горлышко.

**Адаптация для GRO:** для solo-professional — «"проще сделать самому" — это как ты остаёшься единственным исполнителем своей жизни». Для карьериста — «пока ты "быстрее сам", тебя не повышают: незаменимый = непродвигаемый».

### 2. Решения на ощущениях убивают быстрее кризиса

**Оригинал (3802):** «На счёте плюс — предприниматель спокойно распределяет деньги. Через месяц платить команде нечем — кассовый разрыв. Пока он не знает свою чистую прибыль с точностью до цента — он не владеет бизнесом. Он просто берёт у бизнеса в долг.»

**Почему работает:** контр-интуитивный хук «ощущения опаснее кризиса». Перекликается с dashboard-метафорой из поста 3792 (управление «на чуйке» = пилот без приборов, см. [[evolving/content-trends/owner-escape-operations-hooks]]). Финальная строка «берёт у бизнеса в долг» — сильный reframe.

**Адаптация для GRO:** «Пока ты не знаешь, на что реально уходит твой день с точностью до часа — ты не управляешь своим временем, ты берёшь в долг у своего будущего». Метрики-в-цифрах ↔ self-tracking GRO.

### 3. Жажда новых горизонтов убивает старые достижения

**Оригинал (3803):** преждевременная диверсификация. «В бизнесе стало скучно → запускает новый проект для "диверсификации" → вместо синергии две обесточенные компании. Старая падает без фокуса, новая не растёт из-за хаоса.»

**Почему работает:** называет тягу к новому как **скрытый саботаж**, а не амбицию. Диаграмма «раздвоение → две ⚠» делает риск наглядным. Близко к [[canon/marketing-frameworks/focus-strategy-porter|фокус-стратегии Портера]] и [[canon/marketing-frameworks/signal-noise-essentialism-spiridonov|эссенциализму]].

**Адаптация для GRO:** «Не начинай пятый проект, пока первый не работает без тебя. Жажда нового — это часто бегство от скуки дисциплины». Для фрилансера — «новая ниша каждые полгода = ты всегда новичок».

## Что копировать / не копировать

**Копировать:**
- Структуру «3 named anti-patterns с механизмом» + единый визуальный стиль карточек.
- Жирный «приговор» в конце каждой карточки как цитатопригодную строку.
- Текстовый якорь-пост перед серией карточек с числовым обещанием.

**Не копировать:**
- CTA на high-touch мастер-класс/мастермайнд — у GRO другая product-модель (self-serve).
- Owner-of-team фрейминг буквально — переводить на язык solo-professional/карьериста.
