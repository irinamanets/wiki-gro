# Founder-expert hook-family на vc.ru/story

Сводка двух устойчивых контент-паттернов, наблюдаемых в разделе «Истории» vc.ru весной 2026 года:

1. **Декларация канала verified-founder'а** (на примере Вячеслава Деля) — hook-family для founder-expert personal brand.
2. **Кейс-разбор публичного видео через академическую рамку** — устойчивый образовательный формат.

Оба паттерна релевантны для контент-стратегии GRO: Дель-декларация даёт hook-family для Сегмента 2 (предприниматели в росте), формат кейс-разбора — переносимый template для блога.

## Паттерн 1 — Декларация канала verified-founder'а

Вячеслав Дель — 50 лет, 30 лет в бизнесе, verified expert по правилу 1 из `rules.md` (track record публично подтверждён: радиостанция 1993, ИД 2007 — РБК назвало «самым динамичным», розничная сеть 20 магазинов в 11 регионах Сибири, Академия предпринимательства с лицензией, >300 учеников с суммарным оборотом >6.5 млрд ₽, спикер Сколково, член комитета по наставничеству ОПОРА РОССИИ). `confidence: high` на статус эксперта, `medium` на конкретные цифры (Academy и student-revenue не верифицированы внешним источником).

### Hook-family из контент-декларации канала Деля

Дель в анонсе канала формулирует **три ключевых hook'а** — каждый — самостоятельный narrative arc:

1. **«Как выстроить систему, чтобы бизнес работал без тебя»**
   - JTBD: освобождение времени основателя от операционки.
   - Sub-hooks: делегирование, оргструктура, найм первых нескольких сотрудников, ROP, регламенты.
   - **Прямая релевантность для GRO Сегмента 2:** см. [[canon/target-audience/gro-segments]] — JTBD «превратить хаотичную экспертизу в системный масштабируемый бизнес».

2. **«Почему компании с хорошей выручкой остаются без денег»**
   - JTBD: cash flow management, понимание разницы между выручкой и прибылью.
   - Sub-hooks: cash gap, ДДС vs ОПУ, рост vs cash, оборотный капитал.
   - **Релевантность для GRO:** business-метрики для founder'ов — пересечение с [[canon/marketing-frameworks/business-metrics-for-owners]] и [[canon/marketing-frameworks/data-illusion-management-rybakov]].

3. **«Как расти, когда вокруг говорят "сейчас не время"»**
   - JTBD: founder agency в макро-условиях, anti-FOMO, anti-«ждать лучших времён».
   - Sub-hooks: contrarian-стратегии, рост в кризис, ресурс-арбитраж.
   - **Релевантность:** пересечение с [[canon/marketing-frameworks/contrarian-location-bet-logistics-vs-resources]] и общим contrarian-нарративом.

### Что переносится для GRO

Эти три hook'а — **готовый каркас для контент-плана** Сегмента 2:

- Серия постов «система, чтобы бизнес работал без тебя» (4-6 материалов: делегирование → найм → регламенты → метрики → оргструктура).
- Серия постов «выручка ≠ деньги» (3-4 материала: cash gap → ДДС → working capital → kpi прибыли).
- Серия постов «расти в кризис» (3-4 материала: contrarian-кейсы, ресурс-арбитраж, anti-«не время»).

Каждый — content-cluster, который можно публиковать ежемесячно. Декларация Деля показывает: **founder-expert audience реагирует на hook'и, которые формулируют проблему ясно**, а не на абстрактные темы («про управление», «про финансы»).

## Паттерн 2 — Кейс-разбор публичного видео через академическую рамку

Два связанных материала на vc.ru/story (статьи 2801337 и 2801375, март 2026) от к.ф.н., доцента МГТУ — эксперта по системному моделированию. Формат:

1. **Источник** — публичное видео (в данном случае — Полонский про небоскрёб «Федерация», провальное кризисное совещание + успешный after-action review после пожара).
2. **Академическая рамка** — анализ через системный подход (факты vs эмоции, фокус-кризис, after-action review методология).
3. **Вывод** — переносимый практический принцип (в данном случае: «факты, не эмоции» в кризисном управлении).

### Почему это reusable формат

Преимущества для founder/expert-content:

- **Низкий cost-производства:** не нужно создавать новый кейс — анализируется уже существующее видео.
- **Высокая authority-сигнальность:** автор демонстрирует expertise через анализ конкретики, а не через общие рассуждения.
- **SEO-моментум:** имя медиа-фигуры (Полонский, в этом случае) — поисковый запрос, который приведёт трафик.
- **Conflict-driven engagement:** разбор провала более engaging, чем разбор успеха (см. Tokovinin-паттерн анализа провалов в YouTube — [[sources/2026-05-05-yt-tokovinin-billion-debts-sellers-startups]]).

### Что переносится для GRO

Reusable template для блог-публикаций:

> «Разбор [публичного видео / интервью с founder'ом / выступления] через рамку [GRO-методологии / 4-шаговой тренировки / hook-family Сегмента N]».

Примеры applicable themes:
- Разбор интервью с founder'ом на podcast'е через рамку «4 шага системного роста».
- Разбор популярного управленческого видео на YouTube через рамку «хабиты vs усилия воли».
- Разбор кейса провала vc.ru/story через рамку «диагностика без подушки безопасности».

Этот формат **дополняет** founder-expert hook-family из паттерна 1: hook'и формулируют тему, кейс-разбор даёт конкретный noun для серии («не "про систему", а "разбор кейса Деля про систему"»).
