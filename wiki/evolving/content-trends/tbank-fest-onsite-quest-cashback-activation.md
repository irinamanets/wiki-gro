# Fest-activation: pluggable бренд-spaces на чужом event'е

Наблюдаемый паттерн: Т-Банк **запускает онсайт-бренд-activation** на стороннем фестивале (Veter Spring Fest, Парк Горького, 23–24 мая 2026) с **двумя компонентами**: Маркет с кэшбэком (consumer-target) + квест Т-Бизнеса (B2B-target). Один event = два сегмента.

Base-кейс: [[sources/2026-05-26-tg-tinkoffbank-may-19-26-2026]] — пост [@tinkoffbank/10737](https://t.me/tinkoffbank/10737) (22 мая 2026).

## Анатомия активации

| Компонент | Target | Mechanic | Reward |
|---|---|---|---|
| **Маркет с кэшбэком** | Consumer (fest-аудитория) | Кэшбэк до 20% при оплате T-Bank-картой | Финансовая выгода |
| **Квест Т-Бизнеса** | B2B / SMB / future-entrepreneurs | Выполнить задания | Летний обвес для телефона + лимонад |

### Onsite-бренд-пространство

«Маркет с кэшбэком» — это **физическая зона** внутри фестиваля, где:
- Местные бренды (handmade-крафт, домашний декор) продают свои изделия
- Покупка картой Т-Банка = +20% cashback
- Брендинг T-Bank yellow в зоне (баннеры, fixtures)

Это **co-branded space** с локальной экономикой — Т-Банк не платит за продажи, но получает **brand-association с local-crafts community**.

### Квест Т-Бизнеса как side-activity

Параллельный механизм для B2B-сегмента:
- Запоминающиеся puzzle/tasks (физические или digital)
- Прогресс = подарки (small physical items)
- **Lead-gen** для Т-Бизнеса (получение контакта через quest-registration)

## Почему pluggable > own-fest

| Параметр | Собственный fest (e.g. Т-Двор) | Pluggable activation на чужом fest'е |
|---|---|---|
| **Capex** | Высокий ($M-уровень для серьёзного fest'а) | Низкий ($K-уровень, оплата за zone) |
| **Risk-shifting** | На бренд (отмена погоды = убыток) | На host-fest (отмена не на бренд) |
| **Audience-acquisition** | Бренд должен сам собрать | Pre-built audience у host-fest'а |
| **Brand-control** | Полный | Частичный (нужно coexist с host-vibe) |
| **PR-сигнал** | «у бренда есть собственный fest» = scale | «бренд активирует на любых event'ах» = agility |
| **Frequency** | 1–2 раза в год | Несколько per month |
| **Geo-coverage** | Локально (где Т-Двор) | Везде, где есть fest |

**Pluggable activation = capital-light expansion** на event-channel.

## Маркетинговая механика двух-сегмент-bundle

### Why одновременно consumer + B2B на одном event'е

1. **Audience overlap.** На fest'е приходят люди разных профилей — некоторые consumers (купить handmade-decor), некоторые small business owners (smb-owner + fan of crafts). Одновременная активация = pickup of multiple segments в одной точке.
2. **Shared-cost для бренда.** Setup, staff, branding amortized across two activations.
3. **Cross-pollination signal.** Consumer видит, что Т-Банк делает квест для бизнеса → когнитивно ассоциирует Т-Банк с small-business support. И наоборот.
4. **Lead-gen + brand-affinity в одной сессии.** Consumer получает cashback (positive emotional moment) + ассоциирует с Т-Банком. B2B — actively engages в квесте → leads.

### Geo-temporal сжатие как urgency-driver

«23–24 мая, Парк Горького, 12:00–22:00» — это **очень specific scope**:
- Geo-anchor (один парк) → easy to remember
- Time-anchor (2 days only) → urgency
- Hours-anchor (12-22) → fits in everyday schedule

Specificity повышает CTR через **mental imageability** («я могу туда поехать в субботу днём»).

## Условия применимости

- **Бренд имеет capex для onsite-presence (физическая зона + staff + branding).** Это **min ~$10K** даже для среднего fest'а.
- **Host-fest имеет alignment с brand-values.** Т-Банк + Veter Spring Fest = both have «городская spring lifestyle» vibe. Т-Банк + heavy-metal-фестиваль = misalignment.
- **Host-fest audience pre-aligned с target.** Veter Spring Fest = urban Moscow, 25–40, middle/upper-middle class = аудитория T-Bank Black.
- **Брендинг flex'ит между consumer- и B2B-tone.** Т-Банк (consumer-yellow) + Т-Бизнес (beige/tan) — это два разных visual языка. Хорошее зонирование в onsite-space.
- **Bandwidth для multi-segment execution.** Если только consumer-team, B2B-квест не получится. Multi-departmental coordination нужен.

## Anti-patterns

1. **Plug-in на любом event'е без alignment-теста.** «Мы спонсируем всё, что есть» = dilution бренда, audience confusion.
2. **Только B2B-активация на consumer-fest'е.** Если на Spring Fest только квест Т-Бизнеса = слабая участвующая аудитория, B2B-fish in consumer-pond.
3. **Onsite без digital-bridge.** Если onsite-зона не упомянута в посте TG (или Instagram), digital-amplification (followers, далее-not-attending users) теряется.
4. **Branding too aggressive.** «Маркет с кэшбэком» — это **frame, не just T-Bank logo everywhere**. Crafts-vendors должны feel partner, не sponsored. Если Т-Банк over-brands, vendors не будут рад coexist'ить.
5. **Quest-механика без clear-reward connection.** Если reward (летний обвес + лимонад) воспринимается как мелочь, B2B-аудитория не engaged. Reward должен быть **proportional к effort'у и context-aligned**.

## Переносимость на GRO

GRO как fitness/wellness-продукт может pluggable-activate на:

1. **City marathons / running races** — branded warm-up zone + consultation booth + free trial sign-up.
2. **Yoga / wellness retreats / festivals** (e.g., yoga-фестиваль) — branded mat-area + free 15-min session sample.
3. **Health/wellness expos** — booth с trial-codes + skin/posture-screening.
4. **Sports brand collab-events** (например, Adidas community runs) — multi-brand activation.
5. **Local park fests** (как Veter Spring Fest) — branded fitness-zone с workout-class в час пик.

Trio-frame: **consumer-experience (free try) + community-engagement (group-activity) + B2B-prospects (trainers / wellness-pros booth)**.
