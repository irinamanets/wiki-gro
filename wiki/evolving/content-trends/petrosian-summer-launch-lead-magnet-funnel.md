# Стодневка summer-launch воронка — 3-уровневый lead-magnet → newsletter → платная

3-уровневая контентная воронка Армена Петросяна, активированная летним запуском программы [Стодневка](https://stodnevka.ru/) 1 июня 2026. Анонсирована постом 2312 в [@stodnevka2](https://t.me/stodnevka2) (2026-05-20; см. [[sources/2026-05-26-tg-stodnevka2-may-20-26-2026]]). **Структура:** free self-paced PDF-книги (2 руководства, 76 страниц совокупно) → free TG-канал + рассылка «Контур важного» → платная Стодневка с групповой поддержкой.

## Анализ каждого уровня

### TOP: free PDF-книги как lead-magnet

**Petrosian-формат:**
- 2 книги, 34 + 42 = 76 страниц совокупно
- Опубликованы в 2025 году, self-published («б. и.» — без издательства), УДК/ББК присвоены
- **Каждая в 2 форматах** (PDF + EPUB), отдает в Telegram inline = no email gating

**Critical UX choice:** **no email gating** — файлы прикреплены непосредственно к посту в Telegram, без обязательной формы регистрации. Это **counter-conventional** для lead-magnet patterns (обычно email-gating = core mechanism). 

**Implication:** Petrosian **жертвует email-list growth** в обмен на:
- Trust (zero friction для получения value)
- Distribution amplification (легче переслать, нет login wall)
- Brand-aligned philosophy (антирекламный paradigm, см. [[canon/marketing-frameworks/petrosian-attention-as-anti-market-resource]])

`[conf:medium]` на trade-off interpretation.

### MID: TG-канал + newsletter «Контур важного»

- **TG-канал @stodnevka2** — 18-летний established personal-brand, regular posts (multiple per week), see [[sources/2026-04-14-tg-stodnevka2-mar-apr-2026]] для full prior context
- **Newsletter «Контур важного»** на stodnevka.ru/kontur + Substack-зеркало — **weekly cadence sustained ~90 дней** (письмо #7 = 2026-04-13 → письмо #13 = 2026-05-26 = 6 weeks без пропусков), `[conf:high, src:2026-05-26]`

**Mid-funnel mechanism:** read books → enjoy content → subscribe to TG / newsletter → sustained engagement → внутренняя motivation для перехода на платный уровень

### BOTTOM: платная Стодневка (1 июня 2026)

- 100-дневная групповая программа
- Старт раз в месяц (с 2015 года)
- Цена не публикуется в TG-канале (вероятно — landing-page-only)

**Conversion event:** **сезонный trigger «1 июня»** + **«среда людей, которые не ждут "Когда?"»** (пост 2323, см. [[canon/marketing-frameworks/petrosian-when-question-doing-vs-planning]]).

## Summer-positioning hook

**«Лето» как permission-buying mechanism:**
- Traditional permission: «Новый год / понедельник / 1 числа месяца» — все известные artificial-anchor points
- Petrosian-summer: «Лето — удобное время для начала перемен»
- **Implication:** **summer как seasonal anchor** работает потому что:
  - **Reduced commitments** (отпуска, расслабление, выходные на даче)
  - **Symbolic «новой жизни»** (как «лето после школы» для молодёжи)
  - **Менее crowded по pohod'у конкурентов** (большинство ставит «September resolutions»)

`[conf:medium]` на seasonal-anchor hypothesis.

**Cross-link** с book 1, ch.8 («лучший день для начала перемен — сегодня») — лето как seasonal-anchor НЕ противоречит «начни сегодня», а **разрешает «сегодня» в момент max-permission** (лето = «сегодня + permission»).

## Feasibility переноса в GRO content-стратегию

GRO — продукт ежедневного журналирования. Petrosian-funnel — **valid reference-architecture** для GRO content marketing:

### Direct application option

**3-уровневая воронка GRO (concept):**

| Уровень | Petrosian-version | GRO-version |
|---|---|---|
| TOP | 2 self-published PDF-книги (без email-gating) | 2-3 PDF-руководства по conкретным aspects GRO (e.g., «Как начать ежедневный дневник», «5 практик внимания для занятого человека») |
| MID | TG + newsletter | GRO blog + Telegram-канал + opt-in newsletter |
| BOTTOM | Платная Стодневка | GRO Pro / Интенсив / B2B cohort |

**Trade-off для GRO:**
- ✅ Builds **content-equity** (PDF-книги как permanent assets vs ephemeral blog posts)
- ✅ Aligns с brand-philosophy «инструмент для управляемого внимания» (anti-attention-extraction)
- ❌ **Cost:** writing 2-3 quality PDF-книг — substantial time investment
- ❌ **No email-gating** = harder to attribution-track conversion (Petrosian приоritises trust > attribution)

### Conditional adoption recommendation

**Adopt if:**
- GRO имеет capacity для writing 60-100 страниц quality original content
- Brand-philosophy GRO allows anti-aggressive mar`keting position
- Long-term horizon (12+ месяцев) — content-equity build-up медленный

**Skip if:**
- Short-term GTM pressure
- Performance-marketing dominant
- Content team underrelated к product-philosophy

## Anti-patterns в адаптации

1. **Скопировать формат без content-substance.** 2 PDF-книги Petrosian'а — 18-летнее distilled knowledge. Quick «2-PDF-lead-magnet» от GRO без equivalent depth = **felt-cheap**, негативный signal.
2. **Применить email-gating «потому что лучше для attribution».** Это **subverts entire trust-mechanism** Petrosian-фрейма. Если копировать, copy in full (no gating).
3. **Сезонный «1 июня» trigger без annual sustainability.** Petrosian запускает Стодневку **каждый месяц** с 2015 года — «1 июня» = specific month-version, не one-shot campaign. GRO должен иметь recurring cadence, не one-time summer launch.
4. **Использовать «Когда?»-positioning hook** в paid-ad. См. [[canon/marketing-frameworks/petrosian-when-question-doing-vs-planning]] anti-patterns.
