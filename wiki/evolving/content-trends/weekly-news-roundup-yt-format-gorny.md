# Weekly news roundup — формат-якорь Александра Горного

Регулярная content-формат-практика @startupoftheday: **раз в неделю** Александр Горный (см. [[sources/2026-04-14-tg-startupoftheday-mar-apr-2026|первый ingest канала]]) публикует один пост в Telegram, который:

1. Содержит **TOC из 15-20 заголовков** новостей за неделю
2. Заканчивается ссылкой на YouTube-выпуск с подробным разбором
3. Использует thumbnail с типографической метафорой

По наблюдению из [[sources/2026-04-27-tg-startupoftheday-apr-15-27-2026]] пост 5026, 2026-04-21.

## Формальная структура

### TOC поста (apr 21 2026 наблюдение)

20 заголовков, перечислены без подробностей:
- Черный день календаря, Отягчающий VPN, Горячий VPN, Заморозка каналов
- Национальные новости, Китай против дронов
- Mythos и Opus 4.7, Разговоры о важном, Linux за AI
- Вайбкод Милы Йовович
- Лучший пивот в истории (Allbirds → AI)
- Microsoft против OpenAI, Молотов против OpenAI, Европейцы против OpenAI
- Греция против соцсетей
- Дешевые робокурьеры
- Рекорды полумарафона
- 700 градусов
- Точка теперь Т
- Реклама на ivi

И единственная ссылка — на [YouTube-выпуск](https://youtu.be/CwJe1k3OVoo).

### Thumbnail формат

Один заголовок на обложке + ассоциативная метафора. Композиция стабильна между неделями: alarming-question/exclamation crops + portrait слева + красный visual element + газетная/типография справа.

**Variant A: 2026-04-21 (RUNET-видео)**
- Типография: «**RUNET / СОВСЕМ НЕ РАБОТАЕТ**» белыми буквами на красном «брызг»-фоне
- Иллюстрация: синий ethernet-кабель, перекусываемый кусачками
- Бейдж: «НОВОСТИ» внизу слева
- Левая треть: портрет ведущего на белом фоне (см. [[sources/2026-04-27-tg-startupoftheday-apr-15-27-2026]] раздел про распознанный текст 5026.jpg)
- Topic: RU-регуляторика недели

**Variant B: 2026-04-30 (AI-productivity-видео)**
- Типография: «**Где / польза / от AI?!**» белыми буквами на тёмном фоне
- Иллюстрация: красная стрелка-падение справа от текста + газета развёрнутая «AI productivity study» с red-bar charts падения
- Левая треть: портрет ведущего (русые/тёмно-русые волосы, серая футболка, нахмуренный) на размытом тёмно-городском фоне
- Topic: AI-productivity (alarmism)
- Источник: [[sources/2026-05-05-tg-startupoftheday-apr-may-2026]] пост 5042

**Pattern сохраняется через 9 дней** = format уже стабильный, не разовый. Используется для cross-platform трафика из TG к YouTube — это **clickbait-thumbnail** category.

### Cross-platform-формула

| Платформа | Формат | Цель |
|---|---|---|
| Telegram (этот пост) | Текст + TOC | Trigger для подписчиков канала, кто в TG |
| YouTube (по ссылке) | Видео-выпуск | Подробный разбор, повторное просмотр для retention |
| Thumbnail (на YouTube) | Метафора + типография | Сторонний YT-трафик, не из TG-канала |

## Почему это интересно как формат

### 1. Single-touch для всей недели

Одного поста достаточно, чтобы покрыть всю неделю newsworthy-content. Это **opposite** ежедневного режима «один стартап = один пост». Оптимизация по объёму создаваемого content (1 видео > 7 текстов).

### 2. Двойная monetization

- TG-канал: подписки, реклама-каналы, native-рекламы (см. [[sources/2026-04-14-tg-startupoftheday-mar-apr-2026]] про Лавку, Сбер, Т-Банк)
- YouTube: реклама в видео + подписки

### 3. Format-flexibility (текст vs видео)

Горный **сам решает**, что лучше упаковать как пост, что как weekly-видео:
- Авторская колонка → пост
- Лекция, длинная мысль → видео
- Newsworthy week → этот weekly-roundup-формат

## Что это значит для content-стратегии GRO

GRO — фитнес-приложение, не media. Прямого функционального переноса нет. Но как **content-architecture pattern** есть переносимое:

### Pattern 1: Один консолидированный пост на тематический промежуток

Если GRO-команда делает много content (что **сейчас не происходит**, но может в будущем), нет смысла отдельно публиковать каждое наблюдение. Можно:
- 7-9 daily-постов с конкретными hooks (упражнения, цитаты, мотивация) → ежедневный канал
- 1 weekly-roundup пост: «Что в фитнес-новостях на этой неделе» + ссылка на YouTube-выпуск

Это **усиливает retention** в обеих платформах:
- TG-подписчики получают **predictable rhythm**
- YouTube-зрители получают **regular content** vs ad-hoc

### Pattern 2: Cross-platform anchor

TG-пост → YouTube-видео = **известная связка для RU-аудитории**. Позиционирует canal как «авторский, regular, professional». Если GRO начнёт активно использовать YouTube — этот формат даст структурный базис.

### Pattern 3: Метафорические thumbnail-ы

Caption «RUNET совсем не работает» + кусачки + кабель = **strong clickbait архитектура** в RU-новостях. У GRO в фитнес-категории аналогичные сильные метафоры:
- «БОЛЬ ВЕЗДЕ» + сломанная пружина матраца
- «ДОПИВАЙ ЛАТЕ» + сломанная мускулистая рука с чашкой

Использовать осторожно — для clickbait-content, не для core-контента (см. [[evolving/content-trends/anti-authority-positioning-hook]] про границы).

## Anti-pattern: что НЕ делать

- **Не копировать TOC-формат для не-news-контента** — формат специфичен для newsworthy week. У GRO базовый контент ведь не «новости», а evergreen-фитнес-инструкция. Если применять weekly-roundup формат на evergreen-content — он будет читаться как искусственный «sample».
- **Не копировать кричащие thumbnail-ы для wellness-категории** — RU-news-роуспы используют alarmism, что может неуместно работать для wellness. У GRO своя эстетика, см. [[canon/brand-guidelines/gro-typography]].
