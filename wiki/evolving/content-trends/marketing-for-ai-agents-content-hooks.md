# Маркетинг для ИИ-агентов — content hooks 2026

Контентный паттерн начала 2026: серия постов / статей про то, что **классический маркетинг становится неактуальным, когда главными «пользователями» продуктов становятся ИИ-агенты, а не люди**. Зафиксирован **Аркадием Морейнисом** ([@temno](https://t.me/temno), [пост 7833 от 2026-05-14](https://t.me/temno/7833)).

## Центральный hook

> Большинство маркетинговых инструментов, которые ты использовал для продвижения своего программного продукта, скоро станут неактуальными. Потому что они рассчитаны на людей. Но скоро главными пользователями программ станут не люди... а ИИ-агенты! — Морейнис, [[sources/2026-05-14-tg-temno-moreynis-may-5-14-2026|пост 7833, 2026-05-14]]

Хук работает потому, что:
- **Конкретный + контр-интуитивный** — «твой видеоролик не нужен ИИ-агенту» режет глаз и заставляет дочитать.
- **Применим к B2B/SaaS-аудитории** — это **их** маркетинговый бюджет на кону.
- **Понятен без длинных предисловий** — за 1-2 предложения автору понятно «о чём пост».

## Структура поста с hook'ом «маркетинг для агентов»

Шесть устойчивых элементов, повторяющихся в exemplars:

1. **Hook-провокация** — «вы тратите деньги на маркетинг, который скоро устарел». Variation: «ваши видеоролики не нужны». «Ваши сториз бесполезны».
2. **Setup осознавания** — кто такие AI-агенты как пользователи (1-2 предложения).
3. **Контраст «человек vs агент»** — что нужно человеку (эмоции, история, дизайн) vs что нужно агенту (API, docs, structured data, benchmarks).
4. **Что нужно делать НОВОЕ** — конкретный список (API-first content, machine-readable specs, agent-readable docs).
5. **Anchor**: «начни СЕЙЧАС, потом будет поздно» — urgency.
6. **CTA / открытый вопрос** — «что в твоём маркетинге работает только для людей?»

## Категории hook'ов

Hook «маркетинг для агентов» — это family, в которой есть подвиды:

### Hook A: «Твои инструменты устарели»

Прямая формулировка Морейниса. Угрожающий тон. Подходит для **awareness** в B2B, особенно SaaS.

Vairaitons:
- «Зачем ИИ-агенту твой видеоролик?»
- «Провокация в посте: для кого? Для людей или для агентов?»
- «80% маркетинговых креативов нагло пропускаются ИИ»

### Hook B: «Новые сигналы доверия»

Объяснительный тон. Подходит для **decision** stage.

Variations:
- «5 сигналов, которые ИИ-агент использует для выбора продукта (и почему ни один не из твоего бренда-бука)»
- «Как сделать docs, которые читает ИИ»
- «API-first брендинг: что это и зачем»

### Hook C: «Двойной маркетинг»

Pragmatic, без угрозы. Подходит для **consideration** stage.

Variations:
- «Маркетинг для людей и маркетинг для агентов — две стратегии, один продукт»
- «Как структурировать контент для двойной аудитории»
- «Не выкидывайте брендинг — добавьте agent-readable layer»

### Hook D: «Конкурент уже сделал»

FOMO-tone. Подходит для **awareness → consideration** transition.

Variations:
- «Stripe / Twilio / OpenAI уже зашли в agent-readable docs. А ты?»
- «3 SaaS, которых видит ИИ — и не видит конкурентов»

## Какие сигналы ИИ-агент использует (что нужно «давать»)

Морейнис не углубляется, но context требует уточнения. Канонические сигналы, на которые ориентируются ИИ-агенты при выборе продукта (через AEO/GEO research):

| Сигнал | Что это | Где обычно отсутствует |
|---|---|---|
| Machine-readable docs (OpenAPI / GraphQL schemas) | API specs в стандартизированном формате | Большинство B2B продуктов без API-first design |
| Structured data в HTML (Schema.org) | Микроразметка для search engines | Большинство marketing pages |
| Benchmarks с публикованной методологией | Конкретные числа: throughput, latency, accuracy + how measured | Большинство SaaS hide за «contact sales» |
| Decision logic в open data | Когда применять, когда не применять, edge cases | Только Anthropic, OpenAI с явными model cards |
| Citations и references | Кто использует, какие use-cases | Большинство case studies — narrative, не structured |
| Pricing в open data (не «contact sales») | Прозрачное pricing, читаемое агентом | RU B2B preferentially hide pricing |
| Integrations table (machine-readable) | Какие сервисы поддерживаются, через какой стандарт | Большинство сайтов hide за «integrations» tab без structured data |

## Применение для GRO

GRO — B2C-product, но движение к **agent-as-buyer** уже видно (ChatGPT recommends apps, Claude recommends tools, Perplexity ranks). Серия постов для блога:

1. **Hook A (awareness):** «Ваш ChatGPT уже выбирает приложения для вас. На основе чего?» — для русскоязычной B2C-аудитории.
2. **Hook C (consideration):** «Двойной content: для пользователя и для рекомендательной системы» — для marketing manager'ов B2C-продуктов.
3. **Hook D (FOMO):** «Какие приложения чаще всего рекомендует ChatGPT в категории personal development. Анализ май 2026» — actionable competitor analysis.

**Каналы distribution:**
- Telegram (короткие версии hooks A, D)
- Habr (длинные deep-dive версии hooks B, C)
- vc.ru (D с актуальными данными)
- Блог groapp.ru (главная статья + linking)
