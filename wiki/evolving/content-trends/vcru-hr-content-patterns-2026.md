# vc.ru/hr как контент-платформа: паттерны 2026

Наблюдения о форматах, которые работают на vc.ru/hr, извлечённые из анализа 37 статей.

## Паттерн 1: Серийный SEO-advertorial (Garmony AI)

Garmony AI продемонстрировала устойчивый формат:
- 8-10 лонгридов (3000-5000 слов) опубликованы параллельно
- Структура: длинная экспертная статья + ROI-калькулятор + FAQ + рейтинг конкурентов (с собой на #1)
- Native advertorial, маскирующийся под редакционный контент
- SEO-оптимизация (ключевые запросы «автоматизация подбора», «AI в рекрутинге»)
- CTA встроен в текст, а не вынесен отдельно

Подробный разбор: [[evolving/competitor-positioning/garmony-ai-advertorial-campaign-2026]]

## Паттерн 2: Крючковые заголовки (engagement bait)

В рекомендательных блоках vc.ru видны устойчивые формулы:
- Числа-пугалки: «1200 откликов / 30 секунд отказ / 900 отказов»
- Personal-story: «моя история поиска работы»
- Вопрос-провокация: «AI заменит рекрутера?»
- Страх: «Snap уволит 16% из-за ИИ»

## Паттерн 3: Голос соискателя (job-seeker side)

Серия эмоциональных постов от соискателей формирует отдельный поджанр:
- «Система сломана» -- нарратив отчаяния (1200 откликов -- 1199 отказов -- 0 обратной связи)
- Замкнутый круг ATS: ATS отсекает «неформатных» -> кандидаты используют ChatGPT для оптимизации резюме -> рекрутеры получают 90% «пустышек» -> ATS ужесточается ещё сильнее

Для GRO этот голос -- сырьё для empathy-контента Сегмента 1.

## Паттерн 4: Рейтинги и списки

Формат «Топ-N инструментов для X» -- доминирующий жанр на vc.ru/hr для B2B-вендоров. Не только Garmony -- многие используют этот формат для SEO-захвата поисковых запросов.

## Паттерн 5: Программатик гео-city content-farm (vc.ru/hr «Удалённая работа в {Город}»)

Третий распознанный **коммерческий** жанр площадки (после Garmony Top-N advertorial и engagement-bait заголовков) — **программатик гео-листикл** «Удалённая работа в {Город}: вакансии на дому и онлайн». Единый шаблон с подстановкой топонима под гео-long-tail-запрос; тело — навигатор на ~9 внешних Telegram-каналов + job-сайты, плотность фактуры близка к нулю. Exemplars: [[sources/2026-05-19-vcru-hr-remote-work-kemerovo-city-seo-listicle|Кемерово]], [[sources/2026-05-19-vcru-hr-udalennaya-rabota-v-penze|Пенза]].

- **Отличие от Garmony Top-N (Паттерн 1/4):** Garmony продаёт один B2B-SaaS на #1 рейтинга; гео-ферма не продаёт ничего своего — трафик уходит наружу (реклама в TG, реф-программы площадок). Garmony — толстый материал на head-запрос; ферма — thin-материал на гео-long-tail.
- **Главный распознавательный признак:** замените название города — текст осмыслен на 100%. Город-замещаемость = программатик-шаблон.
- **Хрупкость:** канонический таргет helpful-content/антиспам-апдейтов; платформенный risk (vc.ru может вычистить thin-серию).

**Импликация для интерпретации vc.ru/hr:** раздел — **не однородно-экспертная** площадка. Здесь сосуществуют (а) гостевые экспертные статьи, (б) серийный SEO-advertorial вендоров (Garmony), (в) **programmatic geo-SEO content-farm**. При ingest vc.ru/hr нужно различать слой — экспертный материал даёт фактуру, content-farm даёт только формат.

Полный разбор анатомии, монетизации и переносимости — отдельными страницами: [[evolving/content-trends/local-seo-city-vacancy-content-farm-2026]] и [[evolving/content-trends/geo-templated-local-seo-listicle-funnel-2026]] (две страницы об одном жанре — кандидаты на слияние в lint-проходе).

## Переносимость для GRO

| Паттерн | Переносимость | Как адаптировать |
|---|---|---|
| Серийный SEO-лонгрид | Высокая | Серия на vc.ru про productivity / карьерный рост / AI-инструменты для самоорганизации |
| Крючковые заголовки | Высокая | Числа из wiki (23 резюме на маркетинговую вакансию, 64% уволятся) |
| Голос соискателя | Средняя | UGC от пользователей GRO / переосмысление нарратива «система сломана → решение в себе» |
| Рейтинги | Низкая | GRO не B2B-tool, формат «Топ-N» не подходит |
| Программатик гео-ферма | **Anti-pattern** (контр-референс) | НЕ копировать буквально (риск антиспам-санкций + −trust); переносим только trust-блок-as-content + geo-arbitrage-нарратив («расти в доходе вне столицы») через honest-ценность с реальной фактурой и воронкой в свой продукт |
