# «Журнал Деловой Мир» — practical-listicle pattern для CEO (2026)

Зафиксированный 2026-05-14 паттерн **business-publication advertorial-listicle для управленцев** через Дзен-канал «Журнал Деловой Мир». Единственная наблюдаемая статья на момент создания — [[sources/2026-05-14-dzen-deloviy-mir-ceo-cognitive-endurance]] (нутрициолог Шутенко про энергию CEO). Поэтому `confidence: low` — паттерн описан **по одному образцу**, требует подтверждения вторым источником прежде чем масштабировать.

## Зачем эта страница

«Деловой Мир» **не** vc.ru/Inc./Forbes — это **отдельный архетип** business-publication в RU 2026, ориентированный на широкую management-аудиторию (HR-директор, коммерческий, операционный, CEO средней корпорации), **не на founder'ов SaaS-стартапов**. ICP «Делового мира» имеет существенный overlap с [[canon/target-audience/ru-smb-founder-owner-seller|founder-owner-seller]] и [[canon/target-audience/hrd-portrait-2025-2026|HRD]] сегментами ГРО, но смещён в сторону **корпоративных управленцев**. Это даёт **новый distribution-вектор** для GRO — если редакция принимает гостевых экспертов, GRO-co-founder'ы (Тарасов / Егошин) могут писать туда об операционной продуктивности и self-management.

## Pattern-анатомия (по одной статье — гипотеза, не норма)

| Элемент | Наблюдение в Шутенко/Деловой Мир |
|---|---|
| Издание | «Журнал Деловой Мир» (Дзен-канал, не основной сайт) |
| ICP читателя | Управленцы: HRD, COO, CMO, директор СМБ |
| Автор | Гостевой эксперт (нутрициолог) — не штатный журналист |
| Длина | ~3500 знаков, ~10 минут чтения |
| Структура | Hook → re-frame проблемы → 8 практических блоков → 5-шаговая программа на неделю |
| Тон | Дружелюбный, второе лицо («вы»), без академизма («без таблиц и запретов») |
| Visual | Стоковые фото-иллюстрации (продукты/процессы) |
| Native-ad disclaimer | **Нет** — материал presented как editorial guide |
| CTA | Отсутствует / неявный (нет ссылок на продукт автора) |
| Тематика | Health/productivity/self-management для управленца, **не** бизнес-news и **не** industry-analysis |

## Узнаваемые format-templates «Делового мира»

(Гипотезы, по одному образцу — нужно подтверждение)

1. **«N шагов / N ошибок»** — Шутенко даёт 5-шаговую программу и 6 «здоровых» продуктов-ловушек.
2. **«Программа на неделю»** — micro-commitments: «один новый шаг в неделю».
3. **«Старая картина vs реальная причина»** — re-framing hook: «"усталость после обеда — это норма" → реальная причина — скачки глюкозы». Применимо к любому ICP-pain'у.
4. **«Без таблиц и запретов»** — anti-academic positioning, отстройка от health-инфобиза. Полезно как brand-voice ориентир.

## Reusable hooks для GRO content (адаптация «Делового мира»)

Структуру re-framing'а можно перенести на собственную тему GRO (рефлексия, самоменеджмент, продуктивность):

1. **«Вы не устаёте от работы — вы устаёте от того, чем кормите мозг»** → GRO-version: **«Вы не устаёте от работы — вы устаёте от того, что не возвращаете ей смысл»**. Re-frame усталости как management-вопроса, не «работайте меньше».
2. **«Это не норма»** → GRO-version: **«"Я весь день в реактивном режиме" — это не норма. Это симптом отсутствия системы»**.
3. **«Программа на неделю»** → GRO-version: **«Один новый шаг в неделю — реалистичная программа на 4 недели»**. Низкая friction, compound.

## Возможный distribution-канал для GRO

**Гипотеза:** «Деловой Мир» принимает гостевых экспертов с практическими guide-материалами (нутрициолог, психолог, юрист — широкая палитра). GRO-co-founder'ы (Тарасов, Егошин) могут писать туда **operational guide для CEO/managers**: «5 ошибок руководителя в самоменеджменте», «программа на неделю для возврата фокуса», «6 продуктовых триггеров burnout'а» — в формате «Делового мира».

**Что проверить перед инвестицией усилий:**

1. Связаться с редакцией «Делового мира», уточнить процесс приёма гостевых материалов и плату за размещение.
2. Подсчитать reach (Дзен-метрики канала «Деловой мир» — public-counter views/dzen, должны быть видимы в API/SimilarWeb).
3. Сравнить с reach vc.ru / Forbes / Inc. для оценки **cost per reach**.
4. Проверить ICP-overlap с GRO более точно — после второго ingest-источника от «Делового мира» (нужен второй наблюдаемый guide-формат).

**Риски:**

- Может оказаться, что «Деловой Мир» — просто Дзен-агрегатор без редакторской фильтрации (low-quality SEO-farm). Тогда reach ≠ recall.
- Тон «дружелюбный coach» может конфликтовать с GRO-positioning «спорит, но не отказывает» (anti-flattery из [[canon/brand-guidelines/gro-channel-tone-of-voice]]) — нужно тестировать.

## Что дальше

- **Искать второй образец** «Делового мира» — желательно из другой темы (не nutrition), чтобы подтвердить, что format-template повторяется, а не одноразовый.
- При появлении второго образца — поднять `confidence: medium` и расширить pattern-анатомию из гипотез в наблюдаемые нормы.
- **Параллельный мониторинг** Дзен-каналов adjacent business-publications (РБК Тренды, Бизнес-журнал, СБК ru, Эксперт) — на предмет похожих practical-listicle паттернов для управленцев.
