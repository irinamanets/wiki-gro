# Before/After carousel участников cohort'а — content-format

Reusable Telegram-carousel-формат для **финализации образовательного / coaching-cohort'а**: одна карточка на участника с явными метриками «до» и «после», объединённая в единый карусель-пост. Якорь-пример — карусель 2315-2320 из [[sources/2026-05-26-tg-olegcloser-may-22-26-2026]] (финал реалити «Рекордный апрель» Шевелева).

`confidence: medium` — один observed instance с явной структурой, но методологически связан с устоявшимся carousel-pattern'ом (см. [[evolving/content-trends/expert-cobranded-tg-carousel-pattern]]).

## Структура формата

### Карточка обложки (опционально)
Заголовок типа «Результаты реалити: цифры и главные изменения в бизнесе» + sub-title с контекстом cohort'а. В кейсе Шевелева обложка отдельной карточкой не выделена — текст-пост 2315 играет её роль; карусель сразу начинается с участников.

### Карточка участника (повторяется N раз)

Стандартный шаблон, **обязательные элементы**:

| Зона карточки | Контент | Пример из Шевелева |
|---|---|---|
| **Header (top)** | Фото + ФИО + возраст + локация-pin + бизнес-роль (иконка) | «Литвинов Роман, 43 года, Краснодар, Предприниматель» |
| **Sub-header** | Ниша / отрасль | «Эксклюзивные балясины и стеклянный кирпич» |
| **Block 1: "ДО реалити"** | Иконка-индикатор (👎 спидометр на красном) + **отрицательная метрика** в 2-3 строках | «1 сделка в марте при норме 8, вложил 650 тыс. личных сбережений в зарплаты. Не работал с зависшими клиентами, CRM считал бесполезной.» |
| **Block 2: "ПОСЛЕ реалити"** | Иконка-индикатор (👍 спидометр на зелёном) + **положительная метрика** + **transformation-описание** | «Рекорд по объёму заказов, выручка на 35% выше апреля 2025, объём заказов на 80% выше, чем за все первые три месяца 2026 вместе взятые.» |
| **Visual evidence (bottom)** | 3 скриншота: (1) CRM / таблица с цифрами, (2) переписка с клиентом / письмо клиента, (3) фото участника с благодарственным письмом / автографом | Скриншот CRM с подкрашенными выручками + переписка с reply от клиента + цитата участника со скриншотом |

### Цветовая разметка
- **ДО** — нейтральные оттенки или красные акценты в иконке
- **ПОСЛЕ** — зелёные акценты в иконке + подчёркивание ключевых чисел (рекорд = подчёркивание)

## Почему формат работает

### 1. Concrete-evidence над generic-обещаниями

Каждая карточка содержит **минимум 2 verifiable числа** (ФИО + конкретная метрика) — это анти-инфобиз-paradigm. Сравнить с classic-инфобиз-маркетингом: «наши студенты делают результат» (generic) vs «Юлия Краснова, Новосибирск, медоборудование — 5,1 млн прибыли» (concrete).

Этот pattern критичен в **низкокредитной среде** (post-Q1-2026 RU SMB, см. [[evolving/industry-trends/ru-smb-sales-q1-2026]]) — аудитория устала от обещаний, доверие даёт только confirmable identity участника + конкретная цифра.

### 2. Carousel = высокая retention в Telegram

В отличие от единого длинного текстового поста (читается 30% подписчиков), carousel требует **swipe-engagement** = более глубокая читаемость. Каждая карточка получает ~2-5 секунд внимания подряд, что выше, чем single-post.

### 3. Scrollable case-bank после публикации

Carousel-пост в Telegram **сохраняется** в чате и может быть найден по поиску. Это превращает его в **evergreen content asset** — будущие лиды находят его через «Юлия Краснова продажи реалити» search и попадают в funnel.

### 4. Социальный эффект «один из нас»

Шесть разных карточек с разными нишами / городами / возрастами увеличивают вероятность **self-recognition** у зрителя («Краснодар как у меня», «остекление похоже на моё»). Это **диверсификация anchor'ов**, аналогичная подходу [[evolving/content-trends/sales-ai-narrative-hooks-2026|empathy-geography hooks]] Шевелева в текстовых постах.

## Pre-requirements для формата

Чтобы before/after carousel **работал**, cohort должен соответствовать набору условий:

| Требование | Если не выполнено |
|---|---|
| **6+ участников с измеримыми метриками** | Меньше = неполная statistical-репрезентация, читатель не верит. Больше 8 — carousel становится слишком длинным. |
| **Метрики у всех в одной валюте смысла** (рубли, конверсия %, число клиентов) | Несравнимые метрики = слабый narrative. Шевелев пользуется в основном рублями + конверсия — оба понятны. |
| **Согласие участников на публикацию ФИО+фото** | Без явного opt-in — нельзя публиковать. Carousel требует pre-launch consent на media-release. |
| **Реальные verifiable cases** | Если хоть одна карточка fabricated — узнается, формат коллапсирует в инфобиз-провал. См. [[evolving/content-trends/reality-show-haters-narrative-defense]] — Шевелев уже встречал «наняли актёров»-обвинения. |
| **Pre-launch baseline metrics fixed** | Карточка «ДО» должна быть зафиксирована при старте cohort'а, не reconstructed после. Иначе метрика выглядит подогнанной под результат. |

## Anti-patterns

### Anti-pattern 1 — generic «все получили рост»

Если все карточки звучат как «увеличили продажи / получили результат» — теряется specifity и не работает. **Правило:** каждая карточка должна иметь **уникальную** ключевую метрику (рекорд по выручке / по среднему чеку / по конверсии / по оттоку / по числу сделок и т.д.).

### Anti-pattern 2 — слишком красивые числа

Все «×3» или «+100%» во всех карточках = выглядит подогнанным. Шевелев включает менее радикальные («+12% к марту» для Юрия, «+25%» для Александра) рядом с радикальными (×2,9 средний чек) — это **увеличивает доверие** через variability.

### Anti-pattern 3 — отсутствие visual evidence

Просто текст «5,1 млн прибыли» без скриншота CRM = легко придумать. **Правило:** каждая карточка содержит **минимум один скриншот** real-system (CRM, чат, message от клиента) + одно фото участника с автографом ведущего.

### Anti-pattern 4 — все участники одной ниши

Снижает diversity и self-recognition. **Правило:** разные ниши + разные города + разные размеры бизнеса (см. [[evolving-strict/campaign-metrics/recordnyi-aprel-finale-results-shevelev-2026]] — у Шевелева разброс 13 000 $ – 800 млн ₽/год).

## Применимость к маркетингу GRO

GRO — B2C, без cohort-сетапа в классическом смысле, но формат **переносим** с адаптацией.

### 1. «30 дней с GRO challenge» finale-carousel

Если GRO запустит публичный challenge (см. [[canon/marketing-frameworks/business-reality-show-format]] — секция «Применимость к GRO»), финал должен закончиться carousel'ом 5-6 участников по этому шаблону:

| Зона карточки | GRO-content |
|---|---|
| Header | Фото + имя + возраст + город + должность |
| Sub-header | Ниша / контекст работы («founder агентства», «product-менеджер», «freelance-дизайнер») |
| ДО | «10 часов в день на телефоне, 5 незавершённых задач в неделю, тренировка раз в 2 недели» |
| ПОСЛЕ | «4 часа на телефоне, 0 незавершённых, тренировка 5 раз в неделю» |
| Evidence | Скриншот Screen Time + GRO-app данные + фото с участием |

### 2. Adapt: «месяц с GRO» case-collection

Каждый месяц публиковать carousel из 3-5 anonymized/opt-in пользователей с before/after. Это **regular content cadence**, не нужно ждать формального challenge'а.

### 3. Adapt для блог-постов GRO

Один blog-пост на `groapp.ru/blog` = одна развёрнутая Before/After-карточка одного пользователя. Тогда GRO собирает **case-bank** на уровне блога, который можно cherry-pick'ать в Telegram-carousel'ы.

### 4. Anti-pattern для GRO

GRO **не должен** генерировать fake-cases или сильно преувеличенные. Лучше: меньше карточек (3-4 вместо 6), но **100% verifiable**.

## Reusable как hook для отдельных carousel'ов

Helper-формат: вместо полного finale-carousel'а можно публиковать **одну Before/After-карточку** как самостоятельный пост в Telegram. Это:

- **Cheap-to-produce** (одна история, одно интервью)
- **Часто работает лучше**, чем полный carousel, потому что фокус на одном кейсе
- **Reusable** в нескольких каналах (Telegram-карточка → Instagram-reel → блог-статья)

Шевелев иногда использует такой single-card-формат: пост 2326 («Marat — первый отпуск за 12 лет») — фактически one-card Before/After пост, который работает как mini-anchor + lead-magnet CTA.
