# Корпоративный monthly research digest — формат «СберУниверситет PRO.Людей»

Воспроизводимый content-format для корпоративного образовательного / R&D-департамента: **ежемесячный PDF-дайджест 10–15 страниц с обзором ~1500–1700 публикаций из 50–70 авторитетных источников за месяц, distributed через собственный канал + co-promo через нишевые vertical-каналы**. Зафиксирован у СберУниверситета на примере выпуска «PRO.Людей» за апрель 2026 (распространено через RFF post 4432, 2026-05-19). См. [[sources/2026-05-19-sberuniv-pro-people-digest-april-2026]] и [[sources/2026-05-26-tg-rff-channel-may-19-26-2026]].

`confidence: medium` — один observed выпуск + factual подтверждение «ежемесячности» через метаданные («апрель 2026», списки команды); полная серия не проверена, но факт-наличие brand-frame'а («Дайджест PRO.Людей», стабильный визуал, named-команда) указывает на established-формат, не разовый эксперимент.

## Структура формата

PDF-дайджест состоит из стабильных блоков (14 стр. в апрельском выпуске):

| Блок | Стр. | Назначение |
|---|---|---|
| Cover | 1 | Брендированный визуал, дата выпуска, название («Дайджест PRO.Людей»), издатель (СберУниверситет) |
| О выпуске + список источников | 2 | Количественное обоснование («1600+ публикаций из 70 источников») + namedrop authorities (70 brand-имён) |
| Содержание (ToC) | 3 | 4 категории × N итемов, scannable-листинг |
| Контент по итемам | 4–13 | 1 страница на итем = 1 фрейм/тезис; заголовок-цифра + 2–3 ключевых числа крупно + body + источник |
| Книжная рекомендация | 14 | Не аналитический итем — institutional thought-leadership (одна книга в месяц) |
| Команда | 15 | Named-команда (7 человек с титулами) — proof-of-vitality research-департамента |

## Ключевые мехаmismes формата

### 1. Количественная методология как proof-of-rigour

> Для подготовки дайджеста наша команда проанализировала более **1600 публикаций за апрель 2026 года из 70 ведущих мировых и российских источников** `[conf:high, src:2026-04]`

Эта строка — proof-of-rigour: читатель сразу видит, что дайджест — **не curated by intuition**, а результат структурированной работы. Это **снимает доверительный барьер** для academic / corporate-audiences.

### 2. Список источников как namedrop-asset

Полная страница со списком 70 источников (Accenture, BCG, McKinsey, Mercer, HBS, MIT Sloan, Gallup, Springer, ВШЭ, Сколково, РАНХиГС и т.д.) выполняет **двойную функцию**:
- **Reader-уровень:** ассоциация СберУниверситета с этими брендами через одно соседство.
- **SEO/discovery-уровень:** namedrop authority-источников = content-anchors для AI-search / GEO в HR/management вертикалях.

### 3. Одна страница = один фрейм + key-stat

Формат «крупная цифра-заголовок + body + источник» (страницы 4–13) делает дайджест **scannable** — читатель за 30 секунд скачет по «1 из 100», «20%», «$10 трлн», «89%/50%», «81% vs 56%», «−2 часа», «31%», «25 п.п.». Это **research-as-content-snippet** механика, родственная [[evolving/content-trends/research-as-pr-transactional-data-format|research-as-PR-формату Т-Банка]] (transactional-data publication для PR), но в monthly-cadence-варианте.

### 4. Институциональный credibility через named-команду

Финальная страница с 7 named-людьми (Суханов, Стрельцова, Желябин, Гаврина, Ярцев, Тарасова, Взорина) + их титулами — **proof-of-existence research-департамента**, не «outsourced PR».

### 5. Co-promo через нишевые vertical-каналы

В апрельском выпуске distributed через @sber_university + @rff_channel (RFF post 4432) — нишевой HR-канал с 60K+ аудиторией. **Match relevance:** дайджест по HR-темам → HR-канал. RFF получает proof-of-vitality контент-блок без production-усилий, СберУниверситет получает aligned-distribution.

## Применимость для GRO

### Прямая воспроизводимость — **низкая**

Для GRO как раннестадийной (≤30 человек) productivity-SaaS-компании этот формат **dilutes effort** — production одной такой PDF стоит ~30–60 человеко-часов + design + redaction, а ROI размытый (top-of-funnel awareness без direct-conversion). Sber/Mercer могут себе позволить, GRO — нет.

### Адаптации с сохранением value

1. **Quarterly «mini-digest» вместо monthly.** Не 1600 публикаций / 70 источников, а **30 публикаций / 10 источников / 1 quarter**. Production ~5–10 ч-часов. Сохраняет proof-of-rigour, снимает overhead.
2. **Topic-narrow digest вместо broad.** Не «HR в целом», а **«self-management практики (digest)»** или **«productivity research месяца»** — узкая ниша даёт authoritative-positioning без необходимости в 70 источниках.
3. **Curated-list-style (без PDF-production).** Email- / Telegram-формат с links + 1-абзацными выжимками. Не требует design-overhead; сохраняет «institutional content» tone.
4. **Co-promo со партнёрскими каналами.** Найти 2–3 ниши-канала про self-management / productivity / personal effectiveness, договориться о ежемесячном co-promo своего digest.

## Anti-patterns

- ❌ **«Сделаем такой же как Сбер»** — production-overhead убьёт темп; раннестадийная компания тонет в перфекционизме первого выпуска.
- ❌ **Курировать единолично основателем** — формат живёт за счёт «команды» (named-people), single-author digest теряет институциональный flavour.
- ❌ **Игнорировать distribution** — Sber-формат works **только** через distribution (свой канал + co-promo); без неё дайджест умрёт после 1–2 выпусков.
- ❌ **Подделывать «1500 публикаций»** — proof-of-rigour работает только при honesty; разоблачение разрушает credibility сильнее, чем отсутствие числа.
- ❌ **Книжная рекомендация без attribution-context** — у Sber это работает потому, что Асмолов = руководитель Академии (внутренний); внешняя book-pick без curation-context теряет институциональный смысл.

## Content-hooks для блога / Telegram

- «Что я узнал из 14-страничного PDF от СберУниверситета (за вас)» — meta-комментарий с linkback к самому дайджесту.
- «70 источников за 14 страниц: как Сбер делает thought-leadership через research-aggregation» — формат-разбор для founder/marketing-audience.
- «4 столпа Mercer 2026» — content-snippet один из дайджеста, скоро-долго перепаковка.

Готовая контент-серия из ~5–8 единиц на основе одного апрельского выпуска без необходимости в собственном производстве research.
