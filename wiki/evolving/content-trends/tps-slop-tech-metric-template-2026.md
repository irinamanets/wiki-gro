# TPS — Tokens Per Slop как шаблон сатиры (май 2026)

**Происхождение паттерна:** Telegram-пост [@boris_again](https://t.me/boris_again) 3920 от 2026-05-24 21:15 UTC. См. [[sources/2026-05-26-tg-boris-again-may-19-24-2026]].

## Что это за паттерн

**Берётся набор «канонических tech-метрик»** (то, что каждый CTO и DevOps знает наизусть) и **каждой даётся slop-каламбур** — переосмысление через призму AI-генерации низкокачественного контента.

Оригинальный список Бориса:

```
TPS: Tokens Per Slop - the throughput of garbage
QPS: Questionable Prompts per Second - how fast you can ask the AI for more slop
TTFB: Time To First Bullshit - latency between your prompt and the first hallucinated word
P99 Latency: Pure Slop 99% - threshold at which 99% of your outputs are certified nonsense
IOPS: Inane Output Per Slop - measuring the sheer density of meaningless tokens
MTTR: Mean Time To Regurgitate - how quickly the model can rephrase the same wrong answer after a crash
SLA: Slop Level Agreement - a legally binding promise that the slop will be 99.9% coherent-enough
```

## Анатомия формата

**1. Узнаваемость subject-ов**: каждая метрика (TPS, QPS, TTFB, P99, IOPS, MTTR, SLA) — **canonical** для tech-аудитории, мгновенно узнаваема без объяснений. Это создаёт **«инсайдерский шум»** — читатель чувствует, что находится «внутри» темы.

**2. Анти-evangelism тон**: формат **высмеивает AI без объяснений, что не так**. Подразумевается, что любой работавший с LLM в проде это уже знает (hallucinations, slop, output-quality drift). Это **shared experience humor**.

**3. Лаконичность**: каждая строка — `АББРЕВИАТУРА: расшифровка - one-line объяснение`. Это **scannable** на мобильном, **share-friendly** (можно скопировать и переслать), **screenshot-friendly**.

**4. Универсальная re-applicability**: формула «канонический набор → каждой свой каламбур» **переиспользуется** для любой темы. Готовые подмножества для GRO-блога:
- Marketing-метрики (CTR, CPM, CPA, ROAS, LTV, CAC) → AI-slop версия для AI-генерируемых креативов
- HR-метрики (TTH, eNPS, turnover, time-to-productive) → AI-slop версия для AI-recruiting
- Product-метрики (MAU, DAU, retention, churn, NPS) → AI-slop версия для AI-product

## Почему этот шаблон работает в 2026

**1. Slop-эпоха стала консенсусом.** К маю 2026 «AI generates a lot of low-quality content» больше не контроверсия, а **shared baseline** даже в pro-AI сообществах. Boris-формат **легитимизирует это shared baseline через юмор**.

**2. Высокий signal-to-noise при низкой затрате.** 7 строк = 1 пост. Очень дешёвое production, но **высокий engagement** (потому что узнаваемо).

**3. Параллель с «этот канал» мемом** ([[evolving/content-trends/ai-news-flooding-meme-template-2026]]) — оба паттерна **самосаркастичны**: автор AI-канала шутит над AI-каналом. Это **trust-marker для аудитории** («автор не евангелист, понимает проблемы»).

## Готовые применения для GRO-блога

### 1. «KPI Per Slop» — маркетинговая сатира

```
CTR: Click-Through-Slop - сколько кликов на ваш AI-баннер сделал бот
CPM: Cost Per Mille slop - сколько долларов вы заплатили за 1000 показов сгенерированных AI
ROAS: Return On Ad Slop - сколько центов вернулось из доллара AI-таргетинга
LTV: Lifetime Value of Slop - сколько каналов отписалось от AI-newsletter за месяц
CAC: Cost to Acquire (a) Customer (using AI slop)
```

**Канал:** блог GRO, Telegram, LinkedIn. **Тон:** друзья-маркетологи, не корпоративный.

### 2. «Productivity Per Slop» — для AI-management-аудитории

```
WIP: Work In Slop - количество задач, которые AI начал, но не довёл до результата
DRI: Directly Responsible Iteration - сколько раз вам пришлось переделать за AI
SLA: Slop Level Agreement - 99.9% что у вас будет AI-output, но не гарантия, что useful
ROI: Return On Investment in slop - финансовый показатель того, что вам пора уволить AI-консультанта
```

### 3. «HR Per Slop» — для рекрутинг-аудитории

```
TTH: Time To Hire (via AI-screening) - время от подачи резюме до отказа AI-ассистентом
eNPS: Employee Net Promoter Slop - сколько сотрудников любят AI больше, чем своих коллег
PIP: Performance Improvement Plan via AI - если ваш AI плохо работает, AI его уволит
TPS: Time Per Slop - сколько часов вы тратите, чтобы выправить AI-отказное письмо
```

## Pattern-теория: «инсайдерский каталог + slop-перевод»

Этот формат относится к более широкому **template-content паттерну**:

```
[узнаваемый набор предметов]  +  [одна сатирическая призма]  ===>  лёгкий вирус
```

Параллели вне AI-slop:
- **«типы людей в спортзале»** — canonical классификация + carikатура каждого типа
- **«твоё инди-кафе по знаку зодиака»** — astrology + lifestyle-juxtaposition
- **«роли в команде по типу Pokemon»** — pokemon set + management humor

**TPS-Slop = частный случай**, особенно сильный потому что:
1. tech-метрики **uncontroversial** (нет fan-wars)
2. **AI-slop консенсус** делает сатиру bipartisan
3. **формат скейлится** — можно делать новые подмножества бесконечно

## Почему это важно для GRO

1. **Готовый шаблон под content-производство**. Каждый «X Per Slop» — это **15-минутный пост**, который при правильном тоне набирает engagement выше среднего. **TODO:** включить в content-pool для май–июнь 2026.
2. **Тонорегистрирующий маркер**: использование slop-юмора показывает аудитории, что GRO **не AI-евангелист** (что критично для опытных tech-маркетологов и CTO).
3. **Counter-positioning vs AI-evangelist бренды**: пока конкуренты (Cursor, Anthropic в маркетинг-материалах) хвалят AI-productivity, GRO может **подчеркнуть реальные проблемы** через slop-формат. Это **дифференциация через интеллектуальную честность**.
4. **Связь с METR survey**: [[evolving-strict/market-data/metr-ai-productivity-self-vs-measured-2026-05]] даёт **факт-аргумент** под slop-юмор. Slop как формат **+** METR-факт как доказательство **=** комбо-контент: «вот почему мы шутим о slop, вот цифры».
