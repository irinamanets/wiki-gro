# RU task-manager / productivity-tool landscape — historical baseline ~2016

**Что это:** snapshot редакционно-нормативного среза RU task-manager / productivity-tool-landscape образца ~2016 года, зафиксированный в анонимном evergreen-листикле Жажды [[sources/2026-05-16-zhazhda-task-manager-business-evergreen-2016|«Выбираем планировщик задач для предпринимателя»]]. Hand-pick'нутые редакцией 5 продуктов в 3 платформенных кластера отражают, **как тогдашний издатель для SMB-аудитории представлял себе нормативный productivity-tooling-stack**, и служит **pre-AI baseline** для рассуждений о консолидации и AI-революции категории к 2026.

`confidence: medium` — наблюдения опираются на один источник, но категория «historical baseline» именно про **снимок прошлого**, а не про current'ы, поэтому single-source приемлемо: мы не утверждаем «такой landscape сейчас», утверждаем «такой landscape представляла Жажда в 2016 году, до закрытия Wunderlist (2020) и до AI-революции (2023+)».

Параллели:
- [[evolving/content-trends/ru-online-booking-saas-baseline-2016]] — аналогичный 2016-baseline в SMB-сервисной вертикали (booking-SaaS).
- [[evolving/content-trends/ru-personal-finance-listicle-baseline-2016]] — аналогичный 2016-baseline в SMB-finance-вертикали (личные финансы / семейный бюджет).

Триптих из 3 historical-baseline'ов даёт **полный срез RU SMB-tooling 2016**: запись клиентов (online-booking) → деньги (personal finance) → задачи (task-manager / productivity). Эта triada — фундамент для contrast-нарратива «как изменился SMB-tooling за 10 лет до 2026».

## Зачем эта страница

Этот landscape **не современный** — почти все конкретные факты (цены, доступность продуктов, набор лидеров) устарели. Но **сам срез** ценен как:

1. **Pre-AI baseline для рассуждений о productivity-tool-эволюции.** Чтобы построить контент 2026 года «как изменился стек предпринимателя», нужен фиксированный baseline из прошлого. Этот листикл — готовый baseline (5 продуктов ~2016 → AI-эра 2026 с radically разным набором ожиданий).
2. **Эталонная rubric выбора SaaS-tool в 2016.** Жажда фиксирует **6 критериев выбора** (см. отдельную страницу [[canon/marketing-frameworks/saas-tool-selection-rubric-pre-ai-2016]]). Эта rubric явно показывает, что **AI-функции и messenger-интеграция не были даже на радаре** в 2016 — оба сейчас в топ-3 expected-features productivity-tool 2026.
3. **Reference для дифференциации GRO-контента от legacy-листиклов.** Если GRO пишет «5 AI-инструментов для предпринимателя 2026», знание, чем выглядел жанровый предшественник, помогает не повторить структурные ошибки (анонимность, отсутствие дат, format-fill до круглого числа, parsing-loss заголовков).
4. **Историческая привязка для productivity-gamification.** Todoist Karma в этом снапшоте уже работает — **один из самых ранних массовых in-app productivity-gamification механизмов**. Линия Todoist Karma (~2013) → Habitica → Duolingo streaks → habit-trackers 2020+ → GRO 2026 — каноничный narrative-arc для GRO content.

## Что Жажда говорит о состоянии категории 2016

### Editorial-фрейм

- **«У каждого свой идеальный планировщик»** — категория **зрелее, чем online-booking 2016**: уже есть мировые лидеры (Todoist, Wunderlist, Things), но **нет одного доминанта** для SMB-предпринимателя на RU-рынке.
- **Платформенная фрагментация** — основная editorial-боль 2016 года: продукты делятся на «универсальные кроссплатформенные» (Todoist, Wunderlist) и «нишевые однопотолочные» (Things только macOS/iOS, You Doo только Windows). Это до-mobile-first epoch, где WP-экосистема ещё живая.
- **Predicted choice mode:** «попробуйте установить каждый из них и поработать хотя бы неделю» — то есть редакция признаёт, что **нет объективного критерия выбора**, и предлагает trial-and-error subjective approach. Это типичная SMB-evergreen-editorial-позиция «фрагментированной категории».

### Pain-формулировка (как звучала в 2016)

«**Существует сотня сервисов для планирования рабочего дня и столько же статей по их выбору.**» — editorial-position признаёт что (а) категория **слишком фрагментирована** для авторитетного ранжирования, (б) **читатели перегружены choice-paralysis**, (в) роль листикла — short-list filter.

К 2026 эта pain'а **углубилась**: количество tools выросло (тысячи в App Store), но **AI-революция дала новый класс агентных productivity-tools** (AI Todoist, Reclaim.ai, Motion, Notion AI), которые **меняют сам frame «таск-менеджер»** на «AI-orchestrator who manages tasks for you». См. ниже сравнение с 2026.

### Editorial-критерии выбора (6 критериев)

Сформулированы прямо в листикле (см. отдельную страницу [[canon/marketing-frameworks/saas-tool-selection-rubric-pre-ai-2016|saas-tool-selection-rubric-pre-ai-2016]] для канонического разбора):

1. Кроссплатформенность (iOS / Android / macOS / Windows / web)
2. Расширенный функционал (приоритеты, заметки, attachments, сортировка)
3. Облако + офлайн
4. Бесплатная пробная версия
5. Русификация
6. Простой / интуитивный UI

**Что отсутствует** (появилось бы в 2026 rubric):
- AI-функции (LLM-prompted task creation, smart-prioritization, AI-summary, agentic-execution)
- Messenger-интеграция (Telegram-bot, WhatsApp, Slack)
- Mobile-first design (в 2016 ещё не дефолт)
- E2E-шифрование / privacy
- API / Zapier / automations
- Open-source / self-host опции

### Editorial-структура (3 платформенных кластера)

Жажда не делает плоский ТОП-N, а структурирует по платформенному кластеру:

- **Универсальные** (Todoist, Wunderlist) — рекомендованы как preferred выбор.
- **Только Windows** (You Doo, My Calendar) — для тех, кто **не имеет Apple-устройств** и хочет работать только на Windows. Редакция явно признаёт это **suboptimal-сегментом** («слегка наивный планировщик», «существует ещё около десятка таск-менеджеров для Windows, но все они дублируют функционал You Doo и My Calendar»).
- **Только macOS/iOS** (Things) — для тех, кто **в экосистеме Apple** и готов платить премиум-цену за каждую платформу отдельно.

Это **3-х платформенный матричный listicle**, отступление от классической ТОП-N структуры жанра — но видимо ответ на фрагментацию категории.

## Сравнение с современностью (2026)

| Параметр | Landscape ~2016 (Жажда listicle) | Landscape 2026 (AI-эра) |
|---|---|---|
| Лидер RU productivity-tool | **Не выделен** — Todoist + Wunderlist равноправно ведут | Todoist всё ещё среди лидеров; Wunderlist **закрыт 2020 → Microsoft To Do**; новый класс: AI-orchestrators (Motion, Reclaim, Notion AI) |
| Платформенная фрагментация | Высокая (нужны Windows-only, macOS-only продукты) | Низкая — кроссплатформа дефолт; mobile-first стандарт; web-first вариант |
| Windows Phone доля | Живая (Windows Phone 8.1, Windows 10 Mobile упомянуты) | Закрыта Microsoft декабрь 2019 |
| AI-функции | **Отсутствуют** | Core differentiator — smart-prioritization, voice-LLM, AI-execution, summary |
| Messenger-интеграция | Не упомянута | Expected feature (Telegram-bot, Slack-bot, WhatsApp) |
| Gamification | Todoist Karma (5 уровней) — pioneering | Mature pattern (Habitica, Duolingo streaks, GRO habit-trackers) |
| Ценовой коридор | $50/год Pro (Wunderlist) / 2190 ₽/год (Todoist) | $4-12/мес для AI-tier (×2.5-5 от 2016 в реальном выражении за счёт AI-функций) |
| Геймификация в RU-нише | Только Todoist Karma upstream | Локальная экосистема habit-trackers (GRO, Sectograph, и др.), AI Mate (для AI-prompts), Drinker (для гидрации) — нативная RU productivity-gamification стала зрелой |
| Format обзора в RU-медиа | Анонимный evergreen-листикл без дат | Datated AI-функция-focused обзоры (vc.ru, Habr, tg-каналы с attribution и тестами) |
| Категория | «Сотня сервисов, выбирайте trial-and-error» | Бимодальная: legacy task-manager (Todoist, Things) + AI-orchestrator (Motion, Reclaim) — выбор по «нужен ли мне AI» |

## Что это значит для GRO content strategy

### 1. Reference для рассуждений «как изменился productivity-стек за 10 лет»

GRO как **habit-tracking** consumer-приложение **не конкурирует напрямую** с task-manager (Todoist, Things) — другая категория (привычки vs задачи). Но **смежная категория** даёт полезные контентные углы:

- **«Что не изменилось»:** SMB-предприниматель всё ещё нуждается в простых, кроссплатформенных инструментах с понятной ценой; gamification (с Todoist Karma 2013) — устойчивый эффективный engagement-механизм; основные категории функций (приоритеты, теги, напоминания, дедлайны) — стабильны 10 лет.
- **«Что изменилось»:** AI-функции стали мейнстримом и переопределили саму категорию (task-manager → AI-orchestrator); mobile-first стал дефолтом; Wunderlist (один из 2 лидеров 2016) больше не существует; Windows Phone категория ушла; ценовой коридор вырос в реальном выражении за счёт AI-функций.

### 2. Content angle: «Эволюция productivity-стека предпринимателя за 10 лет»

GRO-контент может использовать этот baseline как **scaffold** для статьи «10 лет productivity-tools — путь от Todoist Karma до AI-orchestrators»:

- 2013: Todoist Karma — pioneering productivity-gamification
- 2016: Жажда листикл — 5 продуктов, 3 платформенных кластера, AI отсутствует
- 2017: Things 3 launch; Todoist + iCal native sync; Wunderlist под Microsoft (signal предстоящего закрытия)
- 2020: Wunderlist закрыт → Microsoft To Do; pandemic-driven productivity-tool бум
- 2022: Notion AI launch — первый mainstream AI в productivity-space
- 2023-2024: ChatGPT API → Motion, Reclaim, AI-Todoist features
- 2025-2026: AI-orchestrator как новая категория; habit-tracker (GRO) рядом с task-manager как complementary tool

Это **эталонный контентный нарратив для GRO**, который показывает экспертизу в productivity-экосистеме и позиционирует habit-tracker как **дополнение, а не замену** task-manager.

### 3. Дифференциация format от zhazhda-genre

Если GRO выпускает GRO-листикл «5 productivity-инструментов для предпринимателя 2026», знание [[evolving/content-trends/zhazhda-biz-evergreen-listicle-genre|жанровых ошибок Жажды]] критично:

- **Не дублировать анонимность** — author + должность + дата публикации обязательны.
- **Не растягивать до круглого числа** — 4-5 инструментов с реальными тестами лучше «топ-10» с растягиванием.
- **Не терять имена продуктов** — каждый сервис с прямой ссылкой на сайт и текущим прайсом.
- **Включить attribution** — не «по мнению редакции», а «после 30-дневного теста с N конкретными use-cases».
- **Включить AI-эпохальную дифференциацию** — обязательно явно различать «legacy task-manager» (Todoist, Things) и «AI-orchestrator» (Motion, Reclaim) — это **главный narrative-axis 2026**.
- **Включить habit-tracker как complementary category** — GRO не конкурирует с Todoist, а дополняет (привычки vs задачи).

### 4. Productivity-gamification narrative

Todoist Karma (~2013) → Wunderlist Pro (2014-2020) → Habitica (2013, mainstream после 2018) → Duolingo streaks (2014, mainstream после 2020) → GRO habit-tracker (2024-2026) — **12+ лет эволюции gamification в productivity / habit space**. Это богатый нарратив для GRO content marketing:

- Можно показать GRO как **современную фазу** этой эволюции (от per-task Karma к per-habit streaks к AI-personalized engagement loops).
- Можно фреймить gamification не как «играть в задачи», а как **proven engagement-механизм с 12+-летней историей валидации**.
- Можно использовать Todoist Karma как **textbook reference**, не как конкурента.

## Caveat / open questions

- **Single источник** — один листикл Жажды, не cross-verified с другими 2016-обзорами productivity-tools (vc.ru, Habr того времени). Возможно, состав 5 продуктов отражает только подборку этой редакции, не реальное состояние рынка.
- **Editorial cherry-picking** — Жажда могла не включить тогдашних RU-нативных task-managers (если они существовали). Состав «Todoist + Wunderlist + Windows-only + Things» — international-leaders, без RU-native альтернатив, что странно для editorial с акцентом на «русификацию».
- **Цены требуют verification** — все 2 ценовых якоря (Todoist 2190 ₽/год, Wunderlist $50/год) даны без attribution к сайтам продуктов; возможны errors / outdated данные.
- **Parsing-loss** — заголовки секций удалены в дампе (типичный zhazhda-pattern, см. [[evolving/content-trends/zhazhda-biz-evergreen-listicle-genre]]). Реальный состав продуктов и cons-секции могли быть полнее.
- **Things версия не указана** — Things 3 вышел в 2017, листикл скорее говорит о Things 1.x/2.x.
