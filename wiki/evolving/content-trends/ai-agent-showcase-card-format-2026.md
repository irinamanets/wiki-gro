# Showcase-карточка «Битвы агентов» — переносимый формат сравнения продуктов

Анатомия и применимость единого карточного шаблона, которым @Theedinorogblog оформил голосование «Битва агентов» на Conversations 2026 (карточки 7992–7996, [[sources/2026-05-30-tg-theedinorog-may-26-30-2026]]). Формат — это **сравнительная серия из N однотипных карточек** под голосование/опрос, где каждая карточка продаёт один продукт через 3-метричный hook, а серия в целом — engagement-механику (голосуй за лучшего).

`evolving`, потому что это наблюдаемый форматный паттерн (а не вечный принцип): конкретная композиция карточки дрейфует, но структурная логика «серия + голосование + ROI-метрики» переносима.

## Анатомия карточки (5 повторяемых блоков)

1. **Co-brand хедер.** Две капсулы: «Conversations 2026 ✻ The Edinorog» — событие × медиа. Сразу легитимизирует.
2. **Категория капсом → название → подзаголовок «AI-X для Y».** Например «ТЕХНОЛОГИИ И РАЗРАБОТКА → Veai → AI-агент для разработки». За 3 строки читатель понимает вертикаль.
3. **Блок «ЧТО УМЕЕТ»** — 3–4 строки прозы о механике, без маркетинговой воды (что конкретно делает агент).
4. **2–3 иконки-метрики** — самый плотный по доверию блок: команда 50+, конверсия ×3,6, экономия 2–3 млн ₽/год. Числа жирным, подпись серым.
5. **Низ — 2 чёрные капсулы**: клиенты (соц-доказательство) + sound-bite-метрика («1 агент = 2–4 SDR», «5–7 дней вместо 14–18»).
- **Правая зелёная половина** — крупный номер голосования (1–5) + название контуром + «в опросе The Edinorog»: превращает карточку из рекламы в **бюллетень для голосования**.

## Почему формат работает

- **Серийность + единый шаблон** = узнаваемость и «листабельность» (как карусель). Читатель сравнивает яблоки с яблоками, потому что структура карточек идентична. `[conf:medium, src:2026-05-27]`
- **Голосование как engagement-driver.** Победитель проходит в финал «Битвы агентов» → у аудитории есть агентность (их голос влияет на исход). Это сильнее пассивного просмотра. Совпадает с poll-механиками из [[evolving/content-trends/telegram-native-formats]].
- **ROI-метрики вместо фич.** Каждая карточка ведёт числом результата (−72% стоимость лида), а не списком функций. Это honest-кажущийся формат, повышающий доверие даже к рекламе.
- **Co-brand легитимизация.** Связка «событие × отраслевое медиа» снимает с карточек ощущение прямой рекламы, хотя они маркированы erid.

## Применимость для контента ГРО

1. **Сравнительная серия под голосование.** ГРО может сделать карусель/серию карточек «N инструментов/привычек/подходов для [роста]» с механикой голосования в Telegram — переиспользует engagement-логику. Hook: «какой подход к [X] ближе тебе?».
2. **3-метричная карточка** как шаблон любого продуктового/кейсового поста: вертикаль → что делает → 3 числа результата → соц-доказательство. Переносится на кейсы пользователей ГРО.
3. **Honest-framing через результат, а не фичи.** Тон-консистентно с [[canon/marketing-frameworks/native-advertising]] и [[evolving/content-trends/smm-strategy-trends-2026|трендом «живого бренда»]]: показывать число-исход, не список функций.
4. **Anti-pattern:** не копировать рекламную плотность (5 блоков + erid) в органический контент — формат сильнее, когда метрики реальны и проверяемы (в отличие от self-reported карточек источника, см. caveat ниже).

## Caveat

Карточки-источник — рекламный материал («#партнерскийматериал», erid), метрики self-reported и не аудированы. Переносим **форму** (структуру, серийность, голосование, метрика-вместо-фич), не доверие к конкретным числам.
