# Т-Банк «Умная камера» + Tinkoff Space: числовые метрики

Числовые сигналы продукта конкурента (computer-vision фича «Умная камера») и масштаб employer-brand инвестиций (Tinkoff Space) из корп. блога Т-Банка (vc.ru/tbank, 2026-05-19). Качественный формат-разбор — в [[evolving/competitor-positioning/tbank-brand-journalism-employer-storytelling]].

## «Умная камера» (computer vision)

| Метрика | Значение | Источник |
|---|---|---|
| Доля переводов по контактной книжке (инсайт-триггер фичи распознавания номеров с фото) | 30% переводов (исследование 2021) | `[conf:medium, src:2026-05-19]` |
| MAU всех камер (март 2023) | 3,5 млн | `[conf:medium, src:2026-05-19]` |
| MAU всех камер (март 2024) | 7 млн | `[conf:medium, src:2026-05-19]` |
| Эффект мультирежимной камеры | подняла конверсию в платёж vs старая (по итогам A/B-теста) | `[conf:medium, src:2026-05-19]` |
| Центр технологий ИИ Т-Банка (масштаб in-house ML-команды) | ~700 человек | `[conf:medium, src:2026-05-19]` |

**Интерпретация.** MAU камер удвоился за год (3,5 → 7 млн), `[conf:medium, src:2026-05-19]` фича родилась из дата-инсайта (30% переводов по контактам) — пример data-driven product development. Масштаб ML-команды ~700 человек `[conf:medium, src:2026-05-19]` показывает уровень in-house AI-инвестиций конкурента.

## Tinkoff Space (масштаб employer-brand инвестиций)

- Фитнес-комплекс: одновременно 270 человек, 60 силовых + 29 кардио тренажёров Technogym, гантели до 60 кг, ринг 5×5 м, зона борьбы >70 м². `[conf:medium, src:2026-05-19]`

Это числовое выражение employer-brand differentiator — масштаб инфраструктуры как сигнал для IT-кандидатов.

## Применение для GRO

1. **Data-driven product development** — модель «дата-инсайт (30% действий через канал X) → фича под этот канал → рост MAU». Применимо к продуктовой аналитике GRO. [conf:low, src:2026-05-24]
2. **A/B-валидация UX-изменений** — мультирежимный апдейт подняли конверсию через A/B (см. [[evolving-strict/product-metrics/gro-app-milestones]]).
3. **Бенчмарк масштаба конкурента** — ~700 ML-инженеров и employer-инфраструктура задают контекст «веса» Т-Банка как игрока (см. [[evolving/competitor-positioning/tbank-tinvest-premium-positioning]]).
