# Конверсия сайта — форма → Telegram-чат (кейс Молянова, 2026)

CRO-кейс из канала Молянова (verified expert): замена формы обратной связи на прямой контакт. Strict: метрика с inline-маркером. Self-reported, без указания базы/периода → conf:medium.

## Числа

- **Шаг 1.** Убрали форму обратной связи, заменили прямой ссылкой на Telegram-чат с оператором + обещание ответа за 60 сек → количество обращений выросло **в 4 раза** `[conf:medium, src:2026-05-01]`.
- **Шаг 2.** «Сценарий тёплого общения» вместо шаблона («Ваша заявка принята. Ожидайте звонка») — качественное улучшение обработки входящих `[conf:medium, src:2026-05-01]`.

## Прочтение
- Снижение трения (форма → один тап в мессенджер) + явное обещание скорости ответа — главный драйвер роста обращений.
- Кейс одиночный, без abs-чисел и attribution window → как бенчмарк используется направленно (порядок эффекта), не как точная ставка.
- Совместимо с RU-трендом перетекания коммуникации в мессенджеры; ограничение — платформенный риск Telegram (см. [[evolving/industry-trends/ru-telegram-blocking-max-migration-2026]]).
