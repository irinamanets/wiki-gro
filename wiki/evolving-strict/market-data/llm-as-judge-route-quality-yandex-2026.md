# LLM-as-judge: оценка прогулочности маршрутов (Яндекс Карты)

@techno_yandex (пост 5284, 2026-05-29) описал прод-внедрение **LLM-as-judge**: модель-судья оценивает субъективное качество пешеходных маршрутов («прогулочность», «оживлённость»), и на её оценках обучается алгоритм построения маршрутов. Это документированный кейс выхода LLM-as-judge из ресёрча в массовый продукт с измеренным паритетом «судья vs люди».

## Pipeline

1. Разработчики написали подробную инструкцию по оценке прогулочности/оживлённости.
2. Алгоритм составлял маршруты, которые превращались в текстовые описания прогулки.
3. LLM-судья получал описания и оценивал по инструкции.
4. Алгоритм обучался строить маршруты на оценках судьи.

Карту заранее разбили на шестиугольники с записью окружения (парки, кафе, промзоны, ТЦ). При запросе алгоритм подгружает контекст шестиугольников по пути и классифицирует варианты на лету: быстрый / без лестниц / с пандусами / прогулочный / оживлённый.

## Метрики паритета «судья vs люди»

Качество судьи проверяли, сравнивая его оценки с человеческими (метрика — расхождение в оценках):

| Метрика | Расхождение людей между собой | Расхождение модели с людьми | Source |
|---|---|---|---|
| Оживлённость | 17% | 14% | `[conf:high, src:2026-05-29]` |
| Прогулочность | 21% | 19% | `[conf:high, src:2026-05-29]` |

**Вывод:** LLM-судья оказался **не более субъективным, чем сами люди** — расхождение модели с людьми (14% / 19%) меньше, чем расхождение людей между собой (17% / 21%). `[conf:high, src:2026-05-29]`

Инструкция оказалась достаточно универсальной, чтобы повторить процесс обучения для любого города. `[conf:medium, src:2026-05-29]`

## Маркетинговые выводы для GRO

- **Прецедент доверия к LLM-as-judge.** Когда GRO коммуницирует «качество оценивает AI», этот кейс — публичный proof, что AI-оценка может быть не субъективнее человеческой. Хук для trust-нарратива.
- **Связь с RLHF shared-vocab.** «Модель-судья» — узнаваемый термин (см. [[canon/marketing-frameworks/ai-tech-glossary-techno-yandex-2026]], раздел RLHF: «иногда для оценки тренируют отдельную нейросеть-судью»). Это тот же механизм в проде.
- **Caveat по числам.** Метрики — из бренд-публикации Яндекса, не независимый бенчмарк; sample size и методология не раскрыты. Использовать с атрибуцией «по данным Яндекса», не как индустриальный стандарт.
