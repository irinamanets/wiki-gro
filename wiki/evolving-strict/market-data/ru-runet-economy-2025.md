## Согласованность с другими макро-источниками

**Прямая стыковка** с цифрами Максима Решетникова (министр экономразвития РФ), зафиксированными в [[evolving-strict/market-data/ru-ecommerce-platformization-reshetnikov-2026]]:

- Решетников: e-commerce РФ — **>11,5 трлн ₽** в 2025, **+~28% YoY**, **~20% розницы**, **62% — платформы** `[conf:medium, src:2026-04-08]`.
- Рунет-метрика: **онлайн-торговля = ~23 трлн ₽** в 2025 `[conf:medium, src:2026-04-29]`.

**Расхождение в 2 раза** объясняется разными охватами:

- **Решетников** (Минэкономразвития) считает только **B2C e-commerce** в традиционном понимании (товары, доставленные физическим лицам через интернет-магазины и маркетплейсы).
- **РАЭК / рунет-метрика** считают **онлайн-торговлю в широком смысле**: B2B-транзакции, контентные подписки, цифровые услуги (хостинг, SaaS), digital-фин-услуги, рекламные транзакции.

Обе цифры — внутренне согласованны. Использовать вместе:
- Решетников — для нарратива «розница уходит в онлайн».
- РАЭК / рунет-метрика — для нарратива «вся экономика становится цифровой» / макро-масштаба «вы работаете в 38-триллионной экосистеме».

## Релевантность для GRO

- **Macro-якорь** для presentation-материалов GRO: «российская онлайн-экономика — 38 трлн ₽ в 2025 году, 60% из этого — онлайн-торговля» `[conf:medium, src:2026-04-29]`. Это контекст для разговора «GRO работает в подсегменте этой экосистемы».
- **Сразу видно, какой кусок «оплачивает» GRO:** соло-фаундеры, продуктовые предприниматели — это микро-сегмент 38 трлн ₽; даже если GRO успешен, он целится не на 38 трлн, а на персональную layer внутри.
- **Сравнение с глобальными рынками:** для контекста позиционирования.
- **Не использовать как self-standing thesis** в GRO-контенте: это too high-level для прикладного контента, годится только как абзац-открытие.
