## Tier A — потенциальные hook'ы для GRO-контента

### 1. Cursor вайпнул ПК подписчика (4 апреля)

Агент Cursor сгенерировал команду с ошибкой экранирования кавычек в Windows (`\` — разделитель путей, не escape), команда отделилась от пути и снесла системные папки через `rmdir /s /q`. Бэкапов не было, файлы восстановили частично. Автор формулирует мораль: «не запускайте агентов с полным доступом там, где они могут нанести непоправимый вред».

**Почему релевантно GRO:** готовый cautionary-tale про «структурность vs хаотичная автоматизация». Хорошо ложится на value proposition GRO про **системность** (см. [[canon/positioning/gro-value-proposition]]): «инструмент без системы — это риск, инструмент в системе — это рычаг». Формат: короткий пост «как не надо делегировать ИИ» → мостик к «как GRO помогает навести структуру».

**Ссылка:** сообщение 4505 в дампе.

### 2. Vibecoding-курс на Stepik (7 апреля, #промо)

Промо в @ai_newz: «Vibecoding — Claude Code, Codex, Cursor и coding agents в 2026», скидка 40% на 48 часов, ЦА — разработчики, ML-инженеры, data scientists, автоматизаторы, технические фаундеры. Программа: Claude Code / Codex / Cursor, agent mode, работа с кодбазой, subagents / hooks / skills, MCP, ревью кода.

**Почему релевантно GRO:** (a) это **adjacent educational competitor** — продукт, обучающий использованию AI-инструментов, смежный с «GRO как AI-powered productivity coach»; (b) референс стилистики образовательного промо в авторском Telegram-канале (формат, CTA, тайминг скидки). Полезно сравнить с форматами нативного PR, которые GRO может использовать ([[evolving/content-trends/telegram-native-formats]]).

**Что стоит зафиксировать при повторных сигналах:**
- имена конкурирующих educational продуктов про vibecoding / AI agents / productivity
- каноны ценообразования курсов (скидки 40% 48 часов — стандарт?)

**Ссылка:** сообщение 4517 в дампе.

### 3. AI стал поляризированной темой → физическое насилие (11 апреля)

Автор фиксирует эскалацию: коктейль Молотова в дом Сэма Альтмана (подозреваемый 20 лет, задержан после угроз поджечь штаб OpenAI); стрельба в дом члена горсовета Индианаполиса, ранее поддержавшего строительство датацентра (13 выстрелов, записка «нет датацентрам»); бомбардировки AWS-датацентров Ираном (формально не связанные с AI, но сдвигающие окно Овертона). Автор: «политизация, хоть не порождая насилие сама по себе, привлекает аудиторию, для которой насилие уже является инструментом».

**Почему релевантно GRO:** **маркетинговое следствие — тон контента**. Когда AI-тема политизирована и связана с насилием, апокалиптические или триумфалистские фреймы («AI изменит всё», «ты проиграешь без AI») притягивают негативную аудиторию и дают побочные эффекты. Лучше — прагматичный operator-тон: «как конкретно решить конкретную задачу». Это согласуется с GRO brand-guidelines (дружелюбный эксперт, не корпоративный).

**Action item:** добавить в `canon/brand-guidelines/tone-of-voice` (когда он появится) правило «избегать апокалиптических и триумфалистских AI-фреймов».

**Ссылки:** сообщения 4519 (Project Glasswing, тысячи уязвимостей), 4525 (Альтман + Индианаполис).

## Стилистические наблюдения о формате @ai_newz

Эта часть живёт **здесь** временно — при повторяющемся паттерне она должна переехать в [[evolving/content-trends/telegram-native-formats]] как отдельный референс «tech-news авторский канал».

- **Структура поста:** жирный заголовок (иногда с эмодзи) → 1–3 абзаца → ссылки внизу (Пейпер / Репа / Блогпост / Демо / Анонс) → подпись `@ai_newz`
- **Тон:** технически глубокий + разговорный («моделька», «дьявол в деталях», «осадочек остался», «го тестить», «попкорн»)
- **Личная ремарка курсивом** в конце поста — мнение автора после фактологии (`__Я потестил__`, `__Достаём попкорн__`)
- **Еженедельный дайджест** (пятница-суббота): заголовок «Нейродайджест за неделю (#N)», 3 фиксированные рубрики (LLM / Генеративные / Прочее, иногда + Личное), каждый пункт — `[заголовок-ссылка](...) — одно предложение`, завершается ссылкой на предыдущий дайджест и хэштегом `#дайджест`
- **Промо-посты** помечены `#промо`, отличаются длиной и bullet-списком программы

Этот паттерн может пригодиться GRO, если:
- мы решим делать собственный еженедельный дайджест новостей productivity / AI-for-work (формат проверенный)
- мы будем размещать нативное промо у tech-авторов (понимать их конвенции промо-поста)
