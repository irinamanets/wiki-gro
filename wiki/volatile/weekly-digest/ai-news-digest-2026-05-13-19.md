## Генеративные и продуктовые инструменты

**Recraft — генератор для дизайнеров (2026-05-17, пост 10718).** Позиционируется как «простота ChatGPT + эстетичность Midjourney»: понимает промты, подбирает углы камеры и освещение, умеет **векторные картинки**, хорошо справляется с русским текстом на генерациях, щедрые бесплатные кредиты. recraft.ai. Для GRO — потенциальный инструмент продакшна визуала бренд-канала (особенно «русский текст на картинке» — частая боль RU-команд).

**Krea 2 — генератор на мудбордах (2026-05-18, пост 10724).** Первый генератор, ориентированный на **мудборды вместо текстовых промтов**: загружаешь несколько изображений, модель понимает их стиль, генерирует новое в том же стиле. Генерация `≈15 секунд`, неделя без трат кредитов для подписчиков. Сигнал: prompt-less / reference-driven генерация — следующий UX-сдвиг в image-tools. Content-hook про «не нужно учиться писать промты».

**RevPDF 4.0 — бесплатный офлайн PDF-редактор (2026-05-14, пост 10700).** `≈20 МБ`, работает офлайн без аккаунтов: редактирование текста/изображений, скрытие конфиденциальной информации. revpdf.com. Позиционируется как замена Adobe Acrobat. Инструмент-хук для productivity-аудитории.

**ppt-master — skill «любой файл → презентация» (2026-05-18, пост 10714).** Open-source скилл для ИИ-агента: на вход ссылка/файл, на выходе готовый PPTX (текст/картинки раздельными блоками, все языки). github.com/hugohe3/ppt-master. Сигнал: рост экосистемы «agent skills» — переиспользуемые навыки для ИИ-агентов как новый формат дистрибуции.

**Clawdmeter — DIY-индикатор остатка запросов (2026-05-13, пост 10688).** Маленький экранчик, показывающий остаток лимита запросов; код на GitHub. Иллюстрирует «вайбкодер-сообщество» как культурный слой вокруг AI-инструментов.

## Claude Code и AI-агенты

**Claude Code: Agent view + непрерывный режим /goal (2026-05-13, пост 10692).** Две фичи: (1) **Agent view** — оркестрация всех сессий в одном окне (видно, что запущено / ждёт действий / завершено, можно гонять несколько агентов параллельно); (2) **/goal** — непрерывный режим, модель работает без остановки до достижения цели, без постоянных подтверждений. Ссылка claude.com/blog. Сигнал: agentic-tooling движется к multi-session оркестрации и автономности — релевантно нарративу [[evolving/industry-trends/ai-agent-economy-2026]].

**OpenClaw — вебинар по настройке ИИ-агента (2026-05-19, пост 10732, реклама Зерокодер).** Бесплатный вебинар: установка OpenClaw, автоматизация рутины, связка Claude + OpenClaw + Cursor. UTM-маркированный промо-пост. Подтверждает спрос на образовательный контент «как собрать рабочую AI-агентную связку» — adjacent-формат к GRO-аудитории.

## LLM-безопасность и инциденты

**Claude Mythos взломал macOS (2026-05-14, пост 10705).** Нейросеть нашла `2` ранее неизвестных бага и добралась до ядра системы; исследователи лично поехали к Apple. Ссылка wsj.com. **Second-source** к ранее зафиксированному Claude Mythos sandbox-escape — усиливает нарратив «фронтир-модели находят 0-day».

**T-Bank Nulla — превентивная кибератака собственными ИИ-агентами (2026-05-18, пост 10725).** Т-Банк создал атакующую плеяду ИИ-агентов Nulla для профилактической защиты: ищет уязвимости как реальный злоумышленник, собирает сложные цепочки. В пилоте `≈1300 сервисов`, `≈45 минут` на сервис вместо `2–3 дней` ручного аудита, потенциальная экономия `до 100 млн ₽`. Источник — форум ЦИПР. Сигнал RU-бигтех AI-зрелости (red-team как продукт).

**OpenAI adtech-иск (2026-05-14, пост 10703).** Коллективный иск: ChatGPT-аналитика и пиксели собирают названия диалогов, URL, metadata и передают Meta* и Google. Нарратив «бесплатное = ты продукт» + privacy-риски AI-сервисов. Ссылка на courtlistener-документ. *Meta признана экстремистской организацией в РФ. Усиливает объекцию «AI сливает данные» — релевантно для trust-позиционирования.

**AI-радио эксперимент 90 дней (2026-05-16, пост 10717).** `4 LLM` (Gemini/Grok/ChatGPT/Claude) дали по `$20`, доступ к песням, звонкам и Twitter, посадили вести радио на 90 дней. Итог — «безумие»: модели деградировали в шаблоны, галлюцинировали, ни одна не вышла в плюс (Gemini продал рекламу за `$40`, Grok выдумал несуществующих спонсоров). Развлекательная ретрансляция, но иллюстрирует нарратив «LLM непредсказуемы при долгой автономной работе» — контр-аргумент к over-trust.

## RU-доступ и регуляторика

**OpenRouter блокирует россиян (2026-05-15, пост 10711).** По обновлённым правилам платформы россияне не могут использовать API американских компаний (ChatGPT/Claude/Gemini) в проектах; для RU-аккаунтов режут пополнение. Ссылки openrouter.ai/terms, habr. Новый вектор сужения доступа — теперь на уровне **инфраструктурного посредника-агрегатора**, а не только прямого вендора. Перенесено в [[evolving/industry-trends/ru-digital-regulatory-squeeze-2026]] как новый вектор.

**Казахстан внедряет ИИ в школы (2026-05-13, пост 10687).** Указ Токаева о нейросетях в среднем образовании; пилот на `500 сельских школ` (техника, интернет, персонализированный ИИ). Сигнал: гос-ставка на AI-поколение в СНГ. Ссылка tengrinews.kz. Для GRO — нейтральный макро-контекст «AI-грамотность как госприоритет».

**ВЭБ «Цифровая крепость» на ЦИПР (2026-05-12, пост 10690).** Футуристичный павильон в Нижнем Новгороде, форум `18–20 мая`: AI-native компании, ИИномика, кибербез, фотоника, 6G. Ссылка cnews.ru. Контекст RU-tech-повестки.
