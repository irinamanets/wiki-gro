# Organize to Value (McKinsey)

Операционная модель организационного дизайна, которую McKinsey позиционирует как апгрейд классической рамки **7S** (Strategy, Structure, Systems, Style, Staff, Skills, Shared Values). Если 7S учил быть «хорошо организованной компанией», то Organize to Value отвечает на другой вопрос: **что именно даёт результат и как быстро компания может перестраиваться под новые источники ценности**.

Фреймворк зафиксирован в тренд-репорте SETTERS Media «Будущее работы» (слайд 16, со ссылкой «Источник: McKinsey») — см. [[sources/2026-04-14-hutzp-telegram-20260402-0414|дамп канала @hutzp]]. Первичный источник McKinsey не процитирован в дампе, поэтому `confidence: medium` (одиночный вторичный источник); при следующем ingest'е McKinsey-оригинала следует сделать supersession на верифицированную цитату.

## Центральный сдвиг

| 7S (1980-е, классика) | Organize to Value (2026, McKinsey) |
|---|---|
| «Делать вещи правильно» | «Делать правильные вещи — и делать быстро» |
| Структура как основа дизайна | Ценность как основа дизайна |
| Оптимизация внутренней машины | Оптимизация скорости ответа на рынок |
| «Хорошо организованная компания» | «Компания, построенная вокруг источников ценности» |

Ключевая перестройка мышления: организация не описывается через её орг-схему; она описывается через **value streams** (потоки создания ценности) и через способность перестраивать эти потоки быстрее конкурентов.

## Как Organize to Value связан с AI-adoption

SETTERS Media ставит Organize to Value в контекст более широкого тренда «Будущее работы», где параллельно действуют:

- **Внедрение ИИ на всех уровнях** — каждый сотрудник должен иметь ИИ-помощника. ИИ становится базовой инфраструктурой, а не спец-проектом.
- **Tiny Teams** как новейший паттерн оргструктур — никто больше не раздувает штат, минимальные команды опытных людей автоматизируют рутину ИИ и переходят от идеи к разработке минуя долгие согласования. См. [[evolving/industry-trends/future-of-work-trends-2026]].
- **Культура как конкурентное преимущество** — вовлечённость сотрудников становится ключевым фокусом.
- **Редизайн организаций** — переход от иерархии к децентрализации, акцент на ценности для клиентов и скорости вместо структуры компании.

Organize to Value — это **операционная модель**, которая связывает эти четыре тренда: ИИ даёт скорость, tiny teams дают фокус, культура даёт вовлечённость, редизайн даёт перестраиваемость. Без этой рамки четыре тренда выглядят набором модных словечек; с рамкой — единой стратегией.

## Барьеры внедрения (по McKinsey)

Из того же тренд-репорта (слайд 09, «Качественному внедрению ИИ мешают») — список барьеров, которые Organize to Value должен разгрести:

1. **Отсутствие чёткой стратегии** по внедрению ИИ.
2. **Сомнения в надёжности технологии.**
3. **Страх сотрудников потерять работу из-за ИИ.**
4. **Нежелание менять структуру организации.**
5. **Внешние ограничения:** размытое законодательство, требования к защите данных, этические дилеммы.

Фреймворк не решает эти барьеры сам по себе, но задаёт **точку приложения**: вместо попыток «внедрить ИИ» вообще, организация идентифицирует value streams и внедряет ИИ туда, где он даёт наибольший прирост ценности на поток.

## 6 правил для лидера будущего (SETTERS Media)

В связанном тезисе слайда 33 — набор операционных правил, которые переносят Organize to Value на уровень повседневной практики менеджера:

1. **Внедряйте ИИ как партнёра, а не как замену сотрудникам.**
2. **Растите самостоятельность в командах.** Минимум микроменеджмента.
3. **Изучайте новые бизнес-подходы, экспериментируйте с ними.**
4. **Проектируйте опыт сотрудника так же тщательно, как клиентский.**
5. **Сделайте ИИ-грамотность навыком №1 для всей организации.**
6. **Будьте прозрачными — и наращивайте доверие людей. Они и есть ваш главный актив.**

## Применение для позиционирования GRO

GRO как inner-work инструмент встраивается в рамку Organize to Value несколькими способами:

- **ИИ-партнёр, а не замена** (правило 1) — совпадает с AI-компонентой продукта GRO в [[canon/product-knowledge/gro-app-overview|4-шаговой механике]] (ИИ-помощник в треках, не автоматизатор решений).
- **Развитие самостоятельности** (правило 2) — совпадает с позиционной рамкой «свой ритм» в [[canon/positioning/gro-value-proposition]].
- **Проектирование опыта сотрудника** (правило 4) — GRO как benefit для HR-отделов средних B2B-компаний (потенциальный канал, не закрытый): продукт = инструмент вовлечённости и retention'а.
- **ИИ-грамотность как навык №1** (правило 5) — совпадает с content hooks из [[evolving/content-trends/ai-solopreneur-narrative-hooks]] и с сегментацией [[canon/target-audience/ru-ai-telegram-audience-segments|русскоязычной ИИ-аудитории]].

## Contradictions

- **[2026-04-15]** `Tiny Teams` паттерн из этого же тренд-репорта (слайд 21, Latent Space) и тренд «соло-фаундеры на ИИ-агентах» из [[evolving/industry-trends/ai-solopreneurship-window-2026-2029]] описывают сходящиеся явления с разных углов. Противоречия нет, но возможна путаница в сообщении: Organize to Value применим к «компаниям 50–5000», Tiny Teams — к «командам 1–10», соло-предприниматели — к «1». Все три живут в одном тренде «декомпозиция за счёт ИИ».
