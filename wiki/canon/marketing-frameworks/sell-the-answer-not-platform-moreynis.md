# «Продавай ответ на профессиональный вопрос, не платформу»

Позиционный фрейм **Аркадия Морейниса** ([@temno](https://t.me/temno), [пост 7834 от 2026-05-14](https://t.me/temno/7834)): универсальная «технологическая платформа, с помощью которой кто угодно сделает что угодно», структурно проигрывает узкоспециализированному продукту, который является **точным ответом на профессиональный вопрос конкретной аудитории**. Размещается в `canon/marketing-frameworks` как стабильный positioning-принцип (vertical-SaaS логика существует задолго до ИИ; ИИ — лишь текущий усилитель).

**Атрибуция:** subjective frame Морейниса (priority-2 эксперт по [[rules|rules.md]]). Подкреплён эмпирикой a16z/OpenAI ([[evolving-strict/market-data/chatgpt-entrepreneur-industry-mix-2026|industry-mix данные]]) и классической vertical-SaaS теорией.

## Центральный тезис

> Бухгалтерам нужно продавать платформу для бухгалтеров, функциональность которой является точным ответом на вопрос в формулировке бухгалтера. Владельцам салонов красоты — что-то подобное для них. А «технологическая платформа, с помощью которой кто угодно сможет сделать что угодно» — сядет жопой между стульев. — Морейнис, [[sources/2026-05-19-tg-temno-moreynis-may-14-19-2026|пост 7834, 2026-05-14]]

**Механика «между стульев»:** предприниматели «покупают» не технологию, а **ответ на свой узкопрофессиональный вопрос**. Подавляющую часть их вопросов можно классифицировать по области деятельности. Даже когда ответ технически представляет собой технологическую платформу — клиент воспринимает покупку как «решение моего проф. вопроса», не как «приобретение платформы». Generalist-платформа не звучит как ответ ни на один конкретный вопрос → не покупается ни одной нишей.

**Data-anchor (a16z/OpenAI, март 2026):** массовый ИИ-предприниматель — это professional services (22%), retail/ecommerce (21%), home/trade services (18%), не tech startup (5%). Полные цифры с маркерами — в [[evolving-strict/market-data/chatgpt-entrepreneur-industry-mix-2026]]. Состав аудитории эмпирически подтверждает: «для всех» = промах по реальному распределению.

## Шаг 0: сначала определись с рынком вплоть до специализации

> Стартапу первым делом нужно определиться со своим потенциальным рынком вплоть до специализации — чтобы дальше работать только в нём. Но для этого нужно заранее убедиться, что это или уже большой рынок, или растущий — иначе много лет можно тянуть пустышку.

Двухкритериальный фильтр ниши перед запуском:
- **Узость** — выбрать одну специализацию (бухгалтеры / салоны красоты / сантехники), не «все SMB».
- **Размер или рост** — ниша должна быть **уже большой** ИЛИ **растущей**. Узкая + статично-маленькая = «пустышка», на которую уйдут годы без результата.

Это пересекается с [[canon/marketing-frameworks/genius-audience-over-genius-idea-moreynis|«гениальной аудиторией»]] (того же автора): genius audience = «достаточно большая И достаточно underserved одновременно». Здесь Морейнис добавляет временнóе измерение — растущая ниша допустима, даже если сейчас мала.

## Вариант 2026: одна концепция → AI генерирует N нишевых продуктов (portfolio-of-bets)

> Можно разработать общую концепцию обобщённого продукта… и заставить ИИ генерировать специализированные продукты похожего типа, но для разных ниш. Которые потом продавать как разные продукты с разными названиями для разных аудиторий.

Новый AI-enabled paттерн, снимающий старый trade-off «либо узко (один продукт), либо широко (один generalist)»:

```
Одна обобщённая концепция продукта
  → AI генерирует специализированный вариант под нишу A (своё название, упаковка, язык)
  → AI генерирует вариант под нишу B
  → ... под нишу N
= портфель узких продуктов, каждый звучит как «ответ» для своей ниши
```

**Экономика portfolio-of-bets:**
- Каждая ниша мала, но в сумме складывается «во что-то приятное».
- Много мелких ставок вместо одной крупной → **бóльшая устойчивость бизнес-модели** (не all-in на один рынок).
- Предельный вопрос Морейниса: «какие 10 похожих продуктов для разных ниш ты сможешь сгенерировать из одной концепции?»

**Связь с paint-by-numbers publisher-моделью.** Это структурный родственник [[evolving-strict/competitor-metrics/glority-global-paint-by-numbers-publisher|Glority]] (одна формула × N ниш = $500M lifetime) и серединного кейса в [[evolving/industry-trends/ai-solopreneurship-window-2026-2029|окне соло-пренерства]]. Разница: Glority клонирует **формат** (Identifier-приложения), Морейнис предлагает клонировать **позиционирование одной концепции под разные ниши** через AI-генерацию. Оба — «N ниш из одного ядра».

## Vertical-niche exemplars из дайджеста

Морейнис в том же дайджесте даёт два иллюстрирующих кейса (retell, без верификации первички):

| Пост | Ниша | Сигнал |
|---|---|---|
| 7837 | Онлайн-инфлюенсер для электриков (и далее сантехников) | Стартап с шансом стать миллиардным, начав «с очень простых вещей». Авторитет в узкой ремесленной нише = монетизация. `[conf:low, src:2026-05-16]` |
| 7835 | Платформа «достойной подработки» для квалифицированных специалистов | Квалифицированным специалистам не хватает денег, но таксовать/курьерить «слишком дёшево» для их компетенций → ниша платформ подработки по специальности. `[conf:low, src:2026-05-15]` |

Оба — иллюстрации того, как **узкая профессиональная аудитория + точный ответ на её вопрос** даёт opportunity, недоступную generalist-игроку.

## Anti-patterns

1. **«Платформа для всех».** Messaging, подходящий любому продукту в категории = messaging ни для кого. Тест: звучит ли продукт как ответ на конкретный профессиональный вопрос конкретной роли?
2. **Узкая, но статично-маленькая ниша.** Специализация без проверки «большой или растущий рынок» = «пустышка» (годы без результата).
3. **Псевдо-вертикализация.** Generalist-продукт с лендингом «для бухгалтеров», но без функциональности «в формулировке бухгалтера» — клиент быстро распознаёт, что это тот же универсал в другой обёртке.
4. **Portfolio без общего ядра.** N несвязанных продуктов = N стартапов с N-кратными костами. Паттерн работает, только когда есть **одна концепция-ядро**, дёшево размножаемая AI под ниши.

## Применение для GRO

GRO рискует попасть в ловушку «платформа развития для всех». Vertical-niche применение:

| Ниша | «Вопрос в формулировке ниши» | GRO-ответ |
|---|---|---|
| SMB-founder сервисной ниши | «Как перестать быть узким горлышком своего бизнеса?» | GRO-трек системного делегирования + рефлексии |
| Фрилансер на пороге масштабирования | «Как вырасти, не нанимая команду?» | GRO-трек самоорганизации соло-пренера |
| 50+ профессионал в карьерном переходе | «Как переизобрести себя без инфантильного коучинга?» | GRO с executive-тоном |

**Content hook:** «ChatGPT-предприниматели — это бухгалтеры и ритейлеры, не техностартаперы. Ваш продукт для всех — или для кого-то?» (см. [[evolving-strict/market-data/chatgpt-entrepreneur-industry-mix-2026|data]]).
