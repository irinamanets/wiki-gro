# Аудиодневник «Полный Шварц» — self-contact протокол

Audio-modal complement to text-journaling от Armen Petrosian (из книги «Как приступить к переменам», 2025, ch.7-1; см. [[sources/2026-05-26-petrosian-book-2-how-to-start-changes]]). Petrosian-adaptation **«Полного Шварца»** — упражнения из книги Eric Nuzum «Make Noise: A Creator's Guide to Podcasting and Great Audio Storytelling» (2019). Protocol для воссоздания emotional/sensory memory через **аудио-нарративную медитацию**.

## Core тезис (Petrosian)

> «Я разговариваю с собой и не стесняюсь в этом признаться :) Сейчас веду аудиодневник в приложении Voice Notes (до этого пользовался JustPressRecords). У меня есть список вопросов. Отвечаю на них вслух. В большинстве случаев нахожу решение уже в процессе проговаривания, даже не переслушивая запись. <br><br>В книге Эрика Ньюзума „Пошумим. Как сделать хитовые подкасты" подглядел упражнение **„Полный Шварц"**, которое использую как комбинацию аудиозаписей и медитации. <br><br>Мысленно возвращаюсь к событиям или переживаниям и **как будто описываю фотографию или эпизод картины**. Каждую деталь, ощущения, о чём думал, какие запахи и звуки слышал, на что обратил внимание? <br><br>На это требуется 3-5 минут. По рекомендации в книге, упражнение лучше выполнять в комфортной обстановке, расслабившись в удобной позе. Мне нравится делать записи лёжа, хотя есть риск задремать :) Чаще заполняю аудиодневник в машине.» (Petrosian, 2025, book 2, ch.7-1)

## Внешняя attribution: Eric Nuzum «Make Noise» (2019)

**Эрик Ньюзум** — бывший Vice President of Programming at NPR, ex-WBUR, ex-Audible. Книга «Make Noise: A Creator's Guide to Podcasting and Great Audio Storytelling» (2019) — definitive practical guide для подкастинга. **«Полный Шварц»** (Full Schwartz) — упражнение из книги, по своей сути **sensory-recall meditation** для storytellers.

Petrosian-adaptation **переносит** упражнение из storytelling context в **personal-development context** — same mechanism (sensory-detailed recall via verbal expression), разный outcome.

`[conf:high, src:2019]` на existence of Nuzum book; `[conf:medium]` на specific «Полный Шварц» attribution (Petrosian-translation, не проверено по english-text оригинала).

## Mechanism

3 параллельных mechanism:

1. **Sensory-recall recreates emotional state.** Detailed sensory description (visual / auditory / olfactory / kinesthetic) → re-activates implicit memory нwork → emotional state recurs → opportunity для **re-processing**.
2. **Verbal externalisation reduces cognitive load.** «В большинстве случаев нахожу решение уже в процессе проговаривания» — speaking thought → externalisation → working memory freed.
3. **Audio modality as separate channel.** Text-journaling vs voice-journaling используют разные neural networks. **Cognitive variety** prevents habituation, поддерживает habit.

`[conf:medium]` на mechanism — psychology consensus mixed.

## Operational rituals (Petrosian)

- **App:** Voice Notes (Apple native); previously JustPressRecords
- **Setting:** Relaxed, comfortable position (lying down OK, but risk of falling asleep)
- **Where:** Often in car (before/after meetings)
- **Pre-recorded questions:** Petrosian has a list of standard questions, answers verbally
- **Duration:** 3-5 min per "Полный Шварц" session
- **Post-recording:** Usually doesn't replay — process itself is the value

## Зачем это релевантно GRO

GRO — продукт ежедневного журналирования. Audio-feature — **important UX consideration**:

### Direct product use

Если GRO имеет / планирует **voice-recording feature**, Petrosian-protocol даёт **conceptual basement**:

| Feature element | Petrosian-derived design |
|---|---|
| Recording entry-point | Не «record button» в углу, а **«ask me a question»** flow с pre-set prompts |
| Pre-set questions | Library из 10-20 sensory-recall prompts («опиши момент, который тебе сегодня запомнился, как фотографию») |
| Duration cap | Suggested 3-5 min (matches Nuzum/Petrosian); не unlimited |
| Replay UX | Optional, **не auto-emphasized**; mechanism работает на recording, не listening |
| Transcription | **Optional add-on**, не default — text-transcription **подмывает** verbal-as-primary-output mechanism |

### Direct content copy (с атрибуцией)

> «У text-дневника есть слабое место: ты пишешь медленно. У аудиодневника другая магия. По формуле Армена Петросяна (через Эрика Ньюзума „Пошумим"): „Описывай событие, как фотографию или эпизод картины. Каждую деталь, запахи, звуки. 3-5 минут." В большинстве случаев решение находится уже в процессе проговаривания — без переслушивания. GRO даёт voice-recording с pre-set вопросами в стиле Шварца.»

### Funnel framing

Работает на **consideration** (отличает GRO от text-only конкурентов) и **retention** (modal variety prevents habituation).

## Anti-patterns в применении

1. **Auto-transcribe всё в text по умолчанию.** Это **subverts mechanism**: voice-journaling работает потому что **спокен**, не **прочитан**. Optional transcription — OK, default — anti-pattern.
2. **Push «время для аудиодневника!»** на пользователя. Этот modality — **user-initiated**, требует privacy-context. Push в момент meeting/public-transport = harmful.
3. **Социализировать audio entries.** Audio carries voice → identity → privacy concern. Должно быть **strictly private** by default.
4. **Заменить text-journaling на voice-only.** Это **complement**, не replacement. Некоторые users prefer text (introverts, in noisy environments, in public).
