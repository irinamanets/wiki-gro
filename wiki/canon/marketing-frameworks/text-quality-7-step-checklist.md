# Проверка качества текста: 7-шаговый чек-лист + критерии

Редакционный чек-лист Pressfeed.Журнала для проверки качества контента перед публикацией. Источник — [[sources/2026-05-24-condense-pressfeed-chunk2-25]] (`...proveryaem-kachestvo-teksta...`, 2026-05-19).

`confidence: low` — редакционный evergreen-гайд без явного автора. Применять как **операционный чек-лист**, дополняющий редактуру под тон-оф-войс (см. skill `gro-content-edit`).

## Критерии качественного текста

- **Одна-две основных мысли** на статью.
- **Ориентация на узкую ЦА** и её уровень знаний.
- **Смысловая уникальность** — новый взгляд / эксперимент / опрос / комментарии экспертов (не только техническая уникальность).
- **Чёткая бизнес-задача** (1-2 на материал).
- **Фактчекинг** — источники Brand Analytics, Expert, Яндекс, Google, Росстат, Левада-Центр; ссылки на **первоисточники**, не перепечатки.
- **Логичная структура** — введение → раскрытие → заключение.
- **Визуальная динамика** — подзаголовки, списки, картинки, таблицы.
- **Цепляющий некликбейтный заголовок**.
- **Читабельность / грамотность**.
- **SEO-вхождение ключей** в заголовок/подзаголовки.

## Формулы заголовков

| Формула | Пример |
|---|---|
| Числа | «7 способов…» |
| Вопросительные конструкции | «Почему…?» |
| Глаголы 1-го лица мн.ч. | «Оцениваем конкурентов правильно» |
| Акцент на личном опыте | «Как я собрал первый миллион…» |
| «Полезность» | Чек-лист / список площадок |

## 7-шаговый порядок проверки

1. **Смысл / актуальность / попадание в ЦА**
2. **Фактчек** (цифры / ссылки / цитаты / кейсы)
3. **Структура**
4. **Визуал**
5. **Грамматика / орфография / стиль** (убрать повторы, клише, стоп-слова)
6. **Ключевые слова**
7. **Антиплагиат / техуникальность**

Норма техуникальности — **90-100%** (при обилии цитат — от **80%**). `[conf:low, src:2026-05-19]`

## Связь с другими рамками

- **Шаг 4 (визуал) + структура** совпадают с [[evolving/content-trends/aeo-geo-llm-search-optimization-2026|GEO-требованиями]]: H2/H3, списки, таблицы, FAQ-блок — это и редакционное качество, и фактор попадания в AI-выдачу. Один и тот же набор приёмов работает на двух фронтах.
- **Шаг 2 (фактчек) + соцдок** — операционализация [[canon/marketing-frameworks/trust-through-content-8-techniques|приёма доверия №5/8]] (соцдок + атрибуция эксперта).
- **Стоп-слова / клише (шаг 5)** — пересекается с skill `gro-content-edit` (29 AI-маркеров, чистка канцелярита) и [[canon/marketing-frameworks/ai-text-markers-checklist]].

## Применимость к ГРО

- **Pre-publish gate для блога groapp.ru:** 7 шагов как обязательный чек перед публикацией.
- **Шаг 6 (ключи) + GEO:** для блог-статей ГРО вхождение ключей в заголовки + FAQ-блок (требование SEO/GEO из skill `gro-content-write`).
- **Шаг 2 (первоисточники):** в материалах ГРО ссылаться на первоисточники (Gallup, Сколково, исследования), а не на перепечатки — блок «Источники» в каждой статье.
