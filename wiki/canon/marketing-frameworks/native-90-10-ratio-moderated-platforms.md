# Native 90/10 ratio для модерируемых блог-платформ

**Правило.** Для прохождения модерации на блог-платформах с жёсткой редакторской политикой (VC.ru в первую очередь, далее Дзен, нишевые специализированные медиа) текст должен соблюдать пропорцию **90% польза / 10% нативная продажа в конце**. Нарушение → удаление за 5 минут, статья не показывается в ленте, репутация автора падает.

Источник правила: [[sources/2026-05-19-pressfeed-kovpak-local-media-sales-funnel|Дмитрий Ковпак, Pressfeed]] — RU practitioner; формулирует как операционную дисциплину.

## Что считается «пользой» (90%)

- **Инсайты ниши** — наблюдения, которых нет в очевидных публикациях
- **Расчёты** — конкретные цифры с источником/методикой (срок производства, экономика лида, средний чек, разница в каналах)
- **Кейсы** — реальные истории с результатом и провалами (provide outcome metrics)
- **Анти-паттерны** — что НЕ работает, и почему (контр-фрейминг полезнее «как делать правильно»)
- **Сравнение методов** — рейтинги/таблицы инструментов, площадок, стратегий
- **Чек-листы** — операционные шаги, которые читатель может применить сразу

## Что считается «продажей» (10%)

- Упоминание собственной компании / услуги (имя, специализация)
- Линк на лендинг / контакт / форму
- Conclusion с CTA вида «обратитесь к нам»
- Footer-attribution «эксперт N компании X»

## Топология размещения

| Структура статьи | 90% польза | 10% продажа |
|---|---|---|
| Заголовок | Боль / тренд / спорный тезис | — |
| Лид-абзац | Контекст рынка / актуальность | — |
| Основная часть | Анализ, кейсы, цифры | — |
| Заключение | Резюме «что делать» | Нативное упоминание услуги |
| Bio-блок | — | Атрибуция автора + ссылка |

## Почему это работает

1. **Модерация VC.ru** — алгоритмическая + ручная; reject-критерий = «текст выглядит как реклама». 90/10 пропорция статистически проходит автоматический фильтр.
2. **Доверие аудитории** — комментаторы VC.ru агрессивно атакуют рекламные тексты; «съедят заживо» (Ковпак). 90% пользы создаёт оборону от хейта.
3. **SEO-эффект** — Google/Яндекс понижают рекламные страницы в ранжировании; контентная статья индексируется и работает 6+ мес. как long-tail asset (см. [[canon/marketing-frameworks/seo-for-ai-era-playbook]]).
4. **Виральность** — если статья «мясо», аудитория разнесёт сама. Рекламный текст этого механизма лишён.

## Анти-паттерны (что ломает 90/10)

- **«Мы лучшие на рынке»** — оценочные суждения в адрес собственной компании
- **CTA в середине текста** — призывы «свяжитесь сейчас» рядом с фактами
- **Превышение упоминаний** — больше 2-3 раз названия компании в тексте 4-6 тыс. знаков
- **Маркетинговые штампы** — «прорывные технологии», «эксклюзивные решения», «лидер отрасли»
- **Отсутствие конкретики** — общие рассуждения без чисел, имён, дат

## Применимость

| Платформа | Применяется | Severity модерации |
|---|---|---|
| VC.ru | да (обязательно) | жёсткая, реактивная (комменты) |
| Cossa.ru | да | средняя |
| RB.ru | да | средняя |
| Sostav.ru | да | средняя |
| Дзен | да | алгоритмическая |
| Habr | да (для tech-ниш) | очень жёсткая (Habr-эффект) |
| ЖК-чаты / районные TG | условно (10/30 ratio допустимо) | низкая |
| Городские порталы (Fontanka/E1) | оплаченные размещения — другая логика, native-органика — да | средняя |
| Корпоративный блог | не применяется (там 100% продажа ок) | нет |

## Применение в маркетинге ГРО

- **VC.ru / Cossa / RB.ru** — основные внешние площадки для GRO content-PR. 90/10 — обязательная норма.
- **Формула содержательной 90%-части для GRO:** AI-tooling adoption кейсы / productivity benchmarks / anti-patterns внедрения AI в managerial routines / расчёты ROI интенсивов / сравнения подходов к обучению AI-навыкам.
- **10%-часть:** в bio-блоке + 1-2 нативных упоминания «такая-то проблема решается в интенсиве ГРО» с линком на лендинг.
- **Anti-pattern для ГРО:** текст вида «10 преимуществ нашего интенсива» — сразу reject модерации VC.ru.
