# Audience-segmented PR-messaging

Принцип, проиллюстрированный кейсом мобильной автомойки **Fast&Shine** (zhazhda.biz, автор не верифицирован → `confidence: low`): один и тот же продукт подаётся по-разному под каждый тип медиа, чтобы покрыть всю ЦА. «Каждому из них мы раскрываем продукт по-новому, решая проблему конкретной аудитории» [src:2026-05-30].

## Матрица «тип СМИ → угол подачи»

| Тип медиа | Угол подачи | Source |
|---|---|---|
| Бизнес-медиа | цифры, динамика роста | `[conf:low, src:2026-05-30]` |
| Государственные | экология (vs водные автомойки) | `[conf:low, src:2026-05-30]` |
| Fashion-медиа | женщины как ключевые клиенты | `[conf:low, src:2026-05-30]` |
| IT-медиа | «Uber для автомоек» | `[conf:low, src:2026-05-30]` |

## «Uber for X» — позиционный shortcut

Эвристика быстрого позиционирования: «Назовите вашу компанию "Убером" для чего угодно — успех обеспечен». Работает как мгновенно понятный analogical-якорь для журналиста и инвестора; обратная сторона — клишированность к концу 2010-х.

## Непрерывная новостная подпитка

Когда первая волна освещения затухает, нужно производить новые инфоповоды (брендированные вертолёты/Bentley, первое-в-категории мобильное приложение), чтобы удерживать интерес журналистов. Связка с [[canon/marketing-frameworks/pr-carpet-bombing-info-povody]]: сегментация задаёт *что* сказать каждому СМИ, поток инфоповодов — *как часто*.

## Применимость к ГРО

Прямо применимо при анонсе фич: один релиз → разные углы для tech-медиа (архитектура), бизнес-медиа (unit-экономика клиента), нишевых сообществ (use-case). «Uber for X» использовать осторожно — категория перегрета.
