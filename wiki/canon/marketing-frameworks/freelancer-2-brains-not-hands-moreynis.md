# «Фрилансер 2.0 — нанимают мозги, не руки»

Рамка переопределения роли фрилансера в ИИ-эпоху от **Аркадия Морейниса** ([@temno](https://t.me/temno), [пост 7860 от 2026-05-29](https://t.me/temno/7860)). Стабильный positioning-принцип для фриланс-сегмента → `canon/marketing-frameworks`. Прямо релевантен [[canon/target-audience/gro-segments|сегменту «фрилансеры» GRO]].

## Центральная формулировка

> Чем фрилансер лучше, чем Claude Code? Всем хуже. Кроме одной вещи. У людей есть мозги. Которые большинство фрилансеров почему-то использует, чтобы конкурировать с Claude Code по скорости, объёму и ценам. Хотя мозги людям даны, чтобы понимать и придумывать. — Морейнис, [[sources/2026-05-30-tg-temno-moreynis-may-27-30-2026|пост 7860]]

## «Руки» vs «мозги»

| | Фрилансер 1.0 («руки») | Фрилансер 2.0 («мозги») |
|---|---|---|
| Что делает | выполняет свою часть задачи (код / дизайн) | понимает, придумывает и делает **весь комплекс** под результат |
| Вход | требует чёткое ТЗ | сам вытаскивает реальную потребность из жалоб/хотелок заказчика |
| Конкуренция | с Claude Code по скорости/объёму/цене (проигрышная) | с Claude Code не конкурирует — использует его как инструмент |
| Отношения | аутсорс (исполнитель) | **синергия** (партнёр по результату) |

**Ядро тезиса:** «сделать каждую отдельную вещь — задача для Claude Code. А понять, что нужно сделать, придумать как, и совместить в одном флаконе — задача для мозгов». Для человека «с мозгами в голове и с Claude Code в руках» техническая сторона перестаёт быть проблемой.

## Почему это canon, а не volatile-news

Это не новость про конкретный инструмент, а **переопределение профессиональной роли**, устойчивое на горизонте AI-волны: ценность смещается с execution на judgment/synthesis. Смыкается с judgment-as-new-bottleneck из [[evolving/industry-trends/ai-value-migration-2026]] и с [[canon/marketing-frameworks/b2b-ai-sales-playbook-moreynis|правилом 7 B2B-playbook]] («90% решения — понять, что делать»).

Морейнис добавляет, что фриланс 1.0 не исчезнет, пока есть «ленивые фаундеры, неспособные научиться пользоваться Claude Code» — но прогноз: такие вымрут. И ремарка «от фриланса до стартапа — всего один шаг» (через fastfounder обзоры) — bridge к startup-нарративу канала.

## Применение для GRO

- **Messaging для сегмента «фрилансеры»:** GRO позиционируется как тренажёр того самого «мозгового» слоя (понимание, синтез, инициатива), который и есть defensible навык. Anti-message — «помогаем делать руками быстрее».
- **Контент-hook:** «Фрилансер 1.0 vs 2.0: почему конкурировать с Claude Code по скорости — путь в тупик». Резонирует и с [[evolving/industry-trends/freelance-platform-dependency|зависимостью от платформ]] (фрилансер 2.0 менее заменяем и менее зависим).
