# Stripe / братья Коллисон — последняя миля онбординга

Каноническая sales-рамка для SaaS-продуктов: **«получить да от клиента — это только начало; настоящая работа в продажах — пройти последнюю милю до реального внедрения»**. Названа по канонической истории основателей Stripe.

**Authority.** Передано через Максима Спиридонова. Сама история Stripe / братьев Коллисон документирована в Y Combinator-материалах, биографиях, многочисленных интервью. `confidence: medium` для precision history (детали могут варьироваться), `confidence: high` для устойчивости рамки.

## Кейс

Братья Патрик и Джон Коллисон (Stripe, ~$100+ млрд оценка по последним раундам) на ранних этапах продаж работали по схеме:

1. Питч клиенту → клиент говорит «обязательно попробуем»
2. **Коллисон в эту же секунду** доставал ноутбук клиента
3. Открывал терминал, устанавливал платёжный модуль Stripe прямо там
4. Запускал тестовый платёж — рабочий
5. Клиент уходит **с работающей интеграцией**, не с обещанием попробовать

Эта тактика противоположна стандартному SaaS-сейлсу, где после «мы попробуем» начинается полугодовой sales-cycle с письмами «как ваши тесты?».

## Принцип

> Получить «да» от клиента — это только начало. Настоящая работа в продажах SaaS — **пройти последнюю милю** до реального внедрения и понимания пользы.

«Последняя миля» — отрезок между **обещанием попробовать** и **первым реальным использованием** продукта. На этом отрезке теряется 70-90% pipeline в SaaS-продажах. Большинство команд не считают эту потерю как sales-failure, потому что «обещание попробовать» уже галочка в CRM.

## Структура последней мили

| Шаг | Что обычно происходит | Что должно происходить (Stripe-подход) |
|---|---|---|
| Клиент сказал «попробуем» | Sales отметил «interested», CRM статус → trial | Sales **остаётся в room/exchange** до первого реального использования |
| Установка/integration | Письмо «вот гайд» через 3 дня | Скрин-шаринг, **установка прямо сейчас** |
| Первая конфигурация | Письмо «если возникнут вопросы — пишите» | Sales проводит первую конфигурацию **вместе** |
| Первое реальное использование | Ждут «само случится» | Sales **планирует** первое использование на конкретный день/час |
| Активация | Метрики через месяц | Метрики **в день первого использования** |

## Почему «обещали попробовать» обычно проваливается

Психология клиента:
- В момент питча клиент в **active mode** (думает о вас)
- Через 24 часа возвращается в **operational mode** (думает о своей операционке)
- Через неделю забывает 80% разговора
- Через месяц «попробуем» = «уже не актуально»

«Последняя миля» — попытка **не выпускать клиента из active mode**, пока он не получит первый успех. После первого успеха работает endowment effect: «у меня уже есть рабочая интеграция, легче продолжить, чем удалить».

## Применение к B2B SaaS

| Шаг последней мили | Тактика |
|---|---|
| После demo не отпускать | «Давайте прямо сейчас установим, я помогу» |
| Free trial → активация | Push-notification «у вас 3 дня бесплатного. Давайте проведём 30-минутный onboarding-zoom» |
| Платный план → первое использование | «День X — давайте проведём первое реальное использование вашей команды вместе» |
| Через 7 дней без активности | Live-zoom, не email |
| Через 30 дней | Если не активировался — это **sales failure**, не «marketing failure» |

## Применение к B2C (приложение)

| Шаг | Тактика |
|---|---|
| После установки | Onboarding flow с обязательным первым действием (не «пропустить») |
| После первого открытия | Push в первый-же день с напоминанием о незавершённом действии |
| После 3 дней без активности | Push с конкретной программой (не «попробуйте приложение»), что-то типа «сегодня 7-минутная тренировка для шеи и плеч — давайте сделаем» |
| После 7 дней | Re-engagement push + email с *одной* программой |
| После 30 дней без активности | Это churn, дальше работа на reactivation-кампании |

## Связь с другими рамками

- **«Получить да — это начало»** = obratная сторона **MVP-launch** ([[canon/marketing-frameworks/anti-perfectionism-mvp-launch-muratayev]]): MVP отдают пользователю, потом нужно **пройти последнюю милю** до реального использования.
- **«Последняя миля» в продажах** — структурный аналог **«последней мили» в логистике** (Amazon, доставка). И там, и там 80% времени и стоимости концентрируется на финальном отрезке.

## Применение к ГРО

- **Lead → активация** — после клика на «попробовать ГРО» не отпускать. Onboarding с обязательным выбором первой программы (не «вы можете выбрать программу позже»).
- **Free trial → платный** — за 3 дня до конца триала live-консультация с тренером (не email «у вас заканчивается»).
- **Активация → habit** — push после первой тренировки: «отлично, через 24 часа — следующая, забронируем?». **Конкретное планирование**, не пожелание.
- **Чёрная зона** — пользователи, которые установили, но не запустили первую тренировку, — это **сейлс-фейл**, нужна live-команда (или email-секвенция, или AI-чат), чтобы провести через последнюю милю.
