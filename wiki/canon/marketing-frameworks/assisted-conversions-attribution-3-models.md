# Ассоциированные конверсии — атрибуция медийных касаний 3 моделями

**Ассоциированные конверсии** — методология учёта влияния охватных (медийных) касаний на конверсию в перформанс-каналах через сквозную аналитику. Это **финансовый мост** между investment-треком и operational-треком в [[canon/marketing-frameworks/brand-vs-performance-two-track-strategy-pervukhin|two-track стратегии]]. Канонизация: Артем Первухин, продакшен-директор KINETICA, статья на Деловом мире / Дзен ([[sources/2026-05-27-dzen-delovoymir-pervukhin-brand-vs-performance]]).

## Главный тезис

> «Влияние медийных касаний на конверсию в перформанс-каналах, отслеживаемое через сквозную аналитику. При достаточном объёме данных — через data-driven attribution, при недостаточном — через модель time decay. Это единственный способ показать финансам прямую связь между охватным размещением и выручкой. Без этого медийка всегда будет выглядеть как чистый расход.» `[conf:medium, src:2026-05-27]`

> «Медийное касание не последнее в цепочке — но без него цепочки не было бы.» `[conf:medium, src:2026-05-27]`

Это **центральная проблема охватных каналов** в стандартной last-click атрибуции: финальный конверт всегда «отдаётся» перформансу (контекст, прямой заход), а медийка, разогревшая аудиторию до первого клика, остаётся **невидимой**. Ассоциированные конверсии решают этот разрыв.

## Empirical anchor: эффект медийного касания

> «Показательная механика: пользователи, видевшие медийную рекламу бренда перед переходом на сайт через контекст, конвертируются в разы лучше, чем те, кто пришёл только через платный поиск без предварительного касания.» `[conf:medium, src:2026-05-27]`

«Это не теория — это данные атрибуционных моделей, которые большинство компаний просто не настраивают.» `[conf:medium, src:2026-05-27]`

**Implication:** без настройки multi-touch атрибуции этот эффект **не видим в стандартных отчётах**. Соответственно, при первом же сокращении бюджета охватная статья «обнуляется» как неэффективная — это **самоисполняющийся приговор**.

## 3 модели атрибуции в порядке точности

| # | Модель | Когда применять | Требования | Точность |
|---|---|---|---|---|
| 1 | **Data-Driven Attribution (DDA)** | Достаточный объём данных (обычно 10 000+ конверсий/мес) | Сквозная аналитика, ML/algorithmic attribution | Высокая |
| 2 | **Time decay** | Недостаточно для DDA | Multi-touch fixed-weights, экспоненциальный спад | Средняя |
| 3 | **Ассоциированные конверсии (assisted)** (Google Analytics legacy / GA4 path analysis) | Минимальный baseline для любого бизнеса | Сквозная аналитика с многоканальной воронкой | Базовая |

### Модель 1 — Data-Driven Attribution (DDA)

**Что это:** алгоритмическая атрибуция, которая на основе исторических данных рассчитывает **относительный вклад каждого касания** в финальную конверсию. Использует ML — учится на cohorts «купили vs не купили» и распределяет вес touchpoints пропорционально вкладу.

**Когда применять:** при достаточном объёме конверсий — ориентировочно **10 000+/мес** (порог зависит от платформы — Google Analytics 4, Mixpanel, Adobe, RoiStat и т.д.).

**Пример:** покупатель совершил 5 касаний — YouTube видеореклама → Telegram-канал → Яндекс контекст → email → прямой заход → покупка. DDA: 22% / 18% / 30% / 15% / 15% вместо last-click 100% прямому заходу.

### Модель 2 — Time decay

**Что это:** Multi-touch модель с **экспоненциальным спадом** — чем ближе касание к конверсии по времени, тем больший вес.

**Когда применять:** недостаточно данных для DDA (например, B2B SaaS с 200 сделками в год). Time decay даёт **достаточно справедливое распределение** без ML-требований.

**Пример:** при half-life 7 дней — касание за день до покупки получает 95% веса, за неделю — 50%, за месяц — ~5%. Медийное касание за 14 дней до покупки получает ~25% вклада — это уже **видимая** доля в отчёте, в отличие от 0% при last-click.

### Модель 3 — Ассоциированные конверсии (assisted conversions)

**Что это:** базовая модель из Google Analytics — для каждой конверсии система фиксирует **полный многоканальный путь** и атрибутирует assisted credit каждому non-last-click касанию.

**Когда применять:** **минимальный baseline**, доступный любому бизнесу с настроенной сквозной аналитикой (даже без ML/DDA). В GA4 — отчёт «Multi-channel funnels → Assisted Conversions».

**Что показывает:**
- **Direct conversions** канала: сколько раз канал был **last-click**.
- **Assisted conversions** канала: сколько раз канал участвовал в воронке, но не был last-click.
- **Assist/Last ratio:** если у медийки ratio 5:1 — она ассистировала в 5 конверсиях на каждую last-click → доказательство того, что **большинство её вклада невидимо в стандартных отчётах**.

## Как использовать в **two-track стратегии**

Ассоциированные конверсии — **финансовый мост** между двумя треками:

- В **operational-отчёте** (CPA/ROAS) медийка обнуляется → выглядит расходом.
- В **investment-отчёте** ассоциированные конверсии переводят влияние медийки в финансовый язык: «охватная кампания Q2 атрибутировала 1 200 ассоциированных конверсий с DDA-весом 28% → ~340 эффективных конверсий, рассчитанных по среднему чеку = X млн ₽ выручки».

Это **отвечает на главное возражение CFO**: «бренд — это расход без возврата». Ответ: «вот возврат в рублях, рассчитанный по DDA на ваших же конверсиях».

## Минимальный setup сквозной аналитики

Для базового замера ассоциированных конверсий нужно:

1. **Cross-channel tracking** — UTM-метки на всех источниках, единый client ID (Google Client ID / Яндекс ID / first-party cookie / Stable ID).
2. **Конверсии настроены в GA4 / Яндекс Метрике** как key events с правильным lifecycle (от первого касания до покупки, а не только last-click).
3. **CRM-интеграция** для оффлайн-конверсий (если покупка вне сайта) — без неё цепочка обрывается.
4. **Multi-touch attribution UI** (GA4 path analysis / Mixpanel funnels / RoiStat кастомные модели).

**Anti-pattern:** одна Яндекс Метрика без CRM-интеграции и без UTM-дисциплины → ассоциированные конверсии будут считаться **некорректно** (canonical issue: «прямой заход» доминирует, потому что не настроены referrer-policies).

## Как презентовать финансам

3-шаговый протокол перевода ассоциированных конверсий в **CFO-понятный язык**:

1. **Картина last-click vs assist:** «Если мы смотрим last-click, медийка приносит 50 заказов в месяц при бюджете 2 млн ₽ = 40 000 ₽/заказ. По ассоциированным конверсиям — 800 заказов с DDA-весом 22% = ~175 эффективных конверсий = 11 400 ₽/заказ. Реальная цена в 3,5 раза ниже видимой.»
2. **Опыт с холд-аутом:** «При холд-ауте охватной кампании на 4 недели мы зафиксировали падение конверсий в перформансе на X%. Это контрольный эксперимент: медийка не просто ассистировала по моделям — её отсутствие напрямую обвалило перформанс.»
3. **Прогнозный план:** «Если возобновляем медийку с бюджетом N, ожидаем восстановление прежнего performance-эффекта через 4–6 недель (lag отклика [[canon/marketing-frameworks/share-of-search-brand-metric|Share of Search]]).»

## Anti-patterns

1. **Last-click как единственная модель** — медийка обнуляется автоматически, бренд-инвестиции выглядят расходом.
2. **DDA без достаточного volume** — ML на 50 конверсиях/мес даёт **случайные веса**, не атрибуцию. Использовать time decay.
3. **Сравнение CPA медийки и контекста напрямую** — это different funnels (top-funnel vs bottom-funnel), сравнение бессмысленно.
4. **Hold-out эксперимент без коммуникации с финансами** — выключили медийку, упал performance, никто не связал, бренд-бюджет всё равно срезали в следующем квартале.
5. **Игнорирование оффлайн-конверсий** — для B2B / медицины / автокредитов цепочка обрывается на оставленной заявке; без CRM-интеграции assisted conversions недосчитываются.

## Применение к GRO

GRO как B2C subscription, mobile-first — специфика атрибуции **сложнее**, чем у e-commerce:

### Текущее состояние
- Sources install: AppsFlyer / MyTracker / собственная атрибуция.
- Last-click доминирует — большинство атрибуций идут к «установке из магазина» с прямого захода или из текущего хранилища (deferred deep link).
- **Cold trafic из охвата** (Telegram-канал @gro_me, упоминания в подкастах, PR в фитнес-медиа) — обнуляется в стандартных install-attribution отчётах.

### Минимальный setup для GRO
1. **UTM-дисциплина** на всех каналах (включая deferred deep links из охватных).
2. **AppsFlyer assisted installs** (если используется) — настроить multi-touch view, не только last-click.
3. **CRM-интеграция** — связать install → активация подписки → платёж → удержание (от первого касания до 3-го месяца retention).
4. **Hold-out эксперимент** при первой крупной охватной кампании — выключить ретаргетинг и измерять delta install/activation.

### Что показать CFO
«За квартал охватная кампания через Telegram + PR дала 200 last-click installs при бюджете 1.5 млн ₽ = 7 500 ₽/install. По assisted installs с DDA-весом 30% — 1 800 ассоциированных = ~540 эффективных = 2 800 ₽/install. Это в 2.7 раза дешевле видимой CPI и сравнимо с performance-каналами при гораздо выше LTV (cold-аудитория из подкаста показывает retention D90 в 1.8× выше, чем из перформанса).»
