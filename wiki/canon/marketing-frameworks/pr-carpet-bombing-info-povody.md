# PR carpet-bombing — поток инфоповодов как low-budget PR-канал

Operational-фреймворк дешёвого PR для SMB, изложенный практиком на zhazhda.biz (автор не верифицирован → `confidence: low`, атрибуция к источнику). Идея: вместо дорогого агентства или разовых вбросов — методичная массовая рассылка плотно упакованных пресс-релизов («ковровая бомбардировка» СМИ). Сильный релиз может дать 10–50+ публикаций за день.

## Три обязательных «ключа»

По мнению автора [src:2026-05-30], релиз работает только при наличии трёх компонентов:

1. **Большая тема-волна** — оседлать уже существующий мейнстрим-тренд (типа «селфи», «хипстеры»), чтобы релиз ехал на чужом интересе.
2. **Уникальный неологизм / придуманный термин** — чтобы по этому слову ранжировались только ваши страницы (захват выдачи).
3. **Атрибуция к «официальному» весомому источнику** — придумать ассоциацию/организацию; достаточно сайта или даже страницы в соцсети, чтобы добавить весомости.

## Каденс и механика

- Запланировать ~30 инфоповодов на год, выпускать 1–3 раза в месяц; смысл — методичный повтор, а не разовый залп.
- **Эффект «наслоения смыслов»**: даже неопубликованные релизы работают — журналисты накапливают контекст, ранние релизы «протекают» в позднее освещение.
- Claim автора о механике топа Яндекс-новостей: чтобы попасть в московский топ нужно ~100 СМИ-публикаций в рабочий день, старт с 9:00; региональный топ-5 достижим за часы [conf:low, src:2026-05-30].

## Иллюстративные cost-якоря (мид-2010-е, устарели)

Цифры приводятся только как порядок величины из источника, не как актуальный бенчмарк: годовая пресс-релизная кампания ~400k ₽/год против $3000–5000/мес у типичного PR-агентства; креатив на 50 PR-идей ~300k ₽; один ТВ-сюжет на приличном канале 300–500k ₽ [conf:low, src:2026-05-30].

## Применимость к ГРО

Канал релевантен как дешёвый awareness-инструмент для продуктовых запусков; «уникальный неологизм»-ключ хорошо ложится на категорийный нейминг новых фич. Использовать с поправкой на то, что механика выдачи Яндекс-новостей с тех пор изменилась.
