# Типология площадок для спикера: peer-event vs target-audience event

Reusable рамка для выбора площадки спикером-предпринимателем — от руководителя SEO-агентства **LZ.Media** (Самара, #1 «Рейтинга Рунета»; третья публикация автора в Pressfeed, см. также [[canon/marketing-frameworks/ai-content-marketing-delegation-frame-lz-media]] и [[canon/marketing-frameworks/b2b-homepage-client-route-structure-lz-media]]). Источник: [[sources/2026-05-19-pressfeed-lz-media-speaker-first-event-prep]].

`confidence: medium` — методология согласуется с консенсусом event-marketing практиков 2024-2026, автор inferred-эксперт с публично верифицируемой позицией.

## Центральный тезис

> Площадка для спикера выбирается **не по «качеству», а по маркетинговой задаче**. Одно и то же выступление на разных типах ивентов даёт **совершенно разный результат**.

Это перевод выбора площадки из режима «куда нас пустят» в режим **сегментации по цели**.

## Два архетипа площадок

| Параметр | Peer-event (для своих) | Target-audience event (для ЦА) |
|---|---|---|
| **Кто в зале** | коллеги, конкуренты из той же отрасли | потенциальные клиенты |
| **Маркетинговая задача** | нетворкинг, узнаваемость в проф-среде, поиск партнёров/инвесторов | продажи, лиды, тестирование гипотез, понимание ЦА |
| **Что забираете** | контакты, репутация, поддержка сообщества | заявки, обратная связь от ЦА (боли/возражения/сомнения), материал для product/marketing |
| **Примеры (по отраслям)** | digital-агентство → IT/маркетинг-ивенты; отель/ресторан → HoReCa | косметика → форумы для женщин; фулфилмент → конференция для селлеров маркетплейсов |
| **Региональный масштаб** | федеральный = больше медийки, выше конкуренция за слот; региональный = меньше масштаб, выше концентрация личных контактов | специализация важнее масштаба (см. подклассы ниже) |

**Эту таблицу можно повесить на стену перед заявкой на ивент.** Если не получается ответить «peer или target?» — заявка скорее всего преждевременна, цель доклада не сформулирована.

## 4 подкласса target-audience events

Когда цель — продажи / лиды / понимание клиента, у target-audience events есть **разные trade-off по format'у**:

| Подкласс | Плюс | Минус |
|---|---|---|
| **Масштабные** (средний/крупный бизнес) | большая аудитория | очень неоднородная, сложнее запомниться всем |
| **Специализированные** (CFO-only, HR-D only и т.п.) | выше конверсия (точное попадание) | требует глубокой экспертизы + **кейсов из отрасли ЦА** |
| **Образовательные** (тренинги, вебинары, интенсивы, воркшопы) | высокая вовлечённость, демонстрация **практической стороны продукта** | малая аудитория + организаторы обычно **запрещают прямые продажи со сцены** |
| **Выставки** | деловая программа есть, можно выступить и для участников, и для зрителей | место под стенд **платное**, требуется рекламное оформление |

Образовательные events — наименее очевидный подкласс: автор предостерегает не путать «вебинар обучающего проекта» с «продающим вебинаром собственным». В первом случае продажа со сцены забанена, но качество демонстрации продукта — наивысшее.

## Связь типа площадки с целью продвижения

```
Цель: партнёры/инвесторы/репутация
  → peer-event (региональный или федеральный — по бюджету и доступу к слоту)

Цель: лиды/продажи здесь и сейчас
  → target-audience: specialized или большая отраслевая

Цель: познакомить рынок с new-to-market продуктом, протестировать гипотезу
  → target-audience: образовательный (вебинар, интенсив, воркшоп) — высокий dwell-time + право на детальную аргументацию

Цель: market intelligence (понять боли ЦА)
  → target-audience любой подкласс + плотный networking после
```

## Анти-паттерн

❌ **Спикерство «потому что престижно»** на peer-event'е, когда задача была — лиды. Аудитория из конкурентов не покупает, но потратили 20-40 часов подготовки (см. [[canon/marketing-frameworks/speaker-economics-reality-cherednichenko]]).

❌ **Прямые продажи со сцены образовательного event'а** — нарушение правил организатора, риск отказа в дальнейших слотах. Образовательные ивенты — для **демонстрации экспертизы**, не для прямых продаж; продажи догоняются после, через follow-up.

## Применение для GRO

- **Лапшина / Егошин выступают** → peer-events для founder/AI-сообщества (узнаваемость в среде, потенциальные партнёрства / инвесторы) **vs** target-audience events для целевых сегментов: HR-конференции (Сегмент 1: HRD), business-конференции SMB-владельцев (см. [[canon/target-audience/ru-smb-founder-owner-seller]]), профильные events для knowledge worker'ов (Сегмент 2, см. [[canon/target-audience/automation-eager-knowledge-worker-ru]]).
- **Региональный фокус оправдан**: меньше конкуренции за слот, концентрация в регионе бывает выше федерального события. См. [[canon/marketing-frameworks/speaking-as-marketing-channel]].
- **Образовательные events** — органичный для GRO формат: продукт = практика AI-продуктивности, на webinar/intensив естественно показывать **демонстрацию практической стороны**; продажи догоняются follow-up'ом и/или промокодом «для участников» (если у организатора разрешено).
