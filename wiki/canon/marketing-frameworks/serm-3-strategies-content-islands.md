# SERM-фреймворк: 3 стратегии + контент-острова + градация негатива

Operational-фреймворк управления репутацией в поисковой выдаче (Search Engine Reputation Management). Reusable рамка для любого бренда с публичным присутствием. Источник синтеза — большой гайд по SERM на Pressfeed.Журнал с практиками RU-эксперта и параллельной градацией от Probalance.

## Почему canon

Сам фреймворк (3 стратегии × подход «контент-острова» × градация негатива × модель 4К) переносим между нишами и стабилен на годы. Конкретные RU-инструменты (Arsenkin Tools, Topvisor, Пиксель Тулс, Крибрум) → `evolving/competitor-positioning/`. Цены и доли рынка → `evolving-strict/*`.

## 3 базовые стратегии SERM

| Стратегия | Когда применять | Ключевая механика |
|---|---|---|
| **(1) Антикризисная** | После негативного инцидента, всплеск негатива в поиске | Обработка существующего негатива + новая волна позитива; параллельно — мониторинг попадания позитивных в топ |
| **(2) Building с нуля** | Молодой бренд, мало упоминаний → высокий риск, что первый негатив займёт топ | Заведение каналов на VK, TenChat, RuTube с интеграциями вариаций названия бренда; накопление позитивного digital footprint **до** появления негатива |
| **(3) Укрепление** | Зрелый бренд с устоявшейся репутацией | Регулярный новый экспертный контент + защита от случайного негатива; не разовая кампания, а постоянный процесс |

**Якорные кейсы антикризисной стратегии:**
- «Аэрофлот» × Илья Соболев — обыграл негатив через стенд-ап-интеграцию
- «РЖД» × кот Твикс (январь 2025) — отдельный билет на питомца как ответ на инцидент

## Подход «контент-острова» (rotation негатива)

Главная operational-механика SERM: вместо удаления негатива (часто невозможно) — **создаются «острова контента»** на сайтах с негативом:

- Экспертные UGC-статьи
- Обзоры
- Ветки форумов с позитивным контекстом
- Пресс-релизы
- Авторские колонки

Эти острова **выводятся в топ-10/20** → негатив смещается на 2-3 страницу выдачи (где CTR падает в 10×). Сам негатив остаётся, но его **никто не видит**.

→ Это применение **эффекта Стрейзанд наоборот**: не пытаемся скрыть, а заглушаем своим контентом, который выгоден нам.

## 4К — модель базовых маркетинговых рычагов

Эксперт SERM формулирует **четыре К**, которые должны работать одновременно для устойчивой репутации:

1. **Комьюнити-менеджмент** — WOM (Word-of-Mouth), UGC, активное сообщество
2. **Контент-маркетинг** — регулярные публикации, экспертные материалы, ответы на вопросы аудитории
3. **Коллаборация** — обмен аудиториями с партнёрами (cross-promo, совместные исследования)
4. **Креатив** — что-то новое для PR Value (виральный контент, оригинальные форматы)

Без четвёртого К — репутация «средняя», без выдающегося PR Value. Без любого из первых трёх — нет fundament'а, на котором креатив имеет смысл.

## Градация негатива (Probalance, директор по маркетингу)

3 типа негатива → 3 разных стратегии ответа:

| Тип | Описание | Что делать |
|---|---|---|
| **(1) Объективная критика** | Реальный косяк, обоснованные претензии | **Не удалять** — помогает развиваться; ответить публично, исправить, рассказать о исправлении |
| **(2) Эмоциональная необъективность** | Не справедливо, но искренне | **Не удалять** (хотя хочется) — люди могут заблуждаться; ответить мягко, дать контекст |
| **(3) Явно недостоверная** | Фейк, провокация, конкурент | 3 варианта: (a) удалить; (b) дать выверенный публичный ответ с фактами; (c) **не реагировать** (эффект Стрейзанд — реакция может усилить охват) |

**Правило выбора варианта** при типе 3: оценить охват существующего поста. Если охват маленький (<1000 просмотров) — игнор. Если уже разошлось — ответ с фактами. Удаление только если **юридически очевидно** недостоверная информация (клевета).

## AEO как новая дисциплина (внутри SERM 2026)

Источник особо отмечает: **«Сегодня вместо SEO многие занимаются AEO** (Answer Engine Optimization), стремясь скормить ИИ больше информации о своём бренде для корректной выдачи в нейросетях. AEO позволяет попасть в выдачу по небрендированным запросам».

→ См. отдельный playbook: [[canon/marketing-frameworks/seo-for-ai-era-playbook]].

**EEAT-факторы** (Опыт, Экспертность, Авторитетность, Доверие) — нейросети **отдают явное предпочтение авторитетным источникам**. Это меняет «контент-острова»: остров на mass-форуме слабее, чем экспертная колонка на отраслевом СМИ. Сервис **Geometrika** упоминается как инструмент для отслеживания ресурсов в нейроответах.

## Уменьшенное «окно реакции» бренда (2026)

> «Информация до конечного потребителя/клиента стала доходить намного быстрее»

Формат публикаций для SERM сместился к более структурированному, развёрнутому, с практическими рекомендациями и **уникальными данными**. Это симметрично [[canon/marketing-frameworks/crisis-speed-gap-zharinov|кризисной speed-gap проблематике]] — окно реакции на негатив тоже сократилось.

## Anti-pattern

- ❌ Пытаться удалить весь негатив через юристов — медленно, дорого, часто триггерит [[canon/marketing-frameworks/black-pr-community-doubt-mechanic|Стрейзанд-эффект]]
- ❌ Реагировать одинаково на все 3 типа негатива — особенно отвечать публично на тип 3 с маленьким охватом (раздувает)
- ❌ Заниматься только защитой (типы 1-3 ответы), без активного building'а (стратегия 2)
- ❌ Контент-острова только на одном канале — нужна география across-platform
- ❌ Не мерить «попадание в нейроответы» — AEO-слой невидим без мониторинга

## Применимость к ГРО

GRO как продукт с активным присутствием в RuStore/Play/App Store:

- **Стратегия укрепления** (3) — основная: регулярный экспертный контент в блоге, на VC.ru, в TG
- **Контент-острова** — экспертные публикации в Skillbox Media, Хантфлоу, отраслевых HR-СМИ → выводят бренд GRO в топ при поиске «AI обучение мягким навыкам»
- **AEO layer** — Schema.org FAQPage/HowTo на блоге → попадание в нейроответы ChatGPT/Алиса/Яндекс
- **Градация негатива** — отзывы в магазинах разделить на 3 типа, для типа 1 (объективная критика) **публикация улучшений** в release notes — превращение критики в маркетинг-актив
