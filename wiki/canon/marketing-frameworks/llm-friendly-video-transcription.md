# LLM-friendly HTML транскрипция видео для AI-индексации

Это **специфическая operational техника** GEO/AEO: встраивание скрытой HTML-транскрипции видео в код страницы, чтобы языковые модели могли индексировать содержание ролика как текст. Видео становится «видимым» для LLM при поисковых запросах, релевантных его содержанию.

## Описание техники

> «Классический SEO в своей работе не отменяли, но сейчас в видеофайлы добавляем специальную оптимизацию под ИИ-поиск: так называемый "LLM-friendly код", код, который "дружелюбен" к восприятию ИИ-агентами.
>
> Выглядит это примерно так: в HTML встраивается транскрипция видео в скрытом блоке, чтобы языковые модели могли индексировать содержание ролика. Тогда видео может попадать в ответы ИИ по релевантному запросу. Это возможно, если плеер конкретного хостинга поддерживает автоматическую генерацию субтитров и далее может их обрабатывать. При этом для зрителя ничего не меняется.»
>
> — Pressfeed «13 кейсов адаптации к ИИ-поиску», май 2026 [[sources/2026-05-18-pressfeed-13-cases-ai-search-adaptation]]

## Механизм

1. **Видеоплеер генерирует автоматические субтитры** (нужна поддержка хостинга: YouTube ✓, Vimeo с настройками ✓, RuTube ограниченно, VK Видео ограниченно)
2. **HTML-страница встраивает транскрипцию субтитров** в специальный блок:
   - Скрытый для зрителя через CSS (`display:none` нельзя — Google штрафует; используется `aria-hidden="true"` + offscreen-позиционирование, или collapsible-блок «Транскрипция»)
   - **Видимый для краулеров** Google/Yandex/AI-ботов
3. **LLM-краулер парсит текст транскрипции** и индексирует видео как текстовый контент, сохраняя ссылку на оригинальный ролик
4. **AI-ответ цитирует видео** по релевантному запросу, ведя пользователя на страницу с плеером

## Когда работает (необходимые условия)

- Плеер генерирует автоматические субтитры (или вы загрузили транскрипцию вручную)
- Плеер позволяет извлечь субтитры в обрабатываемый текст
- HTML-страница содержит встроенный текст транскрипции (не lazy-loaded JS, а серверно-рендеренный)
- Транскрипция семантически осмысленная (не сырой ASR с ошибками, а почищенная)

## Когда не работает / ограничения

- ❌ Видео на платформах без автотранскрипции (некоторые RU-хостинги)
- ❌ Embedded video через iframe без сопровождающего HTML-текста на странице
- ❌ Lazy-loading транскрипции через JS — AI-краулеры не видят
- ❌ Скрытие через `display:none` без расширения — может квалифицироваться как cloaking
- ⚠ Не панацея: техника усиливает индексацию видеоконтента, но не заменяет E-E-A-T-сигналы (см. [[canon/marketing-frameworks/seo-for-ai-era-playbook]])

## Связанные техники

### Расширенная: транскрипция как самостоятельный контент

Вместо встроенного блока — отдельная страница `/transcripts/<video-slug>` с полной транскрипцией + summary + key-quotes. Это даёт **two-fold benefit**:
1. Краулеры индексируют transcript-страницу как обычный текстовый контент с богатой семантикой
2. Внутренняя ссылка с видео-страницы → transcript повышает обнаруживаемость

### Schema.org VideoObject markup

Параллельно встраивать JSON-LD `VideoObject` schema с полями:
- `name`
- `description`
- `thumbnailUrl`
- `uploadDate`
- `duration`
- `transcript` ← ключевое поле для AI
- `contentUrl`

Это даёт **structured signal** в дополнение к скрытой транскрипции.

## Импликации для GRO

GRO в основном текстово-ориентирован (приложение тренировки + статьи в блоге), но если планируется видеоконтент (демо-ролики продукта, видео-объяснения от founders, видео-кейсы пользователей), то техника применима:

1. **Demo-видео продукта** — транскрипция через YouTube + встраивание на лендинги. Дополнительно — Schema.org VideoObject.
2. **Видео-выступления founders на конференциях** — встраивание расшифрованных speeches на сайт + ссылка на оригинал.
3. **User testimonials в видеоформате** — обязательно с транскрипцией для попадания в AI-цитируемость на запросы вроде «отзывы о GRO».
4. **Видео-курсы / гайды** — двойное представление: видео + полный текст-аналог как самостоятельная страница (см. [[canon/marketing-frameworks/seo-for-ai-era-playbook|кластерный подход]]).

## Anti-pattern

- ❌ Загружать видео без транскрипции вообще — content-pessimization для AI-эпохи
- ❌ Использовать только iframe-embed без сопровождающего текста на странице
- ❌ Полагаться на «YouTube видит и показывает» — это другая сущность, отличная от того, что **ваш сайт** видим в AI-ответе
