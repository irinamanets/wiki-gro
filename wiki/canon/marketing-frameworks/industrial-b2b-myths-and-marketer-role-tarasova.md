## 4 вредных мифа

| Миф | Реальность по Тарасовой |
|---|---|
| **«Маркетинг — для розницы»** | B2B тоже строится на восприятии и доверии, не только на продукте |
| **«Всё решает цена»** | Ценовые войны проигрышны: клиент уйдёт к более дешёвому. Решают **стабильность поставок, сроки, сервис, гарантия** |
| **«Хороший продукт продаёт себя сам»** | Без коммуникации клиент о продукте не узнаёт |
| **«Сайты/соцсети — для ритейла»** | Инженер/закупщик **первым делом идёт в поиск** |

`[conf:medium, src:2026-05-19]`

**Миф «всё решает цена»** — прямой мост к [[canon/marketing-frameworks/industrial-b2b-brand-framework-tarasova|механизму 2 «премия к цене»]]: proof-driven позиционирование отвязывает от ценовой конкуренции. **Миф «продукт сам себя продаёт»** — инверсия [[canon/marketing-frameworks/industrial-b2b-no-strategy-degradation-tarasova|механизма деградации №2 (отток клиентов)]].

## Кейс-иллюстрация (anti vs proof)

Предприятие отказалось от маркетинга → через год на грани закрытия (старые заказчики сократили закупки). Конкурент развивал онлайн (кейсы с измеримыми результатами, видео с производства, вебинары для инженеров) → **40% новых заказов через цифровые каналы**. `[conf:low, src:2026-05-19]`

Это эмпирическая иллюстрация degradation-spiral из [[canon/marketing-frameworks/industrial-b2b-no-strategy-degradation-tarasova]] (отказ от стратегии → отток → стагнация).

## Современный промышленный маркетинг = 4 опоры

1. **Удобный сайт** (инженер идёт в поиск).
2. **Демонстрация экспертизы** — кейсы с цифрами, видео с производства, вебинары, отраслевые статьи.
3. **Акцент на надёжность / сервис / долгосрочные отношения** (не на цену).
4. **Присутствие там, где ищут клиенты** — поиск, проф-соцсети, отраслевые сообщества.

## Роль промышленного маркетолога

B2B-специалист, оперирующий **рациональными аргументами / цифрами / ТЭО**, а не эмоциями. Особенности роли:

| Особенность | Содержание |
|---|---|
| **Длинный цикл сделки** | Недели — год+ |
| **Техкомпетенция** | ИСО / ГОСТ / АСТМ, чертежи, спецификации |
| **Карты ЛПР** | Карты лиц, принимающих решения, и влияния внутри клиента |
| **Ценообразование** | Через **TCO / срок окупаемости / ROI**, не прайс-лист |
| **Техконтент** | Помогает принять решение, а не развлекает |
| **Sales enablement** | Скрипты, ответы на возражения, шаблоны КП с экономической аргументацией |

**Карты ЛПР** — мост к [[canon/marketing-frameworks/b2b-services-client-maturity-funnel|воронке B2B-services]] (множественные стейкхолдеры на стадии решения). **Ценообразование через TCO** — мост к [[canon/marketing-frameworks/industrial-b2b-brand-framework-tarasova|механизму «премия за решение»]].

## Применимость к ГРО

- **Миф «продукт сам себя продаёт»** — прямое предупреждение: даже сильный AI-продукт требует коммуникации; для B2B-сегмента ГРО (команды, предприниматели) нужен техконтент, а не только product-led рост.
- **Sales enablement** — для B2B-продаж ГРО командам: шаблоны КП с ROI-аргументацией (экономия часов × ставка сотрудника).
- **Контент-anchor для блога:** «4 мифа о промышленном маркетинге» — переносимый формат под B2B-аудиторию groapp.ru.
- **Caveat (по rules.md и Tarasova-кластеру):** цифры (40% заказов, грань закрытия) — анекдотические single-case, использовать как иллюстрации механики с атрибуцией Тарасовой, не как рыночные факты.
