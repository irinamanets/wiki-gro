# AI-course production conveyor — 7 этапов

Универсальная **production-методология** создания онлайн-курса с использованием AI-инструментов. Сформулирована как 7 последовательных этапов с привязкой к функциональным типам инструментов. Каждый этап — отдельная задача со своим AI-инструментарием. Конвейер построен на ключевом структурном принципе: **нет универсального AI-сервиса** для всего курса; есть **специализированные инструменты под этап**, которые надо собрать в pipeline.

Рамка выведена из [[sources/2026-05-19-pressfeed-ai-tools-for-online-courses-15|обзора Pressfeed «Нейросеть для курсов» (2026-05-18)]] и удерживает структурный уровень: какие этапы существуют и какой класс инструмента нужен на каждом. Конкретные имена инструментов (Kandinsky / Qwen / Шедеврум …) дрейфуют ежемесячно — это **evolving-снимок** в [[evolving/content-trends/ru-ai-course-production-stack-2026]]. Сам **конвейерный паттерн** стабилен и пере­носим на любой content-production-проект (видеокурсы, лонгриды, серии Telegram-постов с обучающей нагрузкой, корпоративные L&D-программы).

## Структурный принцип

> «Волшебной кнопки не существует — нет единой нейросети, способной закрыть все этапы разработки обучения. Создание качественного курса — это всегда поэтапный процесс, где каждая задача требует своего инструмента. Ключ не в поиске универсального сервиса, а в выстраивании рабочего конвейера: протестируйте разные инструменты, выберите по одному под каждую задачу, используйте их последовательно и обязательно контролируйте и улучшайте результат самостоятельно.»

— Pressfeed Journal, [[sources/2026-05-19-pressfeed-ai-tools-for-online-courses-15|2026-05-18]]

Этот принцип универсален не только для курсов. Он переносится на **любой content-pipeline с несколькими модальностями** (текст + изображение + видео + аудио + аналитика). На текущем уровне развития AI Q2 2026 единого фронтирного multi-modal производителя продакшн-качества не существует. Pipeline-сборка из специализированных моделей — единственная работающая рабочая модель.

## Семь этапов

### Этап 1 — Структура курса

**Задачи:**
- Составить список компетенций, которые должны освоить ученики
- Сформировать программу курса (модули, темы уроков)
- Предложить идеи практических заданий
- Получить черновую структуру для дальнейшего ручного редактирования

**Класс инструмента:** Generative LLM (генеративная языковая модель) с поддержкой развёрнутого контекста.

**Operational test:** инструмент должен принимать промпт-роль («ты в роли эксперта по X») + контекст ЦА + цели обучения и возвращать иерархичный текстовый артефакт. Чем больше контекста на входе, тем лучше результат.

### Этап 2 — Контент уроков

**Задачи:**
- Создать структуру и черновик текста каждого урока
- Адаптировать материал под уровень подготовки аудитории
- Найти источники: статьи, исследования (через академический поиск)
- Подгрузить свои материалы (статьи, лекции, посты) как контекст для генерации

**Класс инструмента:** Generative LLM (та же) + **поисковой AI-ассистент** с цитируемыми источниками для академической работы.

**Operational test для поискового ассистента:** возможность фильтровать выдачу по типу источника (научные статьи, news, blog) и видеть цитируемые ссылки. Без этого этап ловит галлюцинации в существенных фактах.

**Что ещё AI помогает сделать на этом этапе:**
- Собрать ключевые понятия и определения из разных подходов
- Подобрать примеры и кейсы, придумать гипотетические ситуации
- Найти простые объяснения сложных процессов через метафоры и аналогии

### Этап 3 — Задания и тесты

**Задачи:** AI генерирует разнообразные форматы оценочных активностей:

- **Тестовые вопросы** с вариантами ответа и пояснениями к правильным
- **Открытые вопросы**, побуждающие рассуждать (с эталонным ответом для оценки)
- **Практические задачи**, приближенные к реальным рабочим ситуациям
- **Кейсы** — развёрнутые ситуационные задачи (контекст + проблема + вопросы для разбора). Хороши для управления, маркетинга, права.
- **Творческие задания** — нестандартные форматы с критериями оценки
- **Парные понятия / matching** — термины-определения для проверки терминологии
- **Числовые задачи** с переменными — для финансовых, аналитических, технических курсов

**Класс инструмента:** Generative LLM (любая мульти-задачная); для парных понятий и числовых задач лучше работают модели с расширенным контекстом.

**Operational test:** на одну тему можно сгенерировать минимум 5 разных форматов оценки → если выдача однотипная (только тесты), модель не покрывает педагогический спектр.

### Этап 4 — Иллюстрации

**Задачи:**

- **Авторские иллюстрации** под тему курса (не стоковые)
- **Единый стиль и цветовая гамма** — серия выглядит целостной
- **Герой-персонаж** — «ведёт» ученика через материал, выстраивает эмоциональную связь
- **Визуализация процессов и состояний** — схемы из теории
- **Инфографика** — отдельный sub-этап (RU-кириллица плохо у общих image-моделей)

**Класс инструмента:** **Image-generator (text-to-image)** + отдельный класс **infographic-tool** для текстосодержащей графики.

**Operational test для consistency:** инструмент держит **одного персонажа через множество запросов** (через image-reference или прошитый промпт). Без этого «герой курса» дрейфует от слайда к слайду.

**Operational test для инфографики:** распознаваемая кириллица на выходе. Общие image-модели (Midjourney, Stable Diffusion) плохо рисуют русский текст — нужны specialized-tools для контент-графики.

### Этап 5 — Презентации

**Задачи:**
- Сгенерировать черновик слайдов с нуля по теме
- Собрать презентацию из готовых текстов и иллюстраций
- Подобрать макет, шрифты, иконки, инфографику и таблицы
- Возможность ручного редактирования (переписать текст, заменить картинки)

**Класс инструмента:** **AI-Presentation-Builder** — конструктор слайдов с встроенным LLM + image-generator.

**Operational test:** возможность скачать без водяного знака (либо за подписку), возможность редактирования экспортированной презентации в стандартных редакторах (.pptx / .key / Figma).

### Этап 6 — Видеоуроки

Четыре под-этапа, каждый со своим классом инструмента:

#### 6.1 Фоновое видео для не-говорящей-головы

**Задача:** динамичный фон по текстовому описанию (природа, абстракция, городская среда, рабочее пространство), удерживающий внимание.

**Класс инструмента:** **Text-to-video model** (короткие клипы 4–10 секунд).

#### 6.2 Озвучка скринкастов / закадровый голос

**Задача:** естественный голос с нужной интонацией и темпом, расстановка пауз, акцентов, ударений.

**Класс инструмента:** **TTS-сервис (text-to-speech)** с каталогом голосов и системой команд для расстановки просодии.

**Operational test:** возможность выбрать конкретный голос (не один дефолтный), управлять паузами и ударениями, лимит на бесплатном тарифе достаточен для пилота (~100k+ знаков).

#### 6.3 Фоновая музыка

**Задача:** треки под нужное настроение (эмбиент для концентрации / энергичный ритм для мотивации). Параметризованная генерация по настроению, темпу, длительности.

**Класс инструмента:** **Text-to-music model** (короткие циклы 30–120 секунд).

#### 6.4 Монтаж и автообработка

**Задачи:** автоматическая вырезка пауз, слов-паразитов, добавление эффектов.

**Класс инструмента:** **Video-editor с AI-функционалом** (auto-cut, silence-remover).

**Operational test:** возможность пометить «пустые» фрагменты по визуальному порогу + откатить любое автоматическое действие до коммита.

### Этап 7 — Дополнительные материалы

**Задачи:** генерация артефактов для повторения и углубления:

- **Саммари видеолекций** — расшифровка + структурированный конспект, чтобы освежить урок без перематывания
- **Краткие выжимки текстовых уроков**
- **Флеш-карточки** для повторения терминов
- **Шпаргалки с алгоритмами действий**
- **Чек-листы**
- **Подборки дополнительных материалов** — книги, статьи, каналы, подкасты для углубления темы
- **FAQ-раздел** — реальные или смоделированные типичные вопросы студентов

**Класс инструмента:** Generative LLM (любая) — задача структурного переупаковывания уже готового контента.

**Operational test:** инструмент принимает на вход видеолекцию (через расшифровку) или объёмный текст и возвращает не «общий пересказ», а **структурированный артефакт** с конкретным форматом (флеш-карточки = пара «термин/определение»; шпаргалка = шаги 1–N).

## Сквозной принцип — human-in-the-loop

**Каждый этап требует ручной редактуры.** Pressfeed повторяет это в обзоре троекратно — это структурный invariant, не disclaimer:

1. «Обязательно контролируйте и улучшайте результат самостоятельно»
2. «После этого предстоит дополнить и отредактировать текст самостоятельно»
3. «ИИ создаёт черновик, а финальное слово остаётся за вами»

Это согласуется с [[canon/marketing-frameworks/egoshin-education-formula-2026|формулой Егошина]] (педмастерство + мотивация + среда — AI **усиливает**, не заменяет). Конвейер без human-checkpoint между этапами схлопывается к «AI-generated курс без эксперта» — это **антипаттерн**, см. [[canon/marketing-frameworks/ai-content-3-limitations-pressfeed]] (ограничение 2 — шаблонность).

**Минимальная схема checkpoint'ов:**
- Этап 1 → ручная корректировка структуры (выкидывание лишних тем, расстановка зависимостей)
- Этап 2 → проверка фактов (см. ограничение 1: галлюцинации) + добавление **реальных кейсов из практики**
- Этап 3 → отбор адекватных по сложности заданий, отбраковка тривиальных
- Этап 4 → выбор лучшего варианта из 4–6 сгенерированных, выравнивание стиля
- Этап 5 → ручная корректировка слайдов под бренд / шрифты
- Этап 6 → проверка просодии озвучки на ключевых терминах, прослушать на 1.5×
- Этап 7 → проверка корректности фактов в саммари (та же галлюцинация-уязвимость)

## Применение в маркетинге GRO

### 1. Содержание GRO «Интенсива»

GRO «Интенсив» (см. [[canon/product-knowledge/gro-intensive]]) — high-ticket b2b-формат 240–400k ₽ для owner+CMO. Эта рамка — операционный каркас, по которому интенсив может **обучать собственных участников создавать AI-pipeline-контент** для их бизнеса. Семь этапов = семь возможных дневных модулей в формате 5–7-дневного интенсива.

**Anti-pattern:** «дать обзор 30 нейросетей за день». Это **массовый листикл-формат** (Pressfeed-style), не работающий в high-ticket контексте. Корректная упаковка: 1 day = 1 этап + ручная работа участника на собственном бизнес-кейсе.

### 2. Content-stack самого GRO

GRO-маркетинг сам производит блог, посты, видео, рассылки. 7-этапный конвейер — рамка для **внутреннего content-production-pipeline**:

- Этап 1–2 (структура + черновик) → используется в gro-content-themes + gro-content-write skills
- Этап 4 (иллюстрации) → нужен для blog-постов и Instagram-каруселей
- Этап 6 (видео + озвучка) → нужно для Reels и YouTube Shorts ([[evolving/content-trends/ai-video-tools-stack-2026]] — глобальный стек, [[evolving/content-trends/ru-ai-course-production-stack-2026]] — RU-доступная альтернатива)
- Этап 7 (саммари + FAQ) → готовый pattern для блог-статей (требование по [[evolving/industry-trends/ai-search-aeo-geo-2026]] — FAQ-секция как AEO-сигнал)

### 3. Anti-positioning против «AI-курсов под ключ»

Конкуренты в EdTech-нише часто продают «полностью AI-driven курс». Эта рамка даёт **аргумент против**: семь специализированных этапов + human-checkpoint на каждом → курс «под ключ» от AI = заведомо провален по пятому критерию из [[canon/marketing-frameworks/ai-intensive-format-criteria]] (понятный takeaway-сценарий).

## Anti-patterns

- **Искать один универсальный сервис** для всего курса. Q2 2026 — не существует. Через 12–24 мес ситуация может измениться (мультимодальные frontier-модели), но конвейерный паттерн как страховка от vendor-lock-in останется ценным.
- **Пропускать human-checkpoint** между этапами. Результат — шаблонный обезличенный курс (см. [[canon/marketing-frameworks/ai-content-3-limitations-pressfeed]]).
- **Презентовать стек целиком** как «вот 15 инструментов» — это создаёт когнитивную перегрузку и снижает actionability. Корректная подача — **по этапу за раз** с конкретной задачей.
- **Использовать конвейер для тривиальных курсов** (5–10 минут видео). Overengineering. Конвейер оправдан от формата ~30 минут структурированного материала.
- **Привязываться к конкретным именам инструментов в canon-странице**. Инструменты дрейфуют ежемесячно — конкретика живёт в [[evolving/content-trends/ru-ai-course-production-stack-2026]], здесь — только классы.

## Открытые вопросы

1. **Метрики качества каждого этапа** — какие операционные KPI измеряют «хорошо отработавший» AI на каждом этапе. Сейчас рамка чисто структурная.
2. **Оптимальный последовательный или параллельный pipeline** — Pressfeed предлагает последовательный, но для команд оптимизируется параллельный (этапы 4, 6.1, 6.3 могут идти параллельно с 2-3). Тема для расширения рамки.
3. **Cost-economics** — суммарная себестоимость прохождения конвейера на одном курсе на RU-стеке vs зарубежном (Midjourney+ElevenLabs+Sora+Claude+Gamma). Тема для отдельного evolving-strict-сравнения.
