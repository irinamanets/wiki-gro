# Типология личного бренда (Том Питерс): 5 типов + 5 элементов + 3-шаговая стратегия

Классификационная рамка личного бренда на базе концепции **Тома Питерса**, собранная из нескольких статей Pressfeed.Журнала. Источник — [[sources/2026-05-24-condense-pressfeed-chunk2-25]] (`...lichnyj-brend-komu-nuzhen-tipologiya...` + `...kak-prokachat-lichnyj-brend-10-sovetov...`, 2026-05-19).

`confidence: low` — редакционные гайды с экспертными комментариями без единого верифицированного автора; примеры персон — иллюстративные. Дополняет, а не заменяет, концептуальную разводку [[canon/marketing-frameworks/personal-brand-vs-reputation-chmukh|личный бренд ≠ репутация (Чмух)]] и операционные методики [[canon/marketing-frameworks/personal-brand-7-steps-magas|7 шагов (Магась)]].

## 5 типов личного бренда (по Тому Питерсу)

| Тип | Механика | Пример (иллюстративный) |
|---|---|---|
| **Эксперт** | Через опыт/знания | Максим Ильяхов |
| **«Свой парень»** | Образ + история успеха | Виктория Молдавская |
| **Провокатор** | Скандалы/эпатаж | Прохор Шаляпин |
| **Смешанный (эксперт + провокатор)** | Экспертиза + точечный эпатаж | Артемий Лебедев |
| **Хамелеон / мигрирующий** | Серьёзный специалист + точечные провокации | Павел Дуров |

`[conf:low, src:2026-05-19]` — персоны как иллюстрации типов, не как верифицированная классификация.

**Применение:** типология помогает эксперту/основателю выбрать **архетип**, под который выстраивается контент. Для ГРО (продукт + founder-голос) релевантен тип **Эксперт** или **Смешанный** с акцентом на экспертность, без эпатажа (см. [[canon/marketing-frameworks/political-neutrality-pr-5-rules|brand-safety]]).

## 5 элементов личного бренда

1. **Экспертность**
2. **Личная история / ценности**
3. **Медийность / продвижение**
4. **Имидж** (внешность + манера)
5. **Целостность**

## 3-шаговая стратегия построения

1. **Цель бренда → выбор ЦА**
2. **Описание сегмента / портрета**
3. **«Распаковка» личности → УТП**

**Кому НЕ нужен личный бренд:** тем, кто не готов к публичности / «толстокожести»; делает «просто так за компанию»; не готов к долгому горизонту (минимум год).

## 10 правил личного бренда (операционный слой)

1. Узкая ниша + портрет ЦА.
2. УТП/суперсила, не бояться конкуренции.
3. Имидж (внешний вид, манера, речь).
4. Истории с ошибками/неудачами (искренность > «идеальная картинка»).
5. Системно вести 1-2 соцсети с контент-планом.
6. Дозированно показывать личную жизнь («живой человек»).
7. Светиться в СМИ (колонки, комментарии = соцдоказательство через проверку журналиста).
8. Офлайн/онлайн-мероприятия и спикерство.
9. Мониторить упоминания, реагировать на негатив/позитив.
10. Играть вдолгую (бренд строится годами).

## Модель «видимый → заметный → узнаваемый»

```
Видимый      → порядок в соцсетях / сайт-визитке / портфолио / отзывах
Заметный     → участие в ивентах + системные соцсети
Узнаваемый   → комьюнити вокруг бренда, книга, авторская колонка, подкаст/YouTube
```

Это эскалационная лестница присутствия — каждый уровень требует предыдущего.

## Контр-нарратив: «известность ≠ репутация ≠ успех»

Из той же chunk-группы (positioning-статьи 2 PR-экспертов):

- «**Известность, медийность, вес и репутация не находятся в прямой зависимости**» — бренд/репутацию формируют дела/успехи/вклад, медиа лишь помогают. `[conf:medium, src:2026-05-19]`
- «**Бренд, личный бренд и успех не находятся в прямой зависимости**» (контрпример: все знают лидеров Tesla/Google, но не BMW/Sony/Lego). Личный бренд первым попадает под обстрел в кризис; нельзя делегировать PR-отделу («нельзя делегировать личность»). `[conf:medium, src:2026-05-19]`
- B2B-инсайт: для узкой воронки (~200 клиентов / ~2000 человек) лучший инструмент — **личные встречи**, медиа = «клей» для прогрева и верификации выбора.

Это перекликается с [[canon/marketing-frameworks/personal-brand-vs-reputation-chmukh|Чмух]] (репутация — фундамент, бренд — фасад) и [[canon/marketing-frameworks/personal-brand-resilience-vs-hype-angle|resilience vs hype]].

## 6 каналов продвижения без Telegram + чек-лист «стоит ли»

**6 каналов (на случай давления на Telegram, см. [[evolving/industry-trends/ru-digital-regulatory-squeeze-2026]]):** публикации в СМИ, ТВ/радио (личные истории), выступления на ивентах, собственный сайт, проф-сообщества/клубы, работа с ЛОМами.

**6-шаговый чек-лист «стоит ли личный бренд»:** (1) зачем; (2) аудитория (знаете лично? кто ЛОМы?); (3) позиционирование (кто вы для ЦА); (4) контент (чем отличаетесь, где брать); (5) каналы (свои/чужие); (6) эффективность (лиды/конверсии/знакомства/проекты).

Совпадает с [[canon/marketing-frameworks/personal-brand-channels-5-types-magas|5 типами каналов Магась]] — разные авторы сходятся на мульти-канальности без зависимости от Telegram.

## Применимость к ГРО

- **Архетип founder-голоса ГРО** = Эксперт (с элементами Смешанного), без эпатажа.
- **Модель «видимый→заметный→узнаваемый»** как roadmap для personal brand основателей ГРО.
- **B2B-инсайт «личные встречи для узкой воронки»** — релевантен enterprise-продажам ГРО: медиа прогревают, закрывают встречи.
