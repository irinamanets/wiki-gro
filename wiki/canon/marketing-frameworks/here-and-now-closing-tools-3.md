# 3 инструмента закрытия «Здесь и Сейчас» (Шевелев)

Operational-набор closing-инструментов для прокачки критерия **«ЗС» (Здесь и Сейчас)** из [[canon/marketing-frameworks/sales-100-formula-shevelev|формулы 100% закрытия сделки]]. Сформулированы **Олегом Шевелевым** в co-branded carousel'е с Т-Бизнес секретами ([[sources/2026-05-14-tg-olegcloser-may-7-13-2026]] карточка 2292).

`confidence: medium` — verified expert (кандидат экономических наук, автор бестселлера «Рекорды продаж», 900+ прокачанных отделов продаж); инструменты сами по себе классические (Cialdini scarcity), но **explicit ethical caveat** автора + готовые **речёвочные шаблоны** — original contribution.

## Три инструмента

| Инструмент | Тип ограничения | Готовая речёвка от автора |
|---|---|---|
| **Дедлайн** | По времени | «Эта цена действует до конца месяца» |
| **Дефицит** | По количеству | «Осталась одна машина в этой комплектации на складе» |
| **Ажиотаж** | Социальное доказательство | «На эту модель уже очередь, следующая партия через два месяца» |

## Главный caveat — «честные, только если реальные»

Из карточки 2292 (прямая цитата):

> «Все они — честные инструменты, **только если будут реальными**.»

Это **explicit ethical guardrail** — редкость в публичных sales-методологиях, где обычно urgency-инструменты подаются без оговорок (классическая ошибка Cialdini-popularizers: «scarcity всегда работает», игнорируя long-term cost дискредитации).

### Что значит «реальные»

| Инструмент | Реальный | Фейковый (анти-паттерн) |
|---|---|---|
| **Дедлайн** | Цена реально пересматривается / период скидки реально заканчивается | «Скидка только до конца дня» × каждый день вечером перезагружается |
| **Дефицит** | На складе действительно 1 единица / cohort действительно ограничен | «Осталось 3 места» × месяц подряд, после «выкупа» появляются новые |
| **Ажиотаж** | Очередь действительно есть / next batch действительно через X месяцев | «У нас уже очередь» × у вас никого нет |

**Long-term cost фейкового urgency:** клиент покупает один раз, обнаруживает обман (через сравнение с другим клиентом / повторный визит на сайт), теряется доверие к **этой компании и к самому inventory urgency-сигналов**. После 2-3 раз клиент перестаёт реагировать на любые urgency-сигналы — в том числе настоящие.

### Маркер настоящего vs фейкового

Простой тест: если бы вы продавали клиенту в офисе face-to-face, могли бы **доказать конкретно**:

- Дедлайн → показать прайс-лист с датой пересмотра
- Дефицит → показать систему учёта на экране
- Ажиотаж → показать список pre-ordered клиентов

Если ответ «нет» — инструмент **фейковый**, не использовать. Скорее всего, лучше работать над другими критериями формулы (ФВ, ОП, Д, ЛПР), чем подталкивать в ЗС искусственно.

## Связь с другими closing-методологиями

### С Cialdini «Influence»

3 инструмента Шевелева — это **subset** из 6 классических Cialdini-принципов (reciprocity / commitment / social proof / authority / liking / scarcity):

- **Дедлайн** = scarcity (по времени)
- **Дефицит** = scarcity (по количеству)
- **Ажиотаж** = social proof + scarcity

Шевелев не упоминает Cialdini, но семантически инструменты совпадают. **Уникальный contribution Шевелева** — explicit ethical guardrail и готовые **русскоязычные речёвки**.

### С техникой ВР×КР для возражения «после майских»

См. [[canon/marketing-frameworks/objection-after-holidays-vrkr]]. Техника ВР×КР работает на возражении **«позже»**, эти 3 инструмента — на состоянии **«нет острой причины сейчас»**. Различие:

- ВР×КР → клиент **прямо** говорит «давайте после майских» → нужно reframe time-frame
- 3 инструмента → клиент **молча** откладывает, без явного возражения → нужно показать external cause действовать сейчас

В реальной встрече часто применяются последовательно: сначала 3 инструмента (если работают — сделка закрыта), если не сработали — переходим к ВР×КР для прямой работы с возражением.

### С 4 группами закрывающих техник из книги «Рекорды продаж»

В карточке 2291 Шевелев упоминает классификацию closing-техник из своей книги:

> «В этой ситуации помогают техники закрытия сделок. В своей книге я выделяю четыре группы: подталкиватели, формирователи, доверители, мотиваторы.»

3 инструмента из этой страницы (дедлайн / дефицит / ажиотаж) семантически относятся к группе **«подталкиватели»** (создают внешнее давление на решение). Остальные 3 группы (формирователи / доверители / мотиваторы) в открытом канале не раскрыты — это материал курса/книги. Это значит:

- На уровне публичного контента доступны только **подталкиватели** (этой страницы)
- Для других 3 групп закрывающих техник у нас в вики нет открытого канонического материала
- **Pending** — при появлении дополнительных источников расшифровывающих формирователей/доверителей/мотиваторов, страницу нужно extending'овать

## Application для GRO

GRO — consumer subscription, не B2B-сделочный продукт, но инструменты адаптируются к **завершению onboarding'а / конверсии в paid**:

### Дедлайн в B2C-onboarding

- **Реальный:** «Trial действителен 14 дней — после 14 дней цена X». Не «продлевается каждый день при возврате».
- **Реальный:** «Early-bird цена на новый сезон до 1 сентября» — если действительно повышаете цену.

### Дефицит в продукте

- **Реальный:** «Beta-доступ к новой функции для первых 100 пользователей» — если действительно дам только первым 100, потом ограничу.
- **Реальный:** «Открыт sign-up для cohort из 50 человек, дальше — wait-list».

### Ажиотаж через social proof

- **Реальный:** «За последнюю неделю Х новых пользователей завершили первую тренировку», если данные подтверждены.
- **Реальный:** «Канал @gro_me получил Y testimonial'ов за месяц», если факт.

### Анти-паттерны для GRO

- ❌ «Скидка только сегодня» × каждый день
- ❌ «Осталось 5 мест в triale» × infinite triale на самом деле
- ❌ «Уже 10000 пользователей» × вообще без подтверждения сегмента / metric definition

В контенте GRO эти 3 инструмента нужно использовать **редко и точно**, иначе создаётся инфобиз-впечатление (см. [[canon/brand-guidelines/gro-channel-tone-of-voice]] — strict anti-инфобиз позиция).
