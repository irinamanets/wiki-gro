# AI video production pipeline — 5 этапов

Канонический pipeline для массового производства видеокреативов через AI-tools, отработанный командой Kumar & Solo и смежными практиками в 2025–2026. Заменяет классический цикл «human-produced UGC → $200–250 за ролик, неделя работы команды» на цикл «AI-produced → $7–15 за ролик, ~2 часа полного цикла человеком» при не худшей, а часто лучшей конверсии в перформансе.

Это canon: сама *структура* пяти этапов стабильна, она не зависит от конкретного набора моделей. Конкретные инструменты (Higgsfield, VEO3, Sora, Seedance, Runway, Kling, Midjourney, Nano Banana) — дрейфующий слой, живёт в [[evolving/content-trends/ai-video-tools-stack-2026]]. Канонический инвариант — **последовательность этапов и их декомпозиция**.

Источник: [[sources/2026-04-14-tg-solokumi-nov2025-apr2026|@solokumi]] посты 354, 379, 382, 387, 390, 392, особенно пост 354 (2025-12-12) как наиболее полный разбор.

## Главный инвариант

**Нельзя генерировать видео сразу из текста.** Модели, которые идут «text → video» одним шагом, не держат ни консистентность персонажа, ни логику сцены, ни динамику монтажа. Качество достигается *декомпозицией* задачи на пять этапов, каждый из которых готовит вход для следующего.

## Этап I — Сценарий

- Пишется на основе **трендвотчинга** (анализ работающих креативов своих и конкурентов) + **JTBD / AJTBD** / анализа звонков сейлзов.
- Инструмент по умолчанию — **Claude** (Sonnet 4.5+), он лучше ChatGPT справляется с креативными задачами и способен генерировать 50+ кадров в одном ответе.
- Выход этапа: текстовый сценарий на 30 сек – 1 минуту, разбитый на логические блоки, с обозначенным хуком в первом кадре.

## Этап II — Раскадровка

- Разбиение сценария на сцены **с правилом смены каждые 5 секунд** (удержание внимания).
- Выход этапа — для **каждой сцены** два промпта:
  - **Start Frame prompt** — описание статичной картинки сцены
  - **VEO 3 / animation prompt** — описание действий и движений в кадре
- Инструмент: Claude с кастомным промптом раскадровщика.
- Критически важно: первый кадр — всегда **хук, ломающий парадигму**, иначе ролик не удерживает внимание в первые 3 секунды (см. [[canon/marketing-frameworks/andromeda-creative-framework-2026]]).

## Этап III — Start Frame (статичная генерация)

- Для каждой сцены генерируется **статичный стартовый кадр**, который потом «оживят» в видео.
- Сначала подбирается **референс персонажа** — фото/изображение, которое стабильно воспроизводится нейронками:
  1. Загружаешь несколько разных фото/изображений персонажа в Nano Banana
  2. Генерируешь похожие изображения в разных стилях, по несколько итераций
  3. Выбираешь то, которое воспроизводится точнее всего → это твой референс
- В каждый start-frame промпт прикладываешь этот референс, чтобы персонаж был **консистентным от сцены к сцене**.
- Инструменты: Nano Banana (по умолчанию), Midjourney (для художественных стилей), Flux / Stable Diffusion (для текста на изображении), DALL-E 3 (для прототипов).
- Файлы именуются по дублям (`scene_01.png`, `scene_02.png`, `char_A_run01.jpg`), проверка консистентности — обязательна перед переходом к анимации.

## Этап IV — Генерация видео (анимация)

- Каждый стартовый кадр → передаётся в видео-модель вместе с animation-промптом из Claude.
- Выбор модели зависит от задачи (детали в [[evolving/content-trends/ai-video-tools-stack-2026]]):
  - **VEO3 / Higgsfield** — default, хорошее качество, сложные движения и диалоги, ~58 кредитов / видео
  - **Minimax Hailuo 2.3** — статичные сцены, ~6 кредитов
  - **Seedance** — несложные сцены, ~36 кредитов
  - **Kling 3.0** — когда нужен один персонаж в нескольких сценах (лучший face consistency)
  - **Runway Gen-4.5** — одна сцена, кинематографичный язык камер (dolly zoom, orbit shot)
- Опциональные функции: **Ingredients** (загрузить конкретный объект как обязательный элемент сцены), **Шаблоны** (готовые UGC-пресеты, эффекты, зумы — уход от prompt-focused подхода к preset-focused).
- Параметры: формат, длительность, Enhance-флаг (модель сама дополняет промпт).

## Этап V — Монтаж

- Сцены собираются в финальный ролик в **CapCut** (по умолчанию) или аналогах.
- Русские субтитры накладываются вручную — AI-модели их не генерируют корректно.
- Звуковая дорожка накладывается отдельно (AI-musical-generation: Suno — см. [[canon/marketing-frameworks/suno-music-prompt-anatomy|отдельную страницу]]).

## Итоговая экономика одного ролика

- **Время работы человека на полный цикл (1 минута видео):** ~2 часа
- **Количество сцен в ролике:** обычно 15–20
- **Денежная стоимость:** $10–15 при стандартном flow через Higgsfield/VEO3 (пост 354, 2025-12-12). В марте 2026 — «$7–10 за видеокрео» (пост 390) по мере дешевеющих моделей.
- **Производственная ёмкость одного человека:** ~4 рилса в день, встроенных в фабрику контента

## Как этот pipeline встраивается в фабрику контента

Pipeline — это **рабочий цикл** внутри более крупной машины. Вход — трендвотчинг + JTBD + анализ конкурентных крео. Выход — рилсы, которые идут в:

1. **Фабрику контента** (сетки аккаунтов) — регулярная органика на несколько каналов
2. **Перформанс-кабинеты** — как тестовые креативы в парадигме [[canon/marketing-frameworks/andromeda-creative-framework-2026|Andromeda]]

Сам по себе один ролик без цикла смысла не имеет. Смысл — в **пропускной способности**: цикл настроен так, чтобы выдавать десятки роликов в неделю при фиксированном человеческом ресурсе.

## Anti-patterns

- **Прыгать через этапы** (сразу text → video) — получаешь дрейф персонажа, сломанную логику сцены, нерелевантный хук.
- **Использовать разные модели для разных сцен одного ролика без общего референса** — персонаж мутирует. Ингредиент консистентности — **фикс референса на этапе III**.
- **Попытка описать 15 секунд одним промптом в Runway** — в середине клипа персонаж уплывает. Планировать кусками по 5–6 сек.
- **Генерация без трендвотчинга** — сценарии «из головы» не попадают в аудиторию. Вход pipeline — это анализ конкурентных крео и JTBD, а не фантазия копирайтера.
