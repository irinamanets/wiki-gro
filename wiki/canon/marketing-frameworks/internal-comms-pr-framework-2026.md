# Внутренние коммуникации и корпоративный PR: фреймворк + 2026-тренды

Фреймворк внутренних коммуникаций (внутрикома) как инструмента реализации HR-бренда. Источник — [[sources/2026-05-24-condense-pressfeed-chunk2-25]] (`...vnutrennie-kommunikaczii-i-korporativnyj-pr...`, 2026-05-19, со ссылками на SPN Communications, Gartner).

`confidence: medium` для структуры (несколько источников), `low` для отдельных кейсов. Числовые потери и кейсы вынесены в [[evolving-strict/market-data/ru-internal-comms-losses-skolkovo-2026]].

## Определения

- **Внутриком** = связующее звено руководство ↔ сотрудники; один из инструментов реализации **HR-бренда**.
- **HR-бренд** = комплексное представление о компании как работодателе, включая EVP (employee value proposition).
- **Внутренний PR** = информирование, культура, вовлечение.

**Два направления внутрикома:** (1) построение коммуникаций + (2) создание корпоративной культуры.

## 2026-тренды (SPN Communications, Gartner)

> По мнению исполнительного директора SPN Communications: в 2025 внутриком — инструмент **удержания** и борьбы с **Great Detachment** (массовое внутреннее отчуждение). `[conf:medium, src:2026-05-19]`

- Тренд — **отдельная команда Internal Communications** на стыке PR / HR / digital (по Gartner).
- **CCO становится бизнес-стратегом**, а не «редактором рассылок».

Это согласуется с глобальным engagement-кризисом: см. [[evolving-strict/market-data/employee-engagement-quiet-quitting-2026]] (Gallup 31% вовлечённости, Great Detachment / тихое увольнение).

## Создание стратегии внутрикома = как внешний PR-план

```
Кто аудитория
  → Задачи
    → Ключевые сообщения
      → Результаты
        → Выбор инструментов
```

Та же логика, что и [[canon/marketing-frameworks/pr-evaluation-4-mechanisms-3-kpi-guseva|каскад коммуникационной стратегии Гусевой]] (бизнес-цели → комм-цели → инструменты → KPI), применённая внутрь компании.

## Инструменты внутрикома

| Категория | Примеры |
|---|---|
| Соцсети / корп-СМИ | Газета, портал, подкаст, закрытый Telegram |
| Чаты | Общие рабочие чаты |
| Визуальные | Доски объявлений / почёта |
| Обратная связь | Опросы |
| Развитие | Обучение |
| Собрания | Общие собрания, тимбилдинг |
| Мотивация | Конкурсы, забота о здоровье |

## Применимость к ГРО

- **ГРО как инструмент внутрикома:** общие планы/задачи команды в продукте — частный случай «построения коммуникаций». Hook для B2B-сегмента (команды/работодатели): «прозрачность задач = вовлечённость».
- **HR-бренд-нарратив:** GRO может позиционироваться для работодателей как часть EVP («компания, где видно, кто над чем работает»).
- **Контент-anchor:** «внутриком против тихого увольнения» — формат под B2B-аудиторию работодателей, опирается на Gallup/Сколково-цифры.
