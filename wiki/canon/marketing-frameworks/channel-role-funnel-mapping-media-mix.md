# Роль-декомпозиция медиаканалов по воронке + синергия media-mix

Воспроизводимый фреймворк, как через кросс-канальный замер (тест-контроль + детерминированная атрибуция) определить **роль каждого охватного канала на разных этапах воронки** и доказать, что **комбинации каналов дают эффект сильнее суммы по отдельности**. Извлечён из кейса «Купер» × Билайн Adtech (см. [[sources/2026-05-26-dzen-kuper-bilayn-cross-channel-attribution]]); сама логика канал-агностична и переносится на любой media-mix.

Это **надстройка** над [[canon/marketing-frameworks/clickless-channel-incrementality-stable-id|click-less incrementality фреймворком]]: тот доказывает вклад *одного* канала без клика; этот — раскладывает *несколько* каналов по ролям и измеряет их **синергию**.

## Проблема, которую решает фреймворк

Путь пользователя к покупке редко проходит через один канал: контакт идёт последовательно (например, Smart TV → диджитал → наружка → решение). В классической (last-click / single-channel) атрибуции значительная часть этого влияния остаётся **невидимой**, из-за чего бюджет распределяется неоптимально. Отраслевая оценка масштаба проблемы — см. [[evolving-strict/campaign-metrics/kuper-bilayn-cross-channel-incrementality-2026]].

## Два уровня измерения

1. **Per-channel роль** — что именно делает канал: привлекает новых, реактивирует «спящих», удерживает лояльных, напоминает, или закрывает конверсию на финале.
2. **Синергия комбинаций** — насколько связка из 2+ каналов даёт прирост сверх каждого канала по отдельности.

Оба уровня измеряются на одном тест-контрольном дизайне (см. методологию ниже).

## Роль-таксономия каналов (channel-role mapping)

Эмпирическая привязка каналов к этапам воронки (из кейса; направление переносимо, конкретные числа — нет):

| Канал | Основная роль | Этап воронки | Кого двигает |
|---|---|---|---|
| **Диджитал (perf + медийка)** | Генератор трафика и продаж | Привлечение + монетизация | Новые + существующие |
| **ТВ / Smart TV (CTV)** | Реактивация «спящих» + удержание лояльных | Mid / retention | Существующие, неактивные |
| **Наружная (DOOH)** | Реактивация + стимулирование новых (напоминание, вовлечение) | Awareness → mid | Существующие + новые |
| **Indoor (DI, аэропорты, помещения)** | Усиление конверсии на финальных этапах | Bottom-funnel | Близкие к покупке |

**Ключевой вывод:** ни один охватный канал не является «только awareness». Каждый двигает конкретный этап — но **разный**, поэтому сравнивать их по одной метрике (например, по CPA напрямую) бессмысленно (см. anti-pattern в [[canon/marketing-frameworks/assisted-conversions-attribution-3-models]]).

## Синергия media-mix (комбинации сильнее суммы)

Эмпирические связки из кейса (направление эффекта переносимо):

- **ТВ + наружка** — «закрывает сделку»: реактивирует действующую клиентскую базу и одновременно конвертит новых пользователей. Сильнее всего влияет на конверсии действующих пользователей веб-версии.
- **Диджитал + наружка** — усиливает работу с корзиной и следующими этапами воронки (рост переходов в корзину у новых); повышает вовлечённость и стимулирует повторные покупки → рост **LTV** (Lifetime Value — ценность клиента за всё время взаимодействия).
- **ТВ + диджитал** — эффективна на завершении покупки у **обоих** сегментов (новые + действующие), высокая конверсия на всех этапах воронки.

**Принцип:** охватные каналы не конкурируют за один и тот же эффект — они **дополняют** друг друга по этапам воронки, поэтому медиасплит надо оптимизировать как портфель ролей, а не как набор изолированных CPA-строк.

## Методологическая основа (как это меряют)

Тот же тест-контрольный каркас, что в [[canon/marketing-frameworks/clickless-channel-incrementality-stable-id]]:

1. **Тест-контрольный дизайн** — тестовая группа (вероятно контактировала с рекламой) vs контрольная (сопоставимая, без контакта); обе в один период → общий сезонный фон → разница = чистый эффект.
2. **Детерминированная атрибуция без клика** — пиксель для действий на ресурсах + данные о нагрузке на базовые станции оператора для наружной/indoor; всё **обезличенно и по согласию** на обработку данных в рекламных целях.
3. **Декомпозиция по ролям и связкам** — эффект считается отдельно для каждого канала и для каждой комбинации, на разных сегментах (новые / действующие).
4. **Метрика — инкрементальный lift в п.п.** дельты тест−контроль (не относительный рост одной группы).

## Когда применять / ограничения

- Применимо при наличии **2+ охватных каналов** и детерминированного связующего идентификатора (оператор связи, ритейлер-CRM, единый ID экосистемы).
- Роль-таксономия и направление синергий **переносимы**; конкретные числа из кейса — **нет** (вендорский self-reported, без независимой валидации, не раскрыты attribution window и репрезентативность контроля).
- Главная практическая ценность: вход в **оптимизацию медиасплита** как портфеля ролей вместо изолированного per-channel CPA.

## Применение к GRO

GRO — B2C subscription, mobile-first. Прямой retail-media / indoor контакт пока не релевантен (покупка онлайн), но **логика переносима**:

- Разные охватные каналы GRO (Telegram-канал, PR в фитнес-медиа, подкасты, возможный CTV) играют **разные роли**: одни привлекают cold-аудиторию, другие реактивируют отвалившихся подписчиков (churn win-back), третьи добивают до оплаты.
- При первой мульти-канальной охватной кампании имеет смысл сразу заложить **роль-декомпозицию + замер синергии** (через assisted-installs / hold-out), а не сравнивать каналы по CPI напрямую.
- Связка «awareness-канал + ретаргет» = аналог «ТВ+наружка закрывает сделку».
