# Фильтры выбора, не подборки: формат сравнительного поста

**Тезис.** В любой сложной нише люди **тонут в информации**. Конкуренты вываливают «10 лучших», «20 топ», «подборку моделей» — десятки вариантов без системы. Бренд может выиграть, дав не список, а **критерии для выбора** через формат «3 варианта по одинаковым параметрам».

Сформулирован как **Метод 3** в плейбуке [[canon/marketing-frameworks/distrust-niche-smm-playbook-vtochku]] основателя агентства «В точку». Источник: [[sources/2026-05-19-pressfeed-distrust-niche-smm-4-methods-vtochku]]. `confidence: medium`.

## Алгоритм

1. **Найти частый сценарий выбора** в нише. Не «10 машин», а «какую первую машину взять до 2 млн ₽», «какая CRM для салона красоты», «какой тариф новичку».
2. **Выбрать 3 варианта.** Не 10. Три — это **сравнимая когнитивная нагрузка**, читатель может удержать в голове.
3. **Зафиксировать 3-4 параметра**, которые **влияют на решение**. Не «дизайн», «удобство», «премиум» — а цена, срок, мощность, поддержка, интеграции.
4. **Свести в таблицу или одинаковый-структуры список.** Каждый вариант — те же поля.
5. **Без оценочных прилагательных.** Никаких «лучший», «удобный», «современный», «надёжный». Только факты в полях.
6. **Никакого текста между вариантами.** Сравнение — это сетка, не статья.

## Пример (из кейса доставки авто)

Вместо «10 кроссоверов из Китая» — серия постов, где каждый пост сравнивал **3 машины по 3-4 параметрам**:

- Цена
- Год выпуска
- Пробег
- Мощность
- Привод
- Расход

Без «просторного салона» и «современного дизайна» — только цифры.

## Шаблон

| Параметр | Вариант A | Вариант B | Вариант C |
|---|---|---|---|
| Параметр 1 | значение | значение | значение |
| Параметр 2 | значение | значение | значение |
| Параметр 3 | значение | значение | значение |
| Параметр 4 | значение | значение | значение |

CTA: «Какой подходит вам — пишите в директ, рассчитаем».

## Почему работает

- **Экономит когнитивный ресурс.** Читатель не сравнивает 10 раз — только 3. Может удержать в голове и сравнить.
- **Параметры — выбор клиента, не оценка бренда.** Бренд не говорит «вот этот лучше», а даёт инструмент. Это снимает паттерн «впаривают».
- **Сигнал экспертизы.** Сформулировать 3 правильных параметра = знать рынок. Это видно сразу.
- **Поиск по параметрам.** Пост находится по запросу «X vs Y», «сравнение X», «X для Y» — это популярные user-intent запросы.

## Связь с listicle-каноном

Этот формат — **антитеза** классическому listicle-жанру, который доминирует в RU-медиа с 2010-х:

- [[evolving/content-trends/ru-personal-finance-listicle-baseline-2016]], [[evolving/content-trends/ru-task-manager-listicle-baseline-2016]], [[evolving/content-trends/zhazhda-biz-evergreen-listicle-genre]] — это **broad listicle**: 10 пунктов, обзорная подборка, SEO-driven.
- [[evolving/content-trends/business-publication-ceo-listicle-pattern-2026]] — даже современная вариация listicle всё ещё «N экспертов о X».

**Метод 3** — `narrow comparison`: 3 варианта × 3-4 параметра = **decision tool**, не обзорный текст. Жанр работает на **decision-stage** воронки, listicle — на **awareness-stage**.

## Адаптация под разные ниши

| Ниша | Сценарий выбора | Параметры |
|---|---|---|
| SaaS B2B | «3 CRM для салона красоты» | Цена / интеграции / поддержка / онбординг-срок |
| EdTech | «3 курса по Python новичку» | Цена / длительность / формат / диплом |
| Финансы | «3 брокера для первой инвестиции до 100 тыс ₽» | Комиссия / минимальный депозит / приложение / лицензия |
| Travel | «3 варианта поездки в Турцию на 7 дней до 100 тыс ₽» | Цена / расстояние от моря / трансфер / питание |

## Применимость к ГРО

**3 варианта таск-менеджеров для предпринимателей**, где ГРО — один из:

| Параметр | ГРО | Todoist | Notion |
|---|---|---|---|
| Цена / мес | 2 490 ₽ | 299 ₽ | 800 ₽ |
| AI-сборка плана | да | нет | нет (только AI-генерация текстов) |
| Учёт энергии / времени | да | нет | вручную |
| Время на старт | 7 минут | 5 минут | 30+ минут |

CTA: «Какой подходит — зависит от того, сколько вы готовы потратить времени на настройку. Опишите задачу в комментариях — посоветуем».

**Важно:** **честно** показать конкурентов, не «занижать» их параметры. Доверие выше, когда бренд не боится сравнения.

## Anti-patterns

- **«10 лучших таск-менеджеров 2026»** — классический listicle, не работает в скептичной нише, конкурирует со всеми.
- **Оценочные прилагательные** («самый удобный», «премиум», «топ») — снимают доверие.
- **Параметры не влияющие на решение** («красивый интерфейс», «приятный звук») — обесценивают сетку.
- **Разная структура у вариантов** (для одного — 5 параметров, для другого — 3) — невозможно сравнить.
- **Длинные текстовые описания между вариантами** — рушит «сетковый» эффект.
- **Только свой продукт в сравнении** (без конкурентов) — читается как реклама.

## Operational-чек-лист

- [ ] Сценарий выбора сформулирован одним вопросом аудитории
- [ ] **Ровно 3 варианта**
- [ ] **3-4 параметра**, одинаковые для всех
- [ ] Каждое значение — **цифра или короткое да/нет** (не описание)
- [ ] **Ноль оценочных прилагательных**
- [ ] Конкуренты включены **честно** (не подкручены)
- [ ] CTA приглашает к диалогу (комментарии / директ), не к покупке напрямую
