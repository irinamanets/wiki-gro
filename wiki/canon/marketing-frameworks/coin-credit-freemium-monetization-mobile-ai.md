# Coin/credit-freemium — «монеты» поверх подписки для usage-based AI

Монетизационный паттерн для приложений с **дорогим per-action inference** (генерация изображений/видео/текста): вместо безлимитной подписки или чистой pay-per-use вводится валюта-кредит («монеты», «токены», «генерации»), которую подписка пополняет фиксированным месячным пулом. Каждое действие (генерация) тратит кредиты. Это гибрид subscription + usage-based, спроектированный под нестабильную себестоимость AI-генерации.

## Анатомия паттерна

1. **Free-захват.** Базовый слой бесплатен для всех — обычно это **готовые шаблоны / пресеты** (низкая себестоимость для вендора, но достаточно ценности, чтобы пользователь привык к продукту). Цель — установка и первый «aha».
2. **Trial.** При оформлении подписки — короткий бесплатный период (типично 7 дней). Снимает риск первой оплаты, даёт почувствовать платные генерации.
3. **Подписка = пул кредитов.** Подписка не даёт безлимит, а начисляет фиксированное число кредитов (месячный пул) + иногда стартовый бонус.
4. **Расход кредитов на действия.** Каждая генерация списывает монеты. Когда пул кончается — upsell (докупка кредитов или апгрейд тарифа).

## Зачем именно кредиты, а не безлимит

- **Контроль себестоимости.** AI-inference стоит денег за каждый вызов. Безлимит при тяжёлых пользователях съедает маржу; кредиты привязывают доход к расходу.
- **Управляемый upsell.** Исчерпание пула — естественный, не назойливый триггер для допродажи, привязанный к ценности (пользователь уже в потоке работы).
- **Понятность ценности.** «200 генераций в месяц» считывается лучше, чем абстрактный тариф; пользователь видит, что покупает.

## Референс-кейс: PhotoGen: AI Image 2

Мобильный AI-генератор фото/видео в RuStore реализует паттерн целиком (см. [[evolving/competitor-positioning/photogen-ai-image-2-rustore-2026]]):

| Слой | Реализация PhotoGen |
|---|---|
| Free | Библиотека шаблонов генераций с редактированием промптов — бесплатно всем |
| Trial | Первые 7 дней месячной подписки бесплатно (единоразово) |
| Подписка | 40 монет единоразово при старте + 200 монет/месяц далее |
| Расход | Генерации списывают монеты из пула |

## Применение для GRO

- Если GRO добавит AI-генерацию (контент-планы, тексты, визуалы), coin/credit-модель — рабочий шаблон монетизации: бесплатные шаблоны/пресеты для захвата → trial → подписка с месячным пулом генераций.
- Free-tier должен быть **достаточно полезным, чтобы удержать**, но **не закрывать ядро ценности** — баланс, который PhotoGen решает через «шаблоны бесплатно, кастомная генерация за монеты».
- Кредитная механика сочетается с уже задокументированной геймификацией трат/действий — см. [[evolving/content-trends/ai-avatar-spending-gamification]] (монеты можно геймифицировать: streak-бонусы, награды за активность).
