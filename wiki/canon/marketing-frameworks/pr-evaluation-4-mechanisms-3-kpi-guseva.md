# Оценка эффективности PR: 4 механизма влияния + 3 KPI-стратегии

Авторский фреймворк **Дарьи Гусевой** (партнёр и директор по стратегии PR-агентства), отвечающий на вопрос «как связать PR с продажами». Источник — [[sources/2026-05-24-condense-pressfeed-chunk2-25]] (`web_news.pressfeed.ru_lidogeneriruyushhij-pr-mif-ili-realnost`, 2026-05-19).

`confidence: medium` — verified-эксперт (должность + специализация явно указаны), но единичный источник, субъективная систематизация автора.

## Центральный тезис

> По мнению Дарьи Гусевой: «**лидогенерирующий PR — химера**». Профессионалы настаивают, что напрямую связать PR с продажами **нельзя**, только косвенно — через систему PR-метрик. `[conf:medium, src:2026-05-19]`

Это контр-тезис к популярному запросу бизнеса «покажите ROI PR в лидах». Гусева переводит разговор с прямой атрибуции на **механизмы косвенного влияния** + **выбор KPI-стратегии под тип рынка**.

## 4 механизма влияния PR на бизнес

| # | Механизм | Как работает | Ограничение |
|---|---|---|---|
| 1 | **Прямая лидогенерация** | Эффект новизны + точное попадание дают лиды напрямую | Редко, слабо масштабируема |
| 2 | **PR-«ловушки/приманки»** | Готовим инфополе под будущий поисковый запрос (обзоры на Habr, интервью гендира, SEO-оптимизированные материалы) | Отложенный эффект |
| 3 | **PR-«адвокат»** | Защита репутации (превалирование позитива над негативом) | Не генерит спрос, удерживает |
| 4 | **PR создаёт почву для рекламы/продаж** | Прямая реклама эффективнее, если бренд уже знаком | Косвенный, трудно изолировать |

**Механизм 2 («ловушки»)** — мост к [[evolving/content-trends/aeo-geo-llm-search-optimization-2026|AEO/GEO]]: «готовим инфополе под будущий запрос» = targeted seeding контента на трастовые площадки до того, как пользователь начал искать.

**Механизм 4** совпадает с тезисом, что awareness-PR повышает эффективность downstream-рекламы — см. [[canon/marketing-frameworks/audience-temperature-cold-warm-hot]].

## 3 KPI-стратегии (выбор под тип рынка)

| Стратегия | Когда применять | KPI-фокус |
|---|---|---|
| **(а) Паритет с конкурентами** | Конкурентный рынок одного ценового сегмента, массовые услуги | Схожий уровень заметности с конкурентами |
| **(б) Лидерство категории** | «Если антивирус, то Касперский» — претензия на №1 | Доминирование медиаиндекса в категории |
| **(в) Нишевое присутствие** | Узкие проф-аудитории (напр. врачи в профсообществе) | **Регулярность** на специализированных площадках > охваты/медиаиндекс |

Стратегия (в) важна для ГРО-подобных нишевых продуктов: для узкой аудитории **регулярность** на профильных площадках ценнее, чем большой охват на широких.

## Каскад коммуникационной стратегии

```
Бизнес-цели
  → Коммуникационные цели
    → PR-инструменты
      → KPI/метрики
```

Универсального набора метрик **нет**: даже «количество публикаций + медиаиндекс» требуют дополнения под конкретные бизнес-цели. Это снимает запрос «дайте один правильный набор PR-KPI» — набор выводится из целей, а не из шаблона.

## Применимость к ГРО

- **Не обещать «PR = лиды».** В отчётности GRO разделять PR-цели (awareness, инфополе под запрос, репутация) и performance-цели (лиды). Прямую атрибуцию не требовать.
- **Стратегия (в) нишевое присутствие** — базовая для GRO: регулярность в продуктивность/предприниматель-сообществах важнее одноразового федерального охвата.
- **Механизм 2 («ловушки»):** заранее засевать контент GRO под будущие запросы «как не забрасывать задачи», «AI-планировщик» — чтобы к моменту поиска бренд уже был в инфополе и в LLM-выдаче.
