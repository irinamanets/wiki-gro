# Freemium «первый раз бесплатно» — acquisition→retention

Устойчивая маркетинговая механика: **первое использование продукта бесплатно/без потерь**, чтобы клиент попробовал сервис, а монетизация наступает при повторном использовании по стандартной цене. Это canon-фрейм — механика структурно стабильна между доменами (free-trial в SaaS, «первая поездка бесплатно» в такси, «первый займ 0%» в МФО). Конкретные параметры дрейфуют, паттерн — нет.

Наблюдаемый кейс — рынок МФО ([[sources/2026-06-01-zaim-pod-nol-procentov-findozor]]): «первый займ под 0%» как основной инструмент привлечения новых МФО.

## Механика

1. **Acquisition** — беспроцентный первый займ снимает риск пробы: клиент тестирует сервис (скорость зачисления, удобство) без финансовых потерь `[conf:medium, src:2026-05-30]`.
2. **Retention** — далее МФО рассчитывает на возврат клиента уже под стандартную ставку `[conf:medium, src:2026-05-30]`.
3. **Условие отсечения abuse** — «ставка 0% действует только для новых клиентов при первом займе и при условии полного возврата без просрочек» `[conf:medium, src:2026-05-30]`.

Структура: бесплатное первое использование → формирование привычки/доверия → монетизация на повторе. Идентична логике free-trial и coin/credit-моделей мобильных приложений (см. [[canon/marketing-frameworks/coin-credit-freemium-monetization-mobile-ai]]).

## «Золотой стандарт» доверия (из affiliate-обзоров)

Критерии, на которые опираются affiliate-обзоры при ранжировании «надёжных» МФО `[conf:low, src:2026-05-30]`:

- внешняя безопасная идентификация (Госуслуги / Tinkoff ID)
- отсутствие процентов для новичков (тот самый «0%»)
- длительный стаж на рынке

Это переносимый **trust-stack** для любого продукта с финансовой/чувствительной транзакцией: verified-identity + бесплатный первый шаг + доказуемый track-record.

## Переносимость на GRO и общий маркетинг

- **Free-trial = тот же фрейм.** Бесплатный первый период GRO снимает риск пробы; монетизация — на удержании привычки. Условие отсечения abuse (как «без просрочек») = ограничение триала по одному аккаунту/устройству.
- **Acquisition-стоимость переносится на LTV.** Бесплатный первый шаг — это CAC-инвестиция, окупаемая только при retention. Поэтому метрика-партнёр фрейма — return-rate, а не количество активаций.
- **Trust-stack** (verified-identity + free first step + track-record) применим для онбординга любого продукта, где барьер — недоверие, а не цена.

## Anti-pattern

- **Freemium без retention-механики** = раздача стоимости впустую. Если нет причины вернуться по полной цене (привычка, lock-in, переключательные издержки), бесплатный первый шаг просто субсидирует одноразовых пользователей.
- В МФО это видно прямо: старые игроки (Займер, Екапуста, Манимен, Vivus) **свернули акции 0%** к 2026 — для зрелой базы механика перестала окупаться, осталась инструментом только для новых challenger'ов ([[evolving/industry-trends/ru-mfo-soft-scoring-competition-2026]]).
