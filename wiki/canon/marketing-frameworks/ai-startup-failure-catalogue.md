# AI Startup Failure Catalogue — каталог провалившихся AI-стартапов

## Что это и зачем нужно

Открытый каталог AI-стартапов, которые **закрылись или были поглощены крупными игроками без сохранения бренда**, — публично доступный инструмент конкурентного анализа.

Канонический пример обнаружен в [@neuraldvig 10644](https://t.me/neuraldvig) (2026-05-07): **[tooldirectory.ai/ai-graveyard](https://tooldirectory.ai/ai-graveyard)** — каталог из **178 failed AI startups** на момент 2026-05-07. Куратор-канал ретранслирует с фреймом «прежде чем вайбкодить свой стартап мечты — изучаем».

Catalogue этого типа используется как **due-diligence-инструмент перед запуском или анализом конкурентной ниши**: если 5 предыдущих компаний в этой суб-нише провалились, что было их patterns failure'а, и какие из них применимы к нашей гипотезе?

## Применение фреймворка для GRO

GRO позиционируется в self-development / personal-coaching AI-вертикали. Каталог AI-graveyard используется для **трёх задач**:

### Задача 1 — проверка hypothesis-уникальности

Перед запуском нового feature или направления GRO (например, voice-coach module, vertical-specific прогрессии, B2B enterprise integration) — поиск в catalogue компаний с похожим value proposition.

**Алгоритм:**
1. Сформулировать предлагаемое value proposition в 1-2 предложениях
2. Найти 5–10 closed AI-стартапов с близким VP в каталоге
3. Для каждого выяснить cause of death (acquihire / underfunded / wrong-market / regulatory / no-traction)
4. Извлечь patterns failure'а
5. Проверить, что предлагаемая инициатива GRO **не повторяет** эти patterns

### Задача 2 — конкурентный survey

При написании контента про AI-инструменты для саморазвития / коучинга — упоминание уже умерших конкурентов даёт глубину сравнительного анализа. «Не первый и не последний продукт в категории» — структурный фрейм, повышающий доверие к собственному продукту через демонстрацию рыночной грамотности.

### Задача 3 — content angle

Каталог сам по себе — content asset: «Мы изучили 178 умерших AI-стартапов. Вот 5 patterns, которые их погубили, и почему GRO их избегает.» Это формат сразу для **3 каналов GRO** (blog, Telegram, Instagram), укладывается в [[canon/marketing-frameworks/native-advertising]] как educational native content.

## Анти-паттерны использования

1. **Не использовать catalogue как абсолютную правду** — закрытие стартапа может быть результатом owner-decision (acquihire) и не нести inforation о провале category. Cause of death всегда верифицировать.
2. **Не публиковать список «178 умерших» без анализа** — это слабый content без insights. Цитировать catalogue только в контексте конкретного analytical claim.
3. **Не злорадствовать** — упоминания умерших компаний должны быть нейтральны или сочувствующи (founders watching). Tone of voice [[canon/brand-guidelines/gro-channel-tone-of-voice]] — дружелюбный эксперт, не язвительный.

## Структура причин закрытия AI-стартапов (industry-baseline patterns)

Из общедоступного знания индустрии (industry-baseline), без привязки к конкретному catalogue, типичные patterns failure'а:

- **No moat against incumbent** — функция OpenAI/Anthropic/Google поглощает category (ex: copy.ai vs ChatGPT native writing)
- **Acquihire без сохранения продукта** — Big Tech покупает команду, продукт закрывают (ex: numerous AI startups bought by Apple/Meta/Google в 2018–2024)
- **No product-market fit** — технология работает, но никто не покупает (ex: many AI-art-generators до Midjourney)
- **Regulatory shutdown** — продукт нарушает (privacy, IP, employment) законодательство
- **Underfunded → burned out** — runway закончился до traction
- **Tech debt → unmaintainable** — модель устарела, переобучить не на что
- **Wrong category timing** — продукт на 2–3 года раньше рынка

При анализе конкретных кейсов из catalogue — каждый из этих patterns может быть applicable, и GRO нужно для каждого собственного направления **явно дисамбиguировать**, какой pattern избегается и почему.
