# 6-вопросная диаграмма обработки целей — daily protocol

Daily-protocol Armen Petrosian из книги «Как подготовиться к переменам» (2025, гл. 2; см. [[sources/2026-05-26-petrosian-book-1-how-to-prepare-for-change]]). Авторская **6-вопросная диаграмма**, представленная как круговая диаграмма с центром «Обработка целей» и 6 концентрическими сегментами. **10-15 минут ежедневной обработки** одного-двух вопросов = sustained progress.

## Core тезис (Petrosian)

> «Обработка подразумевает ответы на вопросы и принятие решений о ближайших действиях. Вы напоминаете себе, что хотите изменить, и определяете, что для этого сделаете сегодня. Важна последовательность. **Регулярность повторения обеспечивает переход количества в качество изменений.**» (Petrosian, 2025, book 1, ch.2.3)

`[conf:medium, src:2025]` — operational framework.

## Шесть вопросов (диаграмма)

| # | Вопрос | Категория-метка (с диаграммы) |
|---|---|---|
| 1 | **Как это сделать проще?** | Уверенность в себе |
| 2 | **Как текущие цели связаны между собой?** | Связи решают |
| 3 | **Как текущие задачи связаны с целями?** | Следующие действия |
| 4 | **Что мешает моим целям?** | Устранить препятствия |
| 5 | **Какие возможности я пока не использую?** | Самореализация |
| 6 | **К кому можно обратиться за поддержкой?** | Что происходит |

`[conf:medium, src:2025]` — оригинальная авторская диаграмма.

**Operational tips (Petrosian):**
- **Выбирайте вопрос в очерёдности, случайно, или комбинируйте**
- **Отвечайте письменно, по таймеру 5-10 мин**
- **Придерживайтесь правил фрирайтинга** (пишите быстро, без редактирования)
- **После завершения запишите решения** — что сделаете для целей, какое ближайшее действие по каждой

## Зачем это релевантно GRO

GRO — продукт ежедневного журналирования. 6-вопросная диаграмма даёт **structured-prompt template** для in-app daily ритуала:

### Direct product use

**Daily goal-processing flow в GRO:**

| Step | UI | Content |
|---|---|---|
| 1 | Question selector | Random / sequential / user-choice из 6 |
| 2 | Timer | 5-10 мин countdown |
| 3 | Free-text field | Без editing, чистый фрирайтинг |
| 4 | Decision-capture | «Какое ближайшее действие?» (extracted from free-text) |
| 5 | History view | Cycle через все 6 вопросов за неделю |

**6 вопросов = 6 distinct angles** для one-and-same set of goals. За неделю user обрабатывает все, получая **multi-faceted view** на свой goal-set без необходимости structured planning sessions.

### Direct content copy (с атрибуцией)

> «Цели не требуют тяжёлого планирования. Цели требуют ежедневной обработки. По формуле Армена Петросяна (Стодневка): 6 вопросов, 10-15 минут в день. Как это сделать проще? Что мешает? Какие возможности я не использую? Один вопрос в день — за неделю обработал все 6. Регулярность повторения = качество изменений.»

### Funnel framing

Работает на **retention** (daily ритуал) и **content-marketing** (понятная 1-week onboarding программа).

## Cross-link с monthly-calibration

Petrosian-фрейм формирует **3-уровневую temporal hierarchy** обработки целей:

| Cadence | Page | Что делается |
|---|---|---|
| **Daily** | Эта страница (6 questions × 10-15 min) | One question, written reflection, capture next action |
| **Monthly** | [[canon/marketing-frameworks/petrosian-monthly-calibration-3-layers]] | Факты → смысл → корректировка |
| **Quarterly-annual** | [[canon/marketing-frameworks/petrosian-flexible-goal-pole]] | Цель как шест — gross-adjustment direction |

3 уровня **complementary**, не replacing друг друга.

## Anti-patterns в применении

1. **Превратить в quiz с правильными ответами.** Фрирайтинг работает на **открытом** ответе. Если предложить «выбери опцию», теряется mechanism.
2. **Push-уведомлять все 6 каждый день.** 1 question — sufficient. 6 — overwhelm.
3. **Делать responses public** или **shareable to friends**. Этот protocol — для **private self-dialogue**, не для social-validation.
4. **Скопировать диаграмму как visual asset GRO** без атрибуции. Это **оригинальный визуал Petrosian'а**. Воспроизводить format с атрибуцией идеи, не картинку.
