# Media-pitch best practices

Свод операционных правил эффективного питчинга СМИ, собранный Pressfeed из практики «чемпионов пиара» — топ-специалистов, которые держат конверсию комментария в публикацию 75–100% (см. [[evolving-strict/campaign-metrics/pr-conversion-benchmarks-2026]]). Применимо и в push-, и в pull-режиме (см. [[canon/marketing-frameworks/push-vs-pull-media-relations]]).

## Семь правил питча

### 1. Скорость
Мониторить запросы постоянно, отвечать в первые часы/минуты. Журналисту часто нужен **один** хороший комментарий — после него запрос закрывается. Опоздал — потерял слот.

### 2. Релевантность
Комментировать только темы, где компания на 100% эксперт. «Упоминание ради упоминания» снижает доверие редакции и портит будущие отношения.

### 3. Фактура
Цифры, статистика, динамика, проценты. «Нет фактуры — не будет публикации»; «не лей воду». Это прямое продолжение критерия «цифры» из [[canon/marketing-frameworks/infopovod-criteria-smb-pr]].

### 4. Самодостаточная структура комментария
Комментарий строится из **самодостаточных блоков** — журналист может отсечь его в любом месте, и фрагмент сохранит смысл. Это резко повышает шанс, что цитату возьмут даже при жёстком сокращении.

### 5. Не дублировать комментарии
Не отправлять одинаковые комментарии в разные издания («не сливать баяны»). Под каждое издание — добавить value, перефразировать, найти новый ракурс. (Та же логика, что в анти-паттернах дистрибуции инфоповодов: один релиз ≠ во все издания одинаково.)

### 6. Отношения с журналистом на равных
Профессиональная коммуникация без позиции «просящего» и без монетизации дружбы. Журналист — партнёр, не благотворитель. Подробнее про журналистов как аудиторию — [[canon/target-audience/journalists-as-pr-audience]].

### 7. Организация работы команды
Разделение ролей: медиаменеджер мониторит запросы / райтер пишет / спикер даёт экспертизу / отдельный контур согласования. Плюс **глубокое погружение в бизнес клиента** — без него невозможна скорость (правило 1).

## Связь с воронкой long-cycle продуктов

Для премиальных / long-cycle продуктов media-pitch — один из 5–7 касаний в воронке «СМИ → личная встреча → сделка». PR работает на узнаваемость и попадание в шорт-листы, а не на сиюминутные продажи. Аргумент: «узнаваемые бренды чаще попадают в шорт-листы».

Усиление эффекта PR (омниканальность): раздел публикаций/цитат на сайте, менеджеры по продажам ссылаются на публикации в аргументации, синхронизация месседжей в СМИ с рекламой — в одном кейсе дало +35% «тёплых» запросов `[conf:low]`.

## Применимость к ГРО

Эти 7 правил — операционный чек-лист для pull-режима ГРО (быстрые экспертные комментарии по AI/HR/self-education через Pressfeed). Особенно правила 1 (скорость) и 3 (фактура: метрики retention/completion из продукта) — прямой рычаг конверсии.
