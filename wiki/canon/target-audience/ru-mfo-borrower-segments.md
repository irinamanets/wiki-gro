# Сегменты заёмщиков МФО — consumer behaviour

Портрет аудитории новых МФО и её поисковое поведение. Это canon-материал: сегментная структура (кто берёт микрозайм и почему) стабильна — дрейфуют конкретные офферы, не мотивы. Источники — affiliate-обзоры МФО ([[sources/2026-06-01-findozor-novye-mfo-bez-otkaza]], [[sources/2026-06-01-15-mfo-napodobie-zaimer]]). Релевантность: это **референс-аудитория** для понимания decision-stage intent и acquisition-механики, не наша прямая ЦА.

## Три ядра ЦА новых МФО

1. **Первичные заёмщики** — привлекаются оффером «0%» (бесплатная проба сервиса) `[conf:medium, src:2026-05-30]`.
2. **Клиенты с плохой кредитной историей** — новые компании «закрывают глаза» на прошлое, мягкий скоринг `[conf:medium, src:2026-05-30]`.
3. **Те, кому нужны срочные решения** — ключевой драйвер скорость зачисления (10–15 минут) `[conf:medium, src:2026-05-30]`.

Каждый сегмент привязан к конкретному value prop: 0% → первичные, мягкий скоринг → отказники, скорость → срочные.

## Поисковое поведение

Массовые запросы ЦА `[conf:medium, src:2026-05-30]`:
- «займ как Займер»
- «МФО похожие на X без отказа»
- «где одобрят если отказали»

Характеристики этого intent:
- **высокая интентность** — пользователь уже принял решение взять займ
- **decision-stage** — ищет конкретного провайдера, не информацию
- **чувствительность к скорости одобрения** — главный решающий фактор

## Маркетинговые выводы

- **«Похоже на X» — мощный navigational-intent паттерн.** Запрос «как [известный бренд] но лучше/чаще одобряют» — challenger ловит трафик лидера. Переносимо: страница «альтернатива [конкуренту]» как entry-point.
- **Сегмент-к-офферу мэппинг** — каждый болевой сегмент требует своего hook (бесплатно / без проверок / быстро). Один оффер не покрывает всю аудиторию.
- **Decision-stage long-tail** — высокоинтентные запросы дёшевы в конверсии, релевантны для AEO/GEO ([[evolving/industry-trends/ai-search-aeo-geo-2026]]).

## Caveats

- Сегментация из affiliate-обзоров, не из исследования аудитории. `confidence: medium`.
- Это не ЦА GRO — материал хранится как **референс consumer-behaviour и intent-паттернов**, переносимых на наш контент.
