# B2C vs B2B сегментация по подходу к ценности

Базовое различение в подходе к segmentation: B2C-покупатель оценивает продукт через **статус в референтной социальной группе**, B2B-покупатель — через **технологическое соответствие** существующим процессам, стилю работы, географии. Это структурное различие определяет что является value proposition и как формулируется маркетинговое сообщение.

## Структура value-восприятия

| Контекст | Что определяет ценность | Что покупает по сути |
|---|---|---|
| **B2C** | Усиление статуса потребителя в его референтной социальной группе | Identity / signaling |
| **B2B** | Соответствие принятым у потребителя технологиям, стилю работы, традициям, географии (логистике) бизнес-системы | Compatibility / TCO reduction |

→ Разные «продукты под капотом» при одной и той же физической вещи. iPhone в B2C — статус, identity, дизайн. iPhone в B2B (corporate fleet) — security, MDM compatibility, TCO, integration с corp identity.

## B2C segmentation: референтная группа

Ключевые вопросы:

- **Кто их референтная группа?** (peers, аспирационная элита, sub-culture, age cohort)
- **Какие сигналы статусные в этой группе?** (бренды, поведение, владения, attitudes)
- **Где эта группа собирается?** (платформы, события, медиа, communities)
- **Чьё одобрение важно для них?** (influencers, opinion leaders, peers, parents)

→ B2C-сообщение работает на **identity claim**: «купи это и будь X». Эффективные B2C-кампании показывают не продукт, а **человека**, который этот продукт использует — и этот человек = аспирационный аватар референтной группы.

## B2B segmentation: технологическое соответствие

Ключевые вопросы:

- **Какие технологии у них стоят сейчас?** (вендоры, интеграции, legacy)
- **Какие процессы вокруг этих технологий?** (workflows, согласования, owners)
- **География операций?** (geography, time zones, language)
- **Стиль работы?** (waterfall vs agile, formal vs casual, top-down vs bottom-up)

→ B2B-сообщение работает на **compatibility claim**: «мы вписываемся в то, что у вас есть, без сломов». Эффективные B2B-кампании показывают не продукт, а **рабочий процесс**, который мы делаем легче / быстрее / надёжнее.

## Anti-pattern: B2C-копирайт в B2B контексте

Стартапы, выросшие из B2C, часто переносят identity-копирайт в B2B-контексте: «революция!», «измени свой бизнес!», «будь пионером!». В B2B это:

- Триггерит «риск» — никто в большой компании не хочет быть «революционером», который сломал procurement
- Триггерит «незрелость» — звучит как стартап без enterprise-готовности
- Не отвечает на ключевые B2B-вопросы (security, integration, TCO)

→ В B2B нужен **boring trustworthy** копирайт: integrations / compliance / SLA / case studies от similar enterprises / quantitative ROI.

## Anti-pattern: B2B-копирайт в B2C

Обратная ошибка реже, но встречается: «9.99% reduction in cycle time» в B2C-копирайте. Покупатель не покупает cycle time — он покупает identity / эмоцию. Заменять на «больше времени для близких».

## Универсальный принцип: один продукт ↔ две аудитории

Один и тот же физический продукт может одной аудитории прибавлять ценности, другой — наоборот, убавлять. Это не bug, это структура segmentation.

**Историческая иллюстрация (~2002, conf:low):** маленький полупрозрачный мобильник для женщин был ценностью (украшение, игрушка), для мужчин — снижением ценности («головастик», несерьёзный гаджет). Один и тот же продукт, две аудитории, противоположный эффект.

**Современные параллели:**
- Pink-цветовая schema для женских аудиторий vs репеллент для мужских
- Простой UI для non-tech аудитории vs «недостаточно функциональный» для tech-savvy
- High-end pricing для luxury vs «недоступный» для mass market

→ При выборе позиционирования нужно решить **на кого работаем**, и это автоматически решит **кого репеллируем**. Попытка нравиться всем = не нравимся никому.

## Применимость к GRO

- При выходе на новый сегмент (B2C → B2B или наоборот) — копирайт переписывается полностью, не адаптируется
- При микро-сегментации (B2C-сегмент с разными возрастными или культурными подгруппами) — проверка «один продукт ↔ две аудитории». Если продукт обслуживает обе — нужны два креативных треков
- B2B-trail (если будет): фокус на integration / compliance / case-studies, не «преобразования»
